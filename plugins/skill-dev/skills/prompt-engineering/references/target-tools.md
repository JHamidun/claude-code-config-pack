# Промпт под целевой инструмент

Синтаксис и приёмы по семействам инструментов. Читать только раздел нужного
инструмента. Основа — `nidhinjs/prompt-master` v1.8.0 (MIT, см. `LICENSE-prompt-master`),
переработано 27.09.2026: убраны снятые модели, добавлены наши движки.

**Идентификаторы моделей здесь намеренно не выписаны.** Они устаревают молча:
в оригинале на момент переноса стояли DALL-E 3 (снят 12.05.2026), Sora (гаснет
24.09.2026) и o3/o4-mini (свёрнуты в GPT-5.6). Актуальные ID, цены и что снято —
`~/.claude/config/models.md`. Если нужен «самый свежий» — сверить с докой вендора;
не сверил — так и сказать, а не подставлять правдоподобный slug.

## LLM: Claude

Приёмы под Claude 4.7+ уже собраны в `SKILL.md` → «Claude-Specific Tips» — там и
держать, здесь не дублировать. Коротко: XML-теги для смешанного содержимого, данные
наверх и вопрос вниз, требование вместо запрета, мышление — параметром `effort`, а
не текстом, самопроверку не заказывать, язык вокруг инструментов обычный, без капса.

Для сложной агентной задачи — бриф из `agent-brief-and-decompiler.md`.

## LLM: GPT / Codex

- Четыре компактных блока: **Goal, Context, Constraints, Done**. Каждое правило один раз.
- GPT-5.6 хорошо достраивает намерение: задать контекст, жёсткие ограничения, границы
  одобрения, критерий готовности и то, какая неясность должна вызвать вопрос, — без
  расписанных шагов рассуждения.
- Автономия явно: чтение, правки и проверки в рамках задачи — можно; запись наружу,
  удаление, покупки, расширение объёма — только с подтверждением.
- Эффорт — минимальный, который держит качество. Режим `pro` и мультиагентный бета —
  только когда замер показал выигрыш.
- Длину видимого ответа задаёт контракт вывода (в API ещё `text.verbosity`), а не
  просьба «думай меньше».
- Codex CLI: Goal, Context, Scope, Constraints, Approval Boundaries, Done плюс
  команды проверки. Субагентам — ограниченный результат и потолок параллельности,
  синтез у одного главного агента. Запуск GPT-6 Astra и её грабли — skill
  `multi-model-gateway`.

## LLM: Gemini

- Сильна на длинном контексте и мультимодальности — документы целиком в промпт.
- Склонна выдумывать ссылки: «Cite only sources you are certain of. If uncertain, write [uncertain].»
- Уплывает из строгого формата: фиксировать формат размеченным примером.
- Для работы по источнику: «Base your response only on the provided context. Do not extrapolate.»

## LLM с встроенным мышлением

DeepSeek-R1, Qwen3 в режиме thinking, reasoning-режимы прочих вендоров.

- Короткие чистые инструкции: цель и формат результата. Без «think step by step» и
  расписанных шагов — они ухудшают ответ.
- Сначала zero-shot; примеры — только если без них формат не держится.
- Если модель печатает рассуждение в `<think>`, а оно не нужно: «Output only the final answer.»

## Открытые и локальные LLM

Llama, Mistral, Qwen2.5-instruct, Ollama.

- Сначала узнать, какая именно модель запущена, — они ведут себя по-разному.
- Короче и площе: глубокая вложенность разваливает связность. Явнее, чем для Claude/GPT.
- Роль — в системный промпт (для Ollama выдать его отдельно, для `Modelfile`).
- Температура: ~0.1 для кода и детерминированных задач, 0.7–0.8 для творческих.
- Код — профильные модели (Qwen2.5-Coder и т.п.), а не общая Llama.

## Агенты и IDE

Общее для всех, кто сам правит файлы и запускает команды: **начальное состояние →
целевое состояние → что можно → чего нельзя → условия остановки**. Без условий
остановки агент уходит в петлю — это главный пожиратель лимитов.

- **Claude Code** — бриф из `agent-brief-and-decompiler.md`. Путь-якорь обязателен:
  без конкретных файлов и папок глобальная инструкция расползается. Opus 5+ и Fable 5.1
  охотно расширяют объём и делегируют — добавить «Only make changes directly requested»
  и оставить субагентов для крупных независимых кусков. Отдельного проверяющего на
  рутину не заказывать; просить конкретные тесты и выводы инструментов.
- **Cursor / Windsurf** — путь к файлу + имя функции + текущее поведение + нужное
  изменение + список «не трогать» + язык и версия. «Done when:» обязателен. Крупное —
  цепочкой последовательных промптов.
- **Cline** — стиль под модель внизу; явно какие файлы править и какие нет;
  «Ask before running terminal commands / installing dependencies».
- **GitHub Copilot** — точная сигнатура, докстринг или комментарий прямо перед местом
  вызова: типы входа и выхода, краевые случаи, чего функция делать не должна.
- **Devin / SWE-agent** — очень явные начальное и целевое состояния; список запретов
  критичен; ограничить файловую систему: «Only work within /src».
- **your-proxy** — описывать результат, а не шаги; попросить план-артефакт до
  исполнения; шаг проверки браузером: «verify UI at 375px and 1440px»; одна задача на сессию.

## Генераторы приложений

Bolt, v0, Lovable, Figma Make, Google Stitch.

- По умолчанию раздувают заготовку: явно стек, версии, чего не создавать, границы компонентов.
- «Do not add authentication, dark mode, or features not explicitly listed.»
- Lovable лучше понимает описание через дизайн и UX. v0 — Next.js по умолчанию, иначе
  сказать. Bolt — явно разделить фронт, бэк и базу. Figma Make — ссылаться на имена
  компонентов из Figma. Stitch — цель интерфейса, а не реализация.

## Браузерные и computer-use агенты

Claude in Chrome, OpenAI computer use, Perplexity Comet, OpenClaw.

- Описывать исход, а не клики: «Find the cheapest flight from X to Y, one stop max».
- Ограничения явно — иначе агент решит сам.
- Граница прав: «Do not make any purchase. Research only.»
- Стоп перед необратимым: «Ask me before submitting any form, completing any transaction, or sending any message».

## Research-оркестраторы

Perplexity, Manus.

- Perplexity: указать режим — искать, анализировать или сравнивать; требовать ссылки;
  вопрос, провоцирующий выдумку, переформулировать в вопрос по источникам.
- Manus и Perplexity Computer сами раскладывают задачу — описывать итоговый артефакт
  (отчёт, таблица, код), а не шаги. «Flag any data point you are not confident about.»
- В длинных цепочках — контрольные точки: каждый шаг множит риск выдумки.

## Картинки

Сначала понять: генерация с нуля или правка готового изображения.

- **Наши движки** (Nano Banana, GPT-image) — промпт и выбор ступени по цене ошибки
  ведёт skill `image-generation`; здесь не дублируется.
- **Midjourney** — дескрипторы через запятую, а не проза: объект, стиль, настроение,
  свет, композиция; параметры в конце (`--ar 16:9 --style raw`, версию сверить с
  текущей); нежелательное — `--no ...`.
- **Stable Diffusion** — веса `(word:1.3)`, CFG 7–12, негативный промпт обязателен;
  20–30 шагов на черновик, 40–50 на чистовик.
- **Художественные модели** (SeeDream и подобные) — стиль первым (anime, cinematic,
  painterly), потом сцена; настроение и атмосфера работают хорошо.

Шаблон дескриптора:

```
Subject / Action / Setting / Style / Mood / Lighting / Color palette /
Composition / Aspect ratio / Negative prompt / Style reference
```

## Правка по референсу

Признак: «поменяй», «поправь», «сделай другим» что-то в готовой картинке.

- Сначала сказать пользователю приложить исходник в инструмент.
- Промпт — только про разницу: что сохранить в точности, что изменить, насколько
  (слегка / заметно / сильно). Сцену заново не описывать.
- Midjourney — `--cref` (персонаж) / `--sref` (стиль); Stable Diffusion — img2img,
  denoising 0.3–0.6.

```
Reference image: [attached]
Keep exactly the same: [face, hair, clothing, background, lighting]
Change: [one precise edit]
Amount of change: [subtle / moderate / significant]
Negative: [no new elements, no style change]
```

## ComfyUI

Не одно поле, а граф узлов. Сначала спросить чекпойнт (SD 1.5 / SDXL / Flux).
Выдавать **два отдельных блока** — Positive и Negative, никогда не сливать.

- SD 1.5: до ~75 токенов на блок, синтаксис весов.
- SDXL: длиннее, можно смешивать естественный язык с весами.
- Flux: естественный язык, меньше весов, чутко к описанию стиля.

```
POSITIVE PROMPT:
[subject], [style], [mood], [lighting], [composition], [quality: highly detailed, sharp focus]

NEGATIVE PROMPT:
[blurry, low quality, watermark, extra limbs, bad anatomy, distorted]

CHECKPOINT: [model] · SAMPLER: Euler a · CFG: 7 · STEPS: 20–30 · RESOLUTION: [кратно 64]
```

## Видео

- Писать как режиссёр кадра: движение камеры решает (статика / долли / кран), тип
  плана, длительность в секундах, стиль монтажа.
- Kling — реалистичное движение людей: движение тела и ракурс явно.
- Runway — кинематографический язык, отсылки к стилю фильмов.
- LTX — коротко и визуально, разрешение и интенсивность движения явно.
- Dream Machine (Luma) — свет, объективы, цветокор.
- **Наши движки** (Veo 3.1, Seedance, Runway, Kling) и их пайплайны — skill
  `video-generation`. Sora у OpenAI гаснет 24.09.2026 — промпты под неё не писать.

## 3D

- **Meshy / Tripo / Rodin** — стиль (low-poly / realistic / stylized) + объект +
  ключевые детали + материал + текстура + тех. требования; негатив «no background,
  no base, no floating parts». Meshy — игровые ассеты, Tripo — быстрая чистая
  топология, Rodin — фотореализм (медленнее, дороже). Указать экспорт: GLB/FBX для
  движка, STL для печати. Персонаж под риг — A-поза или T-поза.
- **Blender / CadQuery у нас** — не промптом, а через MCP в `D:/3D` (см. routing,
  строка «3D и CAD»).
- **Unity AI** — `/ask` документация, `/run` автоматизация редактора, `/code` C#;
  генераторы спрайтов и текстур — тип ассета, стиль, разрешение, палитра, цикл или разовая.

## Голос

ElevenLabs и подобные: эмоция, темп, акценты, паузы — параметрами и разметкой
(где ударение, где пауза), а не прозой «скажи тепло».

## Автоматизации

n8n, Zapier, Make: триггер (приложение + событие) → действие (приложение + операция +
сопоставление полей), шаги пронумерованы, что передаётся между шагами — явно.
«Assumes [app] is already connected» — ключи в промпт не вшивать. Наш n8n и его
состояние — skill `n8n`.
