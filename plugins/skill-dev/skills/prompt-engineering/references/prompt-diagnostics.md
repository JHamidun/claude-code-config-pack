# Диагностика промпта: 37 паттернов, из-за которых переспрашивают

Прогон для чужого или своего черновика промпта: найти, починить молча, упомянуть
только ту правку, которая меняет смысл запроса. Основа — `nidhinjs/prompt-master`
v1.8.0 (MIT, см. `LICENSE-prompt-master`); примечания «у нас» — поправки под Claude 4.7+
и под то, как устроена эта конфигурация.

## Что из оригинала не взято и почему

- **«MUST вместо should, NEVER вместо avoid» как финальная проверка.** Для Claude 4.7+
  это вредно: капс и нажим дают перетриггеривание и жёсткость там, где нужна оценка.
  У нас наоборот — причина вместо капса (SKILL.md, «Границы» и совет 5).
- **Потолок «не больше трёх уточняющих вопросов».** Владелец просит задавать все
  вопросы, от которых зависит результат, одним сообщением, а не три из двадцати.
- **Модели и их ID внутри правил.** Устарели за месяц; вынесены в `config/models.md`.
