# Путь B: живой CAD по COM (AutoCAD / GstarCAD / ZWCAD / BricsCAD / nanoCAD)

**Только Windows.** COM/ActiveX — механизм Windows; на macOS и Linux путь неприменим целиком.
CAD должен быть **установлен и запущен** — код подключается к работающему приложению.

```bash
pip install pywin32 pillow
python -c "import win32com.client as c; print(c.GetActiveObject('AutoCAD.Application').Name)"
```

`pywin32` даёт `win32com`, `pythoncom`, `win32gui`; `pillow` нужен только для скриншота окна.

**Не для AutoCAD LT** — он не ActiveX-сервер; его единственная автоматизация — AutoLISP-текст и `.scr`.

## Принцип

COM-слой врёт молча: вызовы возвращают успех, переменные читаются как записаны, а чертёж всё равно не тот.
Проверять геометрию **измерением** (`GetBoundingBox`, `Volume`, число сущностей), а не чтением своей же
настройки.

## Подключение

```python
import pythoncom, win32com.client
pythoncom.CoInitialize()
app = win32com.client.GetActiveObject("AutoCAD.Application")   # к запущенному
```

`GetActiveObject` подключается к запущенному экземпляру; `Dispatch` запускает новый — медленно и с кражей
фокуса. Сначала первое, потом второе.

| Текст ошибки | Смысл |
|---|---|
| `Недопустимая строка с указанием класса` (CO_E_CLASSSTRING) | ProgID не зарегистрирован — программа **не установлена** |
| `Операция недоступна` (MK_E_UNAVAILABLE) | зарегистрирована, но экземпляр не запущен |
| `Ошибка при выполнении приложения-сервера` (CO_E_SERVER_EXEC_FAILURE) | Windows попыталась запустить, процесс умер |

ProgID: `AutoCAD.Application` (версионный `.26` = 2027), `GstarCAD.Application`, `ZWCAD.Application`,
`BricscadApp.AcadApplication`, `nanoCAD.Application`. На этой машине (09.2026) все пять — CO_E_CLASSSTRING.

На стартовой вкладке документа нет — `app.ActiveDocument` бросает исключение; ловить и `app.Documents.Add()`.

## Точки и массивы

Каждая точка — VARIANT-массив double, не список Python:

```python
from win32com.client import VARIANT
def pt(x, y, z=0.0):
    return VARIANT(pythoncom.VT_ARRAY | pythoncom.VT_R8, [float(x), float(y), float(z)])
```

Полилинии — один плоский массив `[x1, y1, x2, y2, …]`. Массивы объектов (границы штриховки) —
`VARIANT(pythoncom.VT_ARRAY | pythoncom.VT_DISPATCH, [...])`.

## Отказы, которые стоили времени

| Симптом | Причина | Фикс |
|---|---|---|
| Размерные линии есть, текста и стрелок нет | `SetVariable("DIMSCALE", n)` не доходит до сущностей, созданных через ActiveX | `dim.ScaleFactor = n` на объекте, затем `doc.Regen(1)` |
| Фильтр по цвету теряет самые большие детали | Boolean сбрасывает цвет в ByLayer (256) | различать детали по объёму или слою, не по цвету после Boolean |
| `Сервер RPC недоступен`, AutoCAD исчез | удалили все объекты листа, включая последний viewport | удалять только `ObjectName != "AcDbViewport"`; переиспользовать viewport |
| `Ошибка при установке текущего видового экрана` | `ActivePViewport` до входа в модельное пространство | сначала `doc.MSpace = True` |
| `PlotToFile` возвращает True, файла нет или 2 КБ | `BACKGROUNDPLOT` по умолчанию 2 | поставить 0; лучше собирать PDF вне CAD |
| `Недопустимый аргумент type в ZoomScaled` | не тот enum | 0 absolute, 1 relative, 2 relative-to-paper |
| `Неоднородное масштабирование невозможно` | тела масштабируются только равномерно | овальные тела через `AddEllipse` → `AddRegion` → `AddExtrudedSolid` |
| `Неверный ввод` из `AddRegion` | `AddPolyline` делает 3D-полилинию, региону нужна плоская | рисовать lightweight-полилинию в XY, потом `Rotate3D` |
| Габариты чертежа много больше модели | `AddRegion`/`AddExtrudedSolid`/`AddRevolvedSolid` не поглощают исходники | удалять исходную кривую и регион после создания тела |
| `Вызов был отклонен` (RPC_E_CALL_REJECTED) | приложение занято перерисовкой | повторить через секунду — это не ошибка кода |
| Все свойства падают `<unknown>.Name`, `.Count` | незавершённый `SendCommand` оставил CAD ждать в командной строке — это блокирует весь ActiveX; выглядит как битый кэш pywin32 и им не является | ESC в окно (`WScript.Shell.SendKeys("{ESC}")`); визуальные стили через переменные `VSFACESTYLE=1`, `VSEDGES=2`; сторож `doc.GetVariable("CMDACTIVE")` |
| `Вызванный объект был отключен от клиентов` | чтение свойства документа после `Close()` | забирать `.Name` до закрытия |
| У нового документа нет `ModelSpace` | `Documents.Add()` возвращается раньше готовности | повторять несколько секунд |
| Список модулей процесса — только `ntdll` + `wow64*` | 64-битный инструмент не видит 32-битный процесс | `C:\Windows\SysWOW64\WindowsPowerShell\v1.0\powershell.exe` |
| Скриншот окна съезжает на ~300 px | масштаб дисплея > 100 % | `ctypes.windll.user32.SetProcessDPIAware()` до `GetWindowRect` |
| Окно «не найдено» или снимок пустой | поиск по заголовку и размеру: свёрнутое окно даёт крошечный rect, у подсказок тот же заголовок | искать по PID процесса, `ShowWindow(RESTORE)` → `MAXIMIZE`, ждать настоящий размер |
| Подсказка свойств посреди снимка | курсор висит над телом | `SetCursorPos` в угол до захвата |

## Проверка измерением

```python
mn, mx = solid.GetBoundingBox()
print(mx[0] - mn[0], mx[1] - mn[1], mx[2] - mn[2])
print(solid.Volume / 1e6, "литров")
```

Объём сверять с ручным расчётом: оболочка «короб минус полость минус проём» обязана равняться сумме
эквивалентных пластин; не сходится — геометрия неверна независимо от вида на экране.

## Команды и локализация

`SendCommand` асинхронный и ничего не возвращает — всё, что зависит от результата, обязано ждать, иначе
следующий `ZoomExtents` выполнится раньше. Команды с `.`, опции с `_` — переживают локализованную сборку:
`doc.SendCommand("._VSCURRENT\n_E\n")`.

## `cookbook.py`

Рабочие помощники: подключение с фолбэком, массивы точек и объектов, тела с Boolean, цилиндры по X и Y,
видимые размеры, листы с viewport, захват окна. Копировать нужное, не импортировать.

| Помощник | Закрывает |
|---|---|
| `attach_only()` | подключиться, **не запуская** CAD: пакетный прогон, чужая машина, расписание |
| `send_command()` | асинхронность `SendCommand`: ждёт по `CMDACTIVE`, снимает зависшую команду через ESC |
| `visual_style()` | то же, что `._VSCURRENT`, но переменными — не трогает командную строку |
| `cad_window()` | окно по PID с разворачиванием и ожиданием размера |

## Типовые ошибки

- Верить прочитанной переменной: `DIMSCALE` читается 50, сущности рисуются 2,5. Мерить сущность.
- Скриншот затенённого вида на белом фоне: цвет 7 белый на тёмном и чёрный на светлом — план может
  выглядеть пустым при полном наборе сущностей. Считать сущности.
- Считать, что цвет переживёт правку: Boolean его сбрасывает ровно тогда, когда он нужен.
- Печатать из CAD: PDF-драйверы печатают в фоне и молча падают. Лист из тех же данных вне CAD быстрее и проверяем.
