# Сравнительные / alternative-страницы (RU)

Порт `competitors` из marketingskills: форматы alternative/vs-страниц для SEO + продаж, переложенные под ваш бизнес (AI-консалтинг + воркшопы + подписочный продукт). Цель — ранжироваться по конкурентным запросам и снимать возражение «а чем вы лучше».

**Перед началом:** `~/.claude/business-context.md` → раздел «Продукт» (отстройка: практик+«стратегия+внедрение» в одном лице, доступ к моделям включён, соцпруф известных клиентов) и `competitive-profiling-ru.md` (профили конкурентов). SEO-публикация — через `seo-machine-ru` + `tilda`. FAQ-разметка страницы — `schema-markup-ru`.

## Принципы

1. **Честность строит доверие.** Признавай сильные стороны конкурента, будь точен в своих ограничениях — читатель сравнивает и проверит.
2. **Глубина, не галочки.** Объясняй *почему* разница важна, давай сценарии.
3. **Помоги выбрать.** Чётко: для кого вы, для кого конкурент. Снижай трение оценки.
4. **Централизуй данные конкурента** (`competitive-profiling-ru.md`) — обновления раскатываются на все страницы.

## Форматы под вас

### Формат 1: «Альтернатива [X]» (единственное число)
Интент: человек хочет уйти от конкретного решения.
URL: `/alternativa-[конкурент]`. Запросы: «альтернатива [курс/инструмент]», «вместо [X]».
Структура: почему ищут альтернативу → вы как альтернатива → детальное сравнение → кому переходить (и кому нет) → как начать (trial/консультация) → отзывы перешедших → CTA.

### Формат 2: «Альтернативы [X]» (множественное)
Интент: исследует варианты, раньше в пути.
URL: `/alternativy-[конкурент]`. Запросы: «лучшие альтернативы [X]», «курсы как [X]».
Структура: боли → критерии выбора → список (вы первым, но 4–7 реальных вариантов) → таблица → разбор каждого → рекомендация по сценарию → CTA. **Включай реальные альтернативы — это и ранжируется лучше, и строит доверие.**

### Формат 3: «Вы/Академия vs [X]»
Интент: прямое сравнение.
URL: `/sravnenie/vasha-akademiya-vs-[конкурент]`. Запросы: «[Academy] vs [X]».
Структура: TL;DR (2–3 предложения) → таблица at-a-glance → сравнение по категориям (программа, формат, цена, поддержка, доступ к моделям) → кому вы → кому конкурент (честно) → отзывы перешедших → CTA.

### Формат 4: «[A] vs [B]» (два конкурента, не вы)
Интент: сравнивает двух чужих.
URL: `/sravnenie/[a]-vs-[b]`. Структура: обзор обоих → сравнение → кому каждый → **третий вариант (вы)** → таблица на троих → CTA. Ловит конкурентный трафик, позиционирует вас как знатока.

## Реальные углы под ваш бизнес

| Тип страницы | Пример | Главный аргумент ваш |
|--------------|--------|--------------------------|
| Academy vs другие AI-курсы | «ваша академия vs [онлайн-курс по нейросетям]» | N+ материалов + симуляторы с AI-тьютором + доступ к моделям включён + автор-практик (руководитель AI-продукта) |
| Консультант vs inhouse | «AI-консультант под задачи vs нанять AI-команду в штат» | быстрее и дешевле старта, связка стратегия+внедрение, без долгого найма |
| Воркшоп vs самообучение | «корпоративный воркшоп vs учить команду по роликам» | 100% практика на ВАШИХ задачах, быстрый результат, ведут практики |
| Concierge vs прямые подписки | «оплата зарубежных AI через вас vs напрямую» | рублёвый барьер закрыт, один счёт, договор с юрлицом РФ |

## Обязательные секции (шаблоны)

**TL;DR:**
```
TL;DR: [Конкурент] силён в [X], но [слабость]. [Ваша академия/услуга] построена для [фокус] и даёт [отличие]. Выбирайте [конкурента], если [сценарий]. Выбирайте [вас], если [сценарий].
```

**Сравнение абзацем (не только таблица):** для каждого измерения — абзац: что делает конкурент, в чём силён, ограничение; затем ваш подход, выгода, честный trade-off, кому это лучше.

**Сравнение по фичам:** на категорию — 2–3 предложения по каждому + «итог: выбирайте X если…».

**Цены:** тир-за-тиром (в рублях), что включено, скрытые расходы, расчёт на команду из N человек.
```
| | [Конкурент] | Ваша академия/услуга |
|---|---|---|
| Старт | [цена] | trial N дней бесплатно / X ₽/мес |
| Доступ к моделям | [есть/нет] | широкий набор моделей включено |
| Формат | [формат] | текст+подкаст+симуляторы с AI-тьютором |
```

**Кому подходит:** явно опиши идеального клиента для каждого варианта — честные рекомендации строят доверие.

**Миграция / как перейти:** что переносится, что нужно перенастроить, какая поддержка, отзыв перешедшего.

**Соцпруф перешедших:** цитаты с именем/ролью/компанией, конкретные результаты.

## Таблицы: за пределами галочек

Вместо «✓ / ✗» пиши что именно: «Полная поддержка с [деталь]» vs «Базово, [ограничение]». Группируй по категориям (программа, формат, цена, поддержка, безопасность данных). Где уместно — звёздочки-рейтинги с пометкой.

## Процесс и обновление

Глубокое исследование конкурента (программа/цены/отзывы) → профиль (`competitive-profiling-ru.md`) → страница. Обновление: цены — ежеквартально, продукт/программа — при изменении, полный рефреш — раз в год.

Связки: `competitive-profiling-ru.md` (профили) · `seo-machine-ru` (SEO/AEO) · `tilda` (публикация) · `schema-markup-ru` (FAQ) · `sales-enablement-ru` (battlecard для продаж).
