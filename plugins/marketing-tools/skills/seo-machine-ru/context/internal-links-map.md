# Карта внутренней перелинковки — ЗАПОЛНИТЬ под проект

> Шаблон. Перечислить ключевые страницы сайта: URL, когда ссылаться, варианты анкора. Использует роль internal-linker.

## Проект: {{SITE_URL}}  [заполнить]

| Страница (URL) | Когда ставить ссылку | Варианты анкора |
|---|---|---|
| / (главная/оффер) | при упоминании продукта целиком | «{{BRAND_NAME}}», «{{MAIN_CATEGORY_KEYWORD}}» |
| /pricing | при разговоре о цене/тарифах | «тарифы {{BRAND_NAME}}», «сколько стоит» |
| /blog/<pillar> | из спутников кластера | вариация ключа пиллара |
| /<feature> | при разборе конкретной возможности | название фичи |

## Правила
- Спутник кластера → пиллар: обязательная ссылка, анкор = ключ пиллара.
- Пиллар → спутники: блок «читайте также».
- Анкор осмысленный (вариация ключа приёмника), не «тут»/«здесь»/«подробнее».
- 2-5 внутренних ссылок на страницу.
