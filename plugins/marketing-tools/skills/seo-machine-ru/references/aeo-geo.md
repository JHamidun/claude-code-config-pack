# AEO / GEO — оптимизация под AI-выдачу (RU)

> Цель — чтобы контент цитировался AI-ассистентами и попадал в их ответы. Для AI-/SaaS-продуктов это вдвойне важно: попадание в AI-ответы = прямой канал трафика.

## Поверхности (RU + глобальные)

| Движок | Что любит цитировать | Как влиять |
|--------|---------------------|------------|
| **Яндекс Нейро** (нейро-ответы в Яндексе) | страницы из топа Яндекса + структурированные ответы | классический SEO под Яндекс + прямые ответы + FAQ-разметка |
| **Alice / YandexGPT** | авторитетные RU-источники, Яндекс-индекс | индексация в Вебмастере, чёткие определения |
| **GigaChat (Сбер)** | RU-веб, новости | присутствие в RU-инфополе, цитируемость на vc/Habr |
| **ChatGPT (с web)** | сильные домены, чёткая структура, свежесть | англо- и рус-контент с ясными ответами, упоминания на авторитетных сайтах |
| **Perplexity** | источники с цифрами/цитатами, недавние | конкретика, даты, цитируемые данные, листиклы |
| **Gemini / Copilot** | структурированные данные, schema | FAQ/HowTo schema, таблицы |

## Что делает контент цитируемым (чеклист)

- [ ] **Прямой ответ сверху**: первые 2-3 предложения отвечают на запрос буквально (проверка — `seo_quality_rater_ru.py` пункт «Прямой ответ в intro»).
- [ ] **Извлекаемые блоки**: определения, нумерованные шаги, таблицы сравнения, FAQ — AI вытаскивает их целиком.
- [ ] **Атрибутируемые факты**: цифры со ссылкой на источник и датой («по данным X, 2026»). AI предпочитает то, что можно процитировать.
- [ ] **Уникальные данные**: свои метрики/исследования (напр. число пользователей, конверсия, результаты кейса) — их больше негде взять, AI цитирует первоисточник.
- [ ] **Сущностная ясность**: что за продукт, для кого, чем отличается — в явном виде (entity SEO).
- [ ] **Schema**: FAQPage, HowTo, Article, Organization (JSON-LD в `<head>`).
- [ ] **Свежесть**: дата обновления, актуальные факты.

## Аудит цитирований (из research-ai-citations)

1. Сгенерировать 30-100 запросов, по которым целевая аудитория спросила бы AI (вокруг темы/продукта).
2. Прогнать их через AI-движки (ChatGPT/Perplexity/GigaChat/Яндекс Нейро или любой агрегатор моделей) и зафиксировать: какие источники цитируются, упоминается ли ты/конкуренты.
3. Кластеризовать запросы по интенту, найти где конкуренты есть, а тебя нет = гэпы цитируемости.
4. План: какой контент создать/улучшить под эти гэпы (прямые ответы, данные, присутствие на цитируемых площадках).

## Размещение для ссылок и цитируемости — RU-каталоги

> Замена Product Hunt/G2/Capterra. Сначала проверь готовность посадочной (оффер, описание, OG, schema), потом размещайся.

- **Анонс/запуск:** vc.ru, Habr (если технологично), Product Radar (producthunt-ru), Spark.ru, vk-сообщества по AI, Telegram-каналы (свой + тематические), rb.ru.
- **B2B-каталоги софта:** startpack.ru, soware.ru, CNews/TAdviser (обзоры), Otзывы: otzovik, Яндекс Бизнес.
- **AI-каталоги:** российские подборки нейросетей (списки «лучшие нейросети 2026» — попадать в листиклы через outreach к авторам), глобальные TAAFT/Futurepedia (для англо-аудитории).
- **Цитируемость:** комментарии экспертов в статьях СМИ (напр. РБК Тренды), гостевые материалы, упоминания в обзорах конкурентов.
- Трекинг — таблица: площадка / тип ссылки (dofollow?) / статус / дата / URL.

## Связки

- Schema-разметка → JSON-LD FAQPage/HowTo/Article прямо в `<head>` страницы (см. пример в `examples/sample-article.schema.json`).
- Публикация площадок → твой CMS/блог + площадки (vc.ru/Habr/РБК/Telegram).
- Инструмент аудита AI-ответов → любой агрегатор моделей (ChatGPT/Perplexity/GigaChat/Яндекс Нейро).
