# SEO-гайдлайны (RU / Яндекс)

> Пороги для скриптов и ролей. Подстроены под русский язык и выдачу Яндекса. Перебивают английские дефолты из seomachine.

## Объём

| Тип | Слов |
|-----|------|
| Информационная статья | 1500-3000 |
| Лонгрид/пиллар | 3000-5000 |
| Коммерческая/категория | 800-1500 |
| SEO-лендинг | 1500-2500 |
| PPC-лендинг | 400-800 |

Ориентир — медиана топ-10 Яндекса по запросу ×1.1 (`content_length_comparator` логика). Не лить воду ради объёма (водность <5%, `readability_ru.py`).

## Плотность ключей (с учётом словоформ)

- Главный ключ: **1-2%** (считать по леммам — `keyword_analyzer_ru.py`).
- Второстепенные: 0.3-1%.
- Переспам >3.5% → риск фильтра Яндекса (Баден-Баден). Распределять равномерно по всем четвертям текста.
- Использовать словоформы и синонимы, а не дословные повторы (Яндекс хорошо понимает морфологию).

## Мета

- **Title:** 45-60 символов, ключ ближе к началу, бренд в конце «… | {{BRAND_NAME}}». Яндекс показывает ~55-60.
- **Description:** 110-160 символов, выгода + ключ + мягкий CTA. Влияет на CTR в выдаче.
- **H1:** один, с главным ключом, ≠ title дословно.

## Структура

- H2 минимум 3, логичная иерархия.
- Абзацы ≤ 80 слов, предложения в среднем ≤ 20 слов (`readability_ru.py`).
- Списки/таблицы для сканируемости и AEO.
- Прямой ответ на запрос в первых 2-3 предложениях.

## Читаемость (RU)

- Флеш-Оборнева ≥ 50 для массовой аудитории; для технического Habr допустимо ниже.
- Канцелярит/вода <5% (список стоп-слов в `readability_ru.py`, дополнять).
- Пассивные конструкции минимизировать.

## Ссылки

- Внутренние: 2-5, осмысленный анкор (вариация ключа приёмника), из карты `context/internal-links-map.md`.
- Внешние: 1-3 на авторитетные RU-источники (не на конкурентов по коммерческим запросам).

## Технич. (Яндекс.Вебмастер)

- Страница в индексе Яндекса; нет дублей/каннибализации.
- ЧПУ-URL, корректный robots/sitemap, скорость (важна для Яндекса).
- Schema (FAQ/Article/Organization) — JSON-LD в `<head>`.
- После публикации — отправить на переобход в Вебмастере.

## Отличия от англо-SEO (важно)

- Читаемость: формула Флеша адаптирована (Оборнева), не textstat-English.
- Морфология: плотность только по леммам, иначе недосчёт.
- Выдача: ориентир Яндекс (CTR-кривая в `opportunity_scorer.py`), Google вторичен для RU-аудитории.
- Каталоги/площадки: RU (см. `aeo-geo.md`), не Product Hunt/G2.
