# Аналитические роли (чеклисты)

> 11 ролей из seomachine, сжатые в RU-чеклисты. Это не отдельные субагенты — применяй как проверочные проходы по тексту. Запускай нужные после черновика.

## seo-optimizer (on-page)
- [ ] Главный ключ в: title, H1, первом абзаце, ≥1 H2, мета-описании.
- [ ] Иерархия заголовков логична (H1→H2→H3, без скачков).
- [ ] LSI/синонимы и словоформы (не дубль ключа дословно).
- [ ] Внутренние ссылки (2-5) с осмысленным анкором; внешние (1-3) на авторитет.
- [ ] Заявка на featured snippet: определение/список/таблица в начале раздела.
- [ ] Alt у картинок с ключом по делу.
- Скрипт: `seo_quality_rater_ru.py`.

## meta-creator
- 5 вариантов title (45-60 симв.): с ключом в начале, с цифрой/годом, с выгодой, с вопросом, с брендом «| {{BRAND_NAME}}».
- 5 вариантов description (110-160 симв.): прямая выгода + ключ + CTA, без воды.
- Психология SERP: цифры, скобки [гайд], год, «без VPN», конкретика.

## internal-linker
- Читать `context/internal-links-map.md`.
- 3-5 ссылок с точным местом вставки и анкором.
- Учитывать пиллар/кластер: спутник→пиллар обязательно.
- Анкор = вариация целевого ключа страницы-приёмника, не «тут»/«здесь».

## keyword-mapper
- Тепловая карта распределения: ключ есть в каждой четверти текста (`keyword_analyzer_ru.py` → `distribution_quarters`).
- Плотность главного 1-2%, второстепенных 0.3-1% (с учётом лемм).
- Каннибализация: этот же ключ не таргетит другая страница.
- Конкретные правки текста где переспам/где пусто.

## editor (очеловечивание)
- Убрать AI-клише (`content_scorer.py` → humanity, priority_fixes).
- Убрать канцелярит/воду (`readability_ru.py` → water_pct).
- Мини-история/пример в каждом крупном разделе.
- Ритм: чередовать длинные и короткие предложения.
- Первое лицо/опыт где уместно (голос бренда — из `context/product.md`).

## headline-generator (лендинги)
- 10 формул H1: выгода, «как», цифра, против боли, соц-доказательство, новизна, вопрос, «без X», для [сегмент], трансформация.
- Скоринг каждого: ясность/выгода/срочность/конкретика/ключ.
- Подзаголовок раскрывает H1, добавляет доказательство.

## cro-analyst (лендинги)
- Принципы Чалдини (соц-доказательство, дефицит, авторитет, взаимность).
- Эмоциональная арка: боль → агитация → решение → доказательство → действие.
- Снятие возражений (цена, риск, сложность, доверие).
- Гипотезы A/B для проверки на трафике.

## landing-page-optimizer
- Первый экран: оффер + выгода + CTA + доказательство ≤ 700 симв.
- CTA: видимый, повторённый, глагол действия.
- Сигналы доверия (логотипы клиентов, цифры, отзывы — {{TRUST_SIGNALS}}).
- Минимизировать трение формы.

## cluster-strategist
- Пиллар = широкий интент, спутники = узкие.
- 1 интент = 1 страница (анти-каннибализация — чеклист).
- Карта перелинковки внутри кластера.
- Последовательность написания: сначала спутники с quick-win, потом пиллар.

## content-analyzer (сводка)
- Запустить связку: `readability_ru.py` + `keyword_analyzer_ru.py` + `seo_quality_rater_ru.py` + `content_scorer.py`.
- Свести в вердикт: публиковать / доработать / переписать + топ-5 правок.

## performance (приоритизация по данным)
- Источники: Яндекс.Вебмастер (позиции/CTR) + Метрика (трафик/конверсии), свой OAuth-токен (см. `.env.example`).
- Типы возможностей: quick-win (поз. 11-20), падающие, низкий CTR при высоких показах, гэпы.
- Скоринг: `opportunity_scorer.py` (Impact/Effort/Confidence).
