# Шаблон гипотез — «3 гипотезы × 2-3 недели»

> Источник: методология (поток N), «Дерево метрик + воронки» / «Формирование гипотез». Домашнее задание урока: сформулировать **3 гипотезы на 2-3 недели каждая с объяснением, почему выбраны именно они**.
> Это planning-артефакт для **экспериментальной кампании** — когда кампания запускается не «вслепую», а как набор проверяемых ставок на узлах дерева метрик.

## Принцип

Каждый узел дерева метрик (CPM → CTR → CPC → CR1/CPL → CR2/CPA → LTV → CAC) — это **поле для гипотез**. Экспериментальная кампания = выбрать проседающие узлы, сгенерировать гипотезы, отобрать топ-3 и проверить их за 2-3 недели.

Почему именно **3** и именно **2-3 недели**:
- 3 гипотезы — фокус: больше гипотез одновременно размывают бюджет и не дают чистого сигнала.
- 2-3 недели — типичный горизонт, за который алгоритмы рекламы успевают обучиться и накопить статистику (минимум ~10 конверсий/неделя для обучения; меньше — выводы недостоверны).
- **с объяснением** — каждая гипотеза должна иметь обоснование (бенчмарк конкурента, прошлый опыт, данные), а не «давайте попробуем».

## Формат одной гипотезы

```
ГИПОТЕЗА № __
Узел дерева метрик:      [CPM / CTR / CPC / CR1 / CPL / CR2 / CPA / LTV / CAC]
Текущее значение:        [метрика сейчас, с источником]
Бенчмарк рынка:          [реальная планка конкурентов/агентств — ОБЯЗАТЕЛЬНО до цели]
Формулировка:            «Если [изменение], то [метрика] вырастет/упадёт с [X] до [Y],
                          потому что [механизм/причина]»
Почему именно она:       [обоснование выбора: бенчмарк / прошлый кейс / данные]
Что меняем (1 параметр): [конкретное действие — креатив / оффер / посадочная / SLA / аудитория]
Метрика успеха + порог:  [по какому числу решаем — сработало или нет]
Срок:                    [2-3 недели]
Минимум данных:          [сколько кликов/конверсий нужно для вывода]
Результат (после):       [заполняется по итогу; фиксируй ЛУЧШИЙ показатель]
```

## Как отобрать топ-3 (приоритизация)

Когда гипотез больше трёх — приоритизируй по **ICE** (Impact × Confidence × Ease, шкала 1-10 на параметр, сумма → ICE Score), бери три с наибольшим ICE:

- **Impact** — насколько вырастет метрика, если гипотеза сработает на 100%?
- **Confidence** — насколько уверен (есть кейсы конкурентов, твой опыт, данные)?
- **Ease** — насколько легко реализовать (10 = очень легко)?

> Глубокая механика ICE, статзначимость и расчёт размера выборки — `ab-testing-ru`. ICE-таблица в контексте воронки — `funnel-design-ru`.

## Правила эксперимента (чтобы сигнал был чистым)

- **Один параметр на гипотезу.** Меняешь и креатив, и оффер, и аудиторию сразу — не поймёшь, что сработало.
- **Бенчмарк до цели.** Нельзя ставить цель по метрике, не зная реальной планки рынка. Сначала узнай у конкурентов/агентств, потом целься.
- **Минимум данных для вывода** (ориентир из курса): ~10 конверсий/неделя для обучения алгоритма; для запроса/площадки — 15-50 кликов; меньше — погрешность слишком велика.
- **Фиксируй лучшие показатели.** Сработавшую гипотезу закрепляешь как новый базовый уровень → следующий спринт стартует от него.
- **Не трогай то, что работает.** «Лучшее — враг хорошего»: победившую связку не ломай ради новых правок.

## Когда применять

- Кампания запускается на новом канале/оффере и нужно быстро нащупать рабочую связку.
- Есть проседающий узел дерева метрик (дорогой лид, низкий CTR, слабая конверсия в оплату) — планируешь спринт его улучшения.
- Бюджет ограничен — нужно проверять ставки последовательно, а не лить «вслепую».
