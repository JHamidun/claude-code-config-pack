# Дерево метрик — обязательный артефакт плана кампании

> Источник: методология (поток N), «Дерево метрик + воронки» (экспертный курс). 
> Это **planning-артефакт** для шага «Measure» в campaign-planning: прежде чем запускать кампанию, разложи цель на цепочку метрик и обозначь, какую тактику применишь на каждом узле.
> **Полная механика дерева** (формулы, исчерпывающие тактики по каждому узлу, как раскладывать расплывчатую бизнес-цель) — в скилле `funnel-design-ru` (`references/metrics-tree.md`). Здесь — короткая версия для плана кампании, без дублирования.

## Зачем дерево метрик в плане кампании

Generic-фреймворк (Objective → Audience → Message → Channel → Measure) отвечает на вопрос «что делаем». Дерево метрик отвечает на вопрос **«по каким числам поймём, что сломалось»** и **«сколько денег нужно, чтобы вырасти X3»**.

Главная метафора методологии: **«Вся жизнь — это воронка».** Сверху — большой охват, на каждом этапе часть людей отваливается. Задача — минимизировать потери на КАЖДОМ узле и приблизить воронку к «прямой трубе».

Без дерева метрик план кампании остаётся набором действий без точек диагностики: когда босс скажет «маркетинг не работает / дорого привлекаем / что-то мы не растём», некуда смотреть.

## Цепочка узлов (от бюджета до CAC)

```
БЮДЖЕТ
  │  (канал: соцсети / поисковики (ключи+баннеры) / блогеры / паблики)
  ▼
ПОКАЗЫ ── CPM   (стоимость 1000 показов)
  │  ×CTR
  ▼
КЛИКИ  ── CTR   (клики ÷ показы)
  │
  ▼
ВИЗИТЫ ── CPC   (стоимость клика)
  │  ×CR1
  ▼
ЛИДЫ   ── CR1 (визит → лид), CPL (стоимость лида)
  │  ×CR2
  ▼
СДЕЛКИ ── CR2 (лид → сделка), CPA / CPO (стоимость действия/заказа)
  │
  ▼
ВЫРУЧКА ── LTV  (Lifetime Value — деньги с клиента за всё время)
  │
  ▼
ИТОГ   ── CAC  (стоимость привлечения) → главный тест: CAC vs LTV
```

## Тактики на каждом узле (краткий список для плана)

Под каждым узлом плана кампании укажи 1-3 тактики, которыми будешь двигать метрику. Полный список — в `funnel-design-ru/references/metrics-tree.md`.

| Узел | Метрика | Что закладывать в план (короткий список) |
|---|---|---|
| Показы | **CPM** | смена плейсментов; сегментация/расширение аудитории; регион/время/сезон; новые каналы; работа с креативом и оффером |
| Клики | **CTR** | бить в JTBD клиента; яркий читаемый баннер; сильный заголовок; хук в первые 3-5 секунд; A/B форматов |
| Визиты | **CPC** | производная от CPM и CTR — снижается через рост CTR (дешевле клики в аукционе) |
| Лиды | **CR1 / CPL** | быстрая загрузка (mobile-first); оффер = JOB + рекламная кампания; ответ на 3 вопроса (почему этот продукт / эта компания / именно сейчас); видимый CTA; social proof; FOMO |
| Сделки | **CR2 / CPA / CPO** | **SLA дозвона ≤15 мин** (ключевой рычаг); скрипты и FAQ; цепочки WhatsApp/SMS/e-mail; ретаргетинг; быстрый checkout; несколько платёжных систем |
| Выручка | **LTV** | подписки/абонементы; онбординг; апселл/кросселл; программы лояльности и рефералы; комьюнити; «вау» при первом опыте |
| Итог | **CAC vs LTV** | главный финансовый тест: воронка здорова, когда LTV кратно выше CAC |

## Как использовать при планировании — от цели к метрикам

1. **Сформулируй цель кампании числом** (шаг Objective). Например: «200 MQL за 6 недель» или «вырасти выручку X3».
2. **Разложи цель сверху вниз или снизу вверх:**
   - *Сверху вниз* (есть бюджет): бюджет → CPM → показы → CTR → клики → CR1 → лиды → CR2 → сделки → LTV.
   - *Обратный расчёт* (есть цель по выручке/лидам): нужная выручка → LTV → сколько сделок → CR2 → сколько лидов → CR1 → сколько визитов → CTR → сколько показов → CPM → **нужный бюджет**. Это и есть ответ на «сколько денег нужно, чтобы вырасти X3».
3. **Подставь бенчмарки на каждый узел.** **Бенчмарки обязательны до постановки цели** — узнай у конкурентов/агентств реальные цифры, прежде чем целиться «CTR с 0.5% до 10%». Нельзя ставить цель по метрике, не зная реальной планки рынка.
4. **Найди проседающий узел** — где конверсия ниже бенчмарка. Это узкое место кампании.
5. **На каждый узел — тактику из таблицы выше** (1-3 пункта). Это превращает план из «запустим рекламу» в «двигаем CR1 через mobile-first + social proof, целевой CPL ≤ X».
6. **Зафиксируй дерево как обязательный артефакт плана** рядом с медиапланом и контент-календарём.

### Перевод расплывчатой задачи в узел

| Что говорит заказчик/босс | Куда смотреть в дереве |
|---|---|
| «Что-то мы не растём» | весь путь: где конверсия ниже бенчмарка |
| «Очень дорого привлекаем клиентов» | CAC vs LTV, затем вверх: CPL → CPC → CPM |
| «Маркетинг не работает» | CR1 / CR2 — лиды есть, но не закрываются (или наоборот) |
| «У нас нет бюджета» | эффективность бюджета: CAC, укорачивание шагов воронки |
| «Сколько денег нужно, чтобы вырасти X3?» | обратный расчёт от выручки: LTV → CR2 → CR1 → CTR → CPM → бюджет |

## Сквозные принципы (закладывать в план)

- объём бюджета и его эффективность важнее абсолютного размера;
- конверсия на КАЖДОМ этапе — отдельная точка приложения гипотез;
- **укорачивать шаги** — чем проще путь клиента, тем выше конверсия;
- **не отпускать клиента «подумать»** — вероятность возврата резко падает;
- тестировать разные воронки и фиксировать лучшие показатели.
