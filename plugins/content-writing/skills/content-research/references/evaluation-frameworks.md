# Evaluation Frameworks — полные шаблоны оценки источников

> Компакт-версия CRAAP и таблица надёжности — в SKILL.md. Здесь — развёрнутые шаблоны для спорных/дорогих случаев (публикация, КП, юридически чувствительные утверждения).

## Полный CRAAP-шаблон (по 1-5 баллов на критерий)

### Currency (свежесть)
- Когда опубликовано / последний раз обновлено?
- Достаточна ли свежесть для темы? (tech/статистика ≤ 2 года; медицина ≤ 5 лет; история/математика — возраст не критичен)
- Работают ли ссылки внутри источника (мёртвые ссылки = признак заброшенности)?

### Relevance (релевантность)
- Отвечает ли источник именно на твой вопрос, а не на смежный?
- Подходит ли уровень (научный / популярный) под назначение контента?
- Смотрел ли ты альтернативные источники перед выбором этого?

### Authority (авторитетность)
- Кто автор? Организация? Какие регалии/аффилиация в этой теме?
- Есть ли у издателя редакционный контроль / peer review?
- Домен: .gov / .edu / рецензируемый журнал > коммерческий блог.
- Указаны ли контакты/автор вообще? Аноним = минус.

### Accuracy (точность)
- Приведены ли данные, методология, размер выборки?
- Есть ли ссылки на первоисточники внутри?
- Подтверждается ли утверждение хотя бы одним независимым источником?
- Есть ли явные ошибки, опечатки, битые цифры (признак небрежности)?

### Purpose (цель)
- Информировать / учить / продавать / агитировать / развлекать?
- Кто платит за площадку (реклама, вендор, лоббист)?
- Отделены ли факты от мнений? Есть ли эмоционально заряженный язык?

**Интерпретация суммы:** 20-25 — отлично · 15-19 — годен · 10-14 — сомнителен, ищи замену · <10 — не использовать.

## Cross-reference (перекрёстная проверка)

Два источника «независимы», только если НЕ цитируют друг друга и не восходят к одному пресс-релизу.

1. Найди утверждение в источнике A.
2. Найди то же утверждение в источнике B из ДРУГОЙ категории (например, СМИ + академическая работа).
3. Проверь: B ссылается на A? A и B ссылаются на один и тот же C? → тогда это ОДИН источник (C), иди к C.
4. Совпадают точные цифры? Расхождение > ~10% — ищи третий источник и указывай диапазон.

## Трассировка к первоисточнику

Типичная цепочка искажения: твит → блог-пересказ → СМИ-заметка → пресс-релиз → **само исследование**.

- В любом пересказе ищи фразы «according to a study by…», «по данным исследования…» — и иди по ссылке вглубь.
- Если ссылки нет — WebSearch: `"<точная цифра>" <организация> study` или название исследования.
- Цитируй первоисточник; пересказ можно упомянуть дополнительно как «популярное изложение».
- Красный флаг: цифра гуляет по десяткам сайтов, но никто не даёт ссылку на оригинал («zombie statistic») — не использовать.

## Source card (карточка источника — для больших рисёрчей)

```markdown
### [Название источника]
- URL: …
- Автор/организация: …
- Дата публикации: …
- Тип: академический / официальный / СМИ / индустриальный / блог
- CRAAP: C_/5 R_/5 A_/5 A_/5 P_/5 = _/25
- Ключевые факты: (точные цифры с контекстом)
- Ограничения/bias: (выборка, кто финансировал, страна)
- Независимые подтверждения: [ссылки]
```

## Cornell-заметки (для конспектирования длинных источников)

| Колонка «вопросы/ключи» | Колонка «заметки» |
|---|---|
| Какой % X? | Точная цифра + страница/раздел |
| Методология? | RCT / опрос / мета-анализ, N=… |

Внизу — саммари своими словами в 2-3 предложения (защита от непреднамеренного плагиата).

## Каталоги инструментов

**Академический поиск:** Google Scholar (scholar.google.com), Semantic Scholar, PubMed (медицина), arXiv (preprints — помни: не рецензированы), SSRN (соц. науки), CORE / DOAJ (open access).

**Fact-checking:** snopes.com, factcheck.org, politifact.com, fullfact.org; для изображений — обратный поиск (Google Images / TinEye).

**Статистика и данные:** data.worldbank.org, OECD Data, Eurostat, Statista (агрегатор — трассируй к первоисточнику!), Our World in Data, Росстат.

**Citation managers:** Zotero (бесплатный, авто-захват метаданных), Mendeley, BibTeX (для LaTeX). Для 3-7 источников под пост менеджер не нужен — хватает таблицы из SKILL.md.

**Archive:** web.archive.org — если страница исчезла/изменилась; фиксируй снапшот важных источников для долгоживущего контента.
