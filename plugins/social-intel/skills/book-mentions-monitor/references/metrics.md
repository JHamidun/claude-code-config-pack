# Метрики мониторинга (как у Медиалогии + расширения)

> Реализованы в `scripts/lib/enrich.py` (МедиаИндекс, тональность, роль, цитирование) и `scripts/lib/reach.py` (охват).

---

## Таблица метрик — соответствие Медиалогии

| Метрика | Определение (МЛ-логика) | Наша реализация | Уровень |
|---|---|---|---|
| **Количество** | число публикаций с упоминанием объекта | `len([m for m in rel if m._is_target])` | сообщение |
| **Оригиналы / Перепечатки** | оригинал = уникальный текст; перепечатка = копипаст из другого СМИ | лемма-шинглы (4-gram, Jaccard ≥ 0.6) → `_reprint_of = original_id`; `content_scrubber.scrub()` перед хешем | сообщение |
| **Тональность** | Позитив / Нейтрал / Негатив — по тексту про объект | haiku-субагент (батч JSON-schema), для `is_target=True`; fallback-правило по ключевым словам | сообщение |
| **Роль** | Главная = объект в центре материала; Эпизодическая = упомянут вскользь | opus-субагент (title+snippet): «книга — главный предмет текста?»; fallback: заголовок содержит название/автора | сообщение |
| **Жанр** | Новость / Аналитика / Интервью / Анонс | opus-субагент (контекст); fallback-regex по ключевым словам | сообщение |
| **Цитирование** | есть прямая цитата автора / редактора / персонажа | opus-субагент `cite: true/false`; regex `«[^»]{10,}»` | сообщение |
| **Охват** | потенциальная аудитория источника (абсолютная, уник/мес) | **Tranco-ранг → бакет** (см. ниже) + Cloudflare Radar bucket + соц-просмотры из API | источник |
| **МедиаИндекс** | интегральная взвешенная метрика (проприетарная у МЛ, своя у нас) | формула `enrich.py::media_index()` (см. ниже) | сообщение |
| **Вовлечённость** | лайки + репосты + комментарии / просмотры в соцсетях | TG: `views + forwards + reactions`; VK: лайки из API (если токен); YT: `view_count + like_count`; остальное = 0 | сообщение |

## Охват: Tranco-ранг → бакет аудитории

Абсолютный трафик СМИ через SimilarWeb/Mediascope — платно. Используем ранг как прокси.

```
Tranco-ранг (глобальный)  →  Оценка аудитории (уник/мес, RU)
≤ 1 000                       > 10 млн
1 001 – 10 000                1 – 10 млн
10 001 – 50 000               100 тыс – 1 млн
50 001 – 200 000              10 – 100 тыс
> 200 000 или нет в Tranco    < 10 тыс
```

Источник ранга: `https://tranco-list.eu/api/ranks/domain/{domain}` (без ключа).  
Cloudflare Radar bucket (`/radar/v1/ranking/domain/{domain}`, ключ `CLOUDFLARE_GLOBAL_API_KEY`) — второй источник, дублирует Tranco.

Для соцсетей охват = `подписчики` (TG: `participants_count`; VK: `members_count`).

## МедиаИндекс — формула

Реализована в `scripts/lib/enrich.py::media_index(mention, n_reprints)`.

```python
import math

W_TONE  = {"Позитив": 1.0, "Нейтрал": 0.5, "Негатив": -1.0}
W_ROLE  = {"Главная": 1.5, "Эпизодическая": 1.0}
W_CITE  = 1.3   # если есть цитирование
W_GENRE = {"Аналитика": 1.2, "Интервью": 1.1, "Новость": 1.0, "Анонс": 0.8}

def media_index(m, n_reprints):
    reach       = m.get("_reach", 0)          # уник/мес из бакета
    engagement  = m.get("_engagement", 0)     # views+likes+reposts+comments
    tone        = W_TONE.get(m.get("_tone", "Нейтрал"), 0.5)
    role        = W_ROLE.get(m.get("_role", "Эпизодическая"), 1.0)
    cite        = W_CITE if m.get("_cite") else 1.0
    genre       = W_GENRE.get(m.get("_genre", "Новость"), 1.0)

    base = math.log10(reach + 10) + math.log10(engagement + 1)
    mi   = base * abs(tone) * role * cite * genre / math.sqrt(n_reprints + 1)
    return round(mi * tone, 3)    # отрицательный МИ при негативе
```

**Интерпретация знака:** положительный МИ = позитив/нейтрал; отрицательный МИ = негатив. Соответствует логике Медиалогии (негатив снижает суммарный МИ объекта).

**МИ объекта** = сумма МИ всех его сообщений.  
**«Заметность» сообщения** = его индивидуальный МИ (как у МЛ: КП #Москва 4.032 = высокий охват × Главная роль × позитив).

## Расширения сверх Медиалогии

| Метрика | Источник | Что даёт |
|---|---|---|
| **Читательский рейтинг** | LiveLib: `rating` (0–5), `ratings_count` | Реальная оценка читателей, не СМИ |
| **Рецензии** | LiveLib: полный текст, автор рецензента | Качественный отзыв |
| **Отзывы покупателей** | Читай-город / Ozon-сниппет | Потребительский голос |
| **Поисковый спрос** | Wordstat: месячный объём запросов | Органический интерес к книге |
| **Жанр** | LLM (наш) vs МЛ (нет) | Разбивка на Новость/Аналитика/Интервью/Анонс |

## Дедуп оригинал/перепечатка

Реализован в `scripts/lib/dedup.py::mark_reprints(mentions)`.

1. `content_scrubber.scrub(text)` — убрать zero-width, BOM, soft-hyphen, nbsp (иначе одинаковый текст → разные хеши).
2. Лемматизировать через `keyword_analyzer_ru.tokens(text)` (pymorphy3).
3. 4-граммовые шинглы → Jaccard-схожесть. Порог ≥ 0.6 → перепечатка.
4. `_reprint_of = id` первого вхождения (оригинал = самая ранняя дата публикации).

Эталон из Медиалогии: типичное соотношение — около 67% оригиналов + 33% перепечаток от общего числа упоминаний.
