# LLM-биллинг и правила экономии

> Критично: неправильное использование = неожиданные расходы из платного пула.

---

## Главное правило: LLM только в интерактивной сессии

| Способ запуска | Биллинг до 15.06.2026 | Биллинг с 15.06.2026 |
|---|---|---|
| **Интерактивная Claude Code сессия** (открытый терминал) | ✅ Claude Max (субсидия) | ✅ Claude Max (субсидия) — остаётся |
| `claude -p "..."` (headless one-shot) | ✅ субсидия | ❌ **платный кредитный пул** ($20/$100/$200) |
| Agent SDK / MCP вызовы из скриптов | ✅ субсидия | ❌ **платный пул** |
| GitHub Actions / cron с `claude -p` | ✅ субсидия | ❌ **платный пул** |

**Итог:** с 15.06.2026 любой headless / автоматизированный запуск Claude тратит деньги.  
**Решение:** классификацию гонять только в живой сессии через `Task()`-субагенты.

```bash
# ANTHROPIC_API_KEY НЕ должен быть задан в окружении
```

**Убрать из `.env`** или не экспортировать перед запуском скилла.

## Распределение задач по моделям

| Задача | Модель | Почему |
|---|---|---|
| Дизамбигуация (is_target_book) | **opus** | Нужно глубокое понимание контекста; в тестовом PoC отсеял 10/35 пограничных кейсов безупречно |
| Роль (Главная/Эпизодическая) | **opus** | Субъективная оценка «в центре текста?» — требует рассуждения |
| Жанр (Новость/Аналитика/Интервью/Анонс) | **opus** | Часто совмещён с дизамбигуацией в одном вызове (экономия) |
| Цитирование (cite: bool) | **opus** | Совмещён с дизамбигуацией |
| Тональность (Поз/Нейтр/Нег) | **haiku** | Простая задача; батч 12 = 3.2 с; корректно на проверенных данных |

**Правило thumb:** opus где сложно (понимание контекста, омонимы), haiku где просто (тональность однозначного текста).

## Как запускать Task-субагенты правильно

В открытой Claude Code сессии после `python monitor.py collect config/mybook.yaml`:

```
# Шаг 1: прочитать батч
Read out/to_classify.json

# Шаг 2: запустить opus (дизамбигуация + роль + жанр + цитирование)
Task(
  model="opus",
  prompt=f"""Промпт из scripts/classify/disambiguate_prompt.md.
  Книга: {book.title}, Авторы: {book.authors}, Якоря: {book.anchors}.
  Батч: {items_json}
  Ответь JSON массивом [{id, is_target_book, role, genre, cite}].
  """,
  schema={"type":"array","items":{"type":"object","required":["id","is_target_book","role","genre","cite"]}}
)

# Шаг 3: запустить haiku на is_target=true (тональность)
Task(
  model="haiku",
  prompt=f"""Промпт из scripts/classify/tone_prompt.md.
  Батч (только целевые): {target_items_json}
  Ответь JSON массивом [{id, tone}].
  """,
  schema={"type":"array","items":{"type":"object","required":["id","tone"],"properties":{"tone":{"enum":["Позитив","Нейтрал","Негатив"]}}}}
)

# Шаг 4: смёрджить → записать out/classified.json
# Шаг 5: python monitor.py finalize config/mybook.yaml
```

---

## JSON-schema обязательна для haiku

Без схемы haiku расписывает ответ текстом вместо JSON:
```
# Плохо (без схемы):
"Тональность этого текста — Позитив, потому что..."

# Хорошо (со схемой):
[{"id": 0, "tone": "Позитив"}, {"id": 1, "tone": "Нейтрал"}]
```

Всегда передавать `schema=` в Task-вызове для haiku. Opus обычно выдаёт JSON без схемы, но с ней надёжнее.

## Большие батчи (100+ упоминаний)

При 100+ кандидатах:

1. **Дробить батчи** по 20–30 для opus (контекстное окно не проблема, но качество лучше на меньших батчах).
2. **Workflow pipeline**: opus сначала, haiku потом на отфильтрованных. Не мешать в одном Task.
3. **Параллельные Task**: можно запускать несколько haiku параллельно (разные батчи тональности).

```python
# Пример дробления (псевдокод в Claude-сессии)
chunks = [items[i:i+25] for i in range(0, len(items), 25)]
results = []
for chunk in chunks:
    r = Task(model="opus", prompt=..., ...)
    results.extend(r)
```

## Альтернативы при недоступности Claude Max

| Ситуация | Альтернатива | Стоимость |
|---|---|---|
| Нет доступа к сессии | Local Gateway `127.0.0.1:8200` (Gemini Flash) | 0 token spend |
| Массовая классификация | Gemini API free tier (1500 req/day) | бесплатно |
| Headless cron | `--llm none` (правила-fallback) | бесплатно, ↓точность |

`local-gateway` skill: `POST 127.0.0.1:8200/openai/v1/chat/completions` с `model: gemini-3-flash`.
