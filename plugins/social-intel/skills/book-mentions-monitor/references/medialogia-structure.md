# Структура Медиалогии — референс для воспроизведения

> Источник: кабинет `pr.mlg.ru`, снято 2026-06-03.
> Продукт: **PR — Мониторинг и анализ СМИ**. Охват: 3,2 млрд аккаунтов + 110 тыс. СМИ.

---

## Модель данных

**Объект** = поисковый запрос с:
- ключевыми словами / словосочетаниями (ИЛИ / И, «Только в заголовках»);
- якорями-дизамбигуаторами: автор, издательство, подзаголовок;
- минус-словами;
- фильтром роли/тональности.

**Отчёт** = прогон объекта за период. Параметры: дата, уровень СМИ (Федеральный/Региональный/Зарубежный), категория, отрасль, топ-100 по имени/автору/языку.

## Что эталон прояснил (не очевидно из веб-интерфейса)

1. **Заметность сообщения = его МедиаИндекс.** В ленте КП #Москва = 4,032 = его же МИ в листе 12.
2. **Перепечатки считаются явно** как отдельная колонка (34 ориг + 17 перепеч = 51).
3. **Инфоповоды** — отдельный лист с кластеризацией: «Библионочь», «Выход книги» и т.д. У нас → LLM-кластеризация по теме сообщения.
4. **Жанры, Рубрики, Слова, Отрасль СМИ** — в веб-UI не видны, только в полном экспорте XLSX.
5. **МИ авторов** часто «н.д.» — не критично, заполнять где есть.

## Экспорт и авторассылка

- Форматы: DOCX, DOC, **XLSX**, XLS.
- Ракурс: текущий / все ракурсы / настраиваемые.
- Регулярный мониторинг = сохранённый объект + отчёт с **авторассылкой на email** по расписанию.
- Лимиты аккаунта: `Лимиты: 99% | 93%` + счётчик `Экспорт N / M`.

**Наш аналог:** `monitor.py finalize` → XLSX (листы 1–21) + дайджест в Telegram. `/loop` или `/schedule` для регулярности.
