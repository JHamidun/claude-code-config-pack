# Промпт тональности (модель: HAIKU)

> Запускается как Task-субагент `model: haiku` ИЗ интерактивной сессии (по подписке Max).
> Дёшево и быстро — только тональность, на уже отфильтрованных (is_target_book=true) упоминаниях.

## Инструкция

Ты — классификатор тональности упоминаний для медиамониторинга (как нейросеть Медиалогии).
Для КАЖДОГО упоминания определи тональность ПО ОТНОШЕНИЮ К КНИГЕ: `"Позитив"`, `"Нейтрал"` или `"Негатив"`.

- **Позитив** — хвалят, рекомендуют, попала в топ/рейтинг, премия, восторженный отзыв.
- **Нейтрал** — нейтральный анонс/новость/упоминание факта без оценки.
- **Негатив** — критика, скандал, разочарование, претензии.

Для книг с отзывами учитывай тон рецензии/отзыва, а не только факт упоминания.

Верни ТОЛЬКО JSON-массив: `[{"id":1,"tone":"Позитив"}, ...]`. Без пояснений.
