# Meta Creative Spy + Atria — анализ креативов конкурентов в FB/Instagram

> Разведка креативов в Meta Ads Library и в Atria: что именно смотреть и как читать выдачу.
> ⚠️ **Meta признана экстремистской организацией в РФ** — указывать в каждом артефакте.

---

## 1. Best practice: искать по имени FB-страницы, а НЕ по названию компании (экспертная методология)

Главный приём анализа Meta Ads Library:

- **Искать НЕ по названию компании, а по точному имени Facebook-страницы.** Одна компания может вести несколько страниц, у бренда и юрлица имена расходятся — поиск по «названию компании» теряет половину объявлений. Типовая ошибка из-за этого: поискал по названию компании → почти пусто → ложный вывод **«у конкурентов почти нет рекламы»**, хотя объявления просто висят на других страницах.
- **Категорий/рубрикатора в библиотеке нет** — «показать всех рекламодателей ниши» она не умеет. Поэтому список FB-страниц конкурентов собирается ЗАРАНЕЕ, отдельным шагом.
- **Список FB-страниц конкурента удобно собирать через ChatGPT с веб-поиском** — попросить найти все FB Pages бренда/конкурентов, затем по каждому имени бить в Ads Library.

Инструменты слоя:
- **Meta Ads Library** — facebook.com/ads/library (официальный, бесплатный).
- **BigSpy** — bigspy.com (альтернатива/дополнение).
- **Atria** — tryatria.com (см. ниже, с оценкой бюджета и рейтингом РК).

## 2. Workflow «analyze creatives for Meta launch»

Цель — перед запуском своих Meta Ads разобрать, что работает у конкурентов. Через Scraping API (см. основной SKILL.md) или вручную через Ads Library:

1. **search → найти страницу.** `search/companies` по точному имени FB-страницы (не компании). Собрать `company_id`.
2. **company_ads → выгрузить все объявления.** `company/ads?company_id=ID` — все активные креативы конкурента.
3. **ad_details → детали.** `ad?ad_id=ID` — полный креатив, текст, CTA, посадочная, даты.
4. **longest running → ранжировать.** Отсортировать по длительности открутки. **Длительно крутящийся = работающий** (конкурент не стал бы лить на убыточный креатив месяцами). Самые «старые» активные объявления = проверенные офферы/хуки, с которых стоит начинать reverse-engineering.

Что вынести из разбора: топовые хуки (первая строка), форматы (статика/видео/карусель), УТП, на какие посадочные льют, сколько объявлений на лендинг.

## 3. Atria (tryatria.com) — clone creatives + budget estimate + рейтинг РК

Самостоятельный spy-инструмент с уникальным value: **оценивает примерный бюджет конкурента** и рейтингует креативы. Платный, тариф смотри на сайте — цены меняются. Контекст доверия от эксперта: его команда **месяц пилила такую автоматизацию сама**, а Atria — «эта штука уже упакована в коробку»; сверх ручного скрининга Ads Library даёт фильтр по длительности открутки + парсинг хуков из подписки на конкурента.

| Возможность Atria | Что даёт |
|-------------------|----------|
| Все активные креативы конкурента | Полный набор объявлений + хуки |
| **Все лендинги** конкурента | На какие посадочные льют, сколько объявлений на лендинг |
| **Longest running ads** | Фильтр по длительности открутки (= что работает) |
| **Примерный бюджет** | Оценка РК конкурента — чего нет в Ads Library |
| **Clone-add** | Адаптирует визуал конкурента под себя (меняет текст/бренд) → готовый креатив в свой кабинет |
| **Автооценка СОБСТВЕННОГО кабинета** | Каждый свой креатив попадает в одну из трёх корзин: **A+ — скейлить / High iteration potential — итерировать / Underperforming — менять** |

### Atria pipeline для конкурентного анализа

```
Atria (подписка на конкурентов)
  → все активные креативы + хуки + бюджеты по лендингам
  → фильтр по longest running ads
  → видение: на какие лендинги льют, сколько объявлений на лендинг
  → clone-add адаптация визуала под себя (меняем текст)
  → готовый креатив в свой кабинет → тест
  → Atria оценивает каждый креатив: A+ / High iteration / Underperforming
  → дальше копировать посадочные через Claude Code + Firecrawl
```

Рейтинг A+ / High iteration / Underperforming = сигнал, какие из клонированных/своих креативов масштабировать, какие итерировать, какие выключить.

## 4. Копирование креативов конкурентов 1-в-1 на зарубежных рынках

> Источник: обсуждение SpyTrend в чате курса, 18.08.2026 — **личный опыт участников**, не методика преподавателя.

**Приём, как он звучал:** если рынок **зарубежный** — найти рекламу конкурентов и **копировать её один-в-один с небольшим ребрендингом**. Обоснование: у любого бизнеса за рубежом конкурентов много, а база SpyTrend (весь FB + TikTok, 10 млн+ новых креативов в день) позволяет выбрать не «какой-нибудь», а заведомо прибыльный. РФ этим не закрывается — базы по РФ нет вообще (на РФ через FB/TikTok никто не льёт).

Фактическая сторона одной строкой: прямое копирование чужого креатива — это риск претензии правообладателя; в источнике приём звучал именно как «1-в-1 с небольшим ребрендингом», так и фиксируем.

### 4.1. Два сигнала отбора: что копировать стоит

Ad Library не даёт ни одного из них — оба берутся из SpyTrend/Atria:

| Сигнал | Что означает | Как читать |
|--------|--------------|-----------|
| **Длительность открутки** креатива | Крутится долго = **работает в плюс**. Конкурент не станет месяцами лить бюджет на убыточную связку | Прокси прибыльности №1. Сортировать выдачу по нему и брать верх списка (в Atria — фильтр *longest running ads*) |
| **Число перезаливов** креатива | Перезаливают = **конвертит**. Перезалив стоит модерации и времени, ради слабого крео этого не делают | Прокси прибыльности №2. Работает и там, где открутка короткая: креатив мог отлежать в бане и вернуться |

Сигналы **независимы и складываются**: долгая открутка + много перезаливов = самая надёжная цель для копирования. Числовых порогов («долго» = сколько дней, «много» = сколько перезаливов) **в источнике не называли** — там оба сигнала даны качественно. Рабочий обходной путь (не из источника): порог набивается на своей нише — выгрузить топ по обоим метрикам и взять верхний дециль относительно остальной выдачи по этой же нише, абсолютные цифры между нишами не переносятся.

### 4.2. Clone-add у Atria — механика копирования

`clone-add` — **адаптация чужого визуала под себя в один клик**: берётся креатив конкурента, подменяется текст и бренд, на выходе готовый креатив **сразу в свой рекламный кабинет**. Именно это и есть «копирование 1-в-1 с небольшим ребрендингом» в инструментальном виде — ручной пересборки макета не требуется.

Замыкание петли: клонированный креатив попадает под **автооценку собственного кабинета** в Atria (три корзины A+ / High iteration potential / Underperforming, см. §3) — то есть после клона сразу видно, скейлить его, итерировать или гасить, без отдельного разбора.

### 4.3. Порядок работы

```
SpyTrend MCP (зарубежное гео, FB+TikTok)
  → сортировка по длительности открутки + числу перезаливов
  → верхний дециль по нише = кандидаты на копирование
  → Atria: подписка на владельца креатива → все его лендинги + число объявлений на лендинг
  → clone-add: подмена текста и бренда → креатив в свой кабинет
  → тест → автооценка Atria (A+ / High iteration / Underperforming)
  → посадочные конкурента копируются отдельно: Claude Code + Firecrawl
```

Что дописывается к клону, а не берётся из него: свой оффер и посадочная (креатив конкурента ведёт в чужую воронку), маркировка/юр-требования гео, свой пиксель. Разбор структуры связки (оффер → хук → механика) по 5-блочному канону — `ai-creative-factory-ru`; там же вариации, когда клон нужно отвести от оригинала.
