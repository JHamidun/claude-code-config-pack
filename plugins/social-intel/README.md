# Social Intelligence

> Trends, ad spy, TikTok intel, SimilarWeb, Reddit/HN, scraping, GitHub gem hunting.

Part of the **[hamidun marketplace](../../README.md)**.

## What's inside

| Skill | What it does |
|-------|--------------|
| `ad-spy` | Ad Library intelligence: Facebook, Google, LinkedIn, Reddit — мониторинг рекламы конкурентов, креативы, бюджеты via Scraping API. |
| `apify-scraping` | Apify Web Scraping Skill. |
| `github-gem-seeker` | Search GitHub for battle-tested open source solutions instead of writing code from scratch. |
| `last30days` | Research what people actually say about any topic in the last 30 days. |
| `meta-ads-analyzer` | Analysis and DIAGNOSIS of existing Meta Ads (Facebook/Instagram) campaigns — what broke, why it's expensive: Breakdown Effect (Marginal vs Average CPA), Learning Phase. |
| `reddit-hn` | Search Reddit and Hacker News for technology opinions, trends, and discussions. |
| `serpapi` | Real-time Google Search API через SerpAPI (SERPAPI_API_KEY): scraping выдачи Google Search / Maps / Shopping / News / Images / YouTube. |
| `similarweb-analytics` | Analyze website traffic and engagement metrics using web search and public SimilarWeb data. |
| `social-intel` | Cross-platform social media intelligence — build a complete dossier on any person, brand, or company across LinkedIn, Instagram, TikTok, X/Twitter… |
| `tiktok-intel` | TikTok & Instagram deep intelligence — trending content, influencer research, audience demographics, TikTok Shop products, popular songs/hashtags… |

## Install

```text
/plugin marketplace add JHamidun/claude-code-config-pack
/plugin install social-intel@hamidun
```

Enable it with `/plugin` — the skills then activate automatically when relevant.
