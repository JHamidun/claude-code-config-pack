# SEO & AI Answer Optimization

> SEO content pipeline, programmatic AI-SEO page generation, schema.org markup, GEO/AEO visibility in ChatGPT, Perplexity and AI Overviews.

Part of the **[hamidun marketplace](../../README.md)**.

## What's inside

| Skill | What it does |
|-------|--------------|
| `ai-seo-agent-pipeline` | Программатическая SEO-фабрика: сотни страниц под длинный хвост через n8n+Perplexity. |
| `geo-aeo-ru` | GEO/AEO/LLM SEO — видимость бренда в ответах ChatGPT, Perplexity, YandexGPT; Citation Share, llms.txt. |
| `schema-markup-ru` | Schema.org / JSON-LD разметка: Organization, Course, FAQPage; Яндекс читает JSON-LD. |
| `seo-machine-ru` | SEO под Яндекс и Google: лонгриды, семантика (Wordstat, Tilda), техбаза, мета-теги, SEO на Запад. |

### Commands

- `/seo-audit`

## Install

```text
/plugin marketplace add JHamidun/claude-code-config-pack
/plugin install seo-geo@hamidun
```

Enable it with `/plugin` — the skills then activate automatically when relevant.
