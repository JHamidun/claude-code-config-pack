# Структура сайта: кликовая вложенность, каталог, теговые страницы, HTML-карта

Ориентир один: **чем меньше кликов от главной до продвигаемой страницы, тем лучше. Идеал — 2
клика.** Это одна из самых дешёвых точек роста: правится вёрсткой и перелинковкой, не требует
контента.

Карта внутренних ссылок конкретного проекта — `context/internal-links-map.md`; роль
`internal-linker` — в `agents-checklists.md`. Здесь — каркас, в котором эта карта живёт.

---

## 1. Главная как хаб (вложенность 1 клик)

На главной «можно не стесняться» — она раздаёт вес и сокращает путь до всего каталога:

- подборки карточек по разным логикам: хиты, новинки, популярные, сезонные;
- популярные категории;
- бренды;
- частотные теговые страницы;
- блог, отзывы.

**Приём:** маленькая строчка ссылок + кнопка «Развернуть», под которой прячется портянка на 50-100
ссылок. Для пользователя главная выглядит прилично, для бота продвигаемые страницы — в один клик.

Кейс из практики: на проекте с кривой структурой рост начался просто от вывода на главную ссылок
на продвигаемые страницы, у которых был спрос, — до всякой переработки каталога.

## 2. Каталог в 3 уровня

```
Главная → Каталог → Семена → Овощи → Томаты        ✗ четыре клика, хуже ранжируется
Главная → Семена → Овощи → Томаты                  ✓ три уровня
```

Антипаттерн, который встречается постоянно: лишний промежуточный экран «Каталог» и разбиение,
которое дублирует уже существующий уровень. **Проверка глубины меню — первое, что смотреть на
чужом сайте.**

Практическая проверка: открыть 10 случайных продвигаемых страниц и посчитать минимальное число
кликов от главной. Больше двух — искать, куда добавить ссылку (главная, меню, блок «смежные»,
HTML-карта).

## 3. Теговые страницы (4-й уровень)

Срезы, которые не влезли в трёхуровневый каталог, уходят в теговые страницы:
`каталог/семена/овощи/томаты/японские`. Технически это те же категории: свой H1, свои теги, своя
семантика, свой шаблон мета (`meta-templates.md`).

Тег заводится, только когда под него есть **ненулевая частотность**. Иначе — мусорные страницы,
которые размывают краулинговый бюджет.

> 💡 **Почему теговые часто выгоднее высокочастотной категории** (Шестаков, методология 8.0,
> «SEO 1», 20.08.2026). «Купить душевую кабину» — популярный запрос, стоять по нему приятно, но
> **конверсия там не всегда хорошая**: она сильно зависит от дизайна и юзабилити, и на этом этапе
> человек ещё выбирает. Тег «угловые душевые кабины 120×120 с гидромассажем» даёт низкую
> конкуренцию, **очень целевой трафик** и продаёт — но при двух условиях: такие товары **реально
> есть в наличии** и сайт нормально сделан. Тег без товаров под ним не закрывает интент и в топ
> не выходит (ассортиментный фактор → `commercial-factors-audit.md` §1).

## 4. HTML-карта сайта

Для больших проектов. Ссылка — в подвале, на каждой странице.

- Выводить **все продвигаемые страницы всех уровней**: категории, подкатегории, теговые срезы.
- **Карточки товара не выводить** — их слишком много и они не продвигаются под отдельные ключи.
- Ориентир: **не больше 1000 ссылок на одну карту** (весна 2026, проверить актуальность). Больше —
  делить на несколько карт по логике.

Кейс портала недвижимости: 5-10 отдельных карт — по улицам, по шоссе, по посёлкам, по коттеджам.
Итог — любая страница в двух кликах от главной.

HTML-карта не отменяет `sitemap.xml`: XML — для бота-обходчика, HTML — для передачи веса и
сокращения вложенности.

## 5. Чеклист структуры

- [ ] Каталог не глубже 3 уровней, лишний экран «Каталог» отсутствует.
- [ ] Все продвигаемые страницы — в 2 клика от главной.
- [ ] На главной выведены категории, бренды, частотные теги (можно под «развернуть»).
- [ ] Срезы сверх 3 уровней оформлены теговыми страницами, у каждой — подтверждённая частотность.
- [ ] HTML-карта в подвале, ≤1000 ссылок на карту, карточки товара не выводятся.
- [ ] `sitemap.xml` отдаётся и не конфликтует со структурой.
- [ ] Каждая страница — под один интент (анти-каннибализация, роль `cluster-strategist`).
