## 1. Что мерить (7 метрик)

| Метрика | Что показывает | Как считать |
|---------|----------------|-------------|
| **Citation Share** | % ответов на тестовый prompt-set, где упомянут твой бренд | прогнать 100-500 промптов через API, считать частоту упоминаний |
| **Share of Voice (SoV)** | доля твоего бренда vs конкурентов в LLM-ответах | сравнительный анализ по prompt-set: упоминания тебя / (тебя + конкурентов) |
| **Sentiment in LLM** | тон упоминаний (позитив/нейтрал/негатив) | manual или LLM-classifier |
| **AI Overview Presence** | % твоих ключей, где появляется AIO и ты в ней | Google Search Console + ручной check |
| **LLM Referral Traffic** | сессии из ChatGPT/Perplexity/Claude/Gemini | GA4 / Метрика — matching по referrer |
| **Brand Mention Velocity** | темп роста brand mentions на цитируемых доменах | Mention / Ahrefs / Semrush |
| **Hallucinated URLs** | LLM генерирует «фейковые» URL под твой бренд | мониторинг 404 в server logs |

**Главная пара для baseline:** Citation Share (есть/нет тебя) + Share of Voice (ты vs конкуренты).
Остальное — углубление.

## 2. Методология промпт-аудита

### Prompt-set: 5 типов промптов

Базовый аудит для любого бренда — 5 категорий, по 10 промптов = 50 на платформу:

1. **Brand direct** — «Расскажи про [Бренд]», «Что такое [Бренд]?»
   → проверяет **training data inclusion** (модель вообще знает бренд?).
2. **Category** — «Лучшие [категория] инструменты для [задача]», «Топ-альтернативы [Конкурент]»
   → проверяет, в **шортлисте** ли твой бренд.
3. **Comparison** — «[Бренд] vs [Конкурент]»
   → проверяет наличие и **тон**.
4. **Problem-aware** — «Как мне решить [проблему, которую решает бренд]?»
   → **самый сильный сигнал** товарного фита (бренд всплывает без упоминания имени).
5. **Niche / long-tail** — специфические запросы из реальных юз-кейсов клиентов.

### Прогон по 6 платформам

ChatGPT / Claude / Perplexity / Gemini / GigaChat / YandexGPT (+ Яндекс Нейро для РФ).
**Каждую платформу — отдельно** (логика выбора источников у всех разная).

**50-100 промптов × 6 платформ = базовый audit.**

Инструменты прогона:
- **Свой агрегатор LLM** (если есть) — прогон через несколько моделей разом.
- `multi-model-gateway` — кросс-модельный прогон.
- `perplexity` — для Perplexity-специфики (citations).
- Свой скрипт на API всех 6 платформ + crontab + Google Sheets/Метрика.

### Чек-лист «мой бренд попал в ответ?» (на каждый ответ)

- [ ] Бренд упоминается напрямую (текстом)?
- [ ] Бренд упоминается со ссылкой на оф. сайт?
- [ ] В каком источнике LLM нашёл бренд (Wikipedia / Reddit / личный сайт)?
- [ ] Тон описания (позитив / нейтрал / негатив)?
- [ ] Корректна ли информация (категория, USP)?
- [ ] Не путается ли LLM с конкурентом?
- [ ] Какие конкуренты упомянуты рядом?
- [ ] В какой позиции (первый / middle / последний)?

### Грабли ручного замера (полевой опыт, август 2026)

> Вес факта: наблюдения участника курса методология из группового чата — ручной прогон по
> вертикали клиник (тот же замер, что в `case-clinics-citation-patterns.md`). Не бенчмарк,
> а список мест, где ручной аудит врёт. Проверять на своём прогоне.

| Грабли | Что происходит | Что делать |
|---|---|---|
| **Модели дают разный толк** | Полезность убывала в порядке **GPT → Claude → Grok**; **Perplexity дал «одни глюки»** на этой задаче | Не считать все шесть платформ равноценными источниками *для замера*; проверять пригодность каждой на пилоте из 5–10 промптов до полного прогона |
| **Половину ответов модели выдумали** | Модель сочиняла отзывы/факты вместо того, чтобы тащить их из реальных источников; выловили **не сразу** — часть замера пришлось переделывать | Зашивать в промпт требование источника и проверку на галлюцинации **либо** делать отдельный фактчек-проход по ответам перед подсчётом метрик |
| **Несопоставимые настройки** | Разные модели и разный уровень effort/reasoning → ответы нерелевантны друг другу, сравнение теряет смысл | Фиксировать модель + уровень reasoning и держать их одинаковыми во всех прогонах; писать настройки в baseline рядом с датой |
| **Максимальный reasoning ломает прогон** | Продвинутые модели на **максимальном** reasoning **отказывались отвечать** | Работать на **стандартных** уровнях; максимальный оставлять для разбора отдельных ответов, а не для массового прогона |

> ⚠️ **Про Perplexity — не противоречие, а разные роли.** В `tactics.md` Perplexity описан как
> самый прозрачный движок (inline-citations, свежесть ×3.2) — это про Perplexity как **объект**
> GEO: его ответы мы хотим занять, а его citations читаем как карту целей. Здесь Perplexity
> провалился как **инструмент** сводного замера по многим брендам сразу. Обе роли живут
> одновременно: цитаты из Perplexity разбирать вручную, сводный прогон вести на других моделях.

Практический вывод: **ручной замер без фактчек-прохода даёт мусор примерно в половине строк.**
Метрика «Hallucinated URLs» из §1 ловит только часть этого — там про фейковые URL под твой бренд,
а здесь модель выдумывает сам контент ответа. Считать Citation Share по непроверенным ответам
нельзя: завышение идёт в обе стороны (и чужие упоминания, и свои).

→ что именно цитировалось в том замере и какие выводы по контенту из него следуют:
`case-clinics-citation-patterns.md`.

### Зачем прогон делать регулярным, а не разовым

LLM вероятностны: один и тот же промпт у разных людей и в разные дни даёт разные ответы и разные
источники — они то появляются, то исчезают. Отсюда **дистилляция источников**: гонять целевые
промпты **ежедневно** и брать **топ-30% источников, которые попадаются каждый день** — это доноры,
на которых модель держится в теме (дальше аутрич или платное размещение). Разовый замер такой
список не даёт вовсе, а квартальный пропускает подмену картины: массовые размещения начинают
влиять на ответы за 6–7 дней.

Ежедневный такт **усиливает требование фактчека** из таблицы выше: без него получится ежедневный
мусор — «источник, которого не существует», модель придумывает так же охотно, как отзыв.
→ механика и вес источника: `llm-mechanics-threats.md` §6, §8.

## 4. Бенчмарки по конверсии (зачем вообще GEO)

- ChatGPT B2B conversion: **14.2-15.9%** (vs Google organic 1.76-2.8%)
- Perplexity: 10.5% · Claude: 5% · Gemini: 3%
- Industry consensus: AI-трафик конвертит **в 4-14× выше** organic
- AI traffic share: ~1% от веба, но рост **+527% за 5 месяцев** (Jan→May 2025)

→ объём маленький, но качество и темп роста делают канал стратегически важным.
