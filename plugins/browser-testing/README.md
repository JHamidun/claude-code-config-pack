# Browser & Testing

> Browser automation (dev-browser, gstack, Playwright), webapp testing, test/perf agents.

Part of the **[hamidun marketplace](../../README.md)**.

## What's inside

| Skill | What it does |
|-------|--------------|
| `dev-browser` | Браузер с сохранением состояния страницы: формы, скриншоты, логин. |
| `gstack` | Быстрый headless-браузер (~100 мс) для QA: переходы, действия, дифф, скриншоты. |
| `playwright-automation` | Playwright: e2e-тесты, скрапинг + демон-браузер bdo.py (параллельные сессии). |
| `webapp-testing` | Проверка локального веб-фронта через Playwright: UI, скриншоты, консоль. |

### Agents

- `qa-specialist`
- `integration-tester`
- `performance-optimizer`
- `test-writer`

### Commands

- `/performance`

## Install

```text
/plugin marketplace add JHamidun/claude-code-config-pack
/plugin install browser-testing@hamidun
```

Enable it with `/plugin` — the skills then activate automatically when relevant.
