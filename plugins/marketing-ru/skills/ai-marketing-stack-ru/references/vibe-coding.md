# Vibe-coding для маркетолога

> Vibe-coding = описываешь намерение словами, AI пишет инструмент. Маркетологу не
> нужно уметь кодить — нужно уметь ставить задачу. Главный принцип:
> **«не увеличивать команду, а увеличивать количество AI-агентов»**.

---

## 1. Рецепты замены подрядчиков

### 1.1 Лендинг за $7 (30 лендингов за $200)

**Было:** лендинг под заказ у подрядчика = **249 000 ₽** за один.
**Стало:** ~$7/лендинг через vibe-coding → **30 лендингов за ~$200**.

```
Бриф (что нужно: оффер, ЦА, структура)
  → Cursor + Claude Code
  → Nano Banana / Gemini Image через fal.ai (или прямой Google AI Studio ключ)
  → standalone HTML / Vercel deploy
  → реальные продукты: example.vercel.app
```

Применение: лендинг под каждый сегмент/оффер/поток вашего продукта. Если уже есть
`tilda`, `website-creation`, `landing-page-effects`, `standalone-html` — vibe-coding
= программатический подход «30 лендингов под ЦА» поверх них.

### 1.2 Personal Data Warehouse за одну сессию

**Было:** $3K/мес дата-инженер. **Стало:** одна сессия.

```
Supabase (БД)
  → Notion (UI + дашборды)
  → Claude Code управляет всем
  → 3 OS: маркетинг, продажи, личные KPI
  → 1-10 AI-агентов под отдельные функции (управляются Claude Code)
```

«Построил DWH без data-инженера, без $3K/мес подрядчика, за одну сессию. Соединяет
маркетинг, продажи, личные KPI».

### 1.3 Email-агентство одним Claude Code

**Было:** целое email-агентство. **Стало:** один Claude Code.
CRM + переписка → draft рассылок в стиле компании → follow-up цепочки. Это
use-case #6 из Cursor-OS, доведённый до полной замены подрядчика.

### 1.4 AI-OS жизни за 9 дней

От пустого Claude Code до полной AI-OS жизни за **9 дней**: манифест →
инфраструктура → перелом мышления → personal DWH → замена email-агентства.
«OS для жизни и бизнеса», заменившая ~15 инструментов.

```
День 1-2:  манифест (что хочу автоматизировать) + базовая инфраструктура
День 3-5:  перелом мышления (перестаёшь делать руками, начинаешь ставить задачу AI)
День 6-7:  personal DWH (Supabase + Notion)
День 8-9:  замена конкретного подрядчика (email-агентство)
```

## 2. Карта сервисов вайбкодинга по категориям

Сервисов под вайбкодинг сотни, и половина умрёт за год. Держать в голове список
бессмысленно — держи категории и подбирай инструмент под задачу:

| Категория | Назначение |
|-----------|------------|
| **Code-gen / IDE** | Claude Code, Cursor, Lovable, RORC — генерация приложений |
| **No-code / hosting** | Vercel, Supabase — деплой и БД без DevOps |
| **Дизайн / UI** | генераторы интерфейсов, компонентов |
| **Шрифты / стили** | подбор типографики, цветовых систем |
| **3D** | генерация 3D-ассетов |
| **Копирайт** | тексты, офферы, посты |
| **Изображения** | Nano Banana / Gemini Image, Midjourney, DALL-E |
| **Базы данных** | Supabase, Notion как DWH |

> Конкретные инструменты по каждой категории — в [`ai-tools-catalog.md`](ai-tools-catalog.md),
> там же указано, какой навык пака закрывает задачу без внешнего сервиса.

## 3. Инструменты vibe-coding

| Инструмент | Что | Заметка |
|------------|-----|---------|
| **Claude Code** | терминальный AI-агент, «OS для жизни и бизнеса» | MCP, daily wrap-up, скрипты |
| **Cursor** | IDE-агент с памятью | см. `cursor-os.md` |
| **Lovable** | full-stack приложения по описанию | есть доступ из РФ |
| **RORC** | генерация приложений | community |
| **Vercel** | деплой standalone-приложений | хостинг лендингов |
| **Supabase** | БД для DWH и перелинковки | personal DWH |
| **Notion** | UI + дашборды + база знаний | связка с Claude Code |

### Подключение генерации изображений к Claude Code

- **fal.ai** — proxy к Nano Banana / Gemini Image: «сам Claude сказал, что у него
  прямее всех».
- **Прямой Google AI Studio ключ** — альтернатива с прозрачными ценами.
- Если у тебя уже есть `local-gateway` (HTTP 127.0.0.1:GATEWAY_PORT, 0 token spend) +
  `nano-banana-pro` — это предпочтительный путь, не нужен внешний proxy.

## 4. Что из этого уже есть в паке

Типовые задачи вайбкодинга закрыты навыками, которые уже стоят у тебя, — отдельные
самодельные скиллы под них заводить не надо:

| Задача | Навык пака |
|--------|------------|
| собрать лендинг | `website-creation`, `landing-page-effects` |
| ревизия архитектуры web-приложения | агент `code-reviewer`, агент `software-architect` |
| прототип с состоянием и формами | `interactive-prototype` |

Если встретишь чужой скилл под ту же задачу — прогони его через `skill-audit` до установки.

---

## 5. Принцип «плодить агентов, а не людей»

Главный стратегический тезис вайбкодинга:

- **1 агент = 1 формат / 1 функция** (машинка контента).
- Не нанимать SMM/копирайтера/дизайнера — собрать агента под каждую роль.
- Маркетолог становится **оркестратором AI-агентов**, а не исполнителем.

> Когда vibe-coded инструмент перерастает в **продакшн-бот** (Telegram, деплой,
> cron, клиент) — это agent-builder tooling (Hermes/OpenClaw). Vibe-coding
> здесь = быстрые ad-hoc инструменты «за одну сессию», не production-grade боты.
