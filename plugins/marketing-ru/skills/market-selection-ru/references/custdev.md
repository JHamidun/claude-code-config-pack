# CustDev: респонденты, карта эмпатии, дружба с конкурентами

Детальная механика этапа CustDev из эксперт. **Логистику самих интервью** (запись, транскрипция, Thematic Analysis, синтез) — см. `user-research-synthesis`. Здесь — что специфично для урока: где брать людей, карта эмпатии, и как через дружбу с конкурентами получить рыночную экспертизу бесплатно.

---

## Что такое CustDev и зачем

> **CustDev (Customer Development)** — исследование потребностей клиента с помощью «глубинных» интервью.

Две задачи на этом этапе:
1. **Услышать язык клиента** (для заголовков, креативов, оффера).
2. **Найти сегменты** — увидеть пересекающиеся ответы, потом проверить на большом объёме.

эксперт разделяет **коридорные интервью** (быстрые, для проверки гипотез на ходу) и полноценные **глубинные/UX-интервью**.

## 2. Пайплайн CustDev 

```
1. Найти респондентов        → таблица источников выше
2. Провести CustDev           → коридорные + глубинные интервью
3. Определить сегменты        → пересекающиеся ответы = гипотеза сегмента
4. Презентовать команде       → синхронизация по находкам
5. Проверить на объёме        → форма/анкета (Google Forms / Typeform)
                                + реклама на вычисленную аудиторию
                                → смотрим результаты
6. Тест спроса (см. ниже)
```

### Тест спроса (количественная проверка)

```
□ Протестировать одинаковые лендинги с РАЗНЫМИ заголовками
□ Сравнить CPQL (Cost Per Qualified Lead — стоимость квал. лида)
□ Провести CustDev (уточнить на основе данных)
□ Сделать креативы
□ Сделать сайт
□ Провести UX-тестирование
□ Сделать предложение лучше
```

> Внимание к деталям: даже **орфографическая ошибка в адресе на сайте** может снизить конверсию (пример из урока про траст).

## 3. Карта эмпатии клиента

Инструмент из Блока 1. Заполняется по 4 квадрантам — отделяет **декларируемое** от **реального** и вскрывает скрытые мотивы.

```
┌─────────────────────────┬─────────────────────────┐
│  ГОВОРИТ                 │  ДУМАЕТ                  │
│  (вслух, в интервью,     │  (про себя, не скажет    │
│   в отзывах)             │   прямо — страхи, сомнения)│
├─────────────────────────┼─────────────────────────┤
│  ДЕЛАЕТ                  │  ЧУВСТВУЕТ               │
│  (реальные действия,     │  (эмоции, фрустрации,    │
│   поведение, покупки)    │   радости)               │
└─────────────────────────┴─────────────────────────┘
```

**Как заполнять:**
- **Говорит** — прямые цитаты из интервью, отзывов, чатов.
- **Думает** — то, что человек НЕ озвучивает: «а вдруг разведут», «не разберусь», «дорого ли».
- **Делает** — наблюдаемое поведение (часто расходится с тем, что Говорит).
- **Чувствует** — эмоциональный фон: тревога, стыд, азарт, облегчение.

**Главная ценность:** разрыв между «Говорит» и «Делает» — это инсайт. Человек говорит «выбираю по качеству», а покупает самое дешёвое. Заголовок и оффер строятся под «Делает» и «Чувствует», а не под «Говорит».

> Для перевода находок карты эмпатии в формализованные **работы (Jobs)** и сегментацию по работам — переходи в `jtbd`.

## 4. «Дружить с конкурентами выгоднее, чем воевать»

Ключевой лайфхак урока. Вместо конкурентной войны — **учиться у маркетологов конкурентов** напрямую.

### Механика

1. Завести **чистый LinkedIn-аккаунт** (без явной привязки к вашему конкурирующему продукту).
2. Найти **маркетологов / фаундеров** конкурентов.
3. Зайти с угла: **«мы делаем не у вас на рынке, а в стране N — поделитесь опытом»**. Вы не угроза → охотно делятся.
4. Получить консалтинг по их же воронкам, метрикам, ошибкам — бесплатно.

> **Барьер — внутренний:** «А что он со мной будет общаться? Кто я такой?». Снять его — и рынок открывается.

### Кейс: разведка нового рынка через самих конкурентов

> Команда написала десятку крупнейших игроков своей ниши на целевом зарубежном рынке. Почти все согласились на встречу, отказался один. Конкуренты охотно делятся экспертизой, если вы выходите на другой рынок и не угрожаете им напрямую.

### Кейс траста: Forbes за 60 курсов

> Обменяли доступ к **60 курсам в записи** на **публикацию в Forbes стоимостью 1,5 млн ₽ — без денежных затрат**. Бартер ценностью вместо рекламного бюджета.

## 5. Построение траста и мультитач

Особенно важно на рынках с высоким уровнем мошенничества.

- Оптимизировать **Google Business**, собирать **отзывы** (с цифрами).
- Публиковать **пресс-релизы** (PRNewsWire) и отслеживать их KPI.
- Создавать **контент** (YouTube, Medium, HackerNoon).
- Нанять **локального бизнес-девелопера** + собрать **локальных адвайзеров** (маркетинг / продажи / продукт / управление командой).

### Правило 5-7 касаний

> По статистике пользователю нужно **5-7 взаимодействий**, чтобы совершить заказ. В день он получает **80+ рекламных касаний** — поэтому одно касание не работает.

Закладывайте мультитач: ретаргетинг (брошенные корзины, спецпредложения, другой дизайн посадочной), рассылки, вебинары, контент. Сценарии и метрики воронки — в `funnel-design-ru`.

> «Блинчики пока горячие» — эксперт про скорость обработки лида: реагировать надо быстро, пока интерес тёплый.
