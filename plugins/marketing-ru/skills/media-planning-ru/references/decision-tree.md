# Decision Tree — дерево решений выбора рекламного канала

> Справочник для скилла `media-planning-ru`. Источник: практика performance-эксперта + сквозной материал курса. Каждая ветка заканчивается КОНКРЕТНЫМ playbook'ом, который надо открыть.

---

## Полное дерево решений

```
START: бизнес хочет запустить платную рекламу
│
├─ ШАГ 1. B2C или B2B?
│   │
│   ├─ B2B (длинный цикл, узкий круг ЛПР)
│   │     → канал-цель: ЛПР, а не масса
│   │     → Google Search (intent) + LinkedIn Ads + Cold Outreach
│   │     → оптимизация под КВАЛИФИЦИРОВАННЫЙ лид, не просто лид
│   │     → ОТКРЫТЬ: google-ads-pro-ru (+ b2b-marketing-ru если есть)
│   │     [B2B обычно НЕ идёт в массовые соц-каналы под прямые продажи]
│   │
│   └─ B2C → ШАГ 2
│
├─ ШАГ 2. Рынок: РФ или международный/СНГ?
│   │
│   ├─ РФ → Google и Meta ОТПАДАЮТ (заблокированы/запрещены)
│   │       доступно: Яндекс / VK / Telegram / посевы → ШАГ 3
│   │
│   └─ Международный / СНГ → +Google +Meta +TikTok → ШАГ 3
│       [СНГ: Google ~70% / Яндекс ~30%; мир: Google 95%+]
│
├─ ШАГ 3. Есть ли СФОРМИРОВАННЫЙ спрос (люди ИЩУТ товар)?
│   │
│   ├─ ДА, ищут активно (есть запросы в поиске)
│   │     → ПОИСКОВЫЙ канал — ловим готовый интерес, объясняем «почему у нас»
│   │     ├─ РФ → ОТКРЫТЬ: yandex-direct-pro-ru (Поиск)
│   │     └─ Межд./СНГ → ОТКРЫТЬ: google-ads-pro-ru (Search)
│   │
│   └─ НЕТ, спрос надо СОЗДАВАТЬ (никто не ищет)
│         → СОЦ-канал — формируем интерес, прерываем внимание → ШАГ 4
│
├─ ШАГ 4. Цель кампании?
│   │
│   ├─ Лиды / продажи (PERFORMANCE)
│   │     → аукционный канал с оптимизацией под конверсию
│   │     ├─ Межд., есть событие/пиксель, доверяем алгоритму → ОТКРЫТЬ: meta-ads-launch-ru
│   │     ├─ РФ, низкий бюджет, ручная работа → ОТКРЫТЬ: vk-ads-pro-ru
│   │     └─ РФ, ретаргетинг/догрев на поиске → ОТКРЫТЬ: yandex-direct-pro-ru (РСЯ)
│   │
│   └─ Охват / узнаваемость (AWARENESS)
│         → охватный канал (часто без оптимизации под конверсию) → ШАГ 5
│
├─ ШАГ 5. Какой охватный канал?
│   │
│   ├─ Есть/нужен Telegram-канал, инфобиз/edtech/B2C-охват
│   │     → ОТКРЫТЬ: telegram-ads-pro-ru (еврокабинет 500€ / тонкабинет 20 TON)
│   │
│   └─ Нужно нативное ДОВЕРИЕ в нише, малый бюджет, эксперты
│         → Посевы/интеграции в ТГ-каналах, портфель 60/30/10 —
│           готового playbook в паке нет; закупка через биржи посевов
│           или напрямую у админов каналов
│
└─ ШАГ 6. ПРОВЕРКА БЮДЖЕТА (после выбора канала)
    │
    ├─ Бюджет < порога входа канала?
    │     → выбрать канал с низким порогом: VK / посевы / тонкабинет TG
    │     → ИЛИ не дробить — один канал вместо нескольких
    │
    └─ Бюджет ≥ порога?
          → проверить формулу: недельный бюджет ≥ средний CPL × 10
          → если не вытягивает 10 конверсий/нед — снизить цель или сменить канал
          → см. references/budget-allocation.md
```

## Быстрые сценарии (типовые ответы)

| Запрос пользователя | Ветка | Итоговый канал → playbook |
|---------------------|-------|---------------------------|
| «РФ интернет-магазин, люди ищут наш товар» | B2C → РФ → спрос есть | Яндекс.Директ Поиск → `yandex-direct-pro-ru` |
| «РФ, малый бюджет, нишевый продукт, нужно доверие» | B2C → РФ → спрос нет → awareness → доверие | Посевы в ТГ-каналах (playbook в пак не входит; закупка через биржи или напрямую у админов) |
| «Инфобиз на РФ, есть Telegram-канал» | B2C → РФ → спрос нет → awareness → канал | Telegram Ads → `telegram-ads-pro-ru` |
| «РФ, минимальный бюджет, всё руками» | B2C → РФ → низкий порог | VK Ads → `vk-ads-pro-ru` |
| «Выходим на Европу, B2C, есть пиксель» | B2C → межд. → performance | Meta Ads → `meta-ads-launch-ru` |
| «СНГ, люди гуглят наш продукт» | B2C → СНГ → спрос есть | Google Search → `google-ads-pro-ru` |
| «B2B SaaS, длинный цикл, узкие ЛПР» | B2B | Google + LinkedIn + Outreach → `google-ads-pro-ru` |

## Важные оговорки при выборе

- **Регион — жёсткий фильтр, не предпочтение.** РФ-проект физически не может рекламироваться в Google/Meta на РФ.
- **Наличие спроса важнее «модности» канала.** Если люди ищут — поиск дешевле и теплее, чем создавать спрос в соцсетях.
- **Один канал редко достаточен** (5-7 касаний). Дерево даёт ПЕРВЫЙ канал; дальше — омниканальность (см. SKILL.md Часть 8).
- **Компетенции команды** влияют: VK = много ручной работы; Meta = нужна антидетект-инфраструктура и риск-толерантность; Telegram Ads = нет автообучения, всё на выборе каналов.
- **После выбора — всегда переход в playbook канала.** Этот скилл доводит до решения, playbook запускает.
