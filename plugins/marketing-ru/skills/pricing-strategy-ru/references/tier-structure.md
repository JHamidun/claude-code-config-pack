# Структура тарифов и упаковка (RU)

Детальные структуры тарифов YourProduct + ценообразование воркшопа/консалтинга, персоны, trial vs курс, B2B-когорты. Конкретные цены ниже — **иллюстративные плейсхолдеры**: подставь свои из единого файла контекста бизнеса.

## Сколько тарифов?

- **2 тарифа:** простой выбор; риск оставить деньги на столе.
- **3 тарифа:** индустриальный стандарт. Good = вход, Better = рекомендованный (якорь к Best), Best = высокоценные. Для образовательного/подписочного продукта — модель Basic / Plus / Pro.
- **4+:** больше гранулярности при широком диапазоне; риск паралича выбора.

Пример линейки: подписка Basic/Plus/Pro + разовый флагманский курс + Concierge add-on + B2B-когорты + проектный консалтинг (вход = бесплатная консультация).

## Good-Better-Best (пример с плейсхолдер-ценами)

- **Basic = Good (X ₽/мес):** вход; базовые треки; снять барьер; для пробующих/B2C-профи на старте.
- **Plus = Better (Y ₽/мес, рекомендованный):** больше треков/симуляторов; якорная цена; где приземляется большинство; **founding-цена W ₽/мес пожизненно для первых N** — acquisition-двигатель.
- **Pro = Best (Z ₽/мес, ~2x от Plus):** все треки включая флагманский; максимум симуляторов; для серьёзно осваивающих/соло-премиум.
- **Годовая −20%** на всех тарифах.

## Дифференциация

- **Фиче-гейтинг треков:** базовые треки в Basic, premium-треки (флагманский, продвинутые) в Plus/Pro.
- **Симуляторы / AI-тьютор:** объём/глубина по тарифу.
- **Поддержка:** self → куратор (для B2B-когорт).
- **Доступ к инструментам/моделям:** включён в обучение (соцпруф/ценность, не отдельный продукт).
- **B2B:** командная аналитика, SSO/SAML/Google/Yandex, кураторы, именные сертификаты с QR (HR валидируют).

## Пример структуры (YourProduct, плейсхолдеры)

```
                  Basic            Plus               Pro
                  X ₽/мес          Y ₽/мес            Z ₽/мес
Треки             базовые          расширенный набор  все (вкл. флагманский)
Симуляторы        базовые          больше             все + продвинутые
AI-тьютор         ✓                ✓                  ✓ приоритет
Доступ к моделям  ✓ (включён)      ✓                  ✓
Сертификаты       ✓                ✓                  ✓ + именные с QR
founding-оффер      —                ✓ (первые N)       —
Годовая −20%      ✓                ✓                  ✓
```

Над тарифами: **флагманский курс разово** (Solo / Group / 1:1 с экспертом — три ценовых уровня, 1:1 фактически = консалтинг); **Concierge add-on** (+фикс/мес или +% — сервисное сопровождение клиента одним счётом в рублях, агентский договор).

## Упаковка под персоны

### Персоны (RU)
| Персона | Кто | Нужды | WTP |
|---------|-----|-------|-----|
| B2C-профи | специалист/маркетолог/предприниматель | системное освоение темы, сертификат | средняя (Basic/Plus) |
| Соло-премиум | хочет лично с экспертом | ментор под руку | высокая (Pro / флагман 1:1) |
| B2B-когорта | HR-директор/руководитель отдела | обучение команды, ROI, сертификаты | высокая (per-seat от 5) |
| Корп (консалтинг) | гендир/владелец | внедрение решения в процессы | проектная, высокая |

### Маппинг на продукты
Basic/Plus — B2C-профи; Pro / флагман 1:1 — соло-премиум; B2B-когорты (от 5, скидки 15-40%, SSO, кураторы) — командное обучение; консалтинг (диагностика→стратегия→внедрение) + Concierge — корп.

### Цена к ценности по персонам
Исследовать WTP по сегменту; отдельные лендинги под B2C (продукт) vs B2B (воркшоп/услуги); для корп вход = бесплатная консультация (квалификация перед проектной ценой).

## Trial vs курс vs подписка

### Trial 7 дней без карты (типовая модель входа в подписочный продукт)
Работает когда: продукт показывает ценность быстро (первая сессия симулятора/AI-тьютора); большой рынок где % конверсии даёт объём; чёткий момент апгрейда (конец trial).
Практики: 7 дней, полный доступ, без карты (снять трение), чёткий отсчёт + напоминания (день 5/6/7 → `paywall-cro-ru`). Для РФ — оплата после trial через платёжный провайдер (ЮKassa и т.п.), СБП/карты МИР.

### Разовый курс (флагманский продукт)
Завершаемый продукт с разовой ценой: Solo / Group / 1:1 — три уровня. Хорош для тех, кому нужен конкретный результат, а не постоянная подписка.

### Гибриды
Trial → подписка (основное); reverse trial (полный Pro-доступ в trial → даунгрейд на Basic-возможности после — хорошо тестируется, см. `onboarding-cro-ru`/`signup-cro-ru`); подписка + разовый апселл флагмана.

## B2B-когорты и консалтинг

### Когда вход = «бесплатная консультация» (не самообслуживание)
Корп-внедрения; кастом-программы воркшопа; обучение команд от 5 человек; требования безопасности/комплаенса; закупочные процедуры. Вход в B2B-воронку — заявка на бесплатную консультацию (квалификация → проектная цена).

### Элементы B2B-пакета
Table stakes: SSO/SAML/Google/Yandex, командная аналитика, админ-контроль, именные сертификаты, кураторы.
Value-adds: кастом-когорта, обучение под задачи компании, скидки 15-40% от 5 человек.

### Ценообразование воркшопа и консалтинга (`[TODO]` — откалибровать)
- **Воркшоп:** от формата (1 день — многонедельная программа) и числа участников (минимум 2). Конкретные цены не на сайте — не выдумывать, калибровать через WTP/конкурентов.
- **Консалтинг:** проектная цена под задачу (диагностика→стратегия→внедрение); прямой консалтинг-продукт = флагман 1:1 с экспертом.
- B2B-сделки и квалификация лидов ведутся через вашу CRM / продуктовую БД.
