# Learning Paths — 4 траектории «выучиться маркетингу на полную катушку»

Когда пользователь говорит «хочу выучиться маркетингу», «учебный план», «прокачаться в X», «маркетинг roadmap» — НЕ вываливай 23 скилла. Спроси цель (кем хочет стать) и выдай ОДНУ траекторию. Каждая — последовательность скиллов с пояснением «что освоить и зачем».

Материал — методическая выжимка по маркетингу; порядок изучения выстроен от рынка к каналам.

---

## Как выбрать траекторию (вопрос пользователю)

| Если цель / профиль | Траектория |
|---|---|
| Лить платный трафик, отвечать за CAC/ROAS, работать с кабинетами | **1. Performance-маркетолог** |
| Растить органику, видео, делать контент системой, видимость в поиске/AI | **2. Контент-маркетолог** |
| Длинный цикл, ЛПР, корпоративные продажи, аутрич | **3. B2B-маркетолог** |
| Отвечать за маркетинг целиком, строить команду, думать как CMO | **4. Рост-команда / CMO** |

Можно комбинировать: пройти базу (Слой 1 любой траектории) и углубиться в нужное. База у всех общая — **стратегия (market → JTBD → воронка)**.

---

## Траектория 1 — Performance-маркетолог

**Кем станешь:** специалист по платному трафику, который умеет выбрать канал, запустить и масштабировать кампании, настроить трекинг и принимать решения по когортной выручке, а не по CPL.

**Порядок:**

1. **База-стратегия** — `jtbd` + `funnel-design-ru`
   *Зачем:* без понимания работы клиента и типа воронки таргетинг бьёт «в пустоту». Освоить дерево метрик (CPM→CTR→CPC→CPL→CPA→LTV→CAC).
2. **Медиапланирование** — `media-planning-ru`
   *Зачем:* научиться выбирать канал под нишу/бюджет/гео/цель ДО запуска. Формула минимального недельного бюджета = ср. цена конверсии × 10, правило 5-7 касаний, аукционные vs неаукционные каналы. 
3. **Норматив** — `ad-benchmarks-ru`
   *Зачем:* держать в голове эталоны CTR/CPM/CPL по каналам, уметь отличить ботовода-подрядчика.
4. **Playbook'и каналов** (учить по релевантности рынку — РФ/международка):
   - `yandex-direct-pro-ru` — Директ от семантики до масштабирования: автостратегии, ЦДРР 100%, защита обучения, правило X3.
   - `google-ads-pro-ru` — для СНГ/международки: Quality Score, карта базисов, PMax, конструктор аудиторий.
   - `meta-ads-launch-ru` — Meta запуск: BM, Pixel, Lookalike-лестница, обучение, антидетект из РФ.
   - `vk-ads-pro-ru` — VK: Target Hunter, Метод А, зацепки.
   - `telegram-ads-pro-ru` — TG Ads: Target Channels/Users, RPP, воронки.
5. **Трекинг** — `capi-no-code-setup`
   *Зачем:* server-side события, CAPI, офлайн-конверсии, дедупликация. Без этого нельзя корректно оптимизировать.
6. **Аналитика** — `full-funnel-analytics-ru`
   *Зачем:* финальный навык — когортная воронка (12 шагов), predict LTV, выбор атрибуции, one-screen дашборд, 9-шаговый еженедельный анализ. Решения по полной воронке.

**Чек-поинт:** умеешь взять бизнес → выбрать канал → запустить → настроить трекинг → за 2-4 недели вывести из обучения → масштабировать по правилу X3 → отчитаться когортным дашбордом.

## Траектория 2 — Контент-маркетолог

**Кем станешь:** специалист по органике, который строит контент как фабрику (а не «постит ручками»), знает структуру виральных креативов, превращает просмотры в лиды и держит бренд видимым в поиске и в ответах AI.

**Порядок:**

1. **Что цепляет** — `jtbd`
   *Зачем:* контент попадает, когда говорит про работу клиента и силы прогресса (Push/Pull/Anxiety/Habit). База под хук.
2. **Фабрика контента** — `content-machine-ru`
   *Зачем:* операционка масштабирования — 6-шаговый pipeline (аккаунты → радар → трендвотчер → декомпозиция → AI-агенты 1 формат=1 агент → автоворонки), unit-экономика, KPI «лиды из SMM», roadmap 0-3-6-12 мес.
3. **Структура креатива** — `ai-creative-factory-ru`
   *Зачем:* хук, 5-блочный канон, дофаминовые триггеры, anti-AI-slop, декомпозиция виральных образцов, A/B 6-8 креативов. (Сама генерация видео/картинок — в `video-generation`/`image-generation`.)
4. **Лиды из органики** — `manychat-funnel-ru`
   *Зачем:* механика «комментарий → автосообщение в директ → прогрев → лид». Разные ключевые слова под каждый оффер.
5. **Поисковая видимость** — `ai-seo-agent-pipeline`
   *Зачем:* программатическая SEO-фабрика на n8n+Perplexity+OpenAI, сотни страниц под long-tail.
6. **LLM-видимость** — `geo-aeo-ru`
   *Зачем:* как попасть в ответы ChatGPT/Perplexity/GigaChat/YandexGPT, Citation Share, llms.txt, Princeton GEO +30-40%.

**Чек-поинт:** умеешь развернуть контент-фабрику, декомпозировать виральное видео в свой формат, поставить автоворонку коммент→директ и измерить «лиды из SMM», плюс держать бренд видимым в поиске и AI-ответах.

## Траектория 3 — B2B-маркетолог

**Кем станешь:** специалист по длинному циклу — ICP, нелинейная воронка TOFU/MOFU/BOFU, холодный мультиканальный аутрич с правильной инфраструктурой, B2B-контент и стыковка с отделом продаж.

**Порядок:**

1. **Рынок** — `market-selection-ru`
   *Зачем:* в B2B критичен правильный рынок/ниша/гео и понимание экономики (TAM, 20 вопросов фаундерам похожих бизнесов).
2. **JTBD для B2B** — `jtbd`
   *Зачем:* ICP строится на работах, которые нанимает компания, а не на демографии. Switching costs, силы прогресса в корпоративной закупке.
3. **B2B-система** — `b2b-marketing-ru` — ядро траектории:
   - воронка TOFU/MOFU/BOFU вместо AIDA, intent-сигналы, диагностика «пустого MOFU», план 30-60 дней;
   - cold outreach: 5-блочное письмо, цепочка 4-7 писем, мультиканал email+LinkedIn+звонок, инфраструктура (отдельные домены, прогрев, SPF-DKIM-DMARC, Liquid Blocks), бенчмарки;
   - B2B-контент: 33/33/33 корпоративный/экспертный/личный, PDF-карусели, структура поста, 3 стадии алгоритма LinkedIn.
   *Усиление из стека:* `lead-research` (список лидов по ICP) → `draft-outreach` (конкретное письмо).
4. **Продажи** — `sales-team-ru`
   *Зачем:* куда передаётся B2B-лид — скрипты, 19 критериев звонка, отработка возражений (Крис Восс), AI-разбор звонков, категоризация лидов A/B/C, SLA.
5. **Аналитика** — `full-funnel-analytics-ru`
   *Зачем:* длинный цикл → атрибуция Multi-Touch / Last Non-Brand Click, когорты по месяцам, офлайн-конверсии из CRM, predict LTV.

**Чек-поинт:** умеешь собрать ICP, развернуть outreach-инфраструктуру (домены+прогрев), написать 5-блочную цепочку, наполнить MOFU контентом, передать лид в продажи и измерить по длинному циклу.

## Траектория 4 — Рост-команда / CMO

**Кем станешь:** человек, отвечающий за маркетинг целиком — стратегия, выбор каналов, найм команды, отдел продаж, управление по цифрам. Не один навык, а система.

**Порядок:**

1. **Рынок и модель** — `market-selection-ru`
   *Зачем:* CMO начинает с «где играем» — рынок, страна, бизнес-модель, TAM, венчур vs lifestyle.
2. **Воронка как система** — `funnel-design-ru`
   *Зачем:* дерево метрик, 8 типов воронок, категоризация лидов A/B/C/D, анти-паттерн «перлидоз». Видеть всю экономику на одном дереве.
   *(JTBD `jtbd` — обязательная подложка под воронку.)*
3. **Медиа-стратегия** — `media-planning-ru`
   *Зачем:* channel mix, распределение бюджета между каналами, омниканальность, performance vs awareness. Решать «куда вкладывать», не уходя в ручную настройку.
4. **Команда** — `marketing-team-builder-ru`
   *Зачем:* карта 35 ролей маркетинга в 3 блоках + AI-роли (GTM engineer, vibe-coders), подготовка перед наймом, правило 3-4 каналов сорсинга, тестовое, план 30/60/90, фикс+KPI. Когда рост требует рук — кого и как нанять.
5. **Отдел продаж** — `sales-team-ru`
   *Зачем:* найм продавцов, РОПы, мотивация 3/5/9%, нормативы 120/120, дозваниваемость, контроль, AI-разбор звонков.
6. **Управление по цифрам** — `full-funnel-analytics-ru`
   *Зачем:* язык CMO — когортная выручка, predict LTV, ROAS-дашборд, еженедельный 9-шаговый анализ, сверка CRM и кабинетов.

**Поверх траектории (постоянные усилители):**
- `ai-marketing-stack-ru` — Cursor/vibe-coding автоматизирует 70% рутины команды.
- `marketing-masterminds-ru` — 7 разобранных кейсов + 15 нестандартных тактик для нетривиальных ходов.
- `ad-benchmarks-ru` — держать нормативы под рукой, контролировать подрядчиков.

**Чек-поинт:** можешь собрать маркетинг-функцию с нуля — выбрать рынок и каналы, спроектировать воронку, нанять команду по 35-ролевой карте, построить отдел продаж и управлять всем по когортному дашборду.

## Общая последовательность освоения (если «всё подряд»)

Если пользователь хочет «выучиться полностью» без специализации — общий порядок от фундамента к надстройке:

1. **Фундамент (всем):** `market-selection-ru` → `jtbd` → `funnel-design-ru`.
2. **Каналы:** `media-planning-ru` + `ad-benchmarks-ru` → playbook'и по релевантности.
3. **Контент/органика:** `ai-creative-factory-ru` → `content-machine-ru` → `manychat-funnel-ru`.
4. **Поиск/AI-видимость:** `ai-seo-agent-pipeline` + `geo-aeo-ru`.
5. **B2B (если нужен):** `b2b-marketing-ru`.
6. **Трекинг и аналитика:** `capi-no-code-setup` → `full-funnel-analytics-ru`.
7. **Продажи и команда:** `sales-team-ru` → `marketing-team-builder-ru`.
8. **Усилители (всё время):** `ai-marketing-stack-ru`, `marketing-masterminds-ru`.

> Совет оркестратору: не грузи всё сразу. Веди пользователя по одной траектории, на каждом шаге давай практику (своя ниша / свой продукт), сверяйся с чек-поинтом, потом следующий скилл.
