# Психология маркетинга: применить, а не пересказать

Скилл превращает каталог психологических принципов (Чалдини, Канеман, Фогг, поведенческая экономика — полный список в `references/models-catalog.md`) в **конкретные правки конкретного артефакта**: лендинга, оффера, письма, попапа, прайс-блока, онбординга. Выход — таблица «принцип → правка (было→стало) → место», а не лекция.

## Когда использовать

- «Прогони мой лендинг/оффер/письмо/попап через психологию» — есть артефакт, нужно усилить убеждение.
- «Почему не покупают / бросают корзину / не доходят до конца trial» — диагностика поведения через модели.
- «Как подать цену / скидку / дефицит, чтобы работало и было этично».
- «Какие принципы использовать для доверия / срочности / удержания» — подбор моделей под вызов.
- Спарринг по стратегии: узкое место роста, второй порядок последствий, штанга бюджета.

НЕ использовать: полноценный CRO-аудит структуры страницы (`page-cro-ru` и др. `*-cro-ru`), построение тарифной сетки (`pricing-strategy-ru`), JTBD-исследования (`jtbd`), написание постов (`tg-post`/`habr-post`/`vc-post`).

## Процедура: применить психологию к [лендингу / офферу / письму / попапу]

**Шаг 1. Определи точку применения и собери входы.**

- Артефакт: текст/скрин/URL (лендинг, оффер, письмо, попап, прайс-блок, онбординг-экран).
- Контекст продукта: что продаём, ICP и его боли, цены, есть ли trial (спроси или возьми из контекст-файла бренда, если есть).
- Стадия воронки: охват → прогрев → деньги → удержание.
- Целевое действие: ЧТО ИМЕННО должен сделать человек (клик, заявка, оплата, возврат).

**Шаг 2. Диагностика — ответь на 5 вопросов.**

1. Какое поведение хотим изменить?
2. Во что аудитория верит ДО встречи с этим артефактом?
3. На какой стадии воронки человек?
4. Что сейчас мешает целевому действию (мотивация ↓ / способность ↓ / нет триггера — по Фоггу)?
5. Что из утверждений проверено на клиентах, а что — гипотеза?

**Шаг 3. Прогони чек-лист принципов.**

- Возьми строку из таблицы «Вызов → модели» (ниже) под диагноз из Шага 2.
- Открой `references/models-catalog.md`, пройди релевантные разделы (для лендинга/попапа минимум: разделы 2, 3, 5; для цены: + раздел 4; для стратегии: раздел 1).
- Для каждого принципа задай вопрос: «Нарушен? Не использован? Использован фальшиво?» Отбери 4–8 применимых — не все 70.

**Шаг 4. Для каждого отобранного принципа — конкретная правка «было → стало».**

- Цитируй реальный фрагмент артефакта («было»), пиши готовую замену («стало»), указывай точное место (хедер, CTA, прайс-блок, subject, 2-й абзац).
- Правка должна быть вставляемой копипастом, не советом «добавьте соцпруф».

**Шаг 5. Этика-фильтр.**

- Дефицит/срочность/дефолты — только настоящие (реальный лимит мест, реальный дедлайн, реально выгодный предвыбор). Фальшивое — вычеркни или замени честным аналогом.

**Шаг 6. Собери выход.**

- Таблица «принцип → правка → место» (шаблон ниже) + пометь, какие правки — проверенные паттерны, а какие — гипотезы под A/B (`ab-testing-ru`).
- Отсортируй по ожидаемому эффекту: сначала то, что чинит главный блокер из Шага 2.

## Выход

Артефакт: **таблица правок** + список гипотез под тест. Шаблон (копипаст):

```markdown
## Психо-правки: [артефакт] — [продукт], цель: [целевое действие]

Диагноз (Фогг): [мотивация ↓ / способность ↓ / нет триггера] — [1 фраза почему]

| # | Принцип | Было | Стало | Место | Статус |
|---|---------|------|-------|-------|--------|
| 1 | [принцип из каталога] | «[цитата]» | «[готовый текст]» | [хедер/CTA/…] | паттерн / A/B-гипотеза |
| 2 | … | … | … | … | … |

Этика-фильтр: [что вычеркнуто/заменено и почему]
Первым тестировать: #[N] — [почему именно он бьёт в главный блокер]
```

## Пример (вход → выход)

**Вход:** попап выхода на лендинге YourProduct (подписка на курс, 1 990 ₽/мес, trial 7 дней без карты). Текст попапа: «Подпишитесь на нашу рассылку, чтобы не пропустить новости». Цель — заявка на trial. Диагноз: триггер есть (попап), мотивация не создана, просьба не про целевое действие.

**Выход:**

| # | Принцип | Было | Стало | Место | Статус |
|---|---------|------|-------|-------|--------|
| 1 | Эффект нулевой цены + неприятие сожаления | «Подпишитесь на рассылку» | «Попробуйте 7 дней бесплатно — без карты, отмена в один клик» | заголовок попапа | паттерн |
| 2 | Эффект Зейгарник | — (нет) | «Вы уже посмотрели программу — осталось одно: увидеть её изнутри» | подзаголовок | A/B-гипотеза |
| 3 | Соцпруф | — (нет) | «2 400+ участников уже учатся» (реальная цифра!) | под CTA мелким | паттерн |
| 4 | Закон Хика | 2 кнопки («Подписаться», «Скачать гайд») | одна кнопка «Начать бесплатные 7 дней» | CTA | паттерн |

Этика-фильтр: не добавляем таймер «предложение сгорит через 10 минут» — дедлайна нет, это фальшивая срочность. Первым тестировать: #1 — чинит главный блокер (просьба не соответствовала целевому действию).

## Чек-лист (перед сдачей)

- [ ] Точка применения и целевое действие названы явно (Шаг 1), диагноз по Фоггу поставлен.
- [ ] Отобрано 4–8 принципов под диагноз, а не свалка из всего каталога.
- [ ] Каждая правка — «было (цитата) → стало (готовый текст) → место», вставляема копипастом.
- [ ] Все цифры соцпруфа/дефицита — настоящие или помечены «подставить реальную цифру».
- [ ] Фальшивая срочность/дефицит/тёмные паттерны вычеркнуты (этика-фильтр отработал).
- [ ] Гипотезы отделены от проверенных паттернов; указано, что тестировать первым.
- [ ] Если задача оказалась про структуру страницы целиком / тарифы / JTBD — передана в `page-cro-ru` / `pricing-strategy-ru` / `jtbd`.

## Быстрая сводка: вызов → модели

| Вызов | Модели |
|-------|--------|
| Низкая конверсия | закон Хика, энергия активации, Фогг, трение |
| Возражения по цене | якорение, фрейминг, ментальный учёт, loss aversion |
| Доверие | авторитет, соцпруф, взаимность, pratfall |
| Срочность | дефицит (настоящий!), loss aversion, Зейгарник |
| Удержание/отток | эффект владения, издержки переключения, статус-кво |
| Рост стагнирует | теория ограничений, локальный/глобальный оптимум, компаундинг |
| Паралич выбора | парадокс выбора, дефолт, nudge |
| Онбординг | градиент цели, эффект IKEA, коммитмент |

## Этика

Дефицит, срочность, дефолты — только настоящие. Манипулятивная срочность и ложный дефицит ломают доверие и LTV дороже, чем дают конверсии. Влияем, не обманываем: каждый принцип из каталога применим честно — если честного применения нет, принцип к этому артефакту неприменим.
