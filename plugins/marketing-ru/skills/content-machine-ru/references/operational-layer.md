# Operational layer — экономика, KPI, roadmap фабрики

То, что превращает «постить контент» в управляемую производственную систему по эксперту. Фабрика как **бизнес внутри бизнеса** — со своей unit-экономикой, KPI-иерархией и roadmap. Этот файл — для разворачивания машинки **под клиента** (консалтинг-продукт по образцу `kp-deck-factory`) и **под свой бизнес**.

---

## 1. «Плодить агентов, а не команду» — архитектурный принцип

> **«Не увеличивать команду — увеличивать количество агентов.»** — эксперт,.

Это не лозунг, а способ устройства производства. Сравнение двух моделей масштабирования объёма контента:

| | Старая модель (люди) | Машинка (агенты) |
|--|---------------------|------------------|
| Как растёт выпуск | +1 человек = +N единиц | +1 формат-агент = +формат на потоке |
| Стоимость единицы | растёт/плато | **падает** со временем |
| Скорость найма | недели-месяцы | часы (спека → агент) |
| Бутылочное горлышко | люди | **число оцифрованных форматов** |
| Качество | зависит от человека | зависит от спеки + anti-AI-slop |

**Следствие для штатного расписания.** Команда фабрики почти **не растёт**. Растёт:
- число форматов, превращённых в агентов,
- число инстансов агента на рабочий формат.

**Минимальная команда фабрики (роли, не обязательно люди 1:1):**
- **Оператор фабрики** — держит радар, трендвотчинг, ведёт реестр форматов-агентов, метрики.
- **Режиссёр/монтажёр** — финальная сборка, anti-AI-slop, «ритм» (часто полу-автоматизируется).
- **Архитектор агентов** — превращает рабочий формат в спеку агента (`ai-marketing-stack-ru` / `autonomous-agent-creator`).
- **Воронщик** — comment→DM flow в ManyChat (`manychat-funnel-ru`), связка контент→flow.

> При росте спроса добавляй **форматы-агенты**, а не дублирующих людей. Человек подключается там, где нужен вкус/режиссура/качество — не там, где нужен объём.

## 2. Unit-экономика фабрики

**Главная формула (упрощённо):**

```
CPL_органика = (стоимость_команды + стоимость_инструментов + платный_разгон) / лиды_из_SMM
```

Где:
- **стоимость_команды** — почти константа (не растёт пропорционально объёму, см. §1);
- **стоимость_инструментов** — LiveDune, трендвотчер, ManyChat (~$20/мес), Apify-ключ, генераторы;
- **платный_разгон** — опциональный буст органики через посевы (`tg-channel-buyout-ru`);
- **лиды_из_SMM** — главная метрика (знаменатель растёт со временем → CPL падает).

**Динамика CPL по времени:**

```
CPL
 │\
 │ \____           старт: дорого (мало форматов-агентов, нет накопленного актива)
 │      \____
 │           \________      рост: агенты тиражируют форматы, база подписчиков растёт
 │                    \_____________  плато → себестоимость (команда + инструменты)
 └───────────────────────────────────► время (0 → 12 мес)
      ▲ break-even: CPL_органика ≤ CPL_платных_каналов
```

**Break-even.** Точка, где CPL органики становится ≤ CPL платных каналов. После неё фабрика — **чистый рычаг**: каждый дополнительный лид дешевле платного. Это и есть момент, когда «контент-фабрика» окупила разворачивание.

**Что считать при разворачивании под клиента:**
1. Целевой объём лидов/мес и продукт, который их монетизирует.
2. Себестоимость: команда (фикс) + инструменты (подписки) + разгон (если нужен).
3. Прогноз падения CPL по месяцам (0-3-6-12) и месяц break-even.
4. Сравнение с текущим CPL платных каналов клиента → когда фабрика дешевле.

## 3. KPI-иерархия

Дашборд фабрики строится **сверху вниз** — от единственной целевой метрики к производственным.

| Уровень | Метрика | Норма / сигнал |
|---------|---------|----------------|
| 🥇 **Главная** | **Лиды из SMM** (→ продажи) | Растёт мес-к-мес; десятки % лидов уже на 10-15K подписчиков |
| 🥈 **Воронка** | CR `comment → DM` | Здоровье автоворонки; падение → проблема в триггере/flow |
| 🥈 **Воронка** | CR `DM → регистрация/лид` | Качество прогрева в директе |
| 🥉 **Производство** | Единиц/неделю на формат | Загрузка агентов |
| 🥉 **Производство** | Стоимость единицы контента | Эффективность; должна падать |
| 🥉 **Производство** | Форматов оцифровано в агентов | Снятие бутылочного горлышка объёма |
| 📊 **Прокси** | Просмотры, ER, виральность | **Ранний сигнал, НЕ цель.** Высокие просмотры без лидов = воронка сломана |

> Главная ловушка: оптимизировать прокси (просмотры/охваты) вместо лидов. Просмотры — **прокси-метрика**. Если просмотры растут, а лиды нет — чинить воронку (шаг 6), а не гнаться за охватами.

**Бенчмарк эксперта:** с **10-15K подписчиков** десятки процентов лидов могут приходить из SMM — при работающей ManyChat-воронке.

## 4. Roadmap 0-3-6-12 месяцев

Разворачивание фабрики как поэтапный проект. Это и есть структура **консалтинг-предложения клиенту**.

### 0 мес — Аудит и радар
- [ ] Аудит ниши + смежных ниш, цель и продукт-монетизатор.
- [ ] Собран пул **100-500 аккаунтов** (`monitoring_accounts.csv`).
- [ ] Поднят **аккаунт-радар** (чистая гигиена, отдельный аккаунт).
- [ ] Выбран трендвотчер (trndwtch / virlo / meedro / свой vibe-code).
- [ ] Зафиксирована метрика №1: лиды из SMM; baseline текущего CPL платных каналов.

### 3 мес — Первые форматы и лиды
- [ ] 2-3 **рабочих формата** стабильны (по результатам трендвотчинга + декомпозиции).
- [ ] Первые автоворонки comment→DM запущены.
- [ ] **Первые лиды из SMM** — есть атрибуция.
- [ ] Anti-AI-slop встроен в production (контент не «палится»).

### 6 мес — Конвейер на агентах
- [ ] Под каждый рабочий формат — **свой AI-агент** (1 формат = 1 агент).
- [ ] Объём контента **не упирается в людей** — упирается в число форматов-агентов.
- [ ] CPL органики устойчиво **падает**; видна траектория к break-even.
- [ ] Несколько flow в ManyChat под разные офферы.

### 12 мес — Самоокупаемый актив
- [ ] **Самоокупаемый медийный актив**: CPL органики ≤ платных каналов (break-even пройден).
- [ ] Фабрика — **отдельный канал продаж**, а не «дополнение к SMM».
- [ ] Актив переживает смену продукта (можно монетизировать новыми офферами).
- [ ] Стратегическая устойчивость на следующие 6-12 мес.

## 6. Troubleshooting

| Симптом | Причина | Что делать |
|---------|---------|-----------|
| Просмотры растут, лидов нет | Воронка не настроена / нет CTA-триггера | Чинить шаг 6, добавить comment-keyword flow |
| Лента радара «грязная» | Радар используется как личный аккаунт | Завести отдельный чистый аккаунт под одну нишу |
| Контент «палится» как AI | Нет anti-AI-slop | Кодек/апскейл/замена аудио/монтаж (`ai-creative-factory-ru`) |
| Объём упирается в людей | Форматы не оцифрованы в агенты | Перейти на «1 формат = 1 агент», нанимать агентов, не людей |
| CPL не падает | Мало форматов-агентов / нет накопления базы | Тиражировать рабочие форматы, добавить форматы |
| Мало виралок на входе | Пул < 100 аккаунтов или только конкуренты | Расширить пул до 100-500, добавить смежные ниши/блогеров/экспертов |
