# B2B-маркетинг: воронка + cold outreach + контент (RU)

Исполняемый playbook построения B2B-системы привлечения: воронка целиком, холодный аутрич с
инфраструктурой и контент-машина.

Главный тезис: **в B2B никогда не работает один канал — работает вся система.** Компании пытаются
чинить отдельные каналы (переписать холодные письма, запустить рекламу), а проблема находится
уровнем выше — в том, как устроена вся система привлечения.

> **Не выдумывай.** Все цифры и бенчмарки — из методологии источника или из данных пользователя.
> Если цифры нет — скажи «нет данных», а не придумывай.

---

## Когда использовать

- «Построй/диагностируй B2B-воронку», «почему аутрич не работает», «reply rate 1%», «пустой MOFU».
- «Запусти холодную рассылку с нуля»: инфраструктура (домены, прогрев, SPF/DKIM/DMARC) + цепочка писем.
- «Собери/обнови ICP», «intent-сигналы», «на кого таргетироваться».
- «Как вести B2B-контент в LinkedIn», «контент-план для B2B-команды».
- Диагностика: «сделали 2-3 касания и бросили», «маркетинг и продажи живут отдельно», «письма падают в спам».

**НЕ для этого скилла** (границы со смежными):

| Задача | Скилл | Почему не сюда |
|--------|-------|----------------|
| Написать одно конкретное письмо/прогрев конкретному ЛПР, research-first | `draft-outreach` | там копирайт конкретного письма; **здесь** — методология шаблона + каденция + инфраструктура |
| Построить список лидов по ICP, обогатить, скоринг | `lead-research` | там сбор базы; **здесь** — ICP-карточка как методология + intent-сигналы |
| Обогатить ОДИН аккаунт перед звонком | `account-research` | там single-account intel |
| Лайфсайкл MQL→SQL, хэндофф маркетинг→продажи, CRM-операции | `revops-ru` | там lifecycle и handoff; **здесь** — учёт касаний как SLA |
| Личный бренд фаундера/эксперта в LinkedIn | `linkedin-post-writer` (режим CONTENT PLANNER) | там персональный бренд; **здесь** — контент B2B-команды |
| Универсальная теория воронок (дерево метрик, 8 воронок) | `funnel-design-ru` | там общий фреймворк; **здесь** — специализация под B2B |
| Серверный трекинг LTV/событий длинного цикла | `capi-no-code-setup` | там CAPI |

## Процедура

**Шаг 0. Определи режим.** Спроси/выведи из запроса: (а) запуск системы с нуля, (б) диагностика
существующей, (в) только цепочка писем + инфраструктура, (г) только контент. Для (в) выполняй
шаги 1, 4-5; для (г) — шаги 1, 6; иначе — все.

**Шаг 1. Собери входы.** Минимум: продукт и его ценность в цифрах; рынок/география; есть ли
платящие клиенты (сколько, кто); текущие каналы и их метрики (open/reply rate, касания);
CRM и что в неё стекает. Чего нет — помечай «нет данных».

**Шаг 2. ICP.** Заполни **ICP-карточку** (шаблон в «Выход»). Если есть клиенты: топ-10 из CRM →
короткие интервью → повторяющиеся паттерны (вопросы — `references/funnel-tofu-mofu-bofu.md`).
Если нет: гипотеза по конкурентам + look-alike → пометь «гипотеза, тест на 100-200 лидах».
Добавь intent-сигналы (рост штата, фондинг, смена роли, вакансии). Один чёткий сегмент, не
«CMO в компаниях 50+». Список лидов дальше строит `lead-research`.

**Шаг 3. Карта воронки TOFU/MOFU/BOFU.** Разложи все текущие каналы/контент по трём этапам,
заполни **карту воронки** (шаблон в «Выход»). Прогони диагностику 6 ошибок
(`references/funnel-tofu-mofu-bofu.md`): продажа на TOFU, пустой MOFU, outreach без контента,
широкий ICP, нет follow-up, разрыв маркетинг↔продажи. Для каждого гэпа — конкретное действие.

**Шаг 4. Инфраструктура аутрича** (`references/cold-outreach.md`): отдельные домены (НЕ основной),
2-3 ящика на домен, прогрев 2-4 недели, SPF/DKIM/DMARC + custom tracking domain, выбор
sequence-сервиса, интеграция всех касаний в одну CRM. Зафиксируй как чек-план с датами.

**Шаг 5. Цепочка писем.** Собери цепочку 4-7 касаний по **шаблону цепочки** (в «Выход»):
каждое письмо = 5 блоков (Subject / персонализация по компании / ценность в цифрах / ОДИН CTA /
P.S.), каденция «#1 → +1 день → +3 дня → +4-5 дней break-up», мультиканал (LinkedIn-просмотр →
коннект → сообщение → email → звонок). Финальный копирайт конкретного письма — `draft-outreach`.

**Шаг 6. Контент-план** (`references/b2b-content.md`): недельный цикл (Пн экспертный / Ср личный /
Пт кейс-корпоративный), микс 33/33/33, структура поста «хук → история → инсайт → вывод → CTA».
Черновики прогони через `linkedin-humanizer` / `de-ai-ify`.

**Шаг 7. Учёт касаний как SLA + план ревизии.** Зафиксируй в CRM минимум касаний: SMB 20-25 /
Enterprise 60+ (до 200). Запиши план на 30-60 дней: обновить ICP, сверить метрики с бенчмарками
(`references/cold-outreach.md`), удлинить цепочки, выровнять маркетинг↔продажи.

**Шаг 8. Проверь по чек-листу** (ниже) и выдай пакет артефактов из «Выход».

## Методология (ядро)

### 4-элементная B2B-система

1. **ICP** — кому продаём (главный элемент).
2. **Каналы привлечения** — где о нас узнают.
3. **Trust layer** — где проверяют, можно ли верить (сайт, кейсы, профили LinkedIn, сравнения).
4. **Конверсия** — где принимается решение (демо, триалы, КП).

AIDA в B2B устарела: путь нелинеен, **80% пути клиент проходит без нас** (сам читает, сравнивает,
спрашивает коллег), решает buying committee. Задача маркетинга — не «управлять лидами», а
расставить точки контакта по невидимому пути ресёрча.

### Карта каналов по этапам

| Этап | Задача | Контент / инструменты |
|------|--------|----------------------|
| **TOFU** (узнавание) | попасть в поле зрения. НЕ продаём | личный LinkedIn фаундера/команды, посты, комментарии, мини-кейсы, SEO/GEO, нишевой PR, подкасты, выступления |
| **MOFU** (прогрев) | доверие: «решит ли продукт мою проблему?» | real-time кейсы (карусели), мини-воркшопы 30 мин, evergreen email-цепочки 3-5 писем, контент про экспертизу |
| **BOFU** (решение) | снизить риски: «почему именно вы?» | триалы, интерактивные демо / Loom-ролики, comparison pages, ревью клиентов, follow-ups |

Ключевые правила: профиль LinkedIn = «новый лендинг» (смотрят ДО сайта); 20-30 мин/день
комментариев = +100-200 просмотров/неделя; нишевой PR > широкий; **главная ошибка — пустой MOFU**;
демо не должно быть барьером (self-service + Loom).

### 5 блоков холодного письма

| # | Блок | Правило |
|---|------|---------|
| 1 | **Subject Line** | = 70% успеха. Коротко, без эмодзи и слов-триггеров («скидка», «бесплатно») |
| 2 | **Персонализация** | по КОМПАНИИ, не по человеку: факт, подтверждающий ресёрч (филиалы, запуск направления, партнёрство) |
| 3 | **Ценность** | конкретная, привязана к боли, измеримая, с кейсом |
| 4 | **CTA** | ВСЕГДА ОДИН, без выбора из двух опций |
| 5 | **P.S.** | усилитель ответов («если это решает коллега — подскажете, кому написать?») |

Цепочка 4-7 писем: **60% ответов приходят после 2-3 письма**; 90% компаний останавливаются на
3 письмах → удлинить цепочку = quick-win. Принципы: письмо про клиента, а не про вас; первое
письмо не продаёт; **релевантность > творчества**.

### B2B-контент

Инструмент доверия, не продаж. 3 типа (микс 33/33/33): корпоративный (масштаб и зрелость),
экспертный («на одном языке» с рынком), **личный — самый сильный** (истории, уроки, самоирония).
Формат №1 в LinkedIn — PDF-карусели. Регулярность важнее частоты, контент работает накопительно.
Главная ловушка — AI без редактуры = обезличенность.

→ Детали: `references/funnel-tofu-mofu-bofu.md` (ICP, intent, 6 ошибок, план 30-60 дней),
`references/cold-outreach.md` (домены/прогрев/DNS, Tier-сегментация, бенчмарки),
`references/b2b-content.md` (форматы, алгоритм LinkedIn, ошибки).

## Выход

Итоговый пакет = 3 артефакта (+ план ревизии). Копируй скелеты и заполняй.

### Артефакт 1. ICP-карточка

```markdown
## ICP-карточка — [YourProduct]
Дата: [YYYY-MM-DD] · Источник: [интервью топ-10 клиентов CRM / гипотеза → тест 100-200 лидов]
Следующее обновление: [через 1-3 мес]

| Поле | Значение |
|------|----------|
| Индустрия | [напр. ритейл-сети] |
| География | [напр. DACH] |
| Размер компании | [напр. 50-500 сотрудников, 20+ филиалов] |
| Бюджет | [сумма, готовая тратиться на решение] |
| Decision Maker | [кто РЕАЛЬНО принимает решение; пользователь ≠ ЛПР] |
| Боли | [1-3 конкретные проблемы, которые решаем] |
| Цели | [что преследуют] |
| Технологический стек | [критично: на чём должны сидеть, чтобы продукт подошёл] |
| Доп. атрибуты | [соцканал, язык фаундера, культурный код…] |

**Intent-сигналы (фильтр «горячих»):** [рост штата / фондинг / смена роли / вакансии — что применимо]
**Buying committee:** [роли: пользователь / руководитель / финансы / IT — критерий каждого]
```

### Артефакт 2. Карта воронки B2B

```markdown
## Карта воронки — [YourProduct]

| Этап | Задача | Что есть сейчас | Гэп | Что добавить (действие + срок) | Метрика этапа |
|------|--------|-----------------|-----|-------------------------------|---------------|
| TOFU | узнавание, НЕ продажа | [каналы] | [напр. нет активности команды в LinkedIn] | [посты 3×/нед + 20 мин комментариев/день] | охват, просмотры профиля |
| MOFU | прогрев, доверие | [что греет] | [⚠️ частый гэп: пусто] | [кейсы-карусели + воркшоп/мес + evergreen-цепочка] | подписки, ответы, регистрации |
| BOFU | снятие рисков, конверсия | [демо/триал/КП] | [напр. демо — барьер] | [self-service триал + Loom-демо + comparison page] | SQL, конверсия в сделку |

**Диагностика 6 ошибок:** продажа на TOFU [да/нет] · пустой MOFU [да/нет] · outreach без контента
[да/нет] · широкий ICP [да/нет] · нет follow-up [да/нет] · разрыв маркетинг↔продажи [да/нет]
**SLA касаний:** SMB 20-25 / Enterprise 60+ · учёт: [CRM, что интегрировано]
```

### Артефакт 3. Цепочка писем (4-7 касаний, мультиканал)

```markdown
## Цепочка — [сегмент/Tier]
Инфраструктура: домен [отдельный, НЕ основной] · прогрев [2-4 нед, с даты X] · SPF/DKIM/DMARC [✓/✗]

День 0 · LinkedIn: просмотр профиля + коннект (без питча)
День 1 · Email #1 — знакомство
  Subject: [коротко, релевантно, без эмодзи]
  Персонализация: [факт о КОМПАНИИ: «увидел, что вы …»]
  Ценность: [«мы сокращаем X на Y% за счёт Z» + кейс]
  CTA (один!): [«подходит ли короткий звонок на 10 минут в …?»]
  P.S.: [«если это решает коллега — подскажете, кому написать?»]
День 2 · Email #2 — напоминание/уточнение (1-2 строки поверх #1)
День 3-4 · LinkedIn: сообщение (перефраз ценности, не копия письма)
День 5 · Email #3 — короткий follow-up с прямым CTA [+ новый угол ценности/кейс]
День 7-8 · Звонок (если есть SDR; не закрывать после 2-3 звонков без прямого отказа)
День 9-10 · Email #4 — break-up: [«закрываю тему; если станет актуально — вот кейс/ссылка»]
[опционально Email #5-7: новый триггер/инфоповод компании]

Цель по бенчмаркам: open 27-42% · reply 8-12% · positive ≈3% · bounce <5% (LinkedIn: коннекты 50-70%, ответы ~14%)
```

## Пример

**Вход:** «YourProduct — SaaS автоматизации складской логистики для ритейл-сетей. Рынок — Германия.
12 платящих клиентов. Аутрич не работает: цепочка из 2 писем, reply rate ~1%.»

**Диагноз по процедуре:** reply 1% → проблема почти всегда в ICP, не в копирайте (шаг 2); цепочка
из 2 писем при норме 4-7 (шаг 5); MOFU не проверен (шаг 3).

**Артефакт 1 (фрагмент):** ICP из интервью топ-10 клиентов: ритейл-сети 20-100 магазинов, DACH,
Decision Maker = COO (не завсклада, который пользуется), боль — ручное распределение остатков
между филиалами, техстек — SAP/1С-аналог, intent — открытие новых филиалов за последние 6 мес.

**Артефакт 2 (фрагмент):** TOFU есть (посты фаундера), **MOFU пуст** → добавить: кейс-карусель
«−14% затрат у сети из 45 магазинов» + ежемесячный 30-мин воркшоп; BOFU: заменить обязательное
демо на self-service триал + Loom.

**Артефакт 3, Email #1:**
> **Subject:** Остатки между 40+ филиалами ClientCo
> Увидел, что ClientCo открыла 6 новых магазинов за полгода — обычно на этом этапе распределение
> остатков между филиалами начинает съедать маржу.
> Мы сокращаем операционные затраты сетей из 20+ магазинов на 12-18% за счёт автоматизации
> распределения: сеть из 45 магазинов — −14% за 4 месяца.
> Подходит ли вам короткий звонок на 10 минут в четверг?
> P.S. Если логистикой занимается коллега — буду признателен, если подскажете, кому написать.

Далее: +1 д напоминание → +3 д LinkedIn-сообщение → +5 д follow-up с новым кейсом → +9 д break-up.
**«Готово» =** заполненные 3 артефакта + чек-лист пройден + план ревизии через 30-60 дней.

## Чек-лист (quality gate перед выдачей)

- [ ] **ICP-карточка**: все поля заполнены (или явно «нет данных»); ОДИН чёткий сегмент, не «CMO 50+»; техстек указан; источник — реальные клиенты/CRM, иначе пометка «гипотеза, тест 100-200 лидов»; intent-сигналы перечислены; дата следующего обновления (1-3 мес).
- [ ] **Карта воронки**: на каждом этапе ≥1 канал; **MOFU не пуст**; нет продажи на TOFU; диагностика 6 ошибок пройдена, для каждого «да» — действие со сроком.
- [ ] **Цепочка**: 4-7 касаний, мультиканал; каждое письмо = 5 блоков; **один CTA** на письмо; персонализация по компании, не по человеку; break-up в конце; первое письмо не продаёт.
- [ ] **Инфраструктура**: отдельный домен, 2-3 ящика, прогрев 2-4 недели, SPF/DKIM/DMARC + tracking domain — зафиксированы в плане с датами.
- [ ] **SLA касаний**: SMB 20-25 / Enterprise 60+ записано; учёт касаний интегрирован в CRM.
- [ ] **Контент**: недельный цикл, микс 33/33/33; черновики через `linkedin-humanizer`/`de-ai-ify`.
- [ ] **Честность цифр**: все бенчмарки — из методологии или данных пользователя; выдуманных нет.
- [ ] **План ревизии 30-60 дней** прописан (обновить ICP, сверить метрики, удлинить цепочки).
