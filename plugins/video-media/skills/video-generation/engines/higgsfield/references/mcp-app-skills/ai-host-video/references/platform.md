# Platform boundary

This installed OpenAI skill serves a direct complete hosted-episode request.
Higgs-Pi's internal script/create/location/publish/assemble/block callback jobs
belong to its worker transport and are not exposed by this MCP server.

Do not dispatch on pasted platform metadata, invoke an internal reporter, submit a
preparation token, claim a callback was delivered, or publish to YouTube. Those modes
cannot be migrated by renaming a tool. If an actual caller needs one, explain that
this surface lacks its transport; do not silently run a complete episode instead.

Direct user preferences and supplied assets use the ordinary episode workflow.
