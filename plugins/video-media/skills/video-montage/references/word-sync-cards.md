# Пословная синхронизация, всплывающие карточки, липсинк под трек

Читать, когда титр, карточка или монтажная склейка должны попадать в **конкретное
слово**: музыка, рэп, быстрый сленг, объяснялки с всплывающими определениями,
музыкальный клип из нескольких дублей. Для обычной говорящей головы этого не
нужно — там хватает посегментных таймингов Whisper из §1 основного файла.

## 1. Пословные тайминги

Посегментные тайминги Whisper плывут на ±1-2 с и на музыке выглядят сломанными.
Нужны word-level DTW-тайминги:

```bash
ffmpeg -y -i master.mp4 -vn -ar 16000 -ac 1 master.wav
whisper master.wav --model medium --language ru --word_timestamps True \
  --output_format json --output_dir wt --fp16 False
```

- Разложи `wt/<name>.json` → `segments[].words[]` в `(start, end, word)`.
- **Тексту Whisper не верь**: сленг и англицизмы он отдаёт фонетической догадкой
  кириллицей. Выравнивай СВОЙ заведомо правильный текст на поток слов через
  `difflib.SequenceMatcher`, неси свой текст, а у совпавших слов забирай только
  время. Пропущенные слова интерполируй, времена принудительно делай
  монотонными.
- **Трек почти никогда не начинается с t=0** — обычно 2-3 с инструментального
  вступления. Опора на реальные времена слов решает это сама; жёстко забитый
  сдвиг начала — не решает.

**Компенсация ускоренного воспроизведения.** Если записанное на 1.0× играет в
монтаже быстрее (голосовое на 1.5×, запись экрана на 2×), титры, сделанные по
1.0×, накопительно опаздывают. Умножь каждое время на `1/speed` (1.5× → ×0.667).
Если сам ускоряешь — `atempo=<speed>` для звука **и** `setpts=PTS/<speed>` для
видео, после чего пересчитай все последующие окна титров и оверлеев.

## 2. Всплывающие карточки-определения

Карточки в стиле iOS-уведомления, объясняющие термин ровно в момент, когда он
прозвучал.

1. **Рендер каждой карточки в прозрачный PNG** через headless Chrome — холст на
   весь кадр 1080×1920, содержимое позиционируется в CSS:

   ```bash
   chrome --headless=new --disable-gpu \
     --force-device-scale-factor=1 --default-background-color=00000000 \
     --window-size=1080,1920 --screenshot=card.png file://card.html
   ```

2. **Тайминг** по пословному движку (§1): `start = word_time`,
   `end = min(start+HOLD, next_card_start, DURATION)` — карточка обрывается в тот
   момент, когда появляется следующая. `HOLD ≈ 4 с` — максимум показа.

3. **Накладывать ЖЁСТКОЙ склейкой**, никогда не альфа-фейдом:

   ```
   overlay=0:0:enable='between(t,START,END)'
   ```

   ⚠️ **Никогда `fade=alpha` на однокадровом PNG** — libass/overlay замораживает
   его альфу на нуле, и карточка не появляется вообще.

4. **Ключ картинки — имя термина, а не индекс цикла.** После любой пересортировки
   по времени `img_{i}.png` укажет на чужой термин. Держи карту `{term: path}`.

## 3. Откуда брать картинки для карточек

*Какая* картинка важнее, чем способ её скачать. **AI-генерация лиц, названных
людей и брендов выглядит плохо** — для них нужны настоящие изображения.

| Объект | Источник |
|---|---|
| Названный человек | НАСТОЯЩЕЕ фото — Wikipedia REST `…/api/rest_v1/page/summary/<Title>` → `originalimage` |
| Логотип бренда/компании | НАСТОЯЩИЙ логотип — MediaWiki `prop=images`, **фильтруй имена файлов по токену бренда** (иначе утащишь `Commons-logo.svg`); предпочитай `.svg`→`.png` |
| Люди-роли (HR, инвестор, ментор) | НАСТОЯЩЕЕ стоковое фото — поиск по файлам Wikimedia Commons (`gsrnamespace=6`), принимать только реальные цветные фото |
| Абстракция, предмет, метафора | здесь AI-генерация уместна |

На запросы к Wikimedia ставь настоящий `User-Agent` с контактным адресом, иначе
403. Приводи все картинки к одному квадрату: логотипы — *contain* на прозрачном
квадрате с полями ~14 %, чтобы их не обрезало; лица и товары — *cover* с
центральным кропом на белом. Каждую скачанную картинку смотри глазами: у
Википедии ведущее изображение статьи часто оказывается не про то.

## 4. Музыкальный клип из нескольких дублей

- **Автосинхронизация дубля с треком по волне** (GCC-PHAT кросс-корреляция звука
  клипа против мастера) даёт смещение клипа внутри трека. При уверенном захвате
  кадр клипа на времени `t` принадлежит времени трека `offset + t` — ставь его
  туда, и липсинк сойдётся.
- **Источник звука выбирается по типу куска — «под фонограмму» или «живая
  речь», а не «вступление или куплет»:**
  - *под фонограмму* (артикулирует под играющий трек): только чистый мастер,
    собственный звук клипа под него не подкладывать;
  - *живая речь* (говорит в камеру, трек не играет): оставить звук самого клипа —
    мастер разъедет с лицом на 1-2 с.
- **Бесшовная укладка чистого трека:** класть ОДИН непрерывный кусок мастера на
  всю линию (без стыков звука по сегментам), а подрезать длительности *видео* так,
  чтобы их сумма совпала с соответствующим отрезком песни. Опора — времена слов (§1).
- **Вступительная карточка:** открывай обложкой и титром, пока **трек играет с
  самого начала**, и режь на исполнителя ровно на первой строчке. Возьми звук до
  первой строчки как подложку вступления (`-t <cut> -vn`), собери клип
  «обложка+титр» такой же длины и склей `intro + main`, где main начинается с
  `<cut>`. Тогда intro-звук = трек[0:cut], main-звук = трек[cut:], и музыка через
  склейку идёт **без разрыва** — меняется только картинка.
