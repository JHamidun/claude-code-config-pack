# Visual ideation playbook — «как нарисовать ЭТУ инфу»

Это «рисовалка» скилла (по мотивам manus-slides): прежде чем генерить картинку, для каждой карточки
сначала **выбери визуальный ПРИЁМ** под тип информации, потом сформулируй метафору-subject для
`card_image_generator.py`. Картинка должна *кодировать идею*, а не быть «просто иллюстрацией».

## Шаг ideation (делать для каждой карточки)

1. Назови ОДНУ идею карточки одним предложением.
2. Какой это ТИП информации? (см. таблицу ниже)
3. Какой реальный объект/сцена кодирует идею так, что понятно за 1 секунду?
4. Проверка читаемости: если метафора неочевидна в вектор-арте → бери **реальное фото + подпись** (как дирижёр).
5. Subject = этот объект, одним `template` на всю колоду (обычно `photoreal-3d`), plain bg → `--cut` → встроить без рамки.

## Тип информации → приём → метафора

| Тип инфы | Визуальный приём (layout) | Метафора-объект для картинки |
|---|---|---|
| Одна метрика-герой | `bignum` + объект сбоку | объект, воплощающий метрику (×4 честнее → лупа находит баг) |
| Сравнение с другими | таблица, своя колонка подсвечена `✦` | — (данные сами визуал) |
| Прогресс к себе (4.7→4.8) | парные бары + дельта-чипы | 3D-стрелка вверх |
| Оркестрация (один → многие) | — | дирижёр + оркестр / пульт управления / рой агентов |
| Трансформация / миграция | — | объект слева→направо морфит (булка→шестерни→мотор) |
| Скорость / перформанс | `stat-strip` | спидометр на максимуме / молния / motion-blur |
| Честность / самопроверка | split + объект | робот с лупой находит красный баг |
| Деньги / цена | `stat-strip` $ | стопки монет / чистая прайс-сетка |
| Как сделать / команды | `terminal-mock` (сам UI и есть визуал) | — |
| Цитата / реплика | `speech bubble` от персонажа | пузырь «нашёл баг 🔍» |
| Слишком абстрактно | — | подбери КОНКРЕТНЫЙ реальный объект-метафору (сильнейший ход) |
| Итог / мысль | navy `takeaway`-плашка | — |

## Принципы (иначе приём не сработает)

- **Одна идея = один объект.** Не пихай 3 смысла в одну картинку.
- **Мгновенная читаемость > красота.** Не угадывается за секунду → меняй метафору или бери реальное фото + `.band-cap` подпись.
- **Единый стиль колоды.** Все картинки одним `template` (см. `card_image_generator.py`). Не мешай flat + 3d.
- **Заземление + бренд.** Тень под вырезкой (`drop-shadow`), ваш лого в углу, цветовой ритм (1-2 navy/terra среди cream).
- **Данные рисуют сами себя** — таблица/бары/терминал не нуждаются в доп. картинке, не дублируй.

## Кейс Opus 4.8 (как применялось)

cover (фото+аватар) · бенчи=таблица · прогресс=бары+стрелка · честность=робот+лупа+облако · workflows=дирижёр-фото ·
как включить=терминал · Bun=булка→мотор · цена=спидометр+effort-сетка · CTA=navy-финал. Один photoreal-3d стиль, лого в углу.
