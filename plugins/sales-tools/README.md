# Sales Tools

> Account research, call prep, outreach, lead research, battlecards, daily briefing.

Part of the **[hamidun marketplace](../../README.md)**.

## What's inside

| Skill | What it does |
|-------|--------------|
| `account-research` | Досье на компанию/человека: веб-поиск + CRM. |
| `call-prep` | Подготовка к продажному звонку: разведка компании и участников, повестка. |
| `competitive-intelligence` | Sales-батлкарта конкурентов: интерактивный HTML с матрицей сравнения. |
| `create-an-asset` | Продажные материалы под сделку: лендинг, дек. |
| `daily-briefing` | Утренний sales-брифинг: встречи, сделки, приоритеты дня. |
| `draft-outreach` | B2B-аутрич с рисёрчем проспекта: email + LinkedIn + Telegram, цепочки касаний под корп-ЛПР. |
| `lead-research` | Свежий B2B-список лидов по ICP (РФ): discovery → ЛПР → скоринг Hot/Warm/Cold. |
| `revops-ru` | RevOps: воронки B2C self-serve и B2B sales-led, скоринг, MQL/SQL-хэндофф, SLA; учёт в B2B-CRM. |
| `sales-enablement-ru` | Sales-материалы B2B: питч-деки, one-pager, возражения, battle-cards, демо-скрипты. |
| `sales-team-ru` | Отдел продаж: найм, мотивация, нормативы, скрипты, AI-разбор звонков. |
| `tender-search-ru` | Russian procurement tender search via Playwright: geo-block workaround (zakupki -> rostender), OKPD2 filtering. |

### Commands

- `/call-summary`
- `/daily`
- `/forecast`
- `/pipeline-review`

## Install

```text
/plugin marketplace add JHamidun/claude-code-config-pack
/plugin install sales-tools@hamidun
```

Enable it with `/plugin` — the skills then activate automatically when relevant.
