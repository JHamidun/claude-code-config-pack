# Sales Tools

> Account research, call prep, outreach, lead research, battlecards, daily briefing.

Part of the **[hamidun marketplace](../../README.md)**.

## What's inside

| Skill | What it does |
|-------|--------------|
| `account-research` | Sales intel on a company or person: web search + CRM enrichment. |
| `call-prep` | Sales call prep: account context, attendee research, agenda; uses CRM, email, transcripts. |
| `competitive-intelligence` | Sales battlecard on competitors: interactive HTML with comparison matrix. |
| `create-an-asset` | Sales assets from your deal context: landing pages, decks, one-pagers, workflow demos. |
| `daily-briefing` | Утренний sales-брифинг: встречи, сделки, приоритеты дня. |
| `draft-outreach` | B2B-аутрич с рисёрчем проспекта: email + LinkedIn + Telegram, цепочки касаний под корп-ЛПР. |
| `lead-enrichment` | Enrich and qualify B2B leads — match a company list against your CRM, pull firmographics, find decision-makers, score and export. |
| `lead-research` | Fresh B2B lead list from an ICP (RU): discovery, DM mapping, Hot/Warm/Cold scoring. |
| `revops-ru` | RevOps across two motions — B2C self-serve (free→trial→paid) and B2B sales-led: data model, handoffs, pipeline hygiene. |
| `sales-enablement-ru` | Sales collateral for B2B — decks, one-pagers, objection handling and proof material for workshops and consulting. |
| `sales-team-ru` | Build and run a sales team — hiring, scripts, quotas, control, plus AI-driven call review for B2C and B2B. |
| `tender-search-ru` | Find Russian procurement tenders (goszakupki) and shortlist contracts matching a product or company profile. |

### Commands

- `/call-summary`
- `/daily`
- `/forecast`
- `/pipeline-review`

## Install

```text
/plugin marketplace add JHamidun/claude-code-config-pack
/plugin install sales-tools@hamidun
```

Enable it with `/plugin` — the skills then activate automatically when relevant.
