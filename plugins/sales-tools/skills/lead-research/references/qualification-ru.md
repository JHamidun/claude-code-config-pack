# Квалификация и скоринг лидов (RU, воркшоп/консалтинг)

Порт 5-фазного фреймворка `prospecting`. Превращает ICP в верифицированный, отскоренный список под холодные касания. Голос RU-рынка, корп-ЛПР. Продаём **AI-воркшоп / AI-консалтинг / B2B-когорту ExampleProduct** компаниям, которые внедряют AI и имеют бюджет на обучение команды.

## 5 фаз

### Фаза 1 — Определить ICP

Бери из `yourname-marketing-context` → `skills/yourname-marketing-context/references/business.md` (§B2B-персоны) + `skills/yourname-marketing-context/references/offerings.md`. Иначе собери:

1. **Фирмографика** — отрасль, размер (численность/выручка), география, форма (юрлицо РФ). Целевые — mid-large компании РФ, внедряющие AI, с бюджетом на L&D/обучение.
2. **Профиль зрелости** — компания уже «требует» от команды AI-навыки, запускает цифровую трансформацию, есть корп-университет / L&D-функция.
3. **Сигнал «почему сейчас»** — вакансии с требованием «опыт работы с нейросетями», запуск цифровой трансформации, новый CDO/директор по трансформации, расширение L&D-бюджета, публичные заявления про AI.
4. **Профиль ЛПР** — роль (HR-директор / руководитель L&D, гендир/владелец, руководитель отдела/функции, директор по цифровой трансформации), что важно.
5. **Дисквалификаторы** — микробизнес без бюджета на обучение; компании, где уже куплено корпоративное AI-обучение на год вперёд; организации, которым AI в принципе не релевантен.

Вывод: ICP одним абзацем + чеклист pass/fail. Без него не идти в discovery.

### Фаза 2 — Собрать кандидатов (discovery)

Источников — 2–3× от нужного объёма (квалификация отсеет). Источники — `references/ru-data-sources.md` (Контур.Фокус/Rusprofile + HH + LinkedIn). Кросс-проверяй 2–3 источника. 25 верифицированных лидов лучше 250 мусорных.

### Фаза 3 — Квалифицировать каждого

Скорь по чеклисту ICP, добавляй **доказательство** (URL источника) к каждому пункту. Не утверждай без бэкапа.

**Уровни уверенности:**
- **High** — подтверждено ≥2 независимыми источниками или офиц. карточкой (ЕГРЮЛ/Контур).
- **Medium** — один надёжный источник + согласующиеся данные.
- **Low** — неполно/неоднозначно — отметить, что осталось неясным.

Для email-контактов проверяй валидность/принадлежность до добавления в список (корп-домен, не личный).

### Фаза 4 — Скоринг и приоритизация

| Скор | Определение |
|---|---|
| **Hot** | сильный ICP-fit + ясный сигнал «почему сейчас» (AI-найм / трансформация) + ЛПР доступен (HR-дир / гендир / рук. отдела) + контакт верифицирован |
| **Warm** | ICP-fit + слабее/старее сигнал + контакт верифицируем |
| **Cold** | рыхлый ICP-fit ИЛИ нет сигнала ИЛИ контакт не подтверждён |
| **Skip** | сработал дисквалификатор (вне ICP, дубль, нерелевантно, low confidence) |

Целевое распределение: ~20% Hot, ~30% Warm, остальное Cold/Skip.

### Фаза 5 — Лид-лист

По умолчанию — markdown-таблица. CSV (через `xlsx`/`csv-analysis`) при >25 строк или по запросу. После таблицы — **«Топ-цели касания»**: топ-3–5 Hot с одним предложением, почему первыми.

## Модель скоринга (воркшоп/консалтинг B2B)

Вес 100, MQL-порог для передачи в касание — ≥60 (Hot/Warm).

| Измерение | Вес | Логика |
|---|---|---|
| Отрасль/сегмент | 15 | компания внедряет AI, есть знаниевая работа (маркетинг/аналитика/продажи/HR) = max |
| Размер компании | 20 | численность 100+ с бюджетом на L&D = max; микробизнес без бюджета на обучение = 0 |
| Сигнал «почему сейчас» | 25 | AI-найм / цифровая трансформация / новый CDO / расширение обучения за 90–180 дней |
| Роль ЛПР | 20 | HR-дир/рук. L&D/гендир/владелец/рук. отдела/директор трансформации = max; не-ЛПР = 5 |
| Бюджет на обучение / L&D-зрелость | 5 | есть корп-университет / L&D-функция / история внешнего обучения = max |
| Контакт верифицирован | 15 | корп-email + профиль/LinkedIn = max; только info@ = частично |

Грейд: A ≥80, B ≥60, C ≥40, D <40. Передавать в `draft-outreach` от B и выше.

## RU-сигналы для топ-целей

Приоритет для топ-3–5 Hot:

1. **Свежесть сигнала** — 30 дней бьёт 6 месяцев.
2. **Конкретность** — вакансия «нужен опыт работы с нейросетями» или новый директор по трансформации бьёт «компания в новостях».
3. **Доступ к ЛПР** — именованный HR-директор / гендир с верифиц. email/профилем бьёт role-only.
4. **Точность fit** — компания с явным AI-намерением и L&D-бюджетом бьёт «смежная».

Формулировка: «Открыли 5 вакансий с требованием AI-навыков 14 дней назад; верифиц. email HR-директора; ритейл 800 сотр. с корп-университетом — точный ICP под воркшоп».

## Комплаенс (152-ФЗ)

- Контакты — только публичные рабочие каналы. Личные email/телефоны — не использовать без основания.
- Для каждого контакта сохраняй **источник + дату** (lineage). Фиксируй в `crm` / academy-CRM `yourname-sales-postgres`.
- Не хранить ПДн дольше необходимого. Не перепродавать список.

## Чеклист перед сдачей

- [ ] Дубли убраны (по ИНН/домену).
- [ ] У каждого Hot — верифиц. контакт + ≥1 URL источника.
- [ ] Нет Hot без ясного сигнала «почему сейчас» (AI-найм / трансформация / L&D-движение).
- [ ] Уверенность честная (High = 2 независимых источника).
- [ ] Источник + дата сохранены (152-ФЗ).
- [ ] Личные адреса помечены/исключены.
- [ ] Итог совпадает с запросом или объяснено, почему меньше (планка качества).
- [ ] Топ-цели касания добавлены.
