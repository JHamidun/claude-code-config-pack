# Excel structure — все 12 вкладок

Финальный enriched.xlsx. Все вкладки имеют `freeze_panes` на шапку, `auto_filter` по диапазону, шапка `1F3864` тёмно-синий + белый bold текст высота 36px.

## Цветовая палитра (повтор из SKILL.md)

```python
HEADER_FILL  = PatternFill('solid', fgColor='1F3864')   # шапка таблиц
MATCH_FILL   = PatternFill('solid', fgColor='E2EFDA')   # Tier B — в базе без касаний
HOT_FILL     = PatternFill('solid', fgColor='FFE699')   # Tier S — горячие касания
WIN_FILL     = PatternFill('solid', fgColor='C6E0B4')   # WON / cold-top по выручке
LOSE_FILL    = PatternFill('solid', fgColor='F4B6B6')   # LOSE
ACTIVE_FILL  = PatternFill('solid', fgColor='BDD7EE')   # активные сделки
DUPE_FILL    = PatternFill('solid', fgColor='F8CBAD')   # дубли источников
LINK_FILL    = PatternFill('solid', fgColor='D9D2E9')   # LinkedIn-матч
HEADER_FONT  = Font(bold=True, color='FFFFFF', size=11)
LINK_FONT    = Font(color='0563C1', underline='single')
```

## Стили общие

- `freeze_panes` на первую строку под шапкой
- `auto_filter.ref = ws.dimensions`
- Bitrix URL и LinkedIn URL — `cell.hyperlink = url` + `LINK_FONT`
- Многострочные ячейки (контакты, касания) — `Alignment(wrap_text=True, vertical='top')`, высота строки `max(20, min(200, line_count * 14))`
