# AI-разбор звонков + AI-пайплайн продаж

> Методология «AI в продажах» (эксперт по продажам). Главная мысль: AI **убирает рутину, а не человека**.

## 0. Главная ошибка

Самая большая ошибка компаний — пытаться **починить продажи** скриптами / CRM / AI-инструментами, **нанимая при этом слабых и немотивированных менеджеров**.

Если продавец не хочет зарабатывать, не умеет общаться, плохо переносит стресс, не способен учиться — система разрушается, и никакой AI не спасёт.

**Сначала — сильная система** (найм, процессы, скрипты, структура). **Только потом — автоматизация.** AI особенно силён в: анализе звонков, тренировках, квалификации, обработке лидов, коммуникации.

## 1. AI-разбор звонков — главная часть

Звонки менеджеров — **«чёрный ящик»**: непонятно, почему падает конверсия, где ошибки, как улучшать. Раньше слушали живые контролёры (ОКК), теперь — AI.

**Что делает AI:**
1. Транскрибирует звонок (речь → текст).
2. Разбивает на **десятки отдельных этапов** и анализирует каждый:
   - приветствие, установление контакта, структура звонка;
   - задаёт ли менеджер вопросы, понимает ли проблему клиента, **слушает ли** клиента;
   - насколько понятно объясняет, адаптирует ли под клиента, доносит ли выгоды;
   - умеет ли удерживать клиента, отвечает ли на сомнения/возражения;
   - подведение к оплате, финальная консультация, закрытие.
3. Выставляет **оценки** (по 19 критериям — см. `scripts.md`).
4. Кладёт оценку + рекомендации в карточку CRM → менеджер изучает и применяет.

### Talk-to-listen ratio (TLT) — ключевая метрика

- AI считает, **сколько говорит менеджер vs клиент**.
- **Менеджер говорит >60% времени → плохой сигнал**: клиент не вовлечён, менеджер «монологит», диалога нет.
- В критериях звонка цель — **сейлз говорит меньше клиента** (≈<40% времени).

### Стек

```
Deepgram          → транскрипция звонка в текст
Claude / Grok     → анализ структуры по 19 этапам, выставление оценок
ElevenLabs        → голос (озвучка, симуляция клиента)
Microsoft Azure   → no-code automation / оркестрация
no-code automation stack → склейка пайплайна
```

- Транскрипцию исполняет `deepgram`. Анализ текста — модели Claude напрямую. Голос/симуляция — `elevenlabs`.

### Полная цепочка Zoom → CRM → AI (внедрение)

```
Zoom (ОП проводит звонок)
  → запись в CRM (карточка клиента)
  → передача в Google Drive
  → Whisper/Deepgram транскрибация в текст
  → PDF «дожимная» под клиента (кейсы + подборка материалов)
  → обратно в карточку CRM (+ транскрипт файлом)
  → AI-оценка качества звонка
  → оценка + рекомендации в карточку CRM
  → менеджер изучает и применяет
```

**Варианты реализации:**
- **Под ключ**: **Spellit** — AI-ОКК для Zoom, $/мес. Также **Sales Lens** (AI-прослушиватель, готовые выводы для РОПа).
- **Самописное**: рекомендации сейлзам в **Telegram-бот** (через no-code automation).
- Подготовка «дожимных» через Cursor + клиентский репозиторий + папка с гайдами/КП.
- Финансовая оговорка: для команды ~10 менеджеров готовые AI-ОКК «выходят в копеечку» — оценивай экономику.

## 2. AI-симуляция клиента (тренажёр)

Один из самых интересных элементов. **AI играет роль клиента**, менеджер тренируется: выявлять потребности, презентовать, работать с возражениями, закрывать. AI анализирует звонок, показывает ошибки, даёт рекомендации, оценивает прогресс.

**Принцип**: нельзя просто сказать «продавай лучше». Надо:
1. Разбить навык на части.
2. Найти **слабое место** (например, плохо выявляет потребность).
3. Заставить тренировать **именно этот этап** через симуляции — до улучшения.

## 3. Опережающие метрики vs конверсия

**Конверсия — поздняя метрика**: когда месяц закончился, менять уже поздно. Управлять надо **опережающими**:

| Опережающая метрика | Что показывает |
|---|---|
| Количество **ролёвок** | сколько тренируются |
| **Качество звонков** (баллы по 19 критериям) | растёт ли мастерство |
| **Скорость ответа на лид (SLA)** | быстро ли перезванивают |
| **Активность в CRM** | работают ли в системе |
| **Время в звонках** (выработка) | 120/120 норматив |
| **TLT** (talk-to-listen) | вовлечён ли клиент |

(SLA, выработка, дозваниваемость детально — `control-metrics.md`.)

## 4. AI до контакта с менеджером

AI используется ещё **до** живого менеджера, чтобы убрать рутину и квалифицировать:

- **AI-квиз**: клиент рассказывает о своей ситуации → получает персонализацию → **прогревается** перед звонком менеджера. Одновременно квалифицирует.
- **AI voice-agent**: отвечает на вопросы (FAQ), консультирует, **передаёт сложные случаи человеку**.
- Авто-квалификация **через мессенджер** — бот на API GPT-4.

## 5. Полный AI-пайплайн продаж

```
Реклама
  → AI-креатив
  → AI-квиз (квалификация + персонализация + прогрев)
  → AI-квалификация
  → AI-переписка
  → менеджер (живой)
  → продажа
  → AI-контроль качества (разбор звонка)
  → AI-обучение (тренажёр на слабом этапе)
  → рост конверсии
```

**Разделение труда AI ↔ человек:**

| AI берёт | Человек оставляет за собой |
|---|---|
| рекламу, прогрев, переписки, квалификацию | финальное закрытие |
| контроль качества, обучение, аналитику | сложные переговоры |
| доведение клиента почти до сделки, сбор данных | эмоциональный контакт, работа с доверием |

**Цель AI** — не заменить человека полностью, а: убрать рутину, ускорить процессы, квалифицировать лидов, снизить стоимость продаж, увеличить конверсию.

Нельзя улучшить **один** элемент — нужно строить всю систему: найм → onboarding → обучение → аналитика → контроль качества → процессы.
