# Daily Standup Summary

Generate concise daily report:

## ✅ Completed Yesterday
- What was finished
- PRs merged
- Issues closed

## 🔄 In Progress Today
- Current work
- Focus areas
- Expected completion

## 🚧 Blockers
- Issues or dependencies
- Need help with
- Waiting on

Check recent git commits, open files, and project status.
Keep it brief and actionable.
