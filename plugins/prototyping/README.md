# Prototyping

> Wireframes, interactive prototypes, component playground, sketch/Claude-design to HTML.

Part of the **[hamidun marketplace](../../README.md)**.

## What's inside

| Skill | What it does |
|-------|--------------|
| `canvas-design` | Оригинальный визуальный арт в PNG/PDF: постеры, обложки, композиции. |
| `claude-in-html` | Вызов LLM прямо из HTML-артефакта — прототипы с живой AI-фичей: чат, саммари, классификация. |
| `component-playground` | Storybook-подобная страница: все компоненты дизайн-системы во всех вариантах, контролы пропсов. |
| `design-canvas` | N вариантов дизайна бок-о-бок в одном HTML: pan/zoom, фокус. |
| `interactive-prototype` | Кликабельный React-прототип в одном HTML (inline JSX, Babel): state, переходы, валидация форм. |
| `placeholders` | Плейсхолдеры картинок и иконок, когда реального ассета нет: полосатый SVG с подписью. |
| `react-pinning` | Готовый блок script-тегов React/ReactDOM/Babel с integrity-хешами для HTML-артефактов с inline JSX. |
| `real-data` | Прототип на настоящих данных: CSV/JSON/SQLite или локальный API-мок вместо фейков. |
| `sketch-to-html` | Скетч, фото доски, салфетки или Excalidraw → HTML-каркас. |
| `storybook-bridge` | Экспорт component-playground в Storybook 7+ (CSF3) для команды с существующим Storybook. |
| `web-artifacts-builder` | HTML-артефакты claude.ai на React, Tailwind, shadcn/ui. |
| `wireframe` | Много идей в низкой детализации на одном листе — скелет до хай-фай. |

## Install

```text
/plugin marketplace add JHamidun/claude-code-config-pack
/plugin install prototyping@hamidun
```

Enable it with `/plugin` — the skills then activate automatically when relevant.
