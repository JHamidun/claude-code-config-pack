# Research & Analysis

> Document Q&A, stock analysis, CEO council, thinking frameworks, meeting analysis.

Part of the **[hamidun marketplace](../../README.md)**.

## What's inside

| Skill | What it does |
|-------|--------------|
| `ceo-council` | Use when needing strategic project analysis from multiple independent expert perspectives. |
| `developer-growth` | Analyze coding patterns and track developer skill progression |
| `domain-brainstormer` | Generate creative domain names and check availability |
| `internal-comms` | A set of resources to help me write all kinds of internal communications, using the formats that my company likes to use. |
| `investor-materials` | Create and update pitch decks, one-pagers, investor memos, accelerator applications, financial models, and fundraising materials. |
| `kaizen` | Continuous improvement methodology - small incremental changes |
| `meeting-analyzer` | Analyze meeting transcripts for insights, action items, decisions |
| `research-docs` | Document Q&A with visual citations. |
| `stock-analysis` | Analyze stocks and companies using financial market data via yfinance Python library. |
| `thinking-frameworks` | Structured thinking frameworks for deep analysis. |
