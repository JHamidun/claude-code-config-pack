# Research & Analysis

> Document Q&A, stock analysis, CEO council, thinking frameworks, meeting analysis.

Part of the **[hamidun marketplace](../../README.md)**.

## What's inside

| Skill | What it does |
|-------|--------------|
| `building-an-exo` | Справочник ExO 3.0 (OpenExO) для AI-перестройки компании: Intelligence Stack, REWRITE, Edge Twin, DRIVE/SHAPE, MTP. |
| `ceo-council` | Параллельный разбор стратегического вопроса независимыми C-level экспертами — срезает слепые зоны. |
| `check-skill-solo` | Фактчек и проверка на галлюцинации кросс-моделями (Claude+Gemini+GPT) с первоисточниками. |
| `developer-growth` | Оценка и рост разработчика: skills matrix, анализ git-вклада, PDP, gap до senior. |
| `domain-brainstormer` | Подбор доменных имён и проверка их доступности. |
| `internal-comms` | Внутренние коммуникации: статус-репорты, 3P-апдейты, рассылки, FAQ, инциденты. |
| `investor-materials` | Материалы для инвесторов: питч-дек, one-pager, меморандум, финмодель, заявки в акселераторы. |
| `meeting-analyzer` | Транскрипт встречи → протокол: решения, action items, риски; вход tl;dv/Plaud/Spark или аудио. |
| `research-docs` | Q&A по папке документов (PDF/DOCX/PPTX/XLSX) со скриншотами страниц и подсветкой цитат, LiteParse. |
| `stock-analysis` | Акции и компании через yfinance: цены, инсайдеры, рекомендации аналитиков, SEC. |
| `thinking-frameworks` | Структурные фреймворки анализа и решений: first principles, pre-mortem, kaizen/PDCA. |

### Commands

- `/deep-research`
- `/kb`
- `/meeting`
- `/retro`

## Install

```text
/plugin marketplace add JHamidun/claude-code-config-pack
/plugin install research-tools@hamidun
```

Enable it with `/plugin` — the skills then activate automatically when relevant.
