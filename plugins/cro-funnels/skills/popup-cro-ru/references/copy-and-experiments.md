# Копирайт и эксперименты попапов (RU)

Формулы копии + полный набор A/B-тестов попапов. Запуск — `ab-testing-ru`. Метрики — ваша аналитика (например, `yandex` / GA4). **Приоритет — закрыть главную дыру воронки** (например, переход из бесплатного контента в платный продукт/консультацию).

## Формулы копирайта

### Заголовки
- Про выгоду: «Получите [результат] за [срок]».
- Вопрос: «Хотите [желаемый исход]?».
- Команда: «Не пропустите [вещь]».
- Соцпруф: «[Экспертная роль / автор] делится…».
- Любопытство: «Главная ошибка, которую совершают [аудитория] с [тема]».

### Подзаголовки
- Раскрыть обещание.
- Снять возражение («Без спама»).
- Задать ожидания («Раз в неделю, 5 минут чтения»).

### CTA-кнопки
- 1-е лицо работает: «Получить мой гайд» vs «Получить ваш гайд».
- Конкретно > дженерик: «Прислать “[название лид-магнита]”» vs «Отправить».
- Про ценность: «Забрать [ценный ресурс]» vs «Подписаться».

### Отказы
- Вежливо, без вины: «Нет, спасибо» / «Может позже» / «Не интересно».
- Избегать манипуляций: НЕ «Нет, я не хочу [достигать желаемого результата]».

## Стратегии по типам (под вашу воронку)

### Контент-площадка (захват email + фикс дыры контент→продукт)
1. Scroll (на статье): подписка на вашу рассылку/дайджест.
2. Page count (после X статей): баннер «[Освоить тему] системно → бесплатный триал/старт».
3. Exit-intent: лид-магнит под тему статьи / триал продукта.

### B2C-аудитория (онлайн-продукт / курс)
1. Click-triggered: лид-магнит «[полезный ресурс по теме]», демо продукта.
2. Scroll: подписка на канал / рассылку.
3. Exit-intent: «[N] дней бесплатно, без карты» / стартовый оффер по спец-цене.

### B2B / корп (услуги, воркшоп)
1. Click-triggered: «Записаться на бесплатную консультацию», лид-магнит для бизнеса.
2. Scroll: анонс корпоративного воркшопа.
3. Exit-intent: «Бесплатная консультация: как внедрить [решение] в процессы».

### Лид-магниты (страница материалов)
1. Click-triggered: скачивание «[гайд]» / «[чек-лист / подборка]».
2. Exit-intent: «Заберите гайд перед уходом».
3. После скачивания → апсейл в триал продукта.

## Эксперименты

### Размещение и формат
- Топ-бар vs баннер под шапкой; sticky vs static; full-width vs контейнер; с таймером vs без.
- Центр-модалка vs slide-in из угла; fullscreen vs малая модалка; bottom bar vs corner.
- Размеры на десктоп/мобайл; левый vs правый угол для slide-in; видимость без блокировки контента (критично на контент-площадке).

### Триггеры
- Exit-intent vs 30-сек задержка vs 50% скролл.
- Оптимальная задержка (10 vs 30 vs 60 сек).
- Глубина скролла (25 vs 50 vs 75%).
- Page count (после X статей на контенте → CTA продукта).
- По источнику/intent; новые vs вернувшиеся.
- Click-triggered для лид-магнитов; кнопка vs ссылка.

### Месседжинг
- Внимание-граб vs информативный заголовок.
- «Ограниченное предложение» (стартовый оффер по спец-цене) vs «Новый лид-магнит».
- Срочность vs ценность.
- Длина/конкретность заголовка.
- Варианты CTA-текста, цвет/контраст кнопки.
- Один CTA vs primary+secondary (подписка + триал продукта).
- С/без изображения; превью лид-магнита / скриншот продукта vs дженерик; соцпруф (ваши маркеры авторитетности — роль, ключевой результат, узнаваемые клиенты) в попапе.
- Таймер обратного отсчёта (если оффер честный).

### Персонализация
- По данным посетителя; по сегменту B2C/B2B-корп; по просмотренным статьям/страницам.
- Прогрессивное профилирование (спрашивать больше со временем).
- Новые vs вернувшиеся; по источнику; по уровню вовлечённости; исключить уже подписавшихся.
- На статье по теме → релевантный лид-магнит (про презентации → «[подборка по презентациям]»).

### Частота и правила
- Капинг (раз/сессия vs раз/неделя).
- Cool-down после dismiss.
- Разное поведение dismiss.
- Эскалация офферов по визитам (подписка → триал продукта → консультация).

## Метрики
- Impression rate, conversion rate (показы → сабмиты).
- Close rate, engagement rate, time to close.
- Просмотры попапа, фокус формы, попытки сабмита, успешные сабмиты, клики close, клики вне, Escape.
- Доля email-подписчиков, кликнувших в CTA продукта/консультации (метрика фикса дыры воронки).
