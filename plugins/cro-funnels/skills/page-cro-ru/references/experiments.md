# Идеи экспериментов для страниц (RU)

A/B-тесты по типам страниц вашего проекта. Запуск, сплитование и стат-значимость — через `ab-testing-ru`. Метрики целей и сегменты — через веб-аналитику (`yandex` / Метрика или ваш аналог). Правки — через конструктор/CMS (`tilda` или иной). Лиды с форм — в вашу CRM.

## Содержание
- Главная (hero, доверие/соцпруф, фичи/контент, навигация)
- Лендинг услуг /services (заявка на бесплатную консультацию)
- Лендинг воркшопа /workshop
- Лендинг онлайн-продукта / academy (trial 7 дней)
- Страница материалов /materials (захват email лид-магнитом)
- Контентный портал / медиа (захват email + сквозной CTA в продукт/консультацию)
- Блог (CTA в контенте, раздел ресурсов)
- Кросс-страничные

## Главная

### Hero
| Тест | Гипотеза |
|------|----------|
| Варианты заголовка | Конкретика («Команда освоит X за один воркшоп на ваших задачах») vs абстракция |
| Подзаголовок | Добавить/уточнить в поддержку H1 |
| Развилка B2B/B2C | Два явных пути (консультация / trial продукта) vs один общий CTA |
| CTA выше сгиба | С заметной кнопкой vs без |
| Формат hero-визуала | Фото эксперта vs скриншот продукта vs видео vs иллюстрация |
| Текст основного CTA | «Бесплатная консультация» vs «Обсудить задачу» vs «7 дней бесплатно» |

### Доверие и соцпруф
| Тест | Гипотеза |
|------|----------|
| Регалии в hero | Ваши маркеры авторитета (роль, ключевой результат) в hero vs ниже сгиба |
| Логотипы клиентов | Узнаваемые клиенты/партнёры (ClientCo и др.) в hero vs ниже |
| Кейс внедрения в hero | Показать результат сразу |
| Соцпруф в заголовке | Один сильный факт-подтверждение (масштаб команды, отраслевое признание) |
| Размещение отзыва | Выше сгиба vs отдельный блок |
| Видео-отзывы участников | Вовлекают сильнее текста |

### Фичи и контент
| Тест | Гипотеза |
|------|----------|
| Подача услуг | Иконки+описания vs детальные секции (консалтинг/воркшоп/продукт) |
| Порядок секций | Поднять самое ценное по приоритету (высокомаржинальный B2B выше массового продукта) |
| Вторичные CTA | Добавить/убрать по странице |
| Выгоды vs фичи | Вести outcome'ами («сотрудники начнут применять X») |
| Блок «стратегия + внедрение» | Отстройка от теоретиков |

### Навигация и UX
| Тест | Гипотеза |
|------|----------|
| Липкая навигация | Постоянная nav с CTA «Бесплатная консультация» |
| CTA-кнопка в навигации | Заметная кнопка в шапке |
| Виджет поддержки | Чат-поддержка vs AI-агент продаж (в вашем tone of voice) |
| Exit-intent попап | Ловить уходящих (см. popup-cro-ru) |

## Лендинг услуг (/services)

### Структура и оффер
| Тест | Гипотеза |
|------|----------|
| Структура боль→диагностика→стратегия→внедрение | Полный нарратив vs короткий оффер |
| Кейсы с числами | ROI-кейсы внедрений vs общие обещания |
| Отстройка | «Стратегия + внедрение в одном лице» как ключевой блок |
| Single-focus | Убрать навигацию, один CTA «Бесплатная консультация» |

### CTA и маршрутизация
| Тест | Гипотеза |
|------|----------|
| Текст CTA | «Бесплатная консультация» vs «Обсудить задачу» vs «Звонок 30 минут» |
| «Что получите на консультации» | Снять неопределённость перед заявкой |
| Бронь звонка inline | Календарь сразу на странице vs форма → ручная бронь |
| Маршрутизация в CRM | Квалификация лида по сегменту/бюджету |

## Лендинг воркшопа (/workshop)
| Тест | Гипотеза |
|------|----------|
| Подача формата | Таблица «1 день / неделя / программа» vs описание |
| «100% практика на ваших задачах» | Усилить как главную выгоду |
| Ведущие | Эксперт + со-ведущий с регалиями vs только эксперт |
| Бонус формата | Подсветить дополнительную ценность (доступ к инструментам/материалам) |
| CTA | «Выбрать формат» vs «Бесплатная консультация» vs «Рассчитать под команду» |
| Соцпруф корп | Отзывы HR-директоров, кейсы команд |

## Лендинг онлайн-продукта / academy

### Hero и оффер trial
| Тест | Гипотеза |
|------|----------|
| Заголовок | Конкретная ценность («N материалов, интерактивные тренажёры») vs абстракция («Освой X системно») |
| CTA trial | «7 дней бесплатно без карты» vs «Начать обучение» |
| «Без карты» в кнопке | Снижает трение регистрации |
| Демо-фича в hero | Дать пощупать ключевую фичу сразу |
| Ключевой бонус | «Включён в подписку» как ценность |

### Тарифы и доверие
| Тест | Гипотеза |
|------|----------|
| Founding offer | «Спец-цена пожизненно для первых N» vs обычные тарифы |
| Бейдж «Популярный» | Подсветить средний тариф |
| Якорение | Порядок Basic/Plus/Pro задаёт ожидания (логика — pricing-strategy-ru) |
| Сертификаты с QR | Подсветить для B2C-профи (резюме/HR) |
| Отзывы о ценности | Цитаты участников про результат |
