# Тактики роста CR1 лендинга (эксперт, методология

> Источник: методология (поток N), эксперт — «Дерево метрик + воронки», практический разбор лендинга на. Конкретные тактики повышения CR1 (визит → заявка/лид) для первого экрана.
>
> **Не дублировать:** полный чек-лист лендинга (8 пунктов с ICE), дерево метрик CPM→CTR→CR1→CR2→LTV, эффект «магазина мороженого», «Система 2» Канемана — в `funnel-design-ru` (`references/leads-landing.md`). Здесь — тактическая выжимка под CRO отдельной страницы. Психология (Система 2, FOMO, дефицит, якорение) — в `marketing-psychology-ru`.

## Три обязательных ответа на лендинге

Первый экран должен закрыть три «почему» — иначе посетитель уходит думать (и не возвращается):

1. **Почему именно этот продукт?** — чем решение лучше альтернатив и «ничего не делать». Результат, а не процесс (см. ниже).
2. **Почему именно эта компания (этот человек)?** — отстройка, регалии, соцпруф. Для пользователя: руководитель ИИ-направления, экс-крупный банк N+ специалистов, практик, а не теоретик (детали — в `yourname-marketing-context` → `references/business.md`).
3. **Почему именно сейчас?** — что мешает отложить. Дедлайн, ограниченность мест, founding-оффер, изменившийся контекст рынка (закрывается FOMO-таймером, см. ниже).

Если хотя бы один «почему» не закрыт на первом экране — гипотеза на правку с высоким приоритетом.

## Тактики первого экрана (битва за CR1)

| Тактика | Суть | Почему работает |
|---|---|---|
| **Один главный CTA** | На первом экране — одно целевое действие, не россыпь (консультация / покупка / подарок одновременно рассеивают) | несколько CTA размывают фокус → действие не совершается. CTA дублировать ниже в точках принятия решения |
| **CTA на видных местах** | Главный CTA виден без скролла + повтор в естественных паузах | решение принимается в разных точках — кнопка должна быть под рукой |
| **Соцпруф с цифрами** | «Увеличили конверсию на 30%», «обучили N+» > «всё супер, спасибо!». Текстовые кейсы с именем/ролью > «роботизированных» видео-отзывов | конкретный измеримый результат вызывает доверие; абстрактная похвала — нет |
| **FOMO-таймер + ограниченность** | Дедлайн, ограничение мест/тиража. **Обновлять каждую неделю** — при обнулении счётчика конверсия падает (доказано на практике) | дефицит подталкивает к действию «сейчас», закрывает «почему сейчас» |
| **Результат вместо процесса** | «Обработка выписок за 1 клик» > «Создай AI-команду». «Команда освоит ИИ за один воркшоп» > «программа обучения нейросетям» | абстрактный/процессный оффер не цепляет; человек покупает исход, а не работу |
| **Убрать горизонтальные слайдеры** | Карусели и горизонтальный скролл — убрать с лендинга | ломают паттерн вертикального скролла → активируют «Систему 2» Канемана (медленное мышление) → когнитивная нагрузка → CR падает. Подробнее — `marketing-psychology-ru` |
| **1–3 тарифа, не больше** | Максимум 3 варианта на экране выбора | эффект «магазина мороженого» (парадокс выбора): много опций парализуют решение → уход |
| **Убрать ценник, где мешает** | Ценник «в лоб» на первом экране часто убивает конверсию; ценность доносить через продажи / SLZ / по ходу страницы | цена без донесённой ценности воспринимается как «дорого». Логика тарифов — `pricing-strategy-ru` |
| **Мобильная адаптация** | mobile-first вёрстка + быстрая загрузка (Tilda) | ~90% трафика РФ — мобайл; самый высокий ICE из чек-листа |

> **Бонус-гипотеза (высокий ICE):** квиз-воронка на первом экране — вовлекает, собирает данные, выдаёт лид-магнит (отчёт на email). Повышает CR1. Механика квиза как ТИПА воронки — `funnel-design-ru`.

## Приоритизация и проверка

- **Приоритизируй гипотезы по ICE** (Impact × Confidence × Ease, шкала 1–10) — таблица и спринт «3 гипотезы × 2–3 недели» в `funnel-design-ru`.
- **Бенчмарки ДО цели:** прежде чем целиться в рост CR1, узнай у конкурентов/агентств, какие показатели реальны. Не «на глаз».
- **Запуск и статзначимость теста** — `ab-testing-ru`.
