# Идеи экспериментов для форм захвата (RU)

A/B-тесты форм всех трёх подтипов: заявка, регистрация/trial, лид-магнит и подписка. Запуск — `ab-testing-ru`. Метрики (старт, заполняемость, дроп по полям и шагам) — твоя продуктовая аналитика + Яндекс.Метрика с целями на шаги формы. Лиды — твоя CRM.

## Структура формы

### Раскладка и поток
- Один шаг vs многошаг с прогресс-баром.
- Многошаг с прогресс-баром vs без.
- 1 колонка vs 2 колонки.
- Форма на странице/встроена в лендинг vs отдельная страница.
- Вертикальное vs горизонтальное выравнивание.
- Форма выше сгиба vs после контента.

### Поля
- Минимум жизнеспособных полей.
- Добавить/убрать телефон (для заявки на консультацию обычно нужен для брони Zoom).
- Добавить/убрать компанию (B2B).
- Одно поле «Имя» vs «Имя/Фамилия».
- Баланс required vs optional.
- Обогащение для авто-подстановки известных данных (из домена / Контур.Фокус).
- Скрывать поля для известных/вернувшихся.

### Smart forms
- Real-time валидация email/телефона.
- Прогрессивное профилирование (спрашивать больше со временем / на самой консультации / в онбординге).
- Условные поля по предыдущим ответам.
- Авто-подсказка названий компаний.

## Копия и дизайн

### Лейблы и микрокопия
- Ясность и длина лейблов: минимальные vs описательные.
- Оптимизация плейсхолдеров.
- Help text: показать vs скрыть vs on-hover.
- Тон ошибок (дружелюбный vs прямой).
- Показ требований к паролю: заранее vs при ошибке.

### CTA и кнопки
- Варианты текста: «Отправить» vs «Записаться на консультацию» vs «Выбрать формат воркшопа»; «Создать аккаунт» vs «7 дней бесплатно» vs «Начать обучение».
- «Без карты» в тексте CTA.
- Цвет/размер кнопки, размещение относительно полей.
- Акцент ценностного предложения в шапке формы («N+ материалов, AI-тьютор»).

### Доверие
- Заверение приватности у формы (152-ФЗ) — формулировка и размещение чекбокса согласия.
- Регалии эксперта ([роль, компания]) рядом с кнопкой; отзыв у формы.
- «Бесплатно и ни к чему не обязывает» / ожидаемое время ответа.
- Бейджи: данные в РФ, «Без привязки карты, отмена в один клик».
- Чистый фон vs продуктовые визуалы (скриншот симулятора / AI-тьютора); карточка vs минимализм.

## По подтипам

### Заявка на бесплатную консультацию (главная B2B)
- С/без обязательного телефона.
- «Предпочтительный канал связи».
- Вопрос «Какую задачу хотите решить с ИИ?» (для квалификации в CRM).
- Встроенный календарь Zoom vs отправка формы → ручная бронь.
- «Что получите на консультации» над формой.

### Запрос формата воркшопа
- Поле «размер команды» обязательное vs опциональное.
- Выбор формата (1 день / неделя / программа) дропдауном vs free text.
- «На каких задачах учить команду» для персонализации.
- CTA «Рассчитать под команду» vs «Выбрать формат».

### Контактная форма
- Дропдаун маршрутизации по теме (консультация / воркшоп / academy).
- С/без обязательного поля сообщения.
- Альтернативные каналы (Sales-AI-агент, Telegram).
- Месседжинг ожидаемого времени ответа.

### Регистрация / trial
- Минимум полей (email + пароль) vs расширенный набор.
- Добавить/убрать выбор интересующего трека на регистрации vs спросить в онбординге.
- Добавить/убрать компанию (только для B2B-когорт).
- Соцавторизация: **Яндекс ID, VK ID, Telegram, Google** (релевантны для РФ); для B2B-когорт — корп-SSO/SAML.
- Соцавторизация заметна vs email-форма заметна; только SSO vs SSO + email.
- Какие провайдеры заходят лучше (зависит от аудитории: B2C-профи vs корп-когорта).
- Верификация email: обязательна vs отложена vs убрана; magic link вместо пароля.
- Влияние CAPTCHA/SmartCaptcha на completion.
- Чекбокс согласия 152-ФЗ vs implicit (implicit для ПД не подходит — учитывать комплаенс).

### Trial и коммитмент
- Карта обязательна vs нет для trial (текущее — без карты).
- Длина trial (7 vs 14 vs 30 дней).
- **Trial vs founding offer**: тестировать «[цена] ₽/мес пожизненно для первых N» как альтернативу trial для горячего трафика.
- Trial с ограниченными треками vs полный доступ.

### Лид-магнит
- Только email vs email + имя.
- Месседжинг value prop над формой (название лид-магнита).
- Гейтед vs ungated контент.
- Апсейл trial после сабмита vs только доставка.

### Email-захват рассылки («YourName Weekly»)
- Размещение формы: inline в ленте vs футер vs exit-intent попап (`popup-cro-ru`).
- Оффер: «AI-новости раз в неделю» vs «+ лид-магнит за подписку».
- Кол-во полей: только email vs email+язык.
- Сразу после подписки: CTA «academy 7 дней бесплатно» vs только подтверждение (чинит дыру контент→продукт).
- Double opt-in vs single opt-in (комплаенс vs конверсия).

## После сабмита
- Понятный следующий шаг после регистрации (→ первый трек/симулятор) vs общее «спасибо».
- Мгновенный доступ к продукту vs подтверждение по email сначала.
- Авто-логин после регистрации vs требовать вход.
- Персонализированное приветствие по данным регистрации (трек/сегмент).
- Подписчик рассылки → апсейл-баннер academy/консультации в письме подтверждения.

## Мобайл и UX
- Крупнее тач-таргеты.
- Правильные клавиатуры по типу поля.
- Sticky-кнопка отправки.
- Авто-фокус первого поля.
- Стиль контейнера (карточка vs минимализм), мобильная раскладка.

## Метрики
- Form start rate, completion rate.
- Дроп по полям и шагам, доля ошибок по полям.
- Время заполнения.
- Mobile vs desktop.
- Соцавторизация vs email.
- Доля заявок, дошедших до qualified / zoom_scheduled (форма консультации).
- Email opt-in rate + доля кликнувших в CTA продукта (рассылка).
