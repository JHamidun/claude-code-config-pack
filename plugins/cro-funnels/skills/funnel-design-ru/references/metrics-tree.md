# Дерево метрик — детально

> Источник: экспертная методология. Дерево метрик = хребет любой воронки. Каждый узел = отдельная метрика и отдельное поле для гипотез. Деньги на входе (бюджет) связаны с деньгами на выходе (LTV) через CAC.

## Полная цепочка

```
БЮДЖЕТ
  │  (канал: соцсети / поисковики (ключи+баннеры) / блогеры / паблики)
  ▼
ПОКАЗЫ ── метрика: CPM (стоимость 1000 показов)
  │  ×CTR
  ▼
КЛИКИ ── метрика: CTR (клики ÷ показы)
  │
  ▼
ВИЗИТЫ ── метрика: CPC (стоимость клика)
  │  ×CR1
  ▼
ЛИДЫ ── метрики: CR1 (визит → лид), CPL (стоимость лида)
  │  ×CR2
  ▼
СДЕЛКИ ── метрики: CR2 (лид → сделка), CPA / CPO (стоимость действия/заказа)
  │
  ▼
ВЫРУЧКА С КЛИЕНТА ── метрика: LTV (Lifetime Value — деньги с клиента за всё время)
  │
  ▼
ИТОГ ── метрика: CAC (стоимость привлечения) → сравнение CAC vs LTV
```

## Как раскладывать бизнес-цель на метрики

Бизнес формулирует проблему расплывчато. Задача — перевести в дерево и найти проседающий узел.

| Что говорит бизнес | Куда смотреть в дереве |
|---|---|
| «Что-то мы не растём» | весь путь: где конверсия ниже бенчмарка |
| «Очень дорого привлекаем клиентов» | CAC vs LTV, затем вверх: CPL → CPC → CPM |
| «Маркетинг не работает» | CR1/CR2 — лиды есть, но не закрываются (или наоборот) |
| «У нас нет бюджета» | эффективность бюджета: CAC, укорачивание шагов |
| «Сколько денег нужно, чтобы вырасти X3?» | обратный расчёт от цели по выручке через LTV→CR2→CR1→CTR→CPM |

**Алгоритм:**
1. Возьми проблему («дорогой лид» / «низкий CTR» / «слабая конверсия в оплату»).
2. Найди соответствующий узел.
3. Сравни с бенчмарком (узнай у конкурентов/агентств реальные цифры — без этого нельзя ставить цель).
4. Сгенерируй гипотезы на этом узле → приоритизируй по ICE → возьми топ-3 на 2-3 недели.

## Узел CPM (стоимость 1000 показов)

**Каналы:** соцсети, поисковики (ключи + баннеры), блогеры, паблики.

**Как снизить CPM:**
- менять плейсменты;
- расширять или сегментировать аудиторию;
- играть с регионами, временем, сезонностью;
- пробовать новые каналы;
- работать с креативами и офферами;
- оптимизировать посадочную / приложение.

## Узел CTR (показы → клики)

**Формула:** клики ÷ показы.

**Как повысить CTR:**
- бить в Jobs to be Done (реальную потребность клиента);
- яркие, читаемые баннеры, правильная цветовая гамма;
- сильный заголовок и тело;
- визуальный акцент (эксперт, бренд, узнаваемость);
- хук/мессадж в первые 3-5 секунд;
- A/B-тесты форматов.

## Узел CPC (стоимость клика)

Производная от CPM и CTR. Снижается через рост CTR (дешевле клики в аукционе) и снижение CPM.

## Узел CR1 / CPL (визит → лид)

**CR1** — конверсия из визита в лид. **CPL** — стоимость лида.

**Как повысить CR1 и снизить CPL:**
- быстрая загрузка (особенно mobile-first);
- визуальный уровень → ориентироваться на лидеров рынка;
- соответствие оффера JOB и рекламной кампании;
- прямые ответы на 3 вопроса: **почему купить именно этот продукт? почему именно у этой компании? почему именно сейчас?**;
- Call-to-Action (CTA) на видных местах;
- простая структура страницы;
- social proof (отзывы, бренды, эксперты, сертификаты);
- FOMO (ограниченность, таймеры, очередь);
- чистый, аккуратный дизайн.

> Это и есть проектный мост к чек-листу лендинга (`references/leads-landing.md`). CR1 — узел, где живёт большинство landing-гипотез.

## Узел CR2 / CPA / CPO (лид → сделка)

**CR2** — конверсия из лида в сделку. **CPA/CPO** — стоимость действия/заказа.

**Как увеличить CR2:**
- **SLA: скорость дозвона и отклика** (≤15 мин — ключевой рычаг);
- скрипты продаж, FAQ, баттл-карты;
- цепочки WhatsApp / SMS / e-mail;
- ретаргетинг;
- быстрый checkout, несколько платёжных систем;
- удобство продукта, сервис;
- поддержка CSAT и NPS;
- акции, продуктовая матрица.

## Узел LTV (Lifetime Value)

Сколько денег клиент приносит за всё время жизни.

**Как увеличить LTV:**
- абонементы, подписки (как Яндекс.Плюс);
- мобильное приложение, онбординг;
- система привычек (фиксировать действия, ведущие к удержанию);
- апселлы и кросселлы;
- программы лояльности и реферальные механики;
- комьюнити и полезный контент;
- «вау-эффект» при первом опыте.

## Итоговый узел: CAC vs LTV

- **CAC** — стоимость привлечения клиента.
- **Главный финансовый тест воронки:** сравнение CAC vs LTV. Воронка здорова, когда LTV кратно выше CAC.

**Сквозные принципы экономики воронки:**
- объём бюджета и его эффективность важнее абсолютного размера;
- конверсия на КАЖДОМ этапе — точка приложения гипотез;
- **укорачивать шаги:** чем проще путь, тем выше конверсия;
- **не отпускать клиента «подумать»** — вероятность возврата резко падает;
- каждый этап = поле для гипотез;
- тестировать разные воронки и фиксировать лучшие показатели.

## Связь тактик CR2/LTV с типами воронок

Тактики узлов CR2 и LTV — это «мясо» конкретных типов воронок. Сопоставление узел → тип (детали в `references/funnel-types.md`):

| Узел / тактика | В каком типе воронки раскрывается |
|---|---|
| SLA + скрипты | Лид → Звонок |
| JTBD-письма + FOMO + social proof | Лид → E-mail |
| x10 value → АХА-момент | Бесплатный продукт (лид-магнит) |
| x10 value + FOMO + upsell | Tripwire |
| контент + продажа + спикер + CRM | Вебинар |
| прогрев + полезность + social proof | Бот |
| контент + разгоны + диалоги | Комьюнити |
| ограничение функций + JTBD-монетизация + онбординг | Freemium → Premium |
