# CRO & Funnels

> Conversion optimization for landing pages, signup, onboarding, paywalls, popups and forms; funnel design, A/B testing, full-funnel analytics.

Part of the **[hamidun marketplace](../../README.md)**.

## What's inside

| Skill | What it does |
|-------|--------------|
| `ab-testing-ru` | A/B-тесты и программа экспериментов: гипотезы, выборка, статзначимость, ICE. |
| `capi-no-code-setup` | Server-side события (Meta CAPI, GTM, офлайн-конверсии) БЕЗ кода — Zapier/n8n/Albato + CRM. |
| `form-cro-ru` | Конверсия форм захвата: заявка, регистрация, лид-магнит, подписка. |
| `full-funnel-analytics-ru` | Сквозная когортная аналитика: когортная воронка, Predict LTV, решения по выручке, не CPL. |
| `funnel-design-ru` | Проектирование воронок: дерево метрик CPM→CPL→LTV, 8 типов, лиды A/B/C/D. |
| `manychat-funnel-ru` | Автоворонки ManyChat «коммент → директ» для Instagram/FB/Telegram. |
| `onboarding-cro-ru` | Онбординг и активация trial ExampleProduct — до аха-момента. |
| `page-cro-ru` | CRO своих маркетинговых страниц: визит→заявка/trial. |
| `paywall-cro-ru` | Пейволлы, экраны апгрейда и фиче-гейты ExampleProduct: trial→платящий. |
| `popup-cro-ru` | Попапы, модалки, баннеры: захват email на news.your-domain.com, exit-intent. |

## Install

```text
/plugin marketplace add JHamidun/claude-code-config-pack
/plugin install cro-funnels@hamidun
```

Enable it with `/plugin` — the skills then activate automatically when relevant.
