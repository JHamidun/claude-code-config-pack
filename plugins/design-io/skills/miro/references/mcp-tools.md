# Miro MCP — все 31 инструмент

> Источник: https://developers.miro.com/docs/miro-mcp-tools (канонический список).
> Обзорная страница `miro-mcp` показывает урезанный набор из 20 и содержит устаревшее
> утверждение «Enterprise only» — не верь ей, сверяйся с этой таблицей и с `/mcp`.
> 15 на чтение (`boards:read`), 16 на запись (`boards:write`).

## Чтение доски и контекст

| Инструмент | Что делает | Ключевые параметры |
|---|---|---|
| `context_get` | Смысловая выжимка доски или элемента. **ЕДИНСТВЕННЫЙ инструмент, который тратит AI-кредиты Miro** | URL доски; URL с якорем на элемент сужает ответ |
| `context_explore` | Верхнеуровневый обзор: фреймы, документы, прототипы, таблицы, диаграммы | URL доски |
| `board_list_items` | Список элементов с курсорной пагинацией | доска, фильтр по типу, родительский контейнер, курсор |
| `board_search_boards` | Поиск досок. **Только внутри авторизованной команды** | запрос; фильтры по имени, описанию, владельцу, содержимому |
| `board_create` | Создать доску (запрашивает подтверждение) | имя, описание |

## Layout — массовые операции через DSL

Пары «спека → действие». **Всегда сначала `*_get_dsl`** — формат меняется на стороне сервера.

| Инструмент | Что делает |
|---|---|
| `layout_get_dsl` | Получить спецификацию DSL. Вызывать ДО создания |
| `layout_read` | Прочитать существующие элементы как DSL-текст |
| `layout_create` | Создать пачку элементов одним вызовом: фреймы, стикеры, шейпы, текст, карточки. Позиции и вложенность — в DSL |
| `layout_update` | Правка через find-and-replace по DSL-представлению |

## Чего MCP не умеет — только REST

Набор объектов у MCP **курируемый**, а не зеркало REST. Отсутствуют:

- **коннекторы** (стрелки между элементами) — самое частое, за чем придётся идти в REST
- **теги**, **группы**, **app cards**, **embeds**, **mind maps**
- данные о команде, организации, участниках и правах доступа
- точечное редактирование элемента по его id (MCP правит find-and-replace по DSL)
