# LinkedIn Suite

> Write, humanize, audit, plan LinkedIn posts; profile optimization; comment & reply drafting.

Part of the **[hamidun marketplace](../../README.md)**.

## What's inside

| Skill | What it does |
|-------|--------------|
| `linkedin` | LinkedIn intelligence via Scraping API — profile enrichment, company research, post monitoring, ad library analysis. |
| `linkedin-comment-drafter` | Draft a high-quality LinkedIn comment on any post from a URL. |
| `linkedin-content-planner` | Generate a 7-day LinkedIn content plan given a theme, audience, and content pillars. |
| `linkedin-detector-tester` | Run text through GPTZero, Originality.ai, ZeroGPT, Sapling, Copyleaks in parallel. |
| `linkedin-emoji-detector` | Detect AI-pattern emoji usage in any LinkedIn post or comment draft. |
| `linkedin-employee-advocacy` | Plan, launch, and operate a LinkedIn employee advocacy program for a marketing team. |
| `linkedin-hook-extractor` | Reverse-engineer the hook formula from any viral LinkedIn post. |
| `linkedin-humanizer` | Remove AI tells from any LinkedIn post or comment draft. |
| `linkedin-post` | Create and schedule LinkedIn posts with text, images, videos, and documents via your social MCP |
| `linkedin-post-audit` | Audit a LinkedIn post draft against 2026 algorithm heuristics and voice rules before publishing. |
| `linkedin-post-writer` | Draft a viral-ready LinkedIn post using a 2026 hook formula. |
| `linkedin-profile-optimizer` | Audit and rewrite a LinkedIn profile end-to-end for 2026 — headline formula, About section 7-step structure, Featured section strategy, banner… |
| `linkedin-reply-handler` | Draft a reply to any existing LinkedIn comment from a URL. |
| `linkedin-rules-explainer` | Explain why each AI-tell rule exists and whether to trust it. |
| `linkedin-thread-engagement` | Monitor LinkedIn threads where the user commented for author replies and inbound signals. |

## Install

```text
/plugin marketplace add JHamidun/claude-code-config-pack
/plugin install linkedin-suite@hamidun
```

Enable it with `/plugin` — the skills then activate automatically when relevant.
