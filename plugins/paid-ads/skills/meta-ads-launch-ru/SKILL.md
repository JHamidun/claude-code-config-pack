# Meta Ads Launch (RU)

> ⚠️ **Организация Meta признана экстремистской и запрещена в РФ.** Этот скилл — для **международных и СНГ-проектов**, B2C на зарубежных рынках и B2B с длинным циклом сделки. Используй только если работаешь на legal-рынках вне РФ или через иностранное юрлицо. Запуск из РФ требует отдельной инфраструктуры (см. ниже) и несёт правовые риски — это зона ответственности рекламодателя, не скилла.

Playbook по **запуску и ведению собственной рекламы** в Meta (Facebook/Instagram). Это про то, как **запустить аккаунт, настроить пиксель и CAPI, выбрать цель и стратегию, построить аудитории, провести кампанию через обучение и масштабировать** — то есть ~80% реальной работы таргетолога, которую не закрывает аналитика готовых кампаний.

> **Главный диагноз:** Meta — одна из самых продвинутых рекламных платформ с **сильнейшим ИИ**. В отличие от Telegram (нет оптимизации) и VK (алгоритмы почти не работают), здесь результат делает **обучение алгоритма** на твоих событиях. Поэтому весь успех — в том, чтобы **дать системе чистые данные** (пиксель + CAPI + правильное событие) и **не мешать ей учиться**. Главный психологический принцип: **«Если работает — не трогай»** — Meta крайне чувствительна к изменениям.

## Когда использовать

- Запуск Meta-рекламы с нуля: инфраструктура аккаунта из РФ → BM-архитектура → первая кампания.
- Настройка трекинга: Facebook Pixel, 6 стандартных событий, кастомные конверсии, Conversions API (CAPI).
- Выбор цели оптимизации под бизнес-модель (короткий цикл / длинный цикл B2B).
- Выбор стратегии ставок (Maximize Conversions / Cost Cap / Min ROAS / Bid Cap) и решение CBO/не-CBO.
- Построение аудиторий (сохранённые / широкая Advantage+ / Lookalike-лестница / Advantage+ Audience).
- Проведение кампании через фазу обучения (50 событий за 7-10 дней) и масштабирование без сброса.
- Диагностика «почему кампания не выходит из обучения / сжирает бюджет / CPM вырос».
- Запуск воронки сообщений (WhatsApp/Direct) или Call Ads для проектов без сайта/пикселя.

**НЕ использовать для:**
- Анализа метрик существующих кампаний, Breakdown Effect, Marginal vs Average CPA, Ad Relevance Diagnostics → **`meta-ads-analyzer`**.
- Шпионажа за креативами конкурентов в Meta Ads Library → **`ad-spy`** (раздел Facebook Ad Library).
- Выбора канала ДО запуска (стоит ли вообще идти в Meta) → **`media-planning-ru`**.
- Telegram Ads (`telegram-ads-pro-ru`), VK Ads (`vk-ads-pro-ru`), Google Ads, Яндекс.Директ.

> **Граница с `meta-ads-analyzer`:** этот скилл **запускает и ведёт** кампанию (setup → launch → scale). `meta-ads-analyzer` **диагностирует** уже работающую (метрики, аномалии аукциона). Для анализа чужой рекламы и поиска работающих креативов конкурентов — `ad-spy` + Atria.

## Что такое Meta Ads (контекст платформы)

- **Аукционная программатик-система.** Meta оптимизирует показы под цель рекламодателя, опираясь на огромные собственные данные о поведении пользователей. Сильная персонализация ленты → Meta строго следит за качеством креативов.
- **Аукцион = три компонента:** `Bid` (ставка) × `Estimated Action Rate` (вероятность целевого действия) × `Ad Quality` (качество объявления). **Качественный и релевантный креатив Meta показывает чаще даже при меньшей ставке** — побеждает «ценность для пользователя», а не голый бюджет.
- **Факторы цены за показ:** история аккаунта (trust) + частота и стабильность спендов + время суток и активность аудитории.
- **Meta классифицирует пользователей** по поведению: кто чаще заполняет лид-формы / кликает / вовлекается / пишет в Direct / покупает онлайн. ⚠️ Поэтому **выбор цели кампании — это выбор целого поведенческого кластера**, а не «галочка в настройках».
- **Эволюция таргетинга (paradigm shift):** интересы теперь работают как **сигналы**, а не как жёсткий таргетинг. Meta использует их как подсказку, но **выходит за рамки интересов**. Многие таргетологи это не учитывают и до сих пор «зашивают» аудиторию интересами — Meta всё равно её расширит.
- **5 групп плейсментов:** Facebook (лента / сторис / Reels / Marketplace / Messenger), Instagram (лента / сторис / Reels / Explore), **Threads** (новый, начинает интегрироваться), Audience Network (сторонние приложения и сайты). ⚠️ **Audience Network даёт много кликов, но низкое качество → портит CPA → отключать вручную.** Рекомендуется **Advantage+ Placements** (автомат всё, кроме Audience Network).

## Архитектура аккаунта Meta

**Business Manager → Campaign → Ad Set → Ads.**

🏛 **Business Manager** — «дом», внутри которого живёт всё: страницы FB/IG, рекламные аккаунты, пиксели, каталоги, пользователи и роли, платёжные методы, **WhatsApp Business номера**.

| Уровень | Что задаётся |
|---------|--------------|
| **Campaign** | цель оптимизации + стратегия ставок + модель бюджета (CBO / не-CBO) |
| **Ad Set** | пиксель + событие оптимизации + аудитория + гео + плейсменты + бюджет (если не CBO) |
| **Ads** | креатив + тексты + заголовки + ссылка + страница бренда + UTM |

**Форматы рекламы:**

| Формат | Когда |
|--------|-------|
| **Статика** (картинка) | самый простой и частый формат; **часто перформит лучше всего**, особенно где видео слабее |
| **Карусели** | сторителлинг, каталог, визуальное объяснение оффера |
| **Видео** | эффективность зависит от страны / плейсмента / ниши |
| **Instant Experience** | мини-лендинг внутри Meta, быстро открывается; частый в e-commerce |
| **DPA** (Dynamic Product Ads) | автоматическая витрина товаров для интернет-магазинов |
| **Collection ads** | формат-витрина для e-commerce |
| **Lead Forms** | встроенные лиды **без сайта** (внутри Meta) |

## Запуск инфраструктуры из РФ (4 пути)

⚠️ Meta запрещена в РФ → нужна обходная инфраструктура. **Полная decision matrix с pros/cons — `references/accounts-setup.md`.**

| Путь | Суть | Pros | Cons |
|------|------|------|------|
| **Антидетект + VPN + прокси** | FB-профиль не-РФ (номер, география) + **Dolphin Anty / GoLogin** + резидентные прокси | дёшево, полный контроль | трудоёмко, риск блока, обучение «с нуля» |
| **Покупка аккаунтов на биржах** | готовые «прогретые» FB-аккаунты | быстрый старт | ⚠️ высокий риск — могут блокнуть, **мета плохо обучается на дистанции** |
| **Премиум-агентские кабинеты** | кабинет агентства-партнёра Meta | стабильность, высокие лимиты | комиссия **3-7%** от бюджета |
| **Иностранное юрлицо** | свой BM на зарубежную компанию | **идеал для стабильного скейла** | дорого, долго, требует резидентства/компании |

**Лимиты нового платёжного аккаунта:**
- Старт: **~$50/сутки**.
- Чтобы поднять лимит → **тратить максимум каждый день**.
- Через **3-7 дней** → до **$200-500/сутки**.
- Через **полгода** → до **десятков тысяч/сутки**.

> **Про аккаунты:** премиум-кабинеты Меты — комиссия 3-7% в зависимости от бюджетов; бывают и обычные с кэшбэком. «Подготовленные» арбитражные аккаунты — высокий риск (могут блокнуть, не обучается мета на дистанции). Вывод: для серьёзного скейла — премиум-агентский или иностранное юрлицо, не биржа.

## Pixel + события + CAPI (трекинг — фундамент)

Без чистого трекинга **алгоритм не на чем учиться** → кампания не выйдет из обучения. Это критичнее креативов. **Полный playbook — `references/pixel-capi.md`.**

**Facebook Pixel** — обязательный инструмент: фиксирует поведение после клика по рекламе (просмотры, клики, отправку форм, AddToCart, покупки, движение по воронке). Без пикселя система не понимает, кто совершает важные действия.

**6 стандартных событий** (Meta использует для классификации поведения всех пользователей):
`PageView` → `ViewContent` → `AddToCart` → `InitiateCheckout` → `Purchase` / `Lead`.

**Кастомные конверсии** — для глубоких этапов, которые нельзя описать стандартным событием: квалифицированный лид, внутренние статусы CRM, звонок, подтверждение сделки.
> **Правило:** максимально использовать **стандартные** события (Meta их «понимает» лучше всего); кастомные — только для глубины воронки (квал-лид / звонок / оплата).

**4 способа установки пикселя:** ручная вставка в `<head>` / готовые интеграции платформ (Tilda, Shopify) / Google Tag Manager / Event Setup Tool (быстрый для базовых событий — клик, форма).

**CAPI (Conversions API) — обязателен для длинного цикла сделки.** Передаёт серверные события (лид, квалификацию, звонки, продажи, LTV), которые пиксель не видит. **7 параметров матчинга** (все нужны для качества): `email` + `телефон` + `страна` + `zip` + `External ID` + `FBC` (Facebook Click ID) + `FBP` (Facebook Browser ID).

**Внедрение CAPI без кода:** Zapier / Albato (российская альтернатива) / Make / n8n / готовая интеграция CRM (HubSpot, your CRM) / кастомная разработка. Обзор no-code-путей — `references/pixel-capi.md`; готовый workflow в `n8n` и отдельный скилл `capi-no-code-setup` (детали там).

**Test Events (обязательная проверка после установки):** открыть сайт в тестовом режиме → пройти воронку → убедиться:
- нет дублей событий;
- события приходят ровно **один раз**;
- данные идут стабильно и равномерно;
- веб-события + серверные события отображаются корректно.

## Аудитории (4 типа) и Lookalike

**4 типа аудиторий** — от ручного контроля к полному автомату. **Глубокий разбор + плейсменты — `references/audiences-targeting.md`.**

| Тип | Что это | Когда |
|-----|---------|-------|
| **Сохранённые** (соцдем) | пол / возраст / родительский статус / узкий соцдем + тематические сигналы | узкие сегменты, контроль |
| **Широкая Advantage+** | никаких настроек — Meta сама ищет людей | хорошие креативы + большой бюджет + широкая ниша |
| **Lookalike** | похожие на тех, кто конвертит | основа масштабирования на качественных событиях |
| **Advantage+ Audience** | алгоритм полностью решает кому показывать | e-commerce; во многих аккаунтах уже не отключается (Meta переводит всех) |

**Lookalike-лестница (строить только на КАЧЕСТВЕННЫХ событиях):** не на сырых лидах, а на **квал-лидах / звонках / оплатах**. Чем больше и качественнее события → тем лучше работает lookalike.

| Сегмент | Точность | Объём |
|---------|----------|-------|
| **1%** | максимально похожие | узкий, точный — старт |
| **1-3%** | расширение | средний |
| **3-5%** | широкий охват | большой |
| **>5%** | ⚠️ слишком широко | не использовать |

**Advantage+ vs ручное:** Advantage+ — e-commerce, большие объёмы данных, мощный пиксель, много веб-событий. Ручное — лидогенерация на маленьком бюджете, узкие сегменты, требуется высокая точность (квал-лиды).

**Стратегия запуска аудиторий (от точного к широкому):** точный пиксель → корректный CAPI → стандартные события → качественные lookalike → стабильные креативы → **потом** расширение на широкую и Advantage+.

## Выбор цели оптимизации (decision tree)

Все цели — 2 группы: **(1) Осознанность** (охват / трафик / вовлечённость) — для запуска нового продукта и узнаваемости, **в перформансе почти не нужны**; **(2) Конверсии** (лиды / продажи / установки приложений) — это основа.

**Decision tree выбора события оптимизации** (4 вопроса):
1. Есть ли сайт и пиксель?
2. Есть ли объём событий?
3. Какой цикл сделки?
4. Прямая продажа или лидогенерация?

| Цикл сделки | Что оптимизируем |
|-------------|------------------|
| **Короткий** (e-com, быстрые покупки) | событие **Purchase** генерируется часто → Meta получает много данных → **работает идеально** |
| **Длинный** (B2B, продажа через недели) | Meta не получает Purchase быстро → лестница: **Lead → Qualified Lead → глубокие события**. Квалификация обязательна, иначе много нецелевых лидов |

> **Правило глубины:** продаж мало → оптимизируйся на лиды; лиды мусорные → создавай квал-лиды; много данных и быстрые покупки → Purchase. Чем глубже событие, тем лучше обучение — **но только если хватает объёма (50+/неделя)**.

**Mini-playbook для проектов без сайта/пикселя (СНГ / emerging markets):** воронки сообщений (`WhatsApp` / `Instagram Direct` / `FB Direct`) и **Call Ads** (оптимизация на звонки) — часто единственный рабочий путь, когда нет сайта или пикселя. Детали — `references/audiences-targeting.md`.

## 4 стратегии ставок (только эти 4!)

| Стратегия | Суть | Когда |
|-----------|------|-------|
| **Maximize Conversions** | Meta сама ищет максимум конверсий | **самая стабильная, ~90% случаев, рекомендовано почти всегда** |
| **Cost Cap** | фиксируем желаемую стоимость лида/покупки | если CPL просаживается |
| **Minimum ROAS** | оптимизация на рентабельность (доход/затраты) | есть покупки в вебе + передаётся value (сумма чека) |
| **Bid Cap** | ручная ставка CPM | маленький бюджет, сильно снизить стоимость лида, работать только в дешёвом аукционе |

**CBO (Campaign Budget Optimization):** Meta распределяет бюджет между ad sets автоматически, уменьшает пересечения аудиторий, даёт максимум за тот же бюджет. ⚠️ Риск — может «залить» **80-90% бюджета в один адсет**; работает хорошо **только при сопоставимых аудиториях**.

**3 уровня любой кампании:** цель → стратегия ставок → модель бюджета (CBO / не-CBO). Когда какую стратегию — `references/learning-optimization.md`.

## Обучение алгоритма и масштабирование

Фаза обучения — это когда Meta анализирует, кому показывать рекламу дальше. **Полный protection-плейбук + scaling — `references/learning-optimization.md`.**

**Порог обучения:** **~50 событий** (лидов / квал-лидов / покупок) **за 7-10 дней** = выход из learning phase → стабильные результаты, предсказуемый CPL/CPA, кампания может работать месяцами. Не вышла → нестабильна, скачки цены, Meta «не понимает кто наш клиент».

**3 стадии воронки обучения** (система постепенно сужает выборку): общая аудитория → пользователи, реагирующие на объявления (**CPC-кластер**) → пользователи, совершающие нужное действие (**ядро**). Цель — найти микро-кластер людей, максимально похожих на тех, кто конвертит.

**7 факторов, СБРАСЫВАЮЩИХ обучение:**
1. изменение таргетинга;
2. изменение события оптимизации;
3. пауза кампании **> 7 дней**;
4. добавление **новых креативов в работающий адсет**;
5. изменение ставок;
6. резкое масштабирование бюджета **×2-×3**;
7. в редких случаях — отключение даже одного слабого креатива.

**4 БЕЗОПАСНЫХ действия (не сбивают):**
1. умеренное повышение бюджета **+10-15%/сутки**;
2. отключение/включение отдельных креативов (чаще не сбивает);
3. перевод с adset-budget на **CBO после накопления данных**;
4. добавление нового адсета (неоднозначно, зависит от случая).

**Ключевые правила:**
- **Правило 3 событий:** дневной бюджет должен покрывать ≥3 целевых события, иначе алгоритм не обучится. Решение — поднять бюджет или оптимизироваться на более верхний шаг воронки.
- **Минимальная аудитория:** **<100-200K** плохо обучает. Решение — расширять или поднимать событие оптимизации выше.
- **Правило креативов:** **6-8 креативов** оправданы (десятки $/день); **20-30 на $10 — бессмысленно**. Креативы — ключевой драйвер: именно они формируют первичную CPC-выборку.
- **Период оценки:** первые **2-3 дня** = накопление сигналов, не выводы. Не делать выводы по 1-2 лидам. **Не выключать первые 5-7 дней.**

**5-step launch (базовый фреймворк запуска):**
1. Начинай с **Maximize Conversions**.
2. Используй **Advantage Placements** (отключив Audience Network вручную).
3. Следи за качеством лидов → вводи **квалификацию**.
4. Проверяй, **проходит ли кампания обучение**.
5. **Не выключай кампанию первые 5-7 дней.**

## Признаки сбоя и аномалия конца квартала

**Метрики оценки:** CPM / CTR / CPC / CR (в лид / квал / оплату) / CPL / CPA.

| Симптом | Действие |
|---------|----------|
| Резкое падение конверсий | подождать сутки (атрибуция) → если подтверждается → **перезапуск** |
| Формы / ленды / тех. сбои | проверить; если всё ок → **перезапуск** |
| FB тратит **в 2-3× больше** дневного бюджета | **стоп и перезапуск** |

> **Аномалия конца квартала:** CPM **в 2-3× выше** нормы (рекламодатели «дожимают» планы). Правильно: **остановить все кампании** → **перезапускать малыми партиями** → мониторить CPM **каждые 2-3 часа**.

**Кардинальный принцип:** **«Если работает — не трогай.»** Meta крайне чувствительна к изменениям — любая правка может сбросить обучение и убить рабочую связку. (Та же логика и в Яндекс.Директ: «работает — не трогай, лучшее — враг хорошего».)

## Бенчмарки (быстрый ориентир)

| Метрика | Значение |
|---------|----------|
| Лимит нового аккаунта | **$50/сутки** → через 3-7 дней $200-500 → через полгода десятки тысяч |
| Премиум-агентские кабинеты | комиссия **3-7%** от бюджета |
| Порог обучения | **~50 событий за 7-10 дней** |
| Lookalike сегменты | 1% / 1-3% / 3-5% (>5% слишком широко) |
| Минимальная аудитория | **100-200K+** (меньше → плохое обучение) |
| Безопасный шаг масштабирования | **+10-15%/сутки** (×2-×3 = сброс) |
| Правило креативов | 6-8 при норм. бюджете; 20-30 на $10 = бессмысленно |
| Правило бюджета | дневной бюджет ≥ стоимости **3 целевых событий** |
| Maximize Conversions покрывает | **~90%** всех кейсов в продакшене |
| CPM b2c EU столицы (Лондон/Париж/Берлин) | **$10-15** в среднем |
| Конец квартала | CPM **2-3×** выше нормы |

> **⚠️ Управление ожиданиями.** Цифры — ориентиры (B2C международный). CPM/CPL/CPA сильно зависят от гео, ниши, качества пикселя и креативов. Достоверные выводы — только на **собственной статистике**. Полная таблица + контекст — `references/benchmarks.md`.
