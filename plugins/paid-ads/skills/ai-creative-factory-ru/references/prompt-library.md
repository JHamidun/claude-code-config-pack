# Библиотека промптов — дословные заготовки с досок курса

Источник: доски методология — «Машинка контента» (экспертная методология), «1 занятие Marketing Ninja» (поток N), «Создание посадочной + креативы». Промпты приведены **дословно**: это переносимый актив, который работает в том виде, в каком его обкатали. Меняй в них предметную область и данные, а не структуру — структура и есть то, за что платили.

> Не путать с **библиотекой промтов креативов** (`references/creative-system-4params.md`) — там хранятся промты каждого выпущенного ролика, чтобы его можно было воспроизвести. Здесь — промпты-инструменты, которыми креативы производятся.

Порядок примерно совпадает с конвейером: идея → сценарий → раскадровка → персонаж → ТЗ на статику.

---

## 1. «Креативный продюсер» — 20 виральных AI-видеокреативов

Самый длинный промпт на доске. Даёт не сценарии, а поле идей: 20 заготовок, из которых в производство уходят единицы. Ценность в жёстком формате вывода — без него модель отдаёт абзацы прозы, которые нельзя сравнить между собой и нельзя отдать в раскадровку.

```
Действуй как креативный продюсер. Придумай 20 идей вирусных AI-видеокреативов.

Для КАЖДОЙ идеи дай:
  · Название — 3-7 слов
  · ЦА — возраст, контекст, боли, мотивации
  · Hook / первый кадр
  · Формат — один из: POV · мини-сценка · ситком · split-screen ·
    fake trailer · CGI/sci-fi · мем-формат · антропоморфизм ·
    лайфхак-формат · UGC · «спорим, ты не знал?» · сторителлинг
  · Сторителлинг — 10-25 секунд
  · AI-визуал / стиль
  · Преимущество продукта — подаётся НАТИВНО, не прямой рекламой

Тон: дерзкий, современный, нативный, клиповый, эмоциональный,
простыми словами, без воды.
Длина ролика: 10-30 секунд.

Формат вывода строго:
1) Название
   ЦА:
   Hook:
   Формат:
   Сторителлинг:
   AI-визуал:
   Преимущество продукта:
```

Список форматов в промпте — не украшение: он не даёт модели свалиться в один формат на все 20 идей, что происходит по умолчанию.

## 2. Промпт-сценарист (на базе своей обучающей базы TOV)

Работает через файл-эталон: модель сначала изучает структуру и TOV твоих текстов, потом адаптирует под них новый материал.

```
Действуй как копирайтер с опытом 15 лет с фокусом на виральный контент.
Первое, что тебе нужно сделать: проанализировать текста в файле, который я
вгружаю, это обучающая база для TOV и структуры роликов. Изучи на 100%,
сохрани в памяти. Проанализируй их структуру. Далее я тебе буду присылать
материал для своего контента, который тебе надо адаптировать по структуре и
TOV текстов из файла. Должен быть максимально крутой хук (первое предложение
в тексте, примерно первые 3 секунды видео, задача которого максимально
захватить внимание).
```

## 3. Промпт-адаптер под рубрику

Тот же жанр, но отправная точка — уже найденный успешный сценарий из трендвотчинга, а материал модель собирает сама.

```
Действуй как копирайтер с опытом 15 лет с фокусом на виральный контент.
Первое, что тебе нужно сделать: проанализировать успешный сценарий из нашего
трендвотчинга. Тебе надо собрать контент из интернет-источников для создания
похожих сценариев в таком же формате, TOV, рубрике и предоставить ответ в виде
готовых 3 сценариев. Должен быть максимально крутой хук…, контентная часть
без воды и СТА подписаться.
```

**Четыре способа скормить модели трендвотчинг** и что с каждым не так:

| Подход | Что хорошо | Что плохо |
|--------|------------|-----------|
| Весь трендвотчинг + «напиши сценарии на его основе» | Нормально копирует сценарии, часто хорошие хуки | Не все темы подходят под ЦА, нет разбивки по форматам, **плохо копирует хронометраж**, слабый контент |
| Вгружаем **видео** и просим адаптировать | Модель видит визуал, а не только текст | Дороже по токенам, нужна модель с video understanding |
| **TOV + сценарий из трендвотчинга** в Google Docs | Стабильный голос бренда | Ограничен одним референсом |
| Весь трендвотчинг + большой промпт на анализ трендвотчинга и рубрикатора | Уникальные сценарии с учётом рубрик | Самый дорогой и долгий вариант |

Общая беда всех четырёх — **хронометраж**. Модель охотно копирует слова и не копирует ритм, поэтому тайминг в раскадровке задаётся отдельно и руками (см. промпт ниже).

## 4. Промпт-раскадровщик (ключевая механика)

Превращает сценарий в набор кадров с двумя промтами на каждый — на картинку и на видеомодель.

```
Действуй как креативный продюсер с экспертизой в AI создании роликов.
Я тебе присылаю сценарий. Твоя задача, основываясь на best practice, сделать
мне раскадровку. Важно: каждые 5 секунд должно что-то меняться, постоянно
должно происходить что-то залипательное в кадре, что а) иллюстрирует
происходящее скрипта, б) повышает метрику удержания. Первый кадр — это всегда
хук, должно произойти что-то, что ломает парадигму. Разбей мой сценарий на
кадры. Для каждого кадра: 1) промпт для Start Frame (картинка), 2) промпт для
Veo 3 с подробным описанием действия объектов.
```

Две зашитые нормы, ради которых промпт и написан: **смена каждые 5 секунд** и **первый кадр = хук**. Без первого требования модель отдаёт длинные статичные планы, и удержание валится к середине; без второго — начинает ролик с представления темы, то есть тратит те самые три секунды, в которых всё решается.

## 5. Character designer — стабильный персонаж

Собирает профиль персонажа так, чтобы его можно было воспроизвести в следующей сцене и через месяц: якоря стабильности плюс короткая сигнатура для вызова.

```
Выбери ОДИН стиль для персонажа и обоснуй выбор одной строкой.
Затем выдай профиль персонажа: возраст, внешность, черты лица, глаза,
волосы, рост и телосложение, одежда, мимика, 5-7 якорей стабильности.
Затем — готовый промпт для Midjourney / Nano Banana.
Затем — seed-подпись персонажа из 3-6 слов.

Формат вывода:
СТИЛЬ:
ПЕРСОНАЖ:
PROMPT ДЛЯ MIDJOURNEY / NANO BANANA:
SEED-СИГНАТУРА:
```

**Якоря стабильности** — это 5-7 признаков, которые повторяются в каждом промте дословно (шрам, оправа, цвет куртки, седая прядь). Модель забывает всё, что не повторено, поэтому персонаж «плывёт» от сцены к сцене именно на неописанных деталях. **Seed-сигнатура** — короткое имя-вызов, чтобы не переписывать профиль целиком в каждой сцене.

Механики консистентности на стороне генератора (Omni reference, предустановленный актёр из 20 фото, Ingredients) — `references/video-creative-pipeline.md`.

## 6. AI-арт-директор — ТЗ на баннер из размеченной таблицы

Вход — таблица с разметкой креативов и результатами открутки плюс выводы генеалогического и регрессионного анализа. Выход — готовое ТЗ дизайнеру и копирайтеру. Это замыкающее звено Creative System (`references/creative-system-4params.md`).

```
Представь, что ты — AI-арт-директор и креативный стратег в команде
performance-маркетинга. Ты получил таблицу с промеченными баннерами и
результатами по метрикам (CPL, лиды). На её основе был проведён анализ,
который выявил, какие параметры дают лучший результат. Задача — собрать
чёткое, минималистичное ТЗ для дизайнера и копирайтера.

Входные данные:
  · таблица с креативами (параметры C-W, метрики AD-AJ)
  · ключевые метрики: CPL и количество лидов
  · результаты анализа: генеалогический + регрессионный

На основе успешных отдельных параметров И их комбинаций сформируй ТЗ на
баннер, который будет визуально в стилистике победивших креативов, включать
сильные офферы, CTA, цвета и объекты, обращаться к релевантной ЦА и её боли.

Формат вывода:
📐 Техническое задание на баннер:
🎨 Визуал: формат · основной цвет · цвет CTA · спикер · контекст · объекты ·
   доп. элементы
📝 Текст: заголовок капсом · подзаголовок · боли ЦА · УТП · CTA
📍 Примечания:
🧠 Дополнительно: если параметров много, предложи несколько вариантов ТЗ
   (A/B/C) — например, один баннер ориентирован на «боль → CTA»,
   другой — «оффер → выгода → CTA».
```

Последняя строка — самая ценная. Без неё модель отдаёт один «средний» бриф, усредняющий все выигравшие параметры сразу; с ней получается **пак вариантов с разной логикой**, а это и есть то, что нужно запускать на тест.

**Пример вывода** (реальный кейс с доски — обучение бухгалтерии в Германии для мигрантов, весна 2026): квадратное видео · светло-оранжевый основной цвет, ярко-красный CTA · спикер — женщина 25-35, улыбается · интерьер домашнего офиса · ноутбук, блокнот, чашка кофе · график роста и значок «−25%» · заголовок капсом «ОБУЧИСЬ БУХГАЛТЕРИИ В ГЕРМАНИИ» · подзаголовок «Начни карьеру за 7 месяцев. Старт в мае» · боль «Нет опыта — не проблема» · УТП «Для мигрантов», «Сертификация от DATEV», «Проверено работодателями» · CTA «Оставь заявку — получи бонус» · отзыв студента в нижнем углу.

## 7. Пятишаговый маршрут «ChatGPT + Midjourney» для статики

Старый, но рабочий маршрут под баннеры: текст рождается первым, картинка подбирается под текст, а не наоборот.

```
Шаг 1  Общий промт — «напиши мне 10 идей»
Шаг 2  ChatGPT прислал идеи
Шаг 3  Просим ChatGPT сгенерировать промт для Midjourney (визуал креатива)
Шаг 4  MJ генерирует картинку
Шаг 5  Дизайнер добавляет текст
```

**Промпт шага 1 (дословно, EN — пример под платформу онлайн-курсов):**

```
Hello, Associate! Imagine you are a creative director of the Stages — a platform
for hosting and selling educational courses. Our target audience is those who
want to make money selling online courses (coaches, online schools, experts).
Write 10 advertising creatives according to the given terms: Headline — no more
than 10 words, preferably less; subheadline — no more than 20 words.
I attached the best creatives we already tested, you may also refer to it.
Also come up with a TOC for this audience and use them. Use best practices to
create a selling and catchy advertising message.
```

**Промпт шага 3 (дословно, EN):**

```
Act as an experienced marketing manager / copywriter. Come up with a consistent
visual for these creatives so that the text and picture match and reinforce each
other. The format of the creative is static. Be specific, describe each detail.
```

Ограничения по длине (заголовок ≤10 слов, подзаголовок ≤20) стоят в промпте не случайно: без них модель выдаёт заголовки, которые физически не читаются в ленте за полсекунды. Шаг 5 — «дизайнер добавляет текст» — остаётся ручным по той же причине, по которой русский текст не отдают генератору: см. правило про кириллицу в `references/anti-ai-slop.md`.

**JTBD → креатив.** Отдельный приём с той же доски: работа клиента переводится не в описание функции, а в **гиперболизированный визуальный образ**. «Улучшить физическую форму» → спортивная женщина в костюме супергероя + «Стань супергероем фитнеса!»; «эффективно управлять временем» → человек-супергерой с огромным циферблатом + «Тик-так, тик-так — будь хозяином своего времени!». Формат заготовки: `JTBD: <работа> → Изображение: → Заголовок: → Текст:`.

## Как этим пользоваться

1. Промпт копируется целиком, меняются только предметная область и входные данные.
2. Формат вывода (`Формат вывода:` в конце) **не удалять** — на нём держится то, что результат можно сравнивать между прогонами и передавать дальше по конвейеру.
3. Свой рабочий вариант промпта после доработки складывать рядом — в ту же библиотеку, что и промты креативов (`references/creative-system-4params.md`), иначе через месяц удачная формулировка не воспроизведётся.
