## Anti-AI-slop — чтобы AI не «палился»

> **AI — это инструмент, а не стиль.** Людям важна ценность и эмоция, а не способ производства. Если ролик кричит «меня сделала нейросеть» — он теряет доверие и попадает под алгоритмический даунгрейд за AI-slop.

Production-гигиена перед публикацией:

| Приём | Зачем |
|-------|-------|
| **Менять кодек** | Перекодировать выход генератора — убрать характерную сигнатуру модели |
| **Апскейлить** | Поднять разрешение → меньше артефактов, «дешёвый» AI-look уходит |
| **Заменять аудио** | Не оставлять стоковый/AI-звук — свой голос/музыка/SFX |
| **Правильно монтировать** | Ручной ритм, дофаминовые всплески, jump-cut — не «один длинный AI-план» |
| **Избегать AI-slop** | Не оставлять типичные глюки: пластиковые лица, морфящийся текст, лишние пальцы, бессмысленный фон |

**Особое правило про текст и числа в хуке:** AI-модели гарбят цифры и буквы. Крупный текст/число в хуке («$10 000 000», название) компонуй оверлеем поверх кадра (PIL/монтаж), а НЕ проси у image-модели и НЕ прогоняй через i2v. (Боевая заметка из `video-generation`.)

### Режиссёрский подход против «одного промта»

❌ Антипаттерн — пытаться сделать готовый ролик «одним промтом».

✅ Думать как режиссёр — каждая стадия отдельный осознанный шаг:

```
идея → сценарий → раскадровка → старт-фреймы → анимация → монтаж → ритм
```

Каждая стадия = отдельный инструмент и/или отдельный AI-агент («1 формат = 1 агент»). Техническая реализация стадий — в `video-generation` (анимация/сборка), `nano-banana-pro`/`image-generation` (старт-фреймы), `video-editor` (монтаж/ритм).

## A/B-тестирование креативов — 6-8, не 20-30

Регулярно тестируй и оптимизируй элементы креатива на основе данных:

- **Что тестируем:** хуки · изображения · тексты (по одному элементу за итерацию, чтобы понять, что сработало).
- **Сколько креативов:** **6-8 на запуск.** Контр-факт эксперта: лить 20-30 креативов на $10 — бессмысленно. Алгоритм не успевает обучиться на каждом — бюджет размазывается, ни один не получает достаточно показов для выхода из обучения.
- **Связь с обучением алгоритма:** дай каждому креативу шанс пройти фазу обучения (накопить достаточно конверсий/показов), прежде чем отключать. 6-8 — это потолок, при котором каждый ещё получает осмысленный объём.
- **Итерация:** отобрал победителей → сделал вариации победившего хука/визуала → новый раунд 6-8. Это и есть «фабрика»: непрерывный поток гипотез, а не разовый запуск.

**Важный контр-факт о приоритете:** в Google в 8-9 случаях из 10 «аудитории > креативов» (эксперт. В соцсетях с авто-таргетингом (Meta/VK Reels/in-feed) — наоборот, выигрывает креатив. Прежде чем вкладываться в дорогое креативное производство, пойми, на какой площадке играешь.

## Анализ креативов конкурентов

### Meta Ads Library — методика чтения

`facebook.com/ads/library` — бесплатная база всех активных рекламных креативов.

- Искать **НЕ по названию компании**, а по **точному имени FB-страницы** конкурента.
- Список нужных FB-страниц удобно собирать через ChatGPT с веб-поиском.
- Что вытаскивать: какие хуки крутят, какие форматы, как часто меняют.
- **Longest running ads = золото.** Объявление, которое крутится дольше всех, — это проверенный временем перформанс-креатив (конкурент не стал бы держать убыточное). Декомпозируй именно их по 5-блочному канону (`references/hook-structure.md`).

Альтернативы: **Bigspy** (spy за рекламой), **Google Ads Transparency Center** (`adstransparency.google.com` — Google Ads).

### Atria — spy + clone creatives (`tryatria.com`)

Продвинутый пайплайн (с эфира [агентство] 09.04):

```
подписка на конкурентов в Atria
  → все активные креативы + хуки + бюджеты по лендингам
  → фильтр по longest running ads
  → видение: на какие лендинги льют, сколько объявлений на лендинг
  → clone-add адаптирует визуал под себя (свой текст)
  → готовый креатив в свой кабинет → тест
  → Atria оценивает каждый креатив: A+ / High iteration / Underperforming
```

> Не копируй визуал один-в-один — извлекай **паттерн** (5-блочный канон + 6 паттернов декомпозиции), адаптируй под свой оффер. Глубже про spy-инструменты и Scraping API — в скилле `ad-spy`.

## Чеклист перед запуском креатива

- [ ] 5-блочный канон собран (хук → сеттинг → тезисы → дофаминовые всплески → CTA)?
- [ ] Хук силент-френдли, ловит за 0-3 сек?
- [ ] Эмоция + понимание боли + решение + social proof в тезисах?
- [ ] FOMO в CTA (если уместно)?
- [ ] Anti-AI-slop пасс пройден (кодек / апскейл / аудио / монтаж)?
- [ ] Текст/числа в хуке — оверлеем, не AI-генерацией?
- [ ] 6-8 креативов на запуск (вариации хука/визуала/текста)?
- [ ] Декомпозированы longest running ads конкурентов из Meta Ads Library / Atria?
- [ ] Понятно, площадка решает аудиториями или креативом?
