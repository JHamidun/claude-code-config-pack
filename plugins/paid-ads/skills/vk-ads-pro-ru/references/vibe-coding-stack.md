# Вайб-кодинг маркетинговых инструментов — стек и экономика

Когда писать свой инструмент, а когда купить готовый. Цены и лимиты — данные августа 2026.

---

## Google your-proxy как рабочая среда

- **Модели:** преимущественно Gemini; в списке также Claude Opus и урезанная версия GPT.
- **Цена:** доступ к максимальному тарифу Ultra ~$20–25/мес через посредников/маркетплейсы.
- **Лимиты:** практически не достигаются — за неделю ежедневной работы по несколько часов уходит ~20% лимита Gemini.
- 🔴 **Две обязательные настройки для агента полного цикла: Turbo Mode + Always Proceed** — агент пишет план, не дожидается ответа и работает до результата без остановок.
- Сильные стороны: бесшовный доступ к Google Docs (родная среда); открывает YouTube-ссылки и докачивает модули для скачивания видео; **Nano Banana внутри того же тарифа** — рисует креативы и наносит текст/плашки на реальные фото спикера.

## Готовый промпт «маркетинговый дашборд из сырья»

> «Проанализируй всю информацию, перейди по всем ссылкам в сообщении и в документах, найди все боли и выгоды, собери фото спикера в отдельную папку. Составь красивый HTML-документ и пропиши в нём 5 самых конверсионных сегментов и для них смыслы, заголовки и тексты объявлений.»

Результат с первой попытки: интерактивный дашборд с анализом продукта, болей, возражений, сегментами по приоритету, готовыми заголовками и текстами — включая самостоятельную проверку лимитов по числу символов, о которой не просили.

## Экономика: свой парсер vs Target Hunter

- Самописный VK-парсер по времени разработки **≈ 2–3 года подписки Target Hunter** (~2 000 ₽/мес, скидка 50% навсегда по промо).
- Вывод: example-queryить стоит **только уникальные задачи** и только если готов поддерживать продукт. Для стабильной командной работы дешевле купить Target Hunter.
- Фича, которой в Target Hunter нет и ради которой парсер имел смысл: **минусование сообществ кластерами** по автоматически выделенным частотным словам — 700 → 500 → 166 сообществ за 4 клика.

## Собственный сборщик инсайтов по рекламе (работает за 0 ₽)

эксперт показал свой инструмент: каждое утро в **9:00** агент проверяет новые статьи по Яндексу, ВКонтакте (и Threads) и складывает их в один дашборд. К августу 2026 накоплено **600+ инсайтов**. Проект открытый, лежит на GitHub, ссылку раздавал через кураторов курса — можно скачать и адаптировать под себя.

Что в карточке статьи: ссылка на первоисточник, **summary** (самое информативное) и **сниппет** — то, что ИИ-агент увидел в выдаче. Разбито по категориям: ошибки при создании кампании, оптимизация, управление ставками. Честная оговорка: «Это сырая выдача, сырой поиск по новинкам. Не все статьи одинаково полезны».

**Почему бесплатно — стек** (ответ на вопрос слушателя, у которого похожий краулер вырос с $0,03 до $1 в день на API Anthropic):

```
Логика       → обычный код (Python), LLM зовётся ТОЛЬКО на написание summary
Поиск        → бесплатный поисковик DuckDuckGo (суточные лимиты не достигаются)
LLM-ключи    → стек из ~10 бесплатных ключей, перебираются по очереди:
               Google AI Studio (Gemini; там же бесплатно первая Nano Banana),
               Grok (не масковский — тот, что «заканчивается на Q» [Groq]),
               Pollinations, Together, OpenRouter
               ⚠️ ключ AI Studio могут забанить — держать несколько
Платный ключ → подключается только когда исчерпаны все бесплатные (дешёвая Gemini)
Хостинг      → GitHub (бесплатно)
Объём        → ~9 новых статей в день (по 3 на источник) — «бесплатных ключей
               даже одного, по идее, хватает»
```

Способ найти новые бесплатные ключи, названный спикером: «спрашиваю у своего ИИ-агента: найди сервисы, которые дают бесплатные ключи». Для этой задачи **Claude избыточен**: «тут вообще нет задач для Клода, код избыточный».

## Целевое видение автоматизации

Агент сам заливает креативы и тексты в кабинет, ночью тестирует по фиксированной цене за гипотезу (5 000 ₽ = 50 гипотез по 100 ₽), утром присылает ссылку с аналитикой победителей. Гипотезу для старта тоже можно спросить у агента — точность сопоставима с профессионалом.
