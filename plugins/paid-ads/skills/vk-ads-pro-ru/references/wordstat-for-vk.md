# Wordstat для VK Ads — перенос семантики в ключи таргетинга

> **Источник:** курс методология (7 поток) — эксперт (блок VK Ads).
> **Граница скиллов:** ЗДЕСЬ — как обработать семантику под ключи VK Ads (что убрать, что оставить).
> Сама выгрузка фраз из Wordstat — сервис Яндекса, скилл `yandex`.

## Зачем

Ключевые фразы — один из самых сильных и **самых дешёвых** инструментов таргетинга в VK Ads.
По бенчмаркам эксперта цена результата по ключам **50–70 ₽** против **200–400 ₽** по категориям
интересов (см. `benchmarks.md`). Источник самих фраз — **Яндекс Wordstat**:
в Wordstat виден реальный спрос (что и как формулирует аудитория про свою проблему/задачу).

## Ключевое отличие от Директа

В VK Ads берём фразы **про проблему/задачу ЦА**, но обрабатываем их иначе, чем для поисковой
рекламы Директа:

| | Директ (Поиск) | VK Ads (ключи) |
|---|---|---|
| Операторы Wordstat (`!`, `+`, `" "`, `[ ]`) | используются для уточнения семантики | **не нужны** — VK не понимает синтаксис операторов, нужны чистые слова/фразы |
| Минусовка | агрессивная, отсекаем всё нерелевантное | **минусуем только очевидно нецелевое** (аудитория и так широкая, лишняя чистка сужает) |
| Что собираем | точные коммерческие запросы под выдачу | фразы вокруг проблемы/задачи — VK ловит тех, кто их вводил в Яндексе |
| Обновление аудитории | — | по понедельникам → планируй объём фраз на неделю вперёд |

## Алгоритм переноса

1. **Собрать маски/фразы в Wordstat** под боль/задачу ЦА (скилл `yandex`, сервис Wordstat).
   Удобнее старый интерфейс `old.wordstat.yandex.ru` + правая колонка похожих запросов.
2. **Очистить от операторов.** Убрать `!`, `+`, `" "`, `[ ]` — оставить чистые слова и
   словосочетания. VK Ads ждёт обычный список фраз, операторы Wordstat он не интерпретирует.
3. **Снять ВЧ-мусор.** Отбросить слишком общие высокочастотные слова без коммерческого/проблемного
   смысла (одиночные ВЧ вроде «купить», «цена» без контекста, информационный шум). Оставить фразы,
   отражающие конкретную задачу/проблему.
4. **Минусовать только очевидно нецелевое** — без агрессивной поисковой минусовки. Типовые
   исключения VK: ищущие бесплатные аналоги («скачать бесплатно», «своими руками»), нерелевантные
   профессии/намерения. (Полный список исключений — `SKILL.md`, раздел «Аудитории и таргетинг».)
5. **Загрузить в VK Ads** как аудиторию по ключевым фразам (зацепка «Ф1»). Дальше — `SKILL.md` и
   `krestinin-methods.md`: нотация аудиторий, Метод А для бесплатного теста фраз, пересечение/вычитание.

## Технический вызов Wordstat — в скилле `yandex`

Wordstat живёт в legacy Direct API v4 (цепочка `CreateNewWordstatReport` → `GetWordstatReportList` →
`GetWordstatReport` → `DeleteWordstatReport`, токен `YANDEX_OAUTH_TOKEN`, заголовок `Bearer`).
Код и эндпоинты держит скилл `yandex` (`SKILL.md`, раздел Wordstat + `references/api-endpoints.md`)
— копию сюда не тащим: две копии одного вызова чинят в одном месте, а вторая молча остаётся старой.
Здесь только то, что делают с фразами ПОСЛЕ выгрузки.

## Связанные скиллы

- `yandex` — сам сервис Wordstat: OAuth, вызов legacy API v4, лимиты отчётов.
- `yandex-direct-pro-ru` — операторы Wordstat и семантика под Поиск Директа (там операторы НУЖНЫ).
- `seo-machine-ru` — Wordstat-семантика под органическую выдачу.
