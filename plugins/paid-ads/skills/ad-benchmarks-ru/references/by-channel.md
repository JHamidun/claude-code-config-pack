## 1. Яндекс.Директ

> Источник: экспертная методология. эксперт. Деталь запуска — `yandex-direct-pro-ru`.

### CTR

| Площадка | Норма | Трактовка отклонения |
|----------|-------|----------------------|
| **Поиск** | **>5%** | <5% → проверить позицию (средняя >3 = нижний блок) или релевантность |
| **РСЯ** | **<2%**, идеал **<1%** | **>2% = плохо**: скликивание, мисклики, накрутка |

- Приложения в РСЯ (`af://`, `id://`) часто дают CTR **30-100%** → скликивание → **отключать немедленно**.
- Высокий CTR на Поиске → верхний блок (позиции 1-4) → улучшает коэффициент качества.

### % отказов

| Площадка | Норма |
|----------|-------|
| **Поиск** | **<30%** |
| **РСЯ** | **<40-50%** (идеал <30%) |

Отказ в Метрике = визит ≤15 сек и ≤1 страница.

### Минимум данных для решений

| Решение | Минимум кликов |
|---------|----------------|
| Любые выводы по кампании | **100 кликов** за неделю |
| Решение по площадке (РСЯ) | **50 кликов** |
| Решение по запросу | **15-20 кликов** |
| На 1-3 кликах | решений НЕ принимать |

### Обучение автостратегий

| Параметр | Значение |
|----------|----------|
| Минимум конверсий | **≥10 в неделю** на РК |
| Минимальная длительность | **7 дней** |
| Полное обучение | **2-3 недели** (РСЯ — до 4) |
| Остановка, обнуляющая данные | **>7 дней** |

### Погрешность алгоритма по объёму конверсий

| Конверсий | Погрешность по цене |
|-----------|---------------------|
| 25 | **±40%** |
| 400 | **~10%** |
| 10 000 | почти нет |

### Ключевые формулы

- **Минимальный недельный бюджет = средняя цена конверсии × 10** (CPA 2000 ₽ → ≥20 000 ₽/нед).
- **Правило X3:** потрачено ≥3 × KPI за лид без лидов → отключать.
- **Масштаб:** не более +10%/нед на автостратегиях; CPA ≤ 1.2 × KPI, откат при >1.3 × KPI.
- Оплата **за клики** — в ~**90%** случаев.

## 2. Google Ads

> Источник: эксперт (Google-блок). Деталь — `google-ads-pro-ru`. В РФ для рекламодателей заблокирован → межд/СНГ.

### Ключевые метрики и нормы

| Метрика | Норма / цель |
|---------|--------------|
| **CTR Search** | **7-15%** |
| **Quality Score** | цель **8-10** |
| **Bounce rate** | **>45% = проблема** с посадкой |
| **Search Impression Share (SIS)** | цель **80-100%** |

### CTR Search по рынкам (для прогноза бюджета)

| Рынок | CTR |
|-------|-----|
| **СНГ** | **10-15%** |
| **Европа / США / Запад** | **5-7%** |

Ставки в РФ/СНГ ниже, на Западе выше.

### CTR в медийке

| Сеть | CTR |
|------|-----|
| **Google Display Network (КМС)** | **<0.4%** (мусорные площадки) |
| **Яндекс РСЯ** | **>0.4%** (качественнее модерация) |

### Обучение и масштаб

| Параметр | Значение |
|----------|----------|
| Learning Phase | **5-7 дней минимум** |
| Переход на Max Conversions / Target CPA | при **50+ конверсиях** |
| Ротация объявлений вкл. | после **30-50 кликов** на объявление |
| Дневной расход | **0.5-2× дневного бюджета** в отдельные дни |

### Масштабирование охвата (нелинейная конкуренция)

- Первые **10-20%** трафика — дёшево; **50-60%** — дороже; **70-80%** — рост экспоненциальный.
- Точка баланса: выкуп 60-70% становится в 2× дороже → дополнять другими каналами.
- Повышать ставки на **10-20%**, ждать **3-7 дней**, оценивать охват/CPC.
- Лайфхак двух кабинетов: +**15-20%** трафика сверх потолка одного кабинета.
- A/B-тест команд: **50/50 → 60/40 → 70/30 → 80/20** (займёт месяцы).

### Доли рынка

| Регион | Google | Яндекс |
|--------|--------|--------|
| СНГ | **70%** | 30% |
| Остальной мир | **95%+** (кроме Китая) | — |

## 3. Telegram Ads

> Источник: эксперт (TG-уроки). Деталь — `telegram-ads-pro-ru`.

### Пороги входа

| Параметр | Еврокабинет | Тонкабинет |
|----------|-------------|------------|
| Минимальный депозит | **500 €** | **20 TON** (~30 $) |
| Минимальный CPM | ~0.5 € (реально 1-2 €) | от 0.1 TON (~13-15 ¢) |

### CPM по нишам

| Ниша | CPM |
|------|-----|
| Финансы / инвестиции / крипто | **2-3 €** (до 6-20 € в дорогих) |
| Бизнес / маркетинг | **1.5-2.5 €** |
| Образование | **1-2 €** |
| Health / lifestyle / массовые | **1-4 €** |
| Развлечения / хобби | **0.5-1.5 €** |

### CTR

| Формат / сегмент | CTR |
|------------------|-----|
| **Текст, РФ** | **0.5-0.7%** (хороший ~0.6%) |
| **Текст, международный** | **2-4%** |
| **Баннер, РФ** | до **~1.5%** |
| **Баннер, международный** | **6-7%** |
| Open rate рекламы (для калибровки) | **~0.5-1%** |

Кейс участника курса (ниша семья/дети): чисто текст **0.3% CTR** («супер мало»), с картинкой **0.6%** (хороший бенч).

### Наценки к CPM за форматы

| Формат | Наценка |
|--------|---------|
| Текст | 0% |
| Кастомные эмодзи | **+20%** (лучшее цена/результат) |
| Аватарка | +30% (слабый эффект) |
| Баннер | **+50%** (в части материалов +80%) |
| Видео | +70% |

Суммируются: баннер + эмодзи = +70%; видео + эмодзи = +90%.

### Прочие пороги

| Метрика | Значение |
|---------|----------|
| Бюджет, ниже которого топики не нужны | **500 000 ₽/мес** → только каналы |
| Подписчик TG-канала — норма | **150-300 ₽** |
| Лимит текста объявления | 160 символов |

### Кейсы ROMI (с оговоркой — это первые запуски)

| Кейс | Бюджет | Результат | ROMI |
|------|--------|-----------|------|
| Нутрициология (tripwire) | 220K ₽ | ~1.5 млн ₽ | **~500%** (сегодня ~200%) |
| Доставка из Китая | 260K ₽ | 5.7 млн ₽ | **~2300%** (повторные 1500→1000%) |
| Бот-воронки самостоятельные | — | — | **>80% негатив** |

## 4. VK Ads

> Источник: экспертная методология VK Ads. Деталь — `vk-ads-pro-ru`. NDA: крупные кейсы под NDA, цифры иллюстративные.

### Объёмы аудитории

| Параметр | Значение |
|----------|----------|
| Гео-РФ | **32 млн** |
| Полное гео (вкл. СНГ) | до **105 млн** |
| Доля мобильного трафика | ~**90%** (там же выше CTR) |

### CPL по типам аудиторий

| Тип аудитории | CPL | Комментарий |
|---------------|-----|-------------|
| **Ф1 (ключевые фразы)** | **50-70 ₽** | при KPI ~100 ₽ — сильнейшая зацепка |

| «Кулинария» в пересечении | ~200 ₽ | vs 300-400 ₽ без обогатителя |
| «Образование» в пересечении | 170 ₽ | vs ~500 ₽ без |

| Цена | Что значит |
|------|------------|
| **150-300 ₽** | **норма** |

| Параметр | Значение |
|----------|----------|
| Минимум подписчиков для таргета на сообщество | **500** |

## 5. Meta Ads

> ⚠️ Meta признана экстремистской в РФ — только межд/СНГ. Источник: экспертная методология. Деталь — `meta-ads-launch-ru`.

### Аккаунты и бюджеты

| Метрика | Значение |
|---------|----------|
| Лимит нового аккаунта (старт) | **$50/сутки** |
| Через 3-7 дней (тратя максимум) | **$200-500/сутки** |
| Через полгода | десятки тысяч/сутки |
| Премиум-агентские кабинеты | комиссия 3-7% |
| Правило бюджета | дневной ≥ стоимости **3 целевых событий** |

### Обучение

| Метрика | Значение |
|---------|----------|
| Порог выхода из learning phase | **~50 событий / 7-10 дней** |
| Минимальная аудитория | **100-200K+** (меньше → плохое обучение) |
| Безопасный шаг масштаба | **+10-15%/сутки** |
| Резкое масштабирование (сбрасывает) | **×2-3** бюджета |
| Пауза, сбрасывающая обучение | **>7 дней** |

### Lookalike

| Сегмент | Точность |
|---------|----------|
| **1%** | максимально похожие (старт) |
| **1-3%** | расширение |
| **3-5%** | широкий охват |
| **>5%** | ⚠️ слишком широко, не использовать |

### CPM

| Метрика | Значение |
|---------|----------|
| CPM b2c EU-столицы (Лондон/Париж/Берлин) | **$10-15** в среднем |
| Конец квартала | CPM **×2-3** выше нормы |
| FB тратит >2-3× дневного бюджета | признак сбоя → стоп |

Maximize Conversions покрывает ~**90%** кейсов. CBO-риск: 80-90% бюджета может уйти в один адсет.

## 6. Блогеры / посевы

> Источник: блок посевов методология. Портфель 60/30/10. Закуп без таблицы = казино.

### Цена и конверсии

| Параметр | Значение |
|----------|----------|
| Цена за 1 млн подписчиков паблика | **3-7 тыс. ₽** (потолок **10 тыс. ₽**) |
| Скидки | от админа с 20+ пабликами |

### Конверсии воронки (экспертный канал)

| Переход | Конверсия |
|---------|-----------|
| Переход → подписка в канал | **~35%** |
| Канал → регистрация через пост | **~30%** (напрямую на сайт 10-15%, через бота 15-20%) |
| Регистрация → покупка (вебинар) | **~1%** |

Рекомендация: сначала в канал, потом регистрация (накопление аудитории + смешанная экономика).

### Таблица закупа (обязательные столбцы)

Дата / Канал / Тип канала / Эшелон / Формат поста / Цена размещения / ERR24 / ER / Подписки / Цена подписки / Регистрации / CPL / Вывод (scale/stop).

Признаки ботов: высокий ERR24 + низкий ER + плоский график + скачки подписчиков.
