# Telegram WebM Video Stickers — spec

Требования к файлу (`May 2026`):

| Параметр | Значение |
|----------|----------|
| Контейнер | WebM |
| Codec видео | VP9 |
| Кодек альфы | VP9 alpha (через BlockAdditional, **не** yuva420p в обычном vp9 stream) |
| Размер | **ровно** 512×512 px |
| FPS | ≤30, рекомендуется 30 |
| Длительность | ≤3 секунды |
| Размер файла | **≤256 KB** (жёстко, иначе бот отвергнет) |
| Звук | НЕ должен присутствовать |

## Подводные камни

- **ffmpeg НЕ умеет VP9 alpha**. Все версии libvpx в ffmpeg тихо роняют альфу при муксе в WebM, даже если кодируешь yuva420p. На выходе будет yuv420p без альфы.
- **Только Google `webm-tools/alpha_encoder`** правильно муксит alpha через BlockAdditional (Matroska feature). Это Linux-only бинарник.
- **Чёткое требование 512×512**. Не 511, не 513. Crop+scale обязательны до alpha-кодирования.
- **256KB лимит** — лимит на ВЕСЬ файл, не на один поток. Высокий битрейт + чистая альфа → может вылезти. Battle-tested target: cbr 50kbps, ~70-90KB.
- **Не более 120 стикеров в одном паке** (формально лимит 120 для video стикеров).
- **3-секундный лимит**. ffmpeg `-t 3` обязателен на этапе извлечения кадров.

## Расширение для WhatsApp

WhatsApp использует тот же VP9 alpha формат, но допускает 512×512 ровно и до 500KB. Тот же пайплайн подойдёт.
