# Config

> Reference configurations for services, servers, and integrations.

## Catalog

| Config | Description |
|--------|-------------|
| `aws` | AWS account, S3 buckets, backup system |
| `cloudflare` | Tunnels, DNS, API credentials |
| `databases` | PostgreSQL, MongoDB, Redis, SQLite |
| `email` | Gmail, Exchange, generic IMAP accounts |
| `google-workspace` | Service Account, OAuth, all Google APIs |
| `models` | AI model names, providers, API keys |
| `monitoring` | Uptime Kuma setup, alerts |
| `orchestrator` | Orchestrator pattern and agent routing |
| `server-secondary` | Secondary Server server (YOUR_SERVER_IP_2) |
| `server-primary` | Main your-server server (YOUR_SERVER_IP) |
| `telegram` | Telegram bots and API credentials (optional) |
| `tools` | CapMonster, SubtitleService, Suno, Pinecone, etc. |
