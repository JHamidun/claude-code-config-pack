# Agent Teams — пилот (Ф7, включён 2026-07-18)

> Справочник, читается по требованию. Флаг `CLAUDE_CODE_EXPERIMENTAL_AGENT_TEAMS=1` добавлен в `settings.json` → env; действует с НОВОЙ сессии. Экспериментальная фича Claude Code: команда тиммейтов с общим таск-листом вместо изолированных субагентов.

## Когда пробовать (пилотные задачи)

- Код-ревью крупного диффа: lead + 3-5 ревьюеров с разными линзами (correctness / security / perf / tests).
- Многофайловая фича с независимыми модулями (frontend + backend + tests параллельно).
- НЕ для: простых задач (<5 tool calls), последовательных пайплайнов (лучше обычные субагенты/Workflow).

## Гейты пилота (канон владельца)

1. **Модель тиммейтов — только Fable 5** (`model: fable`), как у всех text-субагентов. **≤5 одновременно** (правило памяти fable-параллелизм: 3-4 в поток, при rate-limit снижать).
2. **Непересекающиеся файлы** между тиммейтами в одном репо — либо worktree-изоляция (чистка ТОЛЬКО `git worktree remove`).
3. Lead = оркестратор (алиас `opus`): синтезирует, не делегирует понимание (rules/delegation.md — конкретные file paths/line numbers в промптах).
4. TeammateIdle/TaskCompleted-гейты: незанятый тиммейт получает следующую задачу из таск-листа, а не распускается; TaskCreated-cap — не плодить задач больше, чем 5 активных Fable могут переварить.
5. Fable упал на лимите → подхват Opus (resume + смена model) — канон rules/models.md.

## Как запустить пилот

Новая сессия (флаг подхватится) → задача формата: «сделай ревью <diff/ветки> командой: lead + 4 ревьюера (линзы correctness/security/perf/tests), общий таск-лист, вердикты в один отчёт».

## Откат

Убрать `CLAUDE_CODE_EXPERIMENTAL_AGENT_TEAMS` из `settings.json` → env. Больше ничего не затронуто.

## Beads-развилка (Q17 плана)

Если флот приживётся — поставить свежий `bd` (issue tracking для команд агентов); если нет — beads-скилл кандидат на выпил. Решение после 2-3 пилотных прогонов.
