# Hooks Reference

> ⚠️ Здесь НЕТ списка активных хуков — он протухает и уже один раз ввёл агента в заблуждение
> (агент не нашёл существующий bash-guard и «нашёл» несуществующую дыру в защите).
> **Источник истины: `~/.claude/settings.json` → `hooks`** (matcher + путь к скрипту) и `/doctor` в сессии.
> Сами скрипты — в `~/.claude/hooks/`; чтобы понять, что хук делает, читай его код, а не этот файл.

## Принцип: минимум hooks

- **Тяжёлый синхронный хук на частом событии = боль.** Python-хуки на PreToolUse/UserPromptSubmit/Stop роняли Extension Host и добавляли секунды латентности на каждый вызов; по той же причине в своё время отказались от плагина (removed plugin).
- Ориентир стоимости: любой хук, стартующий отдельный процесс (python, powershell), стоит ~0.3–1 с на КАЖДОЕ срабатывание. Node-скрипт и HTTP-хук — дёшевы.
- Держать хуками только то, что должно работать даже когда модель «забыла»: блокировки опасных команд и security-гарды. Всё остальное — skills/commands, вызываемые по надобности.
- Хук-гард — это защита от ошибки, а не от злого умысла: подстроковые matcher'ы обходятся (см. rules/permissions.md, секция про injection).

## `async` — почему важен

Хук можно объявить неблокирующим (`"async": true`). Синхронный хук держит tool call, пока не завершится; async запускается и не тормозит цепочку.
Правило: **гард/валидатор — только синхронный** (иначе он ничего не гарантирует, решение уже принято), **нотификация/логирование/телеметрия — только async**. Синхронный логгер на каждом tool call — прямой путь к деградации сессии.

## Hook events (справочно, не «что включено»)

| Event | Когда срабатывает | Типовое применение |
| --- | --- | --- |
| `PreToolUse` | Перед вызовом инструмента | Блокировка/валидация; может вернуть `{decision: "defer"}` — headless-сессия (`claude -p`) паузится, возобновляется `claude -p --resume` с перевычислением хука (human approval в CI) |
| `PostToolUse` | После вызова | Логирование, автоформат |
| `SessionStart` | Старт сессии | Проверка обновлений; тяжёлое сюда НЕ класть — прямо бьёт по времени старта |
| `Stop` / `SubagentStop` | Конец ответа/субагента | Уведомления (async) |
| `UserPromptSubmit` | На каждый промпт | Опасно по латентности |
| `CwdChanged` / `FileChanged` | Смена cwd / правка файла | Уведомление IDE, hot reload |
| `TaskCreated` | Создан субагент | Мониторинг флота |
| `PermissionDenied` | Действие отклонено | Может вернуть `{retry: true}` |
| `WorktreeCreate` | Создан worktree | Поддерживает `type: "http"` |

## Гочи (проверено на практике)

- `$FILE` и подобные плейсхолдеры в командах PostToolUse на Windows не подставлялись — хук молча ничего не делал.
- Хук, который «не сработал», чаще всего не подошёл по matcher'у, а не сломался: сверяй matcher в settings.json с реальным именем тула.
- Хук, падающий с ненулевым кодом, может блокировать работу — проверяй свой скрипт руками до подключения.

## Ручные утилиты (НЕ хуки — вызываются явно)

```bash
python ~/.claude/tools/vector_memory.py search "запрос"
python ~/.claude/tools/vector_memory.py learn "контент" "категория"
python ~/.claude/tools/vector_memory.py stats
```

`~/.claude/tools/prompt_router.py` — исторически отвергнут как UserPromptSubmit-хук (латентность на каждый промпт); подключён ли он сейчас — только по settings.json.
