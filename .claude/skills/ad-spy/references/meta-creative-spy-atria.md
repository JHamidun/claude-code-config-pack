# Meta Creative Spy + Atria — анализ креативов конкурентов в FB/Instagram

> Разведка креативов в Meta Ads Library и в Atria: что именно смотреть и как читать выдачу.
> ⚠️ **Meta признана экстремистской организацией в РФ** — указывать в каждом артефакте.

---

## 1. Best practice: искать по имени FB-страницы, а НЕ по названию компании (экспертная методология)

Главный приём анализа Meta Ads Library:

- **Искать НЕ по названию компании, а по точному имени Facebook-страницы.** Одна компания может вести несколько страниц, у бренда и юрлица имена расходятся — поиск по «названию компании» теряет половину объявлений.
- **Список FB-страниц конкурента удобно собирать через ChatGPT с веб-поиском** — попросить найти все FB Pages бренда/конкурентов, затем по каждому имени бить в Ads Library.

Инструменты слоя:
- **Meta Ads Library** — facebook.com/ads/library (официальный, бесплатный).
- **BigSpy** — bigspy.com (альтернатива/дополнение).
- **Atria** — tryatria.com (см. ниже, с оценкой бюджета и рейтингом РК).

## 2. Workflow «analyze creatives for Meta launch»

Цель — перед запуском своих Meta Ads разобрать, что работает у конкурентов. Через Scraping API (см. основной SKILL.md) или вручную через Ads Library:

1. **search → найти страницу.** `search/companies` по точному имени FB-страницы (не компании). Собрать `company_id`.
2. **company_ads → выгрузить все объявления.** `company/ads?company_id=ID` — все активные креативы конкурента.
3. **ad_details → детали.** `ad?ad_id=ID` — полный креатив, текст, CTA, посадочная, даты.
4. **longest running → ранжировать.** Отсортировать по длительности открутки. **Длительно крутящийся = работающий** (конкурент не стал бы лить на убыточный креатив месяцами). Самые «старые» активные объявления = проверенные офферы/хуки, с которых стоит начинать reverse-engineering.

Что вынести из разбора: топовые хуки (первая строка), форматы (статика/видео/карусель), УТП, на какие посадочные льют, сколько объявлений на лендинг.

## 3. Atria (tryatria.com) — clone creatives + budget estimate + рейтинг РК

Самостоятельный spy-инструмент с уникальным value: **оценивает примерный бюджет конкурента** и рейтингует креативы. Платный, тариф смотри на сайте — цены меняются.

| Возможность Atria | Что даёт |
|-------------------|----------|
| Все активные креативы конкурента | Полный набор объявлений + хуки |
| **Все лендинги** конкурента | На какие посадочные льют, сколько объявлений на лендинг |
| **Longest running ads** | Фильтр по длительности открутки (= что работает) |
| **Примерный бюджет** | Оценка РК конкурента — чего нет в Ads Library |
| **Clone-add** | Адаптирует визуал конкурента под себя (меняет текст/бренд) → готовый креатив в свой кабинет |
| **Оценка каждого креатива** | Рейтинг: **A+ / High iteration / Underperforming** |

### Atria pipeline для конкурентного анализа

```
Atria (подписка на конкурентов)
  → все активные креативы + хуки + бюджеты по лендингам
  → фильтр по longest running ads
  → видение: на какие лендинги льют, сколько объявлений на лендинг
  → clone-add адаптация визуала под себя (меняем текст)
  → готовый креатив в свой кабинет → тест
  → Atria оценивает каждый креатив: A+ / High iteration / Underperforming
  → дальше копировать посадочные через Claude Code + Firecrawl
```

Рейтинг A+ / High iteration / Underperforming = сигнал, какие из клонированных/своих креативов масштабировать, какие итерировать, какие выключить.
