# Russian Channels Spy — мониторинг рекламы конкурентов в RU-каналах

> Материал (поток N): спикеры курса — эксперт по performance-рекламе и спикер VK Ads.
> Главный тезис курса: **полноценного spy-инструмента уровня Meta Ads Library для российских каналов НЕТ.** По каждому каналу — ограниченные инструменты + ручной reverse-engineering.

---

## 1. Яндекс.Директ

**Главный факт: полноценного spy уровня Meta Ads Library не существует.** Wordstat даёт только объёмы запросов, не креативы/ставки/бюджеты.

| Инструмент | Что даёт | Ограничение |
|------------|----------|-------------|
| **Yandex Wordstat** (wordstat.yandex.ru) | Объёмы запросов | По кликам / креативам / стоимостям инфы **НЕ даёт** (экспертная методология). Только частотность. |
| **BigSpy** (bigspy.com) | Креативы из разных сетей | Ограниченное покрытие RU/РСЯ |
| **AdMobiSpy** | Spy за рекламой | Ограниченное покрытие, не закрывает Директ полностью |

**Открытый вопрос курса:** «анализ Яндекс.Директа конкурентов (стоимости + позиции + креативы)» — полноценного решения в комьюнити не нашли. Только Wordstat-объёмы.

### Паттерн ручного reverse-engineering Директа

Поскольку готового spy нет, конкурентов разбирают руками:

1. **Ключи → объёмы.** Собрать семантику конкурента через Wordstat (что он, вероятно, выкупает).
2. **Имена на Поиске.** Вбивать целевые ключи в Яндекс.Поиск → смотреть, кто стоит в рекламной выдаче (блок «Реклама» сверху/снизу), фиксировать заголовки, тексты, быстрые ссылки, посадочные.
3. **РСЯ-сетка.** Походить по тематическим сайтам РСЯ → ловить баннеры/тизеры конкурента в сетке.
4. **Парсить выдачу.** Систематически прогонять список ключей и складывать заголовки/тексты/УТП объявлений в таблицу. Сравнивать УТП, офферы, посадочные.

Это трудозатратно и неполно, но другого пути для Директа курс не предлагает.

### Связка для анализа ставок (экспертная методология)

- **Google Keyword Planner + keywordtoolcollector.io** — связка для анализа стоимостей кликов, позиций, ставок (применима как ориентир и для оценки аукциона; основное назначение — Google, см. ниже).

## 2. Google

| Инструмент | Что даёт |
|------------|----------|
| **Google Ads Transparency Center** (adstransparency.google.com) | Spy за Google Ads: какие объявления крутит рекламодатель сейчас, форматы, регионы показа, даты. Главный публичный spy-инструмент Google. |
| **Google Keyword Planner** | Объёмы запросов, диапазоны ставок |
| **keywordtoolcollector.io** | Анализ стоимостей кликов, позиций, ставок (связка с Keyword Planner — экспертная методология) |
| **Semrush / Ahrefs** | Spy + объёмы + бэклинки (платно). Экспертная методология: для SEO США — анализ объёма + кто на первой странице |

**Workflow Google spy:**
1. Transparency Center (adstransparency.google.com) → ввести рекламодателя → собрать активные объявления, форматы, longest running.
2. Keyword Planner + keywordtoolcollector.io → прикинуть ставки/стоимость кликов по ключам конкурента.
3. (Опц.) Semrush/Ahrefs → объёмы, посадочные, бэклинки.

## 3. Telegram Ads

Spy по официальному кабинету Telegram Ads делают через сторонние сервисы:

| Инструмент | Что даёт |
|------------|----------|
| **TGMaps** | Spy за рекламой в Telegram Ads — каталог объявлений, кто что крутит |
| **TGSpice** | Аналог — каталог рекламных объявлений Telegram Ads |
| **Баржа** (barzha.com) | Маркетплейс рекламы в Telegram (не spy в чистом виде — биржа размещений у каналов) |

### Как читать TG Ads spy (формат объявлений Telegram Ads)

Объявление Telegram Ads в spy-сервисе разбирается по полям:

- **Формат** — короткий текст (до 160 знаков) + ссылка на канал/бота/пост. С недавних пор возможны картинка/баннер.
- **CPM и наценки.** Базовый CPM в TG Ads + наценки за таргетинги. Картинка/баннер поднимает CPM (по курсу: баннер +80% к CPM, см. benchmarks ниже).
- **Кастомные эмодзи** — премиальные кастом-эмодзи в объявлении (фишка оформления, повышает CTR/заметность).
- **Тип таргетинга** — по каким каналам/тематикам/интересам/языку/гео крутится объявление. Spy показывает, на какие каналы конкурент таргетируется.

**Бенчмарки CTR Telegram Ads (для калибровки чужих кампаний):**
- Текстовое объявление: CTR **0.6%** — хороший бенч (чисто текст на каналах ~0.3% = «супер мало»).
- С баннером/картинкой: CTR **0.9–1%** (баннер +80% к CPM).

## 4. VK (ВКонтакте / VK Ads)

**Главный факт: AdMobiSpy для VK устарел — данные только до 2024 года** (по данным сообщества). За актуальным набором spy-инструментов курс направляет к спикеру VK Ads.

| Инструмент / контакт | Статус |
|----------------------|--------|
| **AdMobiSpy** | Устарел для VK (данные до 2024). Использовать с осторожностью / как исторический срез. |
| **Спикер VK Ads курса** | За **актуальными** spy-инструментами ВК обратиться к спикеру VK Ads курса (крупный бюджет в VK+РСЯ, сотни проектов, профильное сообщество таргетологов). |

### «Защита от копирования» — авторская техника (VK Ads)

Зеркальная сторона spy: как **защитить свои кампании** от чужого подсматривания и одновременно почистить аудиторию.

- **Вычитать список конкурентов-таргетологов из аудитории.** Собрать аудиторию таргетологов/маркетологов-конкурентов (по профильным сообществам) и **минусовать** её из своих рекламных аудиторий в VK Ads.
- Эффект двойной: (а) конкуренты-таргетологи реже видят твои креативы → меньше копируют; (б) аудитория чище — не сжигаешь бюджет на коллег по цеху, которые не покупают.

### VK CPL как точка отсчёта при анализе чужих кампаний (экспертная методология, для калибровки)

При разборе чужой VK-кампании держать в голове нормальные диапазоны:

- **Ф1 (ключевые фразы):** 50–70 ₽ при KPI 100 ₽.
- **Категории интересов:** 200–400 ₽.
- **Цена подписчика норма:** 150–300 ₽. Если 20–40 коп. — это **боты** (серый подрядчик).

> ⚠️ NDA-оговорка: конкретные CPL из чужих кейсов и со скринов — иллюстративные, не использовать как бенчмарк своего проекта.
