# Glossary + Sources Sync Prompt

> Шаблон промпта для агента, который синхронизирует back-matter (глоссарий + источники) после каждого крупного content-update. Запускать после v9, v11, v13.

## ПРОМПТ

```
Ты редактор приложений книги автора (название, издательство и год — из `$BOOK_ROOT/BOOK.md`). Книга v{N} проведена через 22 прохода редактуры + cross-model review. Нужно обновить два файла back-matter под текущее состояние всех {N_chapters} глав.

## ЗАДАЧА 1. Обновить ГЛОССАРИЙ

ФАЙЛ: `$BOOK_ROOT/chapters/15-glossary/DRAFT.proofread.md`

ШАГИ:
1. Прочитай текущий глоссарий
2. Прочитай все {N_chapters} глав v{N} (chapters/*/DRAFT.v{N}.md) и найди термины, которые автор использует, но не определяет в глоссарии
3. Добавь недостающие. Список кандидатов подставляется из `$BOOK_ROOT/book.json`
   (`metrics.key_terms`) и дополняется вручную. Формат строки кандидата:

       {список терминов твоей книги, по одному в строке:}
       - **<термин>** (вводится в гл.N — определение в одной строке)

   Пример заполнения (термины вымышленные, замени своими):

       - **тихий откат** (гл.3 — команда формально приняла инструмент, но вернулась к старому процессу)
       - **бюджет доверия** (гл.5 — сколько ошибок инструмента команда прощает до отказа от него)
       - **проводник** (гл.7 — сотрудник, через которого новая практика входит в отдел)

   Три класса кандидатов, которые пропускают чаще всего:

   - **авторские концепции и метафоры** — слова, которых до книги не существовало;
     они обязаны быть в глоссарии, иначе читатель встретит их в гл.9 без определения
   - **отраслевой жаргон**, который автору кажется общеизвестным (governance, enablement, FTE)
   - **англицизмы без устоявшегося перевода** — дать и русский вариант, и оригинал

Структура термина:
```
**Термин** — определение в одном-двух предложениях. Подробно в гл. N.
```

Стиль определений — сжатый, как в существующем глоссарии (3-5 строк).

## ЗАДАЧА 2. Обновить ИСТОЧНИКИ

ФАЙЛ: `$BOOK_ROOT/chapters/17-sources/DRAFT.proofread.md`

ШАГИ:
1. Прочитай текущий файл источников
2. Прочитай все {N_chapters} глав v{N} и найди упомянутые исследования/публикации, которых нет в источниках
3. Добавь недостающие. Ориентир по объёму: у нон-фикшн такого размера набирается
   10-20 внешних исследований и публикаций. Пройди по классам, ни один не пропусти:

   - **академические работы** — препринт или журнальная статья; атрибуция включает
     авторов, номер (arxiv / NBER / DOI) и год, иначе источник неверифицируем
     (формат строки: `Фамилия, Фамилия, NBER 00000 (2023) — что измеряли, на какой выборке`)
   - **отраслевые отчёты консалтинга и вендоров** — название отчёта + организация + квартал
   - **опросы разработчиков и рынка** — название опроса + год + размер выборки
   - **публичные заявления компаний** — пресс-релиз, письмо акционерам, выступление CEO;
     обязательно площадка и дата, «в интервью» без площадки не годится
   - **локальные источники** твоего рынка — их особенно легко забыть, а рецензент
     заметит первым, что книга опирается только на англоязычные данные

Каждый источник — атрибуция: имя/орг + название + платформа + дата. URL по возможности (если знаешь точный — добавь, если нет — оставь без).

Формат строки источника — следуй существующему файлу.

## ⛔ ВАЖНО

- НЕ удаляй существующие термины и источники
- Если уже есть запись на нужный термин/источник — не дублируй
- Добавляй в логичные секции (алфавитный порядок для глоссария, по теме для источников)
- НЕ ВЫДУМЫВАЙ URL и даты — если не знаешь точно, оставь только название + год
- Не правь голос и структуру существующих записей

## ОТЧЁТ

В конце сообщи:
- Сколько новых терминов добавил в глоссарий
- Сколько новых источников добавил в sources
- Какие термины/источники упоминаются в книге, но ты не смог найти достоверный источник — пометь как «требует ручной проверки автора»
```

## ЧЕГО ЖДАТЬ ОТ ПРОГОНА

Порядок величин, а не норматив — нужен, чтобы отличить нормальный результат от пустого:

- **Глоссарий: +5…+10 терминов.** Ноль означает не «книга чистая», а что агент искал
  по существующему глоссарию вместо текста глав — перезапустить.
- **Источники: +10…+20.** Больше всего добирается из средних глав: во введении и финале
  автор ссылается аккуратно, а в рабочих главах цитирует по памяти.
- **Треть источников уходит с пометкой «требует ручной проверки автора»** — это норма.
  URL и DOI агент не обязан знать и не должен выдумывать; лучше пустое поле, чем
  правдоподобная ссылка в никуда.
