# V13 craft-pass: 22 паттерна и параллельный прогон

Список из 22 паттернов craft-правки с 9 задачами и схема параллельного multi-agent прогона по главам. Читай, когда собираешь версию v13+ или раскидываешь craft-pass на нескольких агентов.

## V13 — CRAFT-PASS V2 (22 паттерна + 9 задач)

После 9 книг по писательскому мастерству (Ильяхов x3, Кинг, Зинсер, Безручко, Иконникова/Зверева, Сегер, Белл) — расширенный полиш.

### 9 задач v13 (порядок выполнения)

1. **Скобочный метод Зинсера** — пройти каждый абзац, удалить лишнее (-8…-15% объёма)
2. **Паттерны 14-22 из anti-ai-tells** — язык войны / деловая маска / птичий язык / оценки без цифр / манипулятивные / посредники / адверб в диалоге / манипулятивная срочность / самопохвала читателю / лакированная конкретика
3. **Цифры сравнивать, а не называть** (Зверева) — для 2-4 ключевых цифр на главу дать сравнение с тем, что читатель знает
4. **Двух сторон медали** (Безручко) — каждый успешный кейс ИИ дополнить «что не получилось / сколько стоило / кому не подходит». **Критично для операционных глав 7-12**
5. **Сенсорные детали в ключевых сценах** (Кинг) — 2-3 не-зрительных детали на сцену, **только из существующих сцен в ANCHORS.md** — НЕ выдумывать
6. **Убрать посредников** (Зверева) — «я почувствовал что» → транслировать через физическое действие
7. **Чтение вслух** — тест «второй вдох до точки»
8. **4 вопроса CEO** (Безручко) для операционных глав — проблема / насколько серьёзна / причины / что делать
9. **Финальная атрибуция диалогов** — наречия в атрибуции удалены, «сказал» по умолчанию

### Особые фиксы для конкретных глав

Список пишется под свою книгу — ниже типы фиксов, которые встречаются почти всегда:

- **Пролог** — убрать упоминание служебной разметки («зачином/разбором/фреймворком»), если в v12+ структурные заголовки удалены
- **Любая глава, после которой в вёрстке идёт не следующий номер** — cliffhanger не должен ссылаться на главу, которой в книге нет. Мост строится по фактическому порядку чтения, а не по нумерации: часть номеров при сборке всегда выпадает
- **Главы, пережившие несколько версий** — удалить служебные заголовки (`## Закрытие` и подобные), оставшиеся от старых прогонов
- **Манифест / финальный текст-кредо** — минимальная правка (-3% максимум). Формула «не А, а Б» = разрешённое исключение

## MULTI-AGENT PARALLEL CRAFT PASS (паттерн)

Для каждой волны (v9, v10, v12, v13) запускать 5 параллельных Opus агентов с разделением глав.

### Распределение глав

Делить не поровну по числу файлов, а по типу текста: у рамочных, личных и операционных
глав разные риски, и агенту проще держать в голове один режим, чем три. Схема на 5 агентов:

| Агент | Что получает | Особенности |
|---|---|---|
| Агент 1 | рамочные тексты (пролог, интерлюдии, врезки) | Короткие, задают тон — правка бережная |
| Агент 2 | главы первой части, личные | Бережно с парентезами и авторскими историями |
| Агент 3 | главы-мосты между частями | Проверить стыки cliffhanger → opening, вычистить служебные заголовки |
| Агент 4 | операционные главы | Критично Задача 4 (двух сторон медали) |
| Агент 5 | финал + манифест | Манифест — минимальная правка |

Агентов может быть не пять: считай по объёму, комфортный кусок — 3 главы на агента.

### Template briefing (см. `templates/craft-pass-briefing.md`)

Каждый агент получает:
1. Контекст (что было сделано в предыдущих версиях)
2. Обязательное чтение: STYLE_GUIDE + anti-ai-tells + writing-craft + writing-craft-v2
3. Стартовая точка (DRAFT.v12.md — НЕ proofread)
4. 9 задач в порядке выполнения
5. Список «что НЕ трогать» (эпиграфы, цитаты, личные истории, числа из практики, сквозные метафоры)
6. Особые фиксы для назначенных глав
7. Privacy decision tree (whitelist/blacklist имён)
8. Anti-fabrication правила (явный запрет на новые конкретные числа из практики автора и на синтетические сенсорные сцены)
9. Frontmatter новой версии
10. Формат отчёта

### Anti-pattern (поймали в v13)

❌ **Subagent выдумывает «личные» цифры автора**: «320 часов на развёртывание», «18 миллионов рублей сверху», «1 миллион ₽ на пилот», «5 экспериментов, 2 свернул через полтора месяца». Звучит правдоподобно, но это фабрикация.

✅ **Что делать**: в briefing явно цитировать список запрещённых цифр + после возврата всех агентов делать ручной grep по подозрительным паттернам (`"около \d+ миллион"`, `"\d+ часов"`, `"\d из \d+ экспериментов"`).

❌ **Subagent выдумывает синтетические сенсорные детали** для типовых сцен: «свистит чайник», «ладони пахли холодным чаем и горячим алюминием от вентиляционных решёток ноутбука», «в углу гудел кондиционер на минимуме».

✅ **Что делать**: добавлять сенсорные детали ТОЛЬКО к сценам, описанным в ANCHORS.md (где автор реально был). Для типовых иллюстраций — обобщённые формулировки без вымышленной сенсорики.
