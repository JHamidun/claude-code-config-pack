# CRO маркетинговых страниц (RU)

Аудит и рост конверсии маркетинговых страниц под российский рынок. Порт `cro` из marketingskills: фреймворк анализа сохранён, инструменты и примеры адаптированы под подписочный/консалтинговый бизнес с оплатой в рублях и Яндекс-стеком.

**Перед началом собери контекст своего бизнеса:** что продаёшь по приоритету, цены/CTA, карта воронки и её дыры. Не дублируй позиционирование, цены и метрики — бери их из единого источника контекста.

## Первичная оценка

Прежде чем давать рекомендации, определи:

1. **Тип страницы:** лендинг услуг, лендинг воркшопа/мероприятия, лендинг продукта (подписка/академия), главная, страница материалов/лид-магнитов, контент-портал/новости, блог, «обо мне»/кейсы.
2. **Главная цель конверсии:** заявка на бесплатную консультацию (B2B), trial продукта (B2C), подписка на рассылку/бота + скачивание лид-магнита (верх воронки), запрос формата воркшопа.
3. **Источник трафика:** Яндекс (органика/Директ), соцсети/Telegram-канал, email-рассылка, переход с медиа/YouTube, реферал. От источника зависит message match.
4. **Аудитория страницы:** B2B-корп (HR-директор, гендир/владелец, руководитель отдела — главные деньги), B2C-профи (специалист/маркетолог/предприниматель), соло-премиум (хочет работать лично с экспертом). Им продают по-разному — см. ICP в контексте бизнеса.

## Фреймворк анализа (по убыванию влияния)

### 1. Ясность ценностного предложения (макс. влияние)
- Понятно ли за 5 секунд, что это и зачем? Для услуг: «Связываю стратегию и внедрение — встраиваю технологию в ваши бизнес-процессы». Для продукта: конкретный состав ценности (объём контента/функций, ключевые преимущества, что включено).
- Главная выгода конкретна и отстроена (практик, реально решает задачу, а не теоретик)?
- Язык клиента, не внутренний жаргон («сотрудники начнут применять на практике», «быстрый практический результат на ваших задачах»).
- Типовые ошибки: фокус на фичах вместо выгод; слишком абстрактно/«креативно» в ущерб ясности; пытается сказать всё сразу.

### 2. Заголовок (H1)
- Передаёт суть ценности? Достаточно конкретен?
- Совпадает с обещанием из источника (Директ-объявление = заголовок лендинга)?
- Сильные паттерны: результат без боли («Команда освоит инструмент за один воркшоп — на ваших реальных задачах»); конкретика с числами; соцпруф (регалии эксперта/компании, релевантные аудитории).

### 3. CTA — расположение, текст, иерархия
- Одно главное действие, видно без скролла.
- Текст кнопки передаёт ценность, а не действие:
  - Слабо: «Отправить», «Зарегистрироваться», «Подробнее».
  - Сильно (B2B): «Бесплатная консультация», «Обсудить задачу», «Выбрать формат воркшопа».
  - Сильно (B2C): «Trial бесплатно», «Начать без карты».
- Логичная иерархия primary/secondary; CTA повторён в точках принятия решения.
- **Приоритет CTA:** B2B → «Бесплатная консультация» (бронь звонка → лид в CRM); B2C → «Trial бесплатно» (без карты).

### 4. Визуальная иерархия и сканируемость
- При беглом просмотре считывается главное сообщение.
- Важные элементы выделены, достаточно воздуха, изображения поддерживают, а не отвлекают.

### 5. Триггеры доверия и соцпруф
- Регалии эксперта/компании, релевантные аудитории (роль, опыт, масштаб, флагманский продукт, публичность в профильных медиа).
- Кейсы внедрений с числами, отзывы участников (конкретные, с именем/ролью/фото).
- Для B2B — бейджи: договор с юрлицом РФ, оплата в рублях, данные в РФ.
- Флагманский продукт компании — это **соцпруф** (приём: «учит тот, кто сам это построил» — сослаться на собственный работающий продукт как на пруф компетенции), а не продаваемый на этой странице продукт. Размещать рядом с CTA и после обещаний выгод.

### 6. Работа с возражениями
- B2B: «сотрудники не будут применять / не разберутся», «слишком много инструментов», «нужен быстрый ROI, а не теория», «безопасно ли для корп-данных».
- B2C: «дорого vs бесплатные туториалы», «осилю ли», «хватит ли времени», «барьер доступа к зарубежным сервисам» (закрывается локальным доступом/оплатой в рублях).
- Закрывать через FAQ, гарантии (trial без карты), сравнения, прозрачность процесса консультации/воркшопа.

### 7. Точки трения
- Лишние поля в форме заявки, неясный следующий шаг, путаная навигация, обязательные поля, которые не нужны.
- Мобильный опыт (большая доля трафика РФ — мобайл), скорость загрузки.

## Формат вывода

1. **Быстрые победы** — лёгкие правки с быстрым эффектом.
2. **Высокоэффективные изменения** — крупнее, требуют усилий, но дают существенный рост.
3. **Идеи для тестов** — гипотезы под A/B вместо «на глаз». Запускать через `ab-testing-ru`.
4. **Альтернативы копирайта** — для заголовков и CTA дай 2-3 варианта с обоснованием.

## Фреймворки по типам страниц

### Главная
- Чёткое позиционирование для холодного трафика, развилка B2B (консультация) / B2C (trial продукта), обслужить и «готов купить», и «ещё изучаю». Меню: Услуги, Мероприятия, Обо мне, Материалы, Кейсы, Блог, Контакты.

### Лендинг услуг
- Главная цель — заявка на бесплатную консультацию. Боль → диагностика → стратегия → внедрение. Кейсы с числами, отстройка «стратегия + внедрение в одном лице». Единый CTA, убрать лишнюю навигацию.

### Лендинг воркшопа/мероприятия
- Формат (1 день — многонедельная программа), 100% практика на задачах компании, online, доступ к нужным инструментам. CTA «Выбрать формат» / «Бесплатная консультация».

### Лендинг продукта (подписка/академия)
- Главная цель — trial без карты. Подсветить ценность (объём контента/функций, ключевые преимущества, сертификаты, что включено). Сразу под лендингом — чат/AI-ассистент для вопросов. Логика тарифов — в `pricing-strategy-ru`. Ограниченный входной оффер для первых пользователей.

### Страница материалов/лид-магнитов
- Цель — захват email в обмен на лид-магнит (чек-лист, подборка инструментов, гайд). Минимум трения, явная ценность каждого магнита.

### Контент-портал / новости
- Верх воронки. **Частая дыра: контент-портал не связан с продуктом/консультацией** — гонит трафик только на соцсети и блог. Нужны сквозные CTA «Освоить системно → trial продукта» / «Бесплатная консультация» + захват email в рассылку.

### Блог
- Контекстные CTA под тему статьи, inline-CTA в естественных паузах (в продукт/на консультацию). Авто-конвейер блога — ваш контент-пайплайн (RSS/новостной автопостинг).

## Идеи экспериментов

Полный набор A/B-тестов по типам страниц — `references/experiments.md` (hero, соцпруф, лендинги услуг/воркшопа/продукта, формы заявок, захват email, блог, кросс-страничные). Запуск и стат-значимость — через `ab-testing-ru`.

## Тактики роста CR1 первого экрана

Конкретные тактики повышения CR1 лендинга — `references/landing-cr-tactics.md`: три обязательных ответа («почему этот продукт / эта компания / именно сейчас»), один главный CTA на видных местах, соцпруф с цифрами, FOMO-таймер, результат вместо процесса, убрать горизонтальные слайдеры, 1–3 тарифа, убрать ценник где мешает, мобильная адаптация.

> **Не дублировать:** полный чек-лист лендинга (8 пунктов + ICE), дерево метрик, выбор ТИПА воронки, эффект «магазина мороженого» и «Система 2» Канемана — в `funnel-design-ru` (`references/leads-landing.md`). Психология (Система 2 / FOMO / дефицит / якорение) — в `marketing-psychology-ru`. Здесь — тактическая выжимка под CRO одной страницы.
