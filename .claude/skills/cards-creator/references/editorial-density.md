# Плотность, картинки и брендинг карточек

Читать, когда колода получилась typography-only или выглядит дешевле референса:
здесь приёмы плотности, рецепт генерации иллюстраций и правила вырезок.
Диагностика пустоты (ANTI-AIR) — в самом SKILL.md, она нужна на каждой серии.

## Приёмы плотности (editorial-magazine)

Плотная колода — это ~9 карточек примерно такого набора: cover-stats, таблица-сравнение,
bar-chart, split с картинкой, терминал-мок, effort-таблица, stat-strip, CTA.

- **cover-stats**: на обложке под lead — ряд из 3 мини-плашек (цифра + подпись) поверх затемнённого фото. Сразу превью контента.
- **split text+image**: `grid 1.18fr 0.82fr` — слева big-number/буллеты/цитата, справа `col-img` с иллюстрацией во всю высоту. Убивает пустоту на «одна-цифра» карточках.
- **bar-chart (A vs B)**: горизонтальные пары баров (baseline `#BCAE8E` / актуал `#3B5BDB`), ширина = `val/max*100%`, цифра в конце бара, дельта-чип справа (`+8.5` зелёным).
- **таблица-сравнение**: колонка «своей» опции подсвечена `cyan-soft`, лучший в строке — класс `best` с `✦`. ЧЕСТНО помечай и чужие победы: карточка, где конкурент нигде не выигрывает, читается как реклама и обесценивает всю колоду.
- **terminal-mock**: `#0B1020` окно с mac-точками + mono `<pre>` с подсветкой (`pr/cmd/ok/cm`). Сильный визуал для «как включить / команды».
- **effort/мини-таблица**: ряд карточек-плашек, дефолтная подсвечена + badge «по умолчанию».
- **stat-strip**: 3-4 белые плашки `st__num` (Inter Tight 800, акцент на единице `.accentnum`).
- **imgband**: слим-полоса 200px с иллюстрацией-фоном как разделитель в карточке.

## Картинки обязательны

На каждой обложке — сильный 3D-cutout или фото, плюс минимум 1 inner-карта с cutout на серию.
Исключение: карта-«число-герой» (цифра 300px+) считается за графику и cutout не требует.
Воздух на cover закрывается этой же картинкой.

### gpt-image-2 рецепт

- Модель `gpt-image-2-2026-04-21`, endpoint `/v1/images/generations` (или `/edits` с рефом), ключ `OPENAI_API_KEY` из creds.
- `size='1024x1536'` (вертикаль под split/band), `quality='high'`, ответ `b64_json`.
- Когезия серии = общий `STYLE`-суффикс с **точными hex палитры** (cream/navy/blue/cyan/terra) + «flat editorial vector, NO text/logos». Модель держит стиль между картинками по префиксу, а не по сиду.
- Генерь пачкой в фоне (`run_in_background`) — 30-60 с на картинку.
- Альтернатива без токенов — local-gateway `/studio/image` (Gemini).
- Быстрый путь `scripts/gen_card_images.py`: список картинок задаётся константой `IMAGES`
  **внутри самого скрипта** — отредактируй её, потом `python gen_card_images.py ./` → `./<name>.png`.

### Фабрика в едином стиле — `scripts/card_image_generator.py`

Зависит только от requests + PIL + rembg. Картинка проходит через шаблон-обёртку до модели:
`TEMPLATES[style] (frozen prefix: палитра + рендер + «plain bg for cutout») + subject → gpt-image-2`.

- **9 шаблонов.** Cutout (объект на plain bg → rembg): `photoreal-3d` (дефолт), `flat-editorial`, `isometric`, `marker` (рукописная маркер-диаграмма — под «нарисуй концепт схемой»), `chromatic`, `paper-craft`. Full-bg (фон карточки, без обрезки): `glamour`, `sketch` (мел на доске), `real-photo`.
- CLI: `templates` (список) · `recommend "тема"` (подсказывает стиль) · `test "<subject>" <style> --cut --size 1536x1024` · `generate cards.json ./img` (вся колода одним стилем). `--cut` / `"cut":true` → rembg-вырезка `_t.png`.
- Конфиг: `{"template":"photoreal-3d","cards":[{"id":"item","subject":"…","size":"1536x1024","cut":true}, …]}`.
- **Правило единства:** ВСЕ иллюстрации одной колоды — одним `template`. Смесь flat + 3d сразу читается как склейка из разных источников.
- ПЕРЕД генерацией выбери визуальный ПРИЁМ под тип инфы карточки → `references/visual-playbook.md`. Картинка должна кодировать идею (×4 → лупа+баг, прогресс → стрелка, скорость → спидометр), а не быть «просто иллюстрацией». Неочевидно в вектор-арте → реальное фото + подпись.

## Интегрированные вырезки — НЕ «картинка в коробке»

Editorial-референс не ставит картинки в скруглённый бокс: объекты вырезаны (прозрачный фон)
и интегрированы — лежат на cream/navy, выходят за край, перекрывают текст.

- **gpt-image-2 НЕ поддерживает `background:transparent`** — отдаёт 400. Поэтому: генерируем обычно (`gen_card_images.py`) → режем фон **rembg** (`scripts/cut_bg.py`, модель `isnet-general-use` + alpha matting + tight-crop по alpha-bbox). На вектор-арте края чистые.
- Размещение: `col-img/imgband { background:transparent; border:none; box-shadow:none }` + `img{object-fit:contain}`; `transform:scale(1.08)` слегка выводит объект за край (`.card` имеет `overflow:hidden`).
- Широкий объект (последовательность) → отдельной `.cutband` (полоса `flex:1`) на всю ширину, не в узкой колонке.

## Что приближает к премиум-уровню

1. **Вырезки без боксов** (rembg) — объекты лежат на фоне, не в рамке.
2. **Варьируй фон** — не все cream: navy-радиалка, светлая графика контрастно поверх.
3. **Рукописные аннотации** — Caveat, terra, `transform:rotate(-7deg)`: `.scribble` «рекорд!» у дельты графика.
4. **Стикер-коллаж** — `.sticker` (жёлтая плашка + Caveat-подпись, повёрнут) поверх картинки.
5. **Тёплая палитра** — terra/yellow, не только cyan.
6. **Глубина** — мягкие тени на белых плашках: `box-shadow: 0 8px 24px rgba(1,3,52,0.07)`.
7. **Реалистичные изображения вместо flat-вектора** — «Photorealistic 3D render … PLAIN seamless background for cutout» → rembg → вставка без бокса. Реал-объекты (робот, спидометр, 3D-стрелка) выглядят дороже иллюстраций.
8. **Если метафора нечитаема — бери реальное фото**, а не иллюстрацию. Фото-полоса на cover без обрезки читается мгновенно.
9. **Речевое облако** `.speech` (белое, обводка navy, хвостик-ромб, лёгкий наклон) — реплика от персонажа.
10. **3D-объект в «воздух»** — не растягивай пустые блоки; верни им высоту по тексту, а свободное место займи вырезанным объектом по теме.

НЕ ставить «рекорд!» там, где конкурент впереди по абсолюту — помечай дельту честно.

## Бренд-логотип в углу

Логотип проекта кладётся рядом с `series.html` как `logo.png` и встраивается **маленьким (~52px)
в верхний-правый угол** каждой карточки: не отвлекает, держит айдентику. Один CSS-приём на колоду:

```css
.card.inner .ast.tr { display: none; }                 /* логотип занимает место правого астериска */
.card.inner::after { content:""; position:absolute; top:44px; right:52px; width:52px; height:52px;
  background:url('logo.png') center/contain no-repeat; border-radius:12px; z-index:6;
  filter: drop-shadow(0 4px 10px rgba(1,3,52,0.22)); }
```

У cover-карточки свои `::before`/`::after` заняты фото-фоном — там логотип ставится `<img>`-элементом:
`.brandlogo-cover { position:absolute; top:46px; right:52px; width:56px; z-index:5; }`.

## Аватарка канала

Зашивается в обложку: `.cover-author .ava { background-image:url('avatar.jpg') }`, файл рядом с `series.html`.
Генерация новых концептов из фото:

```bash
python ~/.claude/skills/cards-creator/scripts/gen_avatar.py <фото.jpg> [concepts|all] [out_dir]
# concepts: brand (PIL-композит, max likeness) | rim (контурное свечение)
#           | circle (светящийся диск) | symbols (парящие code-символы > [] {} <>) | char3d | tech
# gpt-image-2 /edits сохраняет лицо по рефу.
```
