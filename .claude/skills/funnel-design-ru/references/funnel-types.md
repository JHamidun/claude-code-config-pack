# 8 типов воронок — детальная карта

> Источник: экспертная методология. Канонический набор из 8 типов. Каждый тип = своё узкое место + свой набор тактик. Воронки работают лучше в комбинации — редко берётся один тип в чистом виде.

## Как выбирать тип воронки

Решающие факторы:
- **Чек / сложность продукта** — высокий чек и сложность → звонок/вебинар; низкий → tripwire/e-mail/бот.
- **Температура аудитории** — холодная → лид-магнит/контент; тёплая → звонок/прямой оффер.
- **Канал входа** — мессенджер-трафик → бот; сайт → лендинг+звонок; SaaS → freemium.
- **Модель монетизации** — разовая покупка → tripwire→флагман; подписка → freemium / комьюнити.
- **Нужна ли квалификация** — да (B2B) → звонок с анкетой A/B/C/D.

> **Принцип:** клиенты принимают решения через инстинкты и эмоции, а не рациональность. Продажа происходит в момент эмоции — в «аха-момент». Поэтому бесплатный продукт и tripwire должны быть **сверхценными**, а продающий момент ловится на пике эмоции.

## 1. Лид → Звонок

- **Когда выбирать:** дорогой/сложный продукт, B2B, высокий чек, нужна квалификация лида.
- **Узкое место:** скорость и качество обработки лида отделом продаж (узел CR2).
- **Тактики:**
  - **SLA дозвона ≤15 мин** + анкета категоризации A/B/C/D;
  - скрипты продаж, FAQ, баттл-карты;
  - процессы в продажах, контроль качества (19 критериев звонка);
  - боты/мессенджеры удерживают внимание, пока менеджер не дозвонился.
- **Анти-паттерн:** «перлидоз» — много лидов = падение качества обработки.
- **Пример применения:** B2B AI-консалтинг, корпоративные воркшопы (заявка → звонок → квалификация → сделка в CRM).

## 2. Лид → E-mail

- **Когда выбирать:** низкий чек / длинный прогрев / западный рынок. **Работает лучше в США**, чем в РФ.
- **Узкое место:** open rate и вовлечённость в цепочке писем (узлы CR1→CR2).
- **Тактики:**
  - Jobs-to-be-Done в письмах;
  - смелые, цепляющие заголовки писем;
  - ретаргетинг по e-mail-базам в соцсетях;
  - FOMO (ограниченные акции, «осталось 2 места») + social proof (отзывы, бренды, кейсы);
  - продажа в момент эмоции / «аха-момент».
- **Пример применения:** международная B2C-аудитория онлайн-академии, nurture-цепочки.

## 3. Бесплатный продукт (лид-магнит)

- **Когда выбирать:** холодная аудитория, нужно показать ценность ДО оплаты.
- **Узкое место:** доходимость до «АХА-момента» и переход в основной продукт.
- **Тактики:**
  - дать **максимум ценности (x10 value)** → вызвать «АХА-момент» → продать основной продукт;
  - бесплатный продукт должен быть **сверхценным**;
  - CRM + быстрое закрытие после момента ценности.
- **Кейс:** **бесплатный аудит** в B2B рекламном агентстве (выход на европейские банки) → **конверсия 25%** из аудита в клиентов; 1 день команды окупался с лихвой.
- **Пример применения:** бесплатный AI-аудит / диагностика для B2B-консалтинга; бесплатный мини-урок для академии.

## 4. Tripwire (дешёвый продукт)

- **Когда выбирать:** снять барьер первой покупки, конвертировать тех, кто «трогает кошелёк», но не готов на флагман.
- **Узкое место:** upsell из дешёвой покупки во флагман (узел LTV).
- **Тактики:**
  - **x10 value** за низкую цену (снятие барьеров);
  - FOMO;
  - upsell во флагман сразу после первой покупки.
- **Кейс:** **«Мытьё окон за 1000₽»** в сервисе уборки квартир (акция запущена весной, когда окна грязные после зимы) → новый продукт стал ключевой воронкой → рост до **3000 уборок в день**, миллиарды оборота.
- **Пример применения:** дешёвый вход (например, недорогой мини-курс) → upsell во флагманский продукт.

## 5. Вебинар

- **Когда выбирать:** образовательный/экспертный продукт, нужен эмоциональный контакт с аудиторией.
- **Узкое место:** «точки отвала» внутри вебинара (доходимость до продающей части).
- **Тактики:**
  - чёткая структура: контентная + продающая часть;
  - **харизматичный, эмоциональный спикер**;
  - CRM для обработки после вебинара;
  - анализ «точек отвала» (где люди уходят с эфира).
- **Пример применения:** вебинары по AI-внедрению, эфиры под запуск курса/потока.

## 6. Бот

- **Когда выбирать:** быстрый вход без сайта, мессенджер-трафик (TG/Instagram), нужен прогрев.
- **Узкое место:** прогрев и удержание в боте (часто высокий процент негативных кейсов — бот лучше как коллектор базы).
- **Тактики:**
  - быстрый вход без сайта/лендинга;
  - прогрев + полезность (чек-листы, видео, отзывы);
  - social proof.
- **Предупреждение:** в большинстве случаев чистая бот-воронка слабее как продающая → использовать как коллектор базы + прогрев, продажу выносить в звонок/вебинар.
- **Пример применения:** Telegram-бот входа из канала @yourchannel, прогрев перед академией/консультацией.

## 7. Комьюнити

- **Когда выбирать:** удержание, длинный LTV, нужен эффект «стада».
- **Узкое место:** активность и удержание участников (узел LTV).
- **Тактики:**
  - живое общение, разыгранные диалоги;
  - полезный контент + эффект «стада»;
  - разгоны (искусственная активация дискуссий).
- **Пример применения:** комьюнити вокруг AI-практики, выпускники академии, удержание и рефералы.

## 8. Freemium → Premium

- **Когда выбирать:** SaaS/подписка, ценность видна в использовании продукта.
- **Узкое место:** конверсия free→paid (узел CR2) и удержание подписки (LTV).
- **Тактики:**
  - ограничение бесплатных функций → стимул купить платное;
  - **не «фичерить», а показывать решение задач** (Jobs to be Done) → монетизировать JTBD;
  - онбординг, ведущий к ценности.
- **Пример применения:** YourProduct (free-лимиты → платный тариф), self-serve B2C-воронка.

## Комбинирование воронок

**Воронки работают лучше при комбинации.** Типовые связки:

| Связка | Логика |
|---|---|
| Лид-магнит → Вебинар → Звонок | холодную аудиторию прогреваем ценностью, эмоцию даём на вебинаре, дожимаем звонком |
| Бот (коллектор) → E-mail/мессенджер-цепочка → Tripwire | дешёвый вход из мессенджера, прогрев цепочкой, конверсия через дешёвую покупку |
| Tripwire → Upsell флагман → Комьюнити | снимаем барьер, поднимаем чек, удерживаем в комьюнити для LTV |
| Freemium → Онбординг → Premium | self-serve вход, ценность в использовании, монетизация JTBD |

При проектировании комбинации: на каждом стыке закладывай касания (5-7 на покупку) и не отпускай «подумать».

## Пример: связка «медиа → академия → консалтинг»

- **Вход (news.your-domain.com / канал @yourchannel)** — холодный AI-трафик → **Бот** (коллектор) + **E-mail/мессенджер-прогрев**.
- **Академия (B2C self-serve)** — **Tripwire** (мини-курс) → **Freemium/флагман** + **Вебинар** под запуск потока.
- **B2B-консалтинг/воркшопы** — **Бесплатный аудит (лид-магнит)** → **Лид→Звонок** с анкетой A/B/C/D → сделка в CRM.
