# Уникализация под репост (анти-фингерпринт)

Читать, когда заливаешь заново уже опубликованный (свой или перемонтированный)
ролик и площадка помечает его как дубликат / «вы это уже выкладывали». Для
первой публикации не нужно — лишняя перекодировка только портит картинку.

## Почему простых способов не хватает

Совпадение ищут три независимых слоя, и обойти надо все три. Кроп, яркость,
перекодировка и срезание метаданных поодиночке НЕ работают — визуальные CNN
специально обучены быть к ним инвариантными.

| Слой | Что сопоставляет | Что его ломает |
|---|---|---|
| **Визуальные CNN-эмбеддинги** | инвариантны к кропу / яркости / перекодировке — эти приёмы сами по себе не помогают | покадровое временное зерно, сдвиг оттенка, лёгкая геометрическая деформация, виньетка |
| **Аудиоотпечаток** | акустический отпечаток дорожки (по типу Shazam), переживает перекодировку | еле слышная шумовая подложка + полная перекодировка звука |
| **Перцептивный хэш + метаданные** | хэш файла, теги контейнера, раскладка GOP/ключевых кадров | `-map_metadata -1`, смена кодека/битрейта, смена GOP (`-g 18 -bf 3`) |

## Вариант 1 — низкая дисторсия (когда в кадре есть вшитые карточки или плашки субтитров)

```bash
ffmpeg -y -i in.mp4 \
  -vf "crop=iw*0.93:ih*0.93,scale=1080:1920:flags=lanczos,\
hue=h=6,eq=brightness=0.008:contrast=1.015:saturation=1.03,\
noise=c0s=6:c0f=t+u" \
  -c:v libx264 -preset medium -crf 19 -pix_fmt yuv420p -g 18 -bf 3 \
  -c:a aac -b:a 192k -ac 2 -ar 48000 -map_metadata -1 -movflags +faststart \
  out.mp4
```

- **Временное зерно (`noise … c0f=t`)** — главный рабочий инструмент: уникальная
  фактура на каждом кадре рушит эмбеддинг покадрово и почти не видна глазом.
- **Центральный кроп 93 %** выбрасывает исходные краевые пиксели и меняет
  кадрирование, при этом не гнёт геометрию — прямые края карточек остаются прямыми.
- **`hue`, GOP `-g 18`, `-map_metadata -1`** бьют по цвету, границам временных
  сегментов и по двоично-метаданному слою.
- **Никогда не отражать по горизонтали** (перевернёт вшитый текст) и **никогда не
  менять скорость/высоту звука** (расходится с голосом, а сам питч-шифт всё равно
  детектится с точностью ~97 %).
- Если всё ещё помечает — сначала подними зерно до `c0s=8` и `hue=h=9`, и только
  потом думай про геометрию.

## Аудиослой (не пропускать)

Уникализация одной картинки оставляет отпечаток саундтрека нетронутым, а его
одного хватает, чтобы пометить репост.

```bash
# ~ -45 dB шума на всю длину, подмешать под оригинальный звук
ffmpeg -y -i in.mp4 \
  -filter_complex "anoisesrc=color=pink:amplitude=0.004[n];\
[0:a][n]amix=inputs=2:duration=first:weights='1 0.05'[a]" \
  -map 0:v -map "[a]" -c:v copy -c:a aac -b:a 192k -ar 48000 out.mp4
```

Розовый шум амплитудой ~0,4 % сидит ниже порога восприятия на музыке и речи, но
меняет отпечаток. Если совпадение остаётся — `amplitude=0.008`.

## Вариант 2 — агрессивный (когда вшитой графики НЕТ)

Для чистого talking-head или B-roll можно добавить геометрию: бочка + смещённый
кроп + виньетка гнут кадр так, как CNN не умеет нормализовать.

```bash
ffmpeg -y -i in.mp4 \
  -vf "lenscorrection=k1=0.04:k2=0.02,\
crop=iw*0.95:ih*0.95:(iw*0.03):(ih*0.028),scale=1080:1920:flags=lanczos,\
hue=h=4,eq=brightness=0.01:contrast=1.02:saturation=1.04,\
noise=c0s=4:c0f=t+u,vignette=PI/6" \
  -c:v libx264 -preset medium -crf 19 -pix_fmt yuv420p -g 18 -bf 3 \
  -c:a aac -b:a 192k -ac 2 -ar 48000 -map_metadata -1 -movflags +faststart \
  out.mp4
```

| Фильтр | По какому слою бьёт | Эффект |
|---|---|---|
| `lenscorrection k1/k2` | визуальный | мягкая бочкообразная деформация |
| `crop … (iw*0.03):(ih*0.028)` | визуальный + хэш | смещённый кроп, срез краевых пикселей |
| `hue` + `eq` | визуальный | сдвиг цветового пространства |
| `noise c0s=4 c0f=t` | визуальный | покадровое временное зерно |
| `vignette=PI/6` | визуальный | затемнение краёв, смена яркостной подписи |
| `-g 18 -bf 3` | хэш | другая раскладка ключевых кадров |
| `-map_metadata -1` | метаданные | срезает теги контейнера |

⚠️ **Не применять этот вариант к роликам с карточками или плашками субтитров** —
`lenscorrection` и `vignette` выгибают прямые края, и получаются кривые
прямоугольники и завёрнутые углы.

## Связь с безопасными зонами

Центральный кроп зумит примерно в 1,075× и съедает отступы безопасной зоны.
Раскладывай контент с запасом ЗАРАНЕЕ и перемеряй на финальном уникализированном
кадре, а не на исходном.
