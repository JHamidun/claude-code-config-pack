# Бот-воронки из TG Ads — предупреждение эксперта

> Источник: экспертная методология, урок «Воронки в TG».
> Только факты из курса — не выдумывать.

## Главное предупреждение

**80% бот-воронок из TG Ads дают негативный результат.** Бот лучше работает
как **коллектор базы**, а не как первичная точка конверсии из платного трафика.

Из трёх типов воронок в TG (прямая на лендинг/квиз, контентная через канал,
через бот) — именно «воронка через бот» в большинстве кейсов убыточна.

## Антипаттерн

❌ **Бот как первая точка конверсии из TG Ads.**
Гнать холодный платный трафик сразу в бота → низкая конверсия, слитый бюджет.

## Паттерн

✅ **TG Ads → лендинг с регистрацией → бот для прогрева.**
Бот **вторичен**: подключается ПОСЛЕ захвата контакта/регистрации, для прогрева
и доведения до покупки. Сначала собрать базу, потом прогревать ботом.

Сравни с рабочими типами воронок (кейсы из:
- **Прямая (перформанс)**: TG Ads → лендинг/квиз → трипваер → флагман
  (кейс нутрициологии: ROMI ~500%).
- **Контентная через канал**: TG Ads → канал → прогрев контентом → продажа
  (кейс доставки из Китая: ROMI 2300%).

## Когда бот оправдан

Бот уместен как **вторичный** инструмент:
- **Прогрев** уже собранной базы.
- **Follow-up** после регистрации/заявки.
- **ManyChat-механика коммент→директ**: пользователь комментирует пост →
  бот пишет в директ. Здесь бот не первичная конверсия из Ads, а реакция на
  уже проявленный интерес.

## Признаки ботового подрядчика (чек-лист из

Если агентство гонит TG Ads в бота и показывает только «дешёвых подписчиков» —
проверь на накрутку:
- подписчики дешевле 30–40 ₽;
- CTR выше 1.5–2% на широких топиках;
- нет продаж (только «база»).
