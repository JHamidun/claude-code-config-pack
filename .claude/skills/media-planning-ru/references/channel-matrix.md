# Channel Matrix — матрица выбора канала + доли рынка + пороги входа

> Справочник для скилла `media-planning-ru`. Источник: Данилы эксперта + сквозной материал курса методология. Используется ПОСЛЕ дерева решений (`decision-tree.md`) для уточнения выбора и ДО передачи в playbook канала.

---

## 1. Доли рынка по регионам (фильтр доступных каналов)

| Регион | Поиск | Соц/охват | Запрещено/недоступно |
|--------|-------|-----------|----------------------|
| **РФ** | Яндекс (доминирует) | VK Ads, Telegram Ads, посевы | **Google Ads** (заблокирован для рекламы), **Meta** (экстремистская, запрещена) |
| **СНГ** | **Google ~70% / Яндекс ~30%** | TG, Meta (где легально), VK | — |
| **Мир (кроме Китая и исключений)** | **Google 95%+** | Meta (главный соц), TikTok, TG | — |

**Вывод:** регион — первый фильтр. РФ → набор {Яндекс, VK, TG, посевы}. Межд./СНГ → +{Google, Meta, TikTok}.

## 2. Пороги входа по каналам

| Канал | Минимальный порог | Комментарий |
|-------|-------------------|-------------|
| **Telegram Ads — еврокабинет** | **500€** | Все фичи, официальный кабинет ads.telegram.org, высокий порог. |
| **Telegram Ads — тонкабинет** | **20 TON** (через личный TG-аккаунт) | Дешевле войти, меньше возможностей таргетинга. |
| **Meta Ads** | антидетект-стек (VPN+прокси+Dolphin Anty/GoLogin) **или** агентский кабинет (комиссия 3-7%) | Из РФ — только через инфраструктуру/иностранное юрлицо. Лимиты растут поэтапно $50 → $200-500 → десятки тысяч. «Подготовленные» арбитражные аккаунты — высокий риск бана. |
| **VK Ads** | **низкий** | Самый доступный вход для РФ-рынка. |
| **Яндекс.Директ** | низкий-средний (порог пополнения) | Базовый канал РФ. |
| **Google Ads** | средний (платёжный профиль) | Только не-РФ таргетинг. |
| **Посевы / паблики** | **от 3-7 тыс ₽** за пост (1 млн подписчиков), потолок ~10 тыс ₽ | Скидки от админов с 20+ пабликами. Нужен портфель 30-50 пабликов (математика 60/30/10 → 60% слив, 30% в ноль, 10% окупают всё). |

## 3. Матрица «ниша × бюджет × цель → канал»

### По типу спроса
| Спрос | Что это значит | Канал | Playbook |
|-------|----------------|-------|----------|
| **Сформированный** (люди ищут товар) | Есть запросы в поиске | Яндекс.Директ (РФ) / Google Search (межд.) | `yandex-direct-pro-ru` / `google-ads-pro-ru` |
| **Несформированный** (спрос создаём) | Никто не ищет, надо показать | Meta / VK / TG (соц-каналы) | `meta-ads-launch-ru` / `vk-ads-pro-ru` / `telegram-ads-pro-ru` |

### По бюджету (РФ-рынок)
| Бюджет | Рекомендация | Playbook |
|--------|--------------|----------|
| Очень малый (тест) | VK Ads (низкий порог) / посевы у 1-2 пабликов | `vk-ads-pro-ru` / `tg-channel-buyout-ru` |
| Малый-средний | Яндекс.Директ Поиск (ловим горячий спрос) | `yandex-direct-pro-ru` |
| Средний+ (есть канал/инфобиз) | Telegram Ads еврокабинет (500€+) | `telegram-ads-pro-ru` |
| Крупный, омниканал | Яндекс + VK + TG + посевы параллельно | все РФ-playbook'и |

### По цели
| Цель | Тип закупки | Канал |
|------|-------------|-------|
| Продажи / лиды (performance) | аукцион с оптимизацией под конверсию | Яндекс.Директ / Google / Meta / VK |
| Охват / узнаваемость (awareness) | охват без оптимизации | Telegram Ads / посевы / медийка |
| Подписчики в канал | TG-инструменты | Telegram Ads / посевы → `telegram-ads-pro-ru` / `tg-channel-buyout-ru` |
| Нативное доверие в нише | прямая закупка у эксперта | посевы / интеграции у блогеров → `tg-channel-buyout-ru` |

### По бизнес-модели
| Модель | Особенность | Стек каналов |
|--------|-------------|--------------|
| **B2C массовый** | широкая аудитория, короткий цикл | Meta / VK / TG / Яндекс.Директ |
| **B2C нишевый** | узкая аудитория, доверие | посевы у экспертов + ретаргетинг |
| **Инфобиз / edtech** | контент-прогрев, канал | Telegram Ads + посевы + контент-воронка |
| **B2B, длинный цикл** | узкий ЛПР-таргетинг | Google Search + LinkedIn + Cold Outreach |
| **E-commerce** | каталог, сформированный спрос | Яндекс.Директ (Поиск+Товарка) / Google Shopping |

## 4. Сильные стороны каналов (как сравнивать)

| Канал | Механика | Сильная сторона | Слабая сторона |
|-------|----------|-----------------|----------------|
| **Яндекс.Директ** | аукцион + автостратегии | ловит готовый спрос РФ, Крипта, обучение | только РФ-ориентир, конкуренция в нишах |
| **Google Ads** | аукцион + ручные аудитории | масштаб мира 95%, архитектура аудиторий | заблокирован на РФ |
| **Meta Ads** | аукцион + сильнейший ИИ-алгоритм | алгоритм сам оптимизирует на событие | запрещён в РФ, нужна инфраструктура, чувствителен к изменениям |
| **VK Ads** | ручная работа, алгоритм «почти не работает» | низкий порог, ручной контроль, парсинг | всё руками, нет автообучения |
| **Telegram Ads** | аукцион CPM, **нет фазы обучения** | результат виден сразу, охват | нет оптимизации под конверсию |
| **Посевы / блогеры** | прямая закупка размещения | нативность, доверие, дёшево на входе | плохая измеримость, риск ботов, нужен портфель |

## 5. Применение к проектам пользователя (контекст)

- **YourProduct / Academy на РФ** → Яндекс.Директ + VK + Telegram Ads + посевы (Google/Meta отпадают).
- **Международные продукты** → Google Ads + Meta Ads.
- **@yourchannel (личный канал)** → Telegram Ads (подписчики) + посевы у экспертов.

> После уточнения по этой матрице — **обязательно** перейти к playbook'у выбранного канала (см. таблицу маршрутизации в SKILL.md).
