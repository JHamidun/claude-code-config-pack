# Budget Allocation — распределение бюджета, минимальный порог, тестовые бюджеты, эластичность

> Справочник для скилла `media-planning-ru`. Источник: практика performance-эксперта + сквозной материал курса.

---

## 1. Формула минимального бюджета (главное правило входа)

```
минимальный недельный бюджет на канал = средняя цена конверсии × 10
```

**Почему ×10:** алгоритму (и таргетологу) нужна **статистика**. Меньше ~10 конверсий в неделю — система не наберёт данных, не обучится, оптимизация невозможна, бюджет уходит в шум. Это пересекается с порогами обучения в playbook'ах (Meta — 50 событий за 7-10 дней; Яндекс — 10 конверсий/нед).

| Ожидаемый CPL | Минимум в неделю на канал |
|---------------|---------------------------|
| 200₽ | 2 000₽ |
| 500₽ | 5 000₽ |
| 1 000₽ | 10 000₽ |
| 2 000₽ | 20 000₽ |

**Следствия для медиаплана:**
- Если бюджет не вытягивает ×10 на канал → **не дроби** на несколько каналов. Лучше один канал на пороге, чем три «слепых».
- Если CPL слишком высок для бюджета → выбери канал с более дешёвой конверсией (часто VK/посевы дешевле на входе, чем Meta).
- Снижение цели (микроконверсии вместо макро) тоже помогает набрать статистику при дефиците бюджета.

## 2. Бюджетирование «от малого к большому»

Каноничный принцип: **«Не лей большой бюджет на непроверенные связки. Сначала тест на малых суммах, потом анализ, потом масштабирование.»**

### Этапы
1. **Тест** — минимальные суммы на проверку гипотез (канал × аудитория × креатив × оффер).
2. **Анализ** — что дало конверсии по приемлемой цене (по CPL/CPA, не по CPC).
3. **Масштаб** — увеличиваем бюджет **только на работающие связки**, плавно (+10%/нед).

### Тестовый бюджет (ориентир)
- Тестовый бюджет на связку ≈ цена 1-2 конверсий × запас на статистику. Цель теста — не продажи, а **сигнал**: даёт связка конверсии по адекватной цене или нет.
- Правило отключения (X3 из playbook'ов): если потрачено **≥ 3 × целевого CPA**, а конверсий нет → выключать связку без сожаления.
- A/B-тестирование обязательно: тестировать всё — аудитории, офферы, заголовки, креативы, лендинги. «Угадать заранее, что выстрелит, нельзя.»

## 3. Распределение бюджета между каналами (channel mix)

Нет единой «правильной» пропорции — она зависит от стадии и цели. Опорные принципы:

| Принцип | Как применять |
|---------|----------------|
| **Принцип Парето 80/20** | 80% результата дают 20% связок. Фокус на самых эффективных каналах, отключение неработающих. |
| **Не размазывать** | Малый общий бюджет → 1-2 канала на пороге ×10, а не 5 каналов по чуть-чуть. |
| **Awareness + Performance слоями** | Часть бюджета — на охват/прогрев (верх воронки), часть — на сбор конверсий (низ). Не только performance. |
| **Портфель в посевах** | Внутри посевов — диверсификация 60/30/10 (60% слив / 30% в ноль / 10% окупают всё), портфель 30-50 пабликов. → `tg-channel-buyout-ru`. |
| **Ретаргетинг отдельной строкой** | Тёплая аудитория дешевле холодной — всегда закладывать бюджет на ретаргетинг. |

### Логика последовательности (для нового проекта)
1. Сначала **один канал** под главную цель (по дереву решений) — довести до окупаемости.
2. Когда канал даёт стабильный CPL — **добавить второй** (часто охватный к performance или наоборот).
3. Подключить **ретаргетинг** между каналами (омниканальность, 5-7 касаний).
4. Масштабировать работающее, перераспределять с неработающего.

## 4. Эластичность трафика (предел масштабирования)

**Рост бюджета увеличивает CPC, но НЕ увеличивает клики линейно.**

- Удвоил бюджет ≠ удвоил клики/конверсии. Канал начинает «выкупать» более дорогую и менее качественную аудиторию → CPC растёт, CPA портится.
- Поэтому масштабирование **плавное** (+10% в неделю — правило из VK/Meta/Директ playbook'ов), а не скачком.
- При перегреве одного канала эффективнее **распределить** прирост бюджета на другой канал, чем доливать в перегретый аукцион.
- Риск каннибализации при дублях кампаний/аккаунтов/сайтов (до 50%) — не пытаться обойти эластичность дублированием.

### Что это значит для медиаплана
- Закладывай **ухудшение CPA при росте бюджета** — план должен быть с запасом, а не линейной экстраполяцией теста.
- Один канал имеет «потолок ёмкости» по адекватной цене → дальше нужен следующий канал. Это естественный триггер расширения channel mix.

## 5. Чек-лист перед утверждением медиаплана

- [ ] Определён рынок (РФ / СНГ / межд.) → отфильтрованы недоступные каналы.
- [ ] Под каждый выбранный канал бюджет ≥ (средний CPL × 10) в неделю.
- [ ] Бюджет НЕ размазан на каналы ниже порога входа.
- [ ] Заложен тестовый этап на малых суммах перед масштабом.
- [ ] Есть строка на ретаргетинг (омниканальность, 5-7 касаний).
- [ ] План учитывает рост CPA при масштабировании (эластичность), а не линейную экстраполяцию.
- [ ] Настроена аналитика (Метрика/GA4/Pixel) — иначе план невыполним → `full-funnel-analytics-ru`.
- [ ] Для каждого канала назначен playbook запуска (см. маршрутизацию в SKILL.md).
