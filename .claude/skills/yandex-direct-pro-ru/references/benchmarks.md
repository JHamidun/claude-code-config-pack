# Бенчмарки и формулы Яндекс.Директа

Все референсные цифры методологии в одном месте. Это эталонные ориентиры из практики, а не гарантии — реальные значения зависят от ниши.

## CTR

| Площадка | Норма | Трактовка отклонения |
|----------|-------|----------------------|
| **Поиск** | **> 5%** | <5% → проверить позицию показа (>3 = нижний блок → поднять ставку) или релевантность |
| **РСЯ** | **< 2%**, идеально **< 1%** | **>2% = плохо** (скликивание, мисклики, накрутка). Фулскрин-реклама и приложения дают случайные клики |

- Приложения в РСЯ (`af://`, `id://`) часто имеют CTR **30-100%** → скликивание → **отключать немедленно**.
- Высокий CTR на Поиске → показы в верхнем блоке (позиции 1-4) → улучшает коэффициент качества в аукционе.

## Процент отказов

| Площадка | Норма |
|----------|-------|
| **Поиск** | **< 30%** |
| **РСЯ** | **< 40-50%** (идеально < 30%) |

Высокий % отказов = нерелевантные запросы (Поиск) или некачественные площадки (РСЯ). Отказ в Метрике = визит ≤15 сек и ≤1 страница.

## Позиции показа

- Средняя позиция показа **> 3** → объявление ушло в нижний блок → поднять ставку / бюджет / целевую цену конверсии.
- Средняя позиция **≤ 3** → верхний блок.

## Минимум данных для решений (репрезентативность)

| Решение | Минимум кликов |
|---------|----------------|
| Любые выводы по кампании | **100 кликов** за период (неделя) |
| Решение по площадке (РСЯ) | **50 кликов** |
| Решение по отдельному запросу | **15-20 кликов** |
| На 1-3 кликах | решений НЕ принимать |

Анализ по отдельным дням недостоверен — алгоритм учитывает все дни недели.

## Обучение автостратегий

| Параметр | Значение |
|----------|----------|
| Минимум конверсий | **≥ 10 в неделю** на каждую РК |
| Минимальная длительность обучения | **7 дней** |
| Рекомендуемое ожидание полного обучения | **2-3 недели** (РСЯ — до 4) |
| Вес данных | наибольший за последние **7 дней** |
| Остановка, обнуляющая данные | **> 7 дней** |
| Период учёта при оплате за конверсии | **21 день** |

## Погрешность алгоритма по объёму конверсий

| Конверсий накоплено | Погрешность по цене |
|---------------------|---------------------|
| 25 | **± 40%** |
| 400 | **~ 10%** |
| 10 000 | почти нет |

Чем больше данных (Big Data), тем точнее нейросеть.

## Формулы

- **Минимальный недельный бюджет = средняя цена конверсии × 10.**
  Пример: CPA 2000 ₽ → бюджет ≥ **20 000 ₽/нед**. Меньше — стратегия не обучится.
- **Правило X3:** потрачено ≥ **3 × KPI** за лид без лидов (при достаточных кликах) → отключать.
- **Масштабирование бюджета:** не более **+10% в неделю** на автостратегиях; держать CPA ≤ 1.2 × KPI, откат при >1.3 × KPI.
- **Аукцион Директа:** позиция = **ставка × CTR × коэффициент качества × прогноз CTR**.

## Каннибализация и масштаб

- Дубли сайтов → каннибализация лидов **до 50%**.
- На объёмах **CPA всегда растёт** (дешёвая аудитория выкупается первой).
- Эластичность исчерпана, когда рост бюджета +10-20% даёт CPC +15-30%, но клики < +5%.

## Технические лимиты

| Сущность | Лимит |
|----------|-------|
| Рекламных кампаний в аккаунте | до 1000 (обычно 5-20) |
| Целей на счётчик Метрики | **200** |
| Быстрых ссылок в объявлении | до 8 |
| Минус-площадок | 1000 |
| Заголовок 1 (Поиск) | 56 символов |
| Заголовок 2 (Поиск) | 30 символов |
| Текст объявления (Поиск) | 81 символ |
| Текста на картинке (РСЯ) | ≤ 20% |
| Крипта — характеристик пользователя | 300+ |
| Автотаргетинг РСЯ — привязок | 80+ |

## Доли и распределения (микс при масштабировании)

| Таргетинг | Доля бюджета |
|-----------|--------------|
| Автотаргетинг (при добавлении) | 20-30% |
| Ретаргетинг | 10-20% |
| Look-alike / интересы | 10-15% |

## Прочее

- Оплата **за клики** используется в ~**90%** случаев.
- Пакетные стратегии: ~**95%** бюджета уходит на лучшую кампанию (поэтому пока малоэффективны).
- Корреляция Пирсона микро↔макро: **> 0.7** → микроцель годна для обучения.
- ЦДРР для лайфхака микро+макро: **100%**.
