# Семантика, Wordstat и объявления

Источник: экспертная методология. методология, уроки «Семантика + Wordstat» и «Основы контекстной рекламы».

> Для семантики под **органическую выдачу (SEO)** см. `seo-machine-ru` — там тот же Wordstat, но другая цель (трафик, а не транзакция). Операторы Wordstat идентичны; здесь они даны под платную рекламу.

## 1. Ключевые понятия

- **Поисковый запрос** — то, что человек вводит в строку. Попав в кампанию, становится **ключевым словом**.
- **Семантическое ядро (семантика)** — совокупность всех ключевых слов, по которым показывается реклама.
- **Маска (базис, базовая маска)** — базовое словосочетание из 2-3 слов, вызывающее показы по множеству запросов. Самая большая «матрёшка». Пример: `пластиковые окна`.
- **Подзапрос (вложенный запрос)** — маска + дополнительные слова. Каждый запрос делится на множество других (принцип фрактала/матрёшки). **Чем больше масок — тем шире охват.**

## 2. Классификация запросов

### По готовности к покупке (тёплость)

| Тип | Суть | В контексте? |
|-----|------|--------------|
| **Холодные** (информационные) | «как сделать своими руками», «что такое» | ❌ Нет — низкая конверсия, не доходят до покупки |
| **Тёплые** (навигационные) | интерес есть, намерение не явное | ✅ Да |
| **Горячие** (транзакционные) | явное намерение: «купить + товар», «вызвать сантехника» | ✅ Да, приоритет |

**Контекстная реклама работает только с тёплыми и горячими** — там, где спрос уже сформирован.

### По частотности

- **ВЧ** (высокочастотные) — много показов.
- **СЧ** (среднечастотные).
- **НЧ** (низкочастотные).
- Правило: **чем больше слов в запросе — тем он низкочастотнее.**

## 3. Что Яндекс НЕ учитывает

Система отбрасывает окончания и работает с **корнями слов**. НЕ учитываются: **род, число, падеж, лицо**. «Стол», «столы», «столом» — для системы одно и то же. Учитываются только 3 части речи: **существительное, прилагательное, глагол**.

## 4. Операторы Wordstat (4 штуки)

| Оператор | Назначение | Пример |
|----------|-----------|--------|
| `+` | обязательное вхождение предлога/частицы (их Яндекс по умолчанию игнорирует) | `вода +на дом` |
| `!` | фиксация формы слова (род, число, падеж) | `!кий` — не «Киев», не «Kia» |
| `" "` | показы только по словам в кавычках, без дополнительных слов (отсечение) | `"пластиковые окна"` |
| `[ ]` | фиксация порядка слов | `[лечение при осложнениях]` |

**Инструмент:** `wordstat.yandex.ru`. Старый интерфейс **`old.wordstat.yandex.ru` — удобнее** для анализа. Показывает частоту за предыдущий месяц, регионы, **историю и сезонность за 2 года** (спрос может различаться в 2-3 раза лето/зима). Правая колонка — похожие запросы («что ещё искали»).

> Снять **реальные частоты** программно — через `seo-machine-ru` (`wordstat_fetch.py` / internal API на куках; Direct API v4 часто заблокирован, error 58) или скилл `yandex`.

## 5. Алгоритм сбора масок

1. **Базовый запрос** — с твоего сайта, сайтов конкурентов (10-15 сайтов), из знаний о продукте.
2. **Через части речи** (главный приём расширения):
   - Существительное → синонимы: машина / автомобиль / авто
   - Глагол → синонимы: аренда / арендовать / прокат / напрокат / снять / нанять
   - Прилагательное → синонимы: свадебный / свадебная / свадебное
3. **Дополнительные вариации:** однокоренные с приставками (прокат/напрокат), смысловые синонимы (копия/реплика), бизнес-синонимы (перчатки ПВХ / строительные перчатки), транслит (RU/EN названия брендов), слитное/раздельное написание, сокращения и аббревиатуры.
4. **Проверить в Wordstat** — что запросы реальные; посмотреть вложенные и правую колонку; оценить частотность и сезонность.
5. **Отсеять холодные** (информационные).

**Пример (аренда свадебных авто):** из 1 базового запроса → ~10 масок: «аренда свадебных машин/автомобилей/авто», «арендовать свадебную машину/авто», «прокат свадебных машин/авто», «автомобиль на прокат / машина напрокат», «снять свадебную машину / нанять авто на свадьбу».

**Где искать маски:** свой сайт · сайты конкурентов (10-15) · правая колонка Wordstat · тематические статьи, Википедия, онлайн-словари · транслит, сокращения, аббревиатуры.

## 6. Структура аккаунта

```
Аккаунт
└─ Рекламные кампании (до 1000, обычно 5-20)
   └─ Группы объявлений
      └─ Ключевые фразы + объявления
```

Правила структуры:
- **Брендовые запросы → всегда отдельная кампания** (название твоей компании): высокая конверсия, другая стратегия (Максимум кликов).
- **Поиск и РСЯ — разные кампании.**
- **Одна группа = один список слов по одной маске** (или нескольким близким НЧ). Кластеризация по смысловой близости, товарам, направлениям услуг.

**Пример (школа английского):**
```
РК 1: Бренд (название школы)              → Максимум кликов
РК 2: Занятия для детей
      ├─ Группа: Курсы для детей
      └─ Группа: Репетитор для детей
РК 3: Занятия для взрослых
      ├─ Группа: Курсы для взрослых
      └─ Группа: Репетитор для взрослых
РК 4: Корпоративное обучение
```

## 7. Объявления для Поиска

Элементы и лимиты символов:

| Элемент | Лимит | Что писать |
|---------|-------|------------|
| Заголовок 1 (основной) | **56 симв.** | по маске группы |
| Заголовок 2 | **30 симв.** | акция, бренд, УТП |
| Текст | **81 симв.** | сжатое УТП с посадочной (с цифрами) |
| Быстрые ссылки | до **8 шт.** | категории, доставка, преимущества |
| Отображаемая ссылка | — | читаемый «хвост» URL |
| Уточнения | — | короткие некликабельные факты |
| Промоакция | — | скидка / бесплатное |
| Контакты | — | подтягиваются из Яндекс.Бизнеса |

**Заполнять ВСЕ элементы** — чтобы объявление участвовало в максимуме **трафаретов** (вариантов дизайна страницы поиска). Чем больше заполнено, тем чаще объявление попадает в выгодные форматы (эксклюзив, расширенный).

## 8. Объявления для РСЯ

- Прямая релевантность запросу **не нужна** — пользователь не в режиме поиска.
- Писать **конкретно и понятно**: что, где, почему, цена.
- **Избегать тизерных/интригующих заголовков** — автотаргетинг не поймёт объект рекламирования и покажет рекламу не тем людям.
- Картинки — яркие, чёткие; **текста на изображении ≤ 20%**.

## 9. UTM-метки

- Параметры: `utm_source`, `utm_medium`, `utm_campaign`, `utm_term`, `utm_content` + динамические параметры Директа (подстановка campaign id, ключевого слова, типа площадки и т.д.).
- **Для связки Директ + Метрика метки НЕ обязательны** — сервисы одной экосистемы, данные стыкуются автоматически.
- UTM нужны прежде всего для **внешних систем аналитики** (сквозная аналитика, CRM, коллтрекинг).

## 10. Места показа на Поиске (справочно)

- **8 рекламных мест:** 4 сверху (премиум, самые эффективные) + 4 снизу.
- Спецместа: реклама в поисковых подсказках (только заголовок), товарная галерея, баннер на поиске (справа), промоакции.
- Форматы: стандартное объявление, расширенный, эксклюзив (одно большое).
- Как отличить рекламу от органики: пометка «реклама» (по закону всегда есть); 4 сверху + 4 снизу — реклама, 10 между ними — SEO-выдача.
