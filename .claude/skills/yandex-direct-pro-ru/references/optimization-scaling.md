# Оптимизация, масштабирование, офлайн-конверсии

Источник: Дарья Дейн, Ninja Marketing, урок «Аналитика и оптимизация. Масштабирование».

## 0. Золотое правило

**«Работает — не трогай. Лучшее — враг хорошего.»** Если CPA ≤ KPI и лидов достаточно — изменений НЕ вносить (можно сломать обучение). Оптимизировать только то, что вышло за бенчмарк. Минимум для любых выводов — **100 кликов за период (неделя)**, анализ по отдельным дням недостоверен.

## 1. Дашборд «Все кампании» (12 столбцов)

1. Статус кампании · 2. Бюджет · 3. Стратегия · 4. Места показов (Поиск/РСЯ) · 5. **Расход с НДС** (в Директе по умолчанию без НДС!) · 6. Показы · 7. Клики · 8. CTR · 9. CPC · 10. % отказов · 11. **Статистика по целям** (микро+макро: 60 сек, 90 сек, заинтересованный, заявка → конверсии / конверсия сайта % / CPA) · 12. (опц.) дата начала.

Период — неделя минимум. Фильтр «Все кроме архивных» / «Запущенные». В Мастере отчётов: группировка «За выбранный период» (не за каждый день), расход с НДС.

## 2. Чек-лист недельного анализа ПОИСКА (5 шагов)

**Шаг 1 — общие показатели.** Показы идут? Кликов ≥100? CTR ≥5%? % отказов ≤30%? CPA ≤ KPI?

**Шаг 2 — низкий CTR (<5%).** Отчёт «Позиции показа и клика»:
- Средняя позиция показа **>3** → объявление в нижнем блоке → **поднять ставку/бюджет/целевую цену конверсии на 10-20%**.
- Средняя позиция **≤3** (верхний блок), но CTR низкий → проблема в релевантности → проверить поисковые запросы (Шаг 3).

**Шаг 3 — высокий % отказов (>30%).** Отчёт «Поисковые запросы», фильтр клики ≥15, сортировка по % отказов:
- Найти нерелевантные запросы (% отказов >40-50%) → **в минус-фразы**: выбрать запрос → «Добавить в минус-фразы» → **убрать кавычки, оставить только проблемное слово**.

**Шаг 4 — высокий CPA (>KPI).** Отчёты «Устройства», «Пол и возраст», «География», фильтр клики ≥50:
- Сегмент с высоким CPA и низкой конверсией → корректировка ставки **вниз** (-20…-50%) или отключить.
- Сегмент с низким CPA и высокой конверсией → корректировка **вверх** (+20…+50%).
- **Правило X3** (см. §4).

**Шаг 5 — всё OK.** CTR ≥5%, отказы ≤30%, CPA ≤ KPI → **ничего не трогать**; можно +10% бюджета для роста объёма.

## 3. Чек-лист недельного анализа РСЯ (5 шагов)

**Шаг 1 — общие.** Кликов ≥100? CTR **≤2%** (>2% → Шаг 2)? % отказов ≤40% (>40% → Шаг 3)? CPA ≤ KPI (нет → Шаг 4)?

**Шаг 2 — высокий CTR (>2%).** Отчёт «Места размещения», столбцы: площадка, клики, CTR, % отказов, CPA; фильтр клики >0; сортировка по CTR:
- Приложения (**`af://`, `id://`**) с CTR **>30%** и клики <10 → **отключить немедленно** (скликивание).
- Площадки с CTR >5-10% + % отказов >60% и клики ≥50 → «Запретить показы» или в минус-площадки (лимит 1000).

**Шаг 3 — высокий % отказов (>40%).** «Места размещения», фильтр клики ≥50, сортировка по % отказов: площадки >60-70% → запретить (если CTR тоже подозрительный) или ждать больше статистики.

**Шаг 4 — CPA.** Как на Поиске (Шаг 4): устройства / пол-возраст / гео.

**Шаг 5 — оптимизация.** Всё OK → не трогать. **РСЯ часто учится дольше (2-4 недели).**

**Репрезентативность:** 50 кликов для решения по площадке, 15-20 по запросу. На 1-3 кликах — нельзя.

## 4. Правило X3

**Если на площадку / запрос / сегмент потрачено ≥ 3 × KPI за лид, а лидов нет или мало (при достаточном числе кликов) → отключать.** Статистика уже не выйдет в плюс.

## 5. Сегменты Метрики

**Готовые:** новые / вернувшиеся посетители, поисковый / рекламный трафик, отказы / не-отказы.

**Позитивные (целевое поведение)** → условия ретаргетинга:
- активность 4+ в Вебвизоре (тёмно-/светло-зелёный);
- провели на сайте **90+ секунд**;
- достигли микроконверсии (напр. «3+ страницы»);
- пришли из конкретной РК; крупные города; десктоп.

**Негативные (исключить из показов)** → корректировка **-100%**:
- **< 20 секунд из Директа**;
- **3+ визита и суммарное время < 30 сек** (боты);
- нецелевые источники; мобильные с высоким % отказов.

**Создание сегмента:** отчёт Метрики → применить фильтры → в шапке «Сегмент: N условий» → «Сохранить как сегмент» → Настройки → Сегменты → перетащить/«Использовать в Директе» → в кампании выбрать как условие ретаргетинга (позитивные) или добавить корректировку ставок -100% (негативные).

## 6. Ретаргетинг (3 вида)

Работает на **Client ID Метрики**.
1. **Классический (РСЯ)** — показ в РСЯ пользователям из сегмента (напр. «был на сайте, не оставил заявку»).
2. **Поисковый** — показ на Поиске при двух условиях: пользователь в сегменте **И** набрал ключевое слово из кампании. Дожим заинтересованных.
3. **Динамический (e-commerce)** — конкретные карточки просмотренных товаров (нужна настройка электронной коммерции).

Сценарии: брошенные корзины · напоминания (был 3-7 дней назад) · one-time offer · возврат после первого визита.

## 7. Офлайн-конверсии (передача квалифицированных лидов из CRM)

**Зачем:** оптимизировать не на «все лиды», а на **квалифицированные лиды / продажи**; видеть, какие площадки/запросы дают спам, а какие — качество. Это **приоритет №1** для роста эффективности. Работает на **Client ID**. Готовые коннекторы: AmoCRM, Битрикс24 (через интеграторов). Настройка ~1 неделя + программист.

**6 шагов:**
1. **Получить Client ID на сайте:** `var clientID = ym(COUNTER_ID, 'getClientID');` → сохранить в скрытое поле формы, передать в CRM с заявкой.
2. **Хранить Client ID в CRM:** кастомное поле «Metrika Client ID» при создании лида.
3. **Создать цели в Метрике:** «Квалифицированный лид» и/или «Продажа» (JS-событие или составная цель).
4. **При квалификации/продаже отправить событие обратно в Метрику** по этому Client ID:
   `POST https://api-metrika.yandex.net/management/v1/counter/{COUNTER_ID}/offline_conversions/upload?client_id={CLIENT_ID}`
   (параметры: ID цели, Client ID, дата/время).
5. **В стратегиях Директа** указать цель «Квалифицированный лид» вместо «Оставили заявку».
6. **В отчётах** выбирать данные по цели «Квалифицированный лид».

> Технический вызов API (формирование CSV/запроса, OAuth) — напрямую через Metrika API (`POST .../offline_conversions/upload`). Источник Client ID и факта квалификации — твоя CRM.

## 8. Масштабирование (3 этапа)

**Два пути роста:** (а) больше объёма из охваченной аудитории (↑ бюджет/ставки); (б) новая аудитория (расширение таргетингов). **На объёмах CPA всегда растёт** — дешёвая аудитория выкупается первой.

### Этап 1 — ЧИСТКА (отсечь ненужное, ~1 неделя)
- «Места размещения» → отключить приложения с CTR >30%, площадки с % отказов >70% (клики ≥50), площадки с CPA >3×KPI (правило X3).
- «Поисковые запросы» → минус-слова (% отказов >50% или очевидно нецелевые).
- «Устройства»/«Пол-возраст»/«География» → понизить ставки на дорогие сегменты (-30…-50%), повысить на дешёвые с высокой конверсией (+20…+30%).
- Применить негативные сегменты (-100%).
- Итог: CPA стабилен/ниже, объём лидов слегка просел (норма — отсекли мусор).

### Этап 2 — ДОБАВЛЕНИЕ БЮДЖЕТА (2-4 недели)
- Увеличивать бюджет/целевую цену **не более +10% в неделю** (для автостратегий).
- Следить за CPA ежедневно (держать ≤ 1.2 × KPI). Если CPA >1.3 × KPI — откатиться на предыдущий уровень.
- По ходу чистить новые площадки/запросы.
- Итог: лидов +30-50%, CPA +10-20% (норма).

### Этап 3 — РАСШИРЕНИЕ ТАРГЕТИНГОВ (2-4 недели)
- **Семантика:** связанные запросы Wordstat, конкуренты, синонимы, околоцелевые (+30-50% ключей), через неделю — чистка.
- **Автотаргетинг:** включить отдельной группой + 3-5 новых текстов, бюджет 20-30%, чистить мусорные запросы.
- **Ретаргетинг:** сегменты «был, не оставил заявку (7-14 дней)», «3+ страницы, не оставил», «микроконверсия 60 сек, не оставил»; РСЯ + поисковый ретаргетинг, бюджет 10-20%.
- **Look-alike и интересы:** LAL на базе «оставили заявку» (узкая), интересы из релевантных категорий, бюджет 10-15%.
- Итог: суммарно лидов в 2-3 раза от старта, CPA +20-30%.

### Этап 4 — повторное наращивание бюджета (опц.)
Вернуться к Этапу 2 (+10%/нед), следить за CPA, при замедлении — проверить эластичность.

**Общий результат цикла:** лидов в 3-5 раз, CPA +30-50% (допустимо при масштабировании).

## 9. Эластичность трафика и её пределы

**Эластичность** — способность наращивать объём при росте бюджета. **Признаки исчерпания:** рост бюджета +10-20% → CPC +15-30%, но клики <+5%; CPA вырос в 1.5-2 раза; конверсии не растут (точка плато).

**Диагностика:** Wordstat — оценить общий объём спроса vs текущие показы (показы 50-70% объёма → исчерпано по Поиску); проверить, все ли релевантные запросы охвачены; проверить, включены ли автотаргетинг / ретаргетинг / Look-alike / интересы.

**Если таргетинги исчерпаны — альтернативы (с рисками):**
1. **Дубли сайтов** → каннибализация лидов **до 50%**, рост общей конкуренции.
2. **Множественные аккаунты** → те же риски + сложность управления.
3. **Дубли кампаний** → новые работают хуже обученных, удорожание.
4. **Околоцелевая семантика** → низкая конверсия.
5. Другие каналы (VK Ads, посевы, SEO).

**Вывод:** масштабирование имеет предел — не все ниши тянутся в 10 раз.
