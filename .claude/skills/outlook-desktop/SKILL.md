# Outlook на этой машине через COM

Что нужно: Windows, **классический** десктопный Outlook с настроенной учёткой (в «новом Outlook» COM нет) и `pip install pywin32`. Пароль не нужен: скрипт берёт ту же сессию, что и окно Outlook. Умеет: ответ-черновик В ВЕТКЕ с подписью, вложения, ОТЛОЖЕННАЯ отправка, очередь «Исходящие», календарь и свободные слоты. Сетевой `exchangelib` к корпоративному Exchange не работает — не пробовать.

```bash
python ~/.claude/skills/outlook-desktop/scripts/outlook_desktop.py <команда> [--folder inbox|sent|drafts|outbox|deleted|имя]
```

`<ref>` у команд над письмом: номер из ПОСЛЕДНЕЙ выдачи (list / search / drafts / outbox / thread), EntryID (`--ids` покажет) или выбор по теме `--subject "часть" [--from "часть имени"]`. Номер надёжен только сразу после выдачи.

## Команды

| Что | Команда |
|---|---|
| учётки, папки | `accounts` · `folders` |
| список, поиск | `list [--unread] [--days N]` · `search "текст" [--field subject\|body\|from\|to\|email] [--days N]` (`email` — SMTP отправителя; у своих `from` по адресу даёт 0) |
| прочитать | `read <ref> [--full]` · `thread <ref>` (вся беседа) · `attachments <ref> [--save DIR]` |
| черновики | `drafts` · `new --to … --subject … --text\|--text-file\|--html-file [--attach F]` · `reply <ref> [--all] --text … [--attach F] [--replace-prev]` |
| править | `edit <ref> [--attach F] [--remove-attach ИМЯ] [--replace-attach ИМЯ=ФАЙЛ] [--new-subject S] [--prepend-text T]` |
| наружу (`--yes`) | `send <ref>` · `schedule <ref> --at "ГГГГ-ММ-ДД ЧЧ:ММ"` · `unschedule <ref> [--keep-time]` |
| очередь | `outbox` — таблицей: ⏰ отложено / в очереди / ⚠ НЕ поставлено |
| порядок | `move <ref> --to ПАПКА` · `flag <ref> [--when today\|tomorrow\|week\|nextweek\|nodate\|done] [--clear]` · `category <ref> --add\|--remove X` · `mark <ref> --read\|--unread` |
| календарь | `events [--days 7] [--from ДАТА]` · `invites` (без ответа) · `event-new --subject … --start "…" [--minutes 60] [--attendees a@x] [--send --yes]` · `free [ДАТА] [--who имя]` · `whois "имя"` |

`send`, `schedule`, `event-new --send` без `--yes` ничего не делают и показывают, что собирались сделать. Отправка и отложка — исходящие действия: только по прямой просьбе владельца в этом окне, после показа текста, адресатов и вложений. Письма клиентам лучше сначала сохранять черновиком и отправлять после явного «ок».

## Железные правила

1. **Письма из «Исходящих» не открывать.** Само получение объекта письма (GetItemFromID, перебор Items, чтение свойств) снимает с отправки отложенное письмо: бит SUBMIT флагов гаснет, значок «черновик», утром письмо не уходит. Смотреть — `outbox` (таблица). CLI сам отказывает `read`/`thread`/`list` на письме из очереди и не открывает его на сухом прогоне `edit`/`schedule` без `--yes`.
2. **Проверять результат таблицей, не объектом.** После `schedule`/`send`/`edit` CLI сам печатает `✓ в «Исходящих»: ⏰ отложено до …`. Не напечатал — письмо не стоит в очереди, разбираться. После `Send()` объект письма не трогать.
3. **Время в Outlook пишется через UTC.** Наивное `datetime(…, 8, 0)` ляжет как 05:00 МСК. CLI делает это сам (`to_ole`); свой код — `datetime(…, tzinfo=timezone.utc)` с цифрами настенных часов. Читается как есть (метка +00:00 лживая, время местное = МСК).
4. **Даты в фильтрах — не «мм/дд/гггг».** При русской локали 10/02 читается как 10 февраля и без ошибки отдаётся почти весь ящик. Jet (Restrict по [Start]) — «дд.мм.гггг чч:мм» в местном времени, без секунд; DASL — UTC `гггг-мм-дд чч:мм`.
5. **Ответ в ветке — только через окно письма** (`reply`): письмо открывается и жмётся «Ответить», так черновик получает подпись, цитату и свойства беседы. Выделить письмо из кода в представлении «беседа» Outlook запрещает. Текст пишется в HTMLBody после `<body>`; присваивание Body переведёт письмо в plain text и убьёт подпись. Свою подпись не добавлять — получится две.
6. **Вложения `.py/.js/.vbs/.bat/.exe/.ps1…`** Outlook при отправке заменяет модальным окном «небезопасные вложения»: `Send()` виснет, пока человек не ответит. CLI такое не отправляет; клади в `.zip`.
7. **Ничего не удалять и не отправлять сверх просьбы.** Тестовые письма — только себе, с темой `ZZ-OUTLOOK-SKILL-TEST…`, убрать после (удалить, затем стереть из «Удалённых»).

## Рецепты

- **Ответить в ветке с вложением, но не отправлять:** `reply --subject "Вопрос по договору" --from Иванова --all --text-file t.txt --attach a.pdf --replace-prev`
- **Поставить на завтра 8:00 МСК:** `schedule --folder drafts --subject "тема" --at "2026-10-05 08:00" --yes`, затем `outbox`.
- **Заменить вложение в уже отложенном письме:** `--folder outbox edit --subject "тема" --replace-attach "старый.pdf=C:/новый.pdf" --yes` — снимет с очереди, поправит, вернёт на то же время и подтвердит таблицей.
- **Снять отложку:** `--folder outbox unschedule --subject "тема"` — письмо уйдёт в «Черновики», время сброшено.
- **Что висит в исходящих и уйдёт ли:** `outbox`. «⚠ НЕ поставлено в отправку» = утром не уйдёт.
- **Свободные слоты:** `free 2026-10-06`, занятое — `events --from 2026-10-06 --days 1`; чужой календарь без прав недоступен.

## Проверено на

- Outlook 16, Exchange 2019, кэш-режим, ru-RU, время машины = МСК. Хранилищ в профиле бывает много (сетевые архивы, общие ящики), и часть из них падает при входе — перебирать `Stores` по индексу с try/except (сделано в `accounts`).
- Другая локаль Windows: формат даты для Jet-фильтров календаря (`events`, `invites`) задаётся переменной `OUTLOOK_JET_DATE_FMT` (по умолчанию `%d.%m.%Y %H:%M`).
- В «Отправленных» время отложенного письма = момент нажатия «Отправить», не час отправки.
- Папка Контактов может быть пустой (люди лежат в адресной книге Exchange): искать через `whois`. `Calendar.Restrict` по `ResponseStatus` молча даёт 0 — отбор в Python (`invites`).
- Повторяющиеся встречи: `Sort("[Start]")` до `IncludeRecurrences`, верхняя граница окна обязательна (ряды без конца бесконечны).
