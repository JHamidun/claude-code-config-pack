# Жизненный цикл лида: шаблоны (RU, academy CRM + Your CRM)

Полные шаблоны стадий, MQL-критерии по типам, SLA, коды отклонения, recycling и контент→продукт nurture. Реализация — через academy-CRM `yourname-sales-postgres` (вход/B2C) и `crm` (B2B-сделки).

## Шаблоны стадий

### Подписчик
- **Вход:** подписка на news.your-domain.com / бот @your_news_bot / лид-магнит / TG-канал.
- **Выход:** даёт email, или кликает CTA «Освоить системно → academy», или 3+ визита.
- **Владелец:** Маркетинг (авто). **CRM:** academy `leads`, источник=news/контент.
- **Действия:** в nurture (контент→продукт), старт engagement-скоринга.

### Лид
- **Вход:** контакт с именем + email (форма academy, Sales-AI-агент, заявка на консультацию).
- **Выход:** достиг порога MQL ИЛИ ручная квалификация.
- **Владелец:** Маркетинг. **CRM:** `leads` (stage `new`/`interested`).
- **Действия:** обогатить (для B2B — размер/отрасль/роль через `lead-research`), скоринг, nurture.

### MQL
- **Вход:** fit-порог И engagement-порог, ИЛИ high-intent (заявка на консультацию/воркшоп, регистрация на trial academy, страница workshop/services/pricing + форма).
- **Выход:** продажи приняли (→SQL) / отклонили (recycling с кодом) / нет реакции в SLA (эскалация).
- **Владелец:** Маркетинг → Продажи (основатель/старший сейлз). **CRM:** `leads` stage `qualified`; для горячего enterprise — `handoff_to_user`.
- **Действия:** мгновенный алёрт, бронь zoom (`create_calendar_event` / `zoom`), пауза маркетинг-nurture, лог переписки для контекста.

### SQL
- **Вход:** основатель/старший сейлз провёл квалифицирующую консультацию; подтверждены ≥2 из 4 (бюджет/полномочия/потребность/срок).
- **Выход:** создана B2B-сделка с прогнозной суммой ИЛИ дисквалификация (recycling).
- **Владелец:** Продажи (основатель/старший сейлз). **CRM:** `zoom_meetings` (проведена) + Your CRM (новая сделка, стадия «Квалифицирован»).

### Сделка
- **Вход:** формальная B2B-сделка (воркшоп / B2B-когорта / консалтинг-проект) с суммой, датой закрытия, стадией.
- **Выход:** выиграна / проиграна.
- **Владелец:** основатель/менеджер. **CRM:** Your CRM воронка.

### Клиент
- **Вход:** сделка выиграна (договор) ИЛИ academy-подписка оплачена.
- **Выход:** расширение / продление / отток.
- **Владелец:** Аккаунт/онбординг. **CRM:** Your CRM «Успех» / academy `converted`. Снять с sales-цепочек, запустить онбординг; для academy — удержание (`churn-prevention-ru`).

## MQL по типам

### B2C self-serve academy (free→trial→paid)
Вес engagement выше (продукт-сигналы). Из news-трафика и лид-магнитов.

| Сигнал | Очки |
|---|---|
| Регистрация на trial 7 дней | +20 |
| Прошёл 1+ трек / симулятор с AI-тьютором | +25 |
| Достиг конца trial | +20 |
| Визит на pricing | +15 |
| Скачал лид-магнит (чек-лист инструментов, мини-гайд) | +10 |

Порог: продуктовый сигнал → апселл/пейволл (см. `paywall-cro-ru`), не в B2B sales-воронку. Цель — конверсия trial→paid (Tier1 X / Tier2 Y / Tier3 Z; founding W).

### B2B sales-led (воркшоп / когорта / консалтинг)
Вес fit выше.

**Fit (60%):**

| Атрибут | Очки |
|---|---|
| mid-large компания РФ, внедряет AI | +20 |
| Целевая ситуация (команда не использует AI / есть L&D-бюджет) | +15 |
| Роль ЛПР (HR-дир/рук. L&D/гендир/рук. отдела/директор трансформации) | +20 |
| Подтверждённые полномочия/бюджет на обучение | +15 |

**Engagement (40%):**

| Сигнал | Очки |
|---|---|
| Заявка на бесплатную консультацию/воркшоп | +25 |
| Визит на workshop/services-страницу 2+ раз | +15 |
| Ответ на холодное касание | +15 |
| Скачал материалы/кейс / посетил вебинар | +10 |

**Порог MQL:** ~70. Калибруй по историческим выигранным B2B-сделкам в Your CRM.

## SLA

### MQL→SQL

| Метрика | Цель | Эскалация |
|---|---|---|
| Первый контакт | 4 раб. часа (заявка на консультацию — быстрее) | алёрт ответственному/руководителю при 4ч |
| Решение о квалификации | 48 часов | авто-эскалация при 48ч |
| Консультация назначена (если квалиф.) | 5 раб. дней | флаг на ревью воронки |

### Сделка→Закрытие

| Метрика | Цель | Эскалация |
|---|---|---|
| КП отправлено | 5 раб. дней после презентации воркшопа | алёрт руководителю |
| Сделка застряла в стадии | 2× средних дней стадии | флаг на ревью |
| Дата закрытия перенесена 2+ раз | сразу | ревью прогноза |

## Коды отклонения и recycling

| Код | Причина | Действие |
|---|---|---|
| FIT-01 | компания/команда слишком мала, нет бюджета на обучение | nurture; пере-скор при росте |
| FIT-02 | нерелевантная ситуация / AI не применим | архив |
| FIT-03 | не та роль / нет полномочий по обучению | nurture; мониторить смену оргструктуры |
| ENG-01 | нет ответа после 3 касаний | recycling через 90 дней |
| ENG-02 | интересно, но не сейчас | recycling, вернуться через 60 дней |
| QUAL-01 | нет бюджета на обучение | recycling через 90 дней |
| QUAL-02 | заказали корп-обучение AI у другого на год | recycling, триггер до окончания их контракта |
| QUAL-03 | не реальный проект | архив |

### Recycling-нуртур
- **Частота:** раз в 2 недели / месяц (реже исходного).
- **Контент:** AI-инсайты, кейсы воркшопов, лид-магниты, апдейты academy.
- **Длительность:** 6 месяцев, потом архив при отсутствии реакции.
- **Re-MQL триггер:** high-intent (заявка на консультацию, повторный визит на workshop-страницу, регистрация на trial) → обратно в продажи с флагом «Recycled MQL».
- В CRM: engagement-скор сбрасывается в baseline, fit-скор сохраняется; конверсия recycled-MQL трекается отдельно.

## контент→продукт nurture (главная дыра воронки)

Типовая картина: самый горячий контент-трафик (news-портал, бот, email-дайджест) гонит только на TG-канал и /blog — не в academy/консультацию. Построить мостик:

- **Сквозной CTA** в портале/боте/рассылке: «Освоить системно → 7 дней academy бесплатно» (B2C) / «Бесплатная диагностика AI-зрелости команды» (B2B).
- **Email-sequence** news-подписчик → academy-trial (через `email-sequence`/`html-email`): сегментация по интересу (профи → academy; корп-роль → консультация).
- **Mini-app апселл** — блоки academy/консультации вместо только донатов.
- **Метрика хэндоффа:** контент→продукт-trial конверсия (academy Postgres + `product-analytics`). Часто именно этот мостик — первый источник первых продаж academy.
