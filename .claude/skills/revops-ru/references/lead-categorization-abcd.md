# Категоризация лидов A/B/C/D (RU, курсовая методология продаж)

> Источник: курс по маркетингу и продажам. Категоризация лидов A/B/C/D по матрице **деньги × срочность** — из блока «Стратегия и исследования». Связка «категория лида ↔ категория сейлза» и правило «усиливать сильное» — из блока «Продажи и команда» (эксперт — ex-руководитель ОП [SaaS-стартап]).
>
> **Что это и зачем.** Категоризация лидов — это способ **развести входящий поток по качеству источника**, чтобы (а) распределять лиды по сейлзам не «как придёт», а по правилу «лучшие лиды — лучшим сейлзам», и (б) при провале конверсии понять, кто «виноват» — маркетинг (льёт мусор) или продажи (не дожимают качественные заявки).
>
> **Граница с другими скиллами:** выбор *типа* воронки и дерево метрик ДО CRM — `funnel-design-ru`; ежедневная операционка отдела продаж (планёрки, мотивация, ротация сейлзов) — `sales-team-ru`. Здесь — **lifecycle-механика категоризации лидов В CRM** как часть RevOps: какой лид к какой категории отнести, как это привязать к скорингу и распределению.

## Матрица: деньги × срочность

эксперт предлагает категоризировать лиды по двум осям:

- **Деньги** — платёжеспособность / ценность лида (насколько дорого/прогрето пришёл, готов ли платить).
- **Срочность** — насколько горячая потребность (готов покупать сейчас vs «когда-нибудь»).

Из пересечения этих осей и качества источника получается практическая шкала A/B/C/D.

| Категория | Что это | Типичные источники (по эксперту курса) | Деньги × срочность |
|---|---|---|---|
| **A** | Самые качественные, прогретые, дорогие лиды | Брендовый поиск, контент-воронки, **email-маркетинг**, **SMM**, органика | Высокие деньги + высокая срочность |
| **B** | Средние: тёплые, но менее прогретые | Спецпредложения, **вебинарная воронка** | Средние |
| **C** | Холодные / низкокачественные | Остальные каналы: таргет, холодные базы, широкие топики | Низкие |
| **D** | Мусорные / нерелевантные | Нерелевантная отрасль, микробизнес без бюджета, дубли, случайный трафик | Минимум (часто отсев) |

> **Почему A-лиды дорогие (эксперт курса):** «Email-маркетинг — очень дорогой канал. Вы сначала купили лид, потом прогревали его контентом, платя зарплату копирайтеру, дизайнеру, верстальщику писем. Такие лиды стоят дорого — и должны цениться больше, отдаваться более сильным продавцам».

## Анкета определения категории лида

Чтобы отнести входящий лид к категории, ответь по порядку (первое «да» фиксирует категорию):

1. **Источник = брендовый поиск / контент-воронка / email / SMM / органика?** → **A** (прогрет, дорог, высокая срочность).
2. **Источник = спецпредложение / вебинар?** → **B** (тёплый, средняя срочность).
3. **Это релевантный ICP, но холодный канал** (таргет, холодная база, широкий охват)? → **C**.
4. **Нерелевантная отрасль / микробизнес без бюджета / дубль / явный мусор?** → **D** (отсев или recycling с кодом причины).

Дополнительные модификаторы (двигают на полкатегории):
- **Деньги:** есть бюджет / крупная компания / дорогой продукт в запросе → вверх; нет бюджета → вниз.
- **Срочность:** «нужно сейчас / горит дедлайн / заявка на консультацию» → вверх; «изучаю на будущее» → вниз.

> Для типового бизнеса «контент-воронка → подписка + корп-услуги» (см. `~/.claude/business-context.md`): A = заявки с news.your-domain.com → подписка, брендовый поиск по имени основателя, подписчики прогретой контент-воронки, реакции на персональный email-аутрич; B = регистрации с вебинара/спецоффера; C = холодный таргет, широкие базы; D = нерелевант (студенты без бюджета на корп-воркшоп, дубли). Это **дополняет**, а не заменяет MQL-скоринг из `lifecycle-ru.md` — категория описывает **качество источника**, MQL — **fit + engagement**.

## Связка «категория лида ↔ категория сейлза» (правило «усиливать сильное»)

эксперт категоризирует **и сейлзов**, и **лиды**, и соединяет их:

**Категории сейлзов** (пересматриваются раз в ~2 недели, между категориями есть ротация):
- **A** — верхние 30% по конверсии, топ-перформеры, стабильно бьют план.
- **B** — следующие 30% по конверсии.
- **C** — нижние 40% по конверсии (часть — на испытательном сроке).
- **Новички** — работают в компании < ~месяца.

**Правило распределения** (Сунь Цзы, «Искусство войны» → «усиливать сильное»):

| Категория лида | Кому отдаём |
|---|---|
| **A** (бренд/поиск/email/SMM/органика) | сейлзам категории **A** |
| **B** (спецпредложения/вебинары) | делятся между сейлзами **B** и **C** |
| **C** (остальные каналы: таргет, холодные базы) | сейлзам **C** и **новичкам** |

> **Логика (эксперт курса):** «Сильные лиды — сильным сейлзам. Чем дороже лид (особенно в сложном B2B SaaS), тем критичнее, чтобы качественные заявки попадали к самым сильным продавцам. Слабые сейлзы сначала тренируются на холодных заявках / работе с базой — нельзя испортить дорогую заявку, за которую бизнес заплатил кучу денег и времени людей».

**Реализация в CRM:** правило распределения настраивается прямо в CRM — автор практики собирал его в международной CRM того же класса: автораспределение лидов по категории сейлза + регулярное обновление категорий. Реализация — в самой CRM (автораспределение / назначение ответственного по источнику) для B2B-сделок и в логике приёма заявок для входящего потока. Маппинг процесс→API — `crm-mapping.md`.

## Зачем это RevOps (а не только продажам)

1. **Диагностика «маркетинг vs продажи».** Если A-лиды (дорогие, прогретые) плохо конвертят у A-сейлзов — проблема в продукте/оффере/цене, не в трафике. Если C-лиды не конвертят — это нормально, вопрос к экономике канала. Развести категории = увидеть, где реально течёт воронка.
2. **Защита дорогих лидов.** Без категоризации горячая enterprise-заявка (флаг `handoff_to_user`) может уйти новичку и сгореть. Категория A → лучший сейлз (основатель лично для крупного B2B).
3. **Калибровка скоринга.** Категории A/B/C/D — внешний (по источнику) срез; MQL-скоринг (`lifecycle-ru.md`) — внутренний (fit+engagement). Сверяя их на исторических конверсиях, калибруешь порог MQL.
