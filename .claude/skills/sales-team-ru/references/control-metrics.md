# Контроль эффективности отдела продаж

> Операционка ОП по методологии эксперта по продажам ([SaaS-стартап], $1M+/мес). «Отдел продаж по культуре ближе всего к армии»: построения, нормативы, ротация.

## 1. РОП — руководитель отдела продаж

- Руководитель среднего звена под директором по продажам. **Команда 10–12 сейлзов.**
- Премия РОПа при выполнении плана команды **80–100%**.
- Каждый день все РОПы вносят, **сколько денег внесла их команда** → возникает понимание **run-rate / forecast**. Команды видят результаты друг друга (они конкурентны — это мотивирует копировать лучшие практики: «одна группа делает 1.7М, а соседняя 6.5М — почему? Идёт спрашивать»).

## 2. Система мотивации

### Сейлзы — недельная мотивация (главный буст [SaaS-стартап])

- Месячный план **÷ 4** = недельная квота.
- **Прогрессивная шкала бонуса от выручки:**

| Выполнение квоты | Бонус |
|---|---|
| 80–100% | **3%** |
| 100% | **5%** |
| 110%+ | **9%** |

Большой перекос в сторону перевыполнения мотивирует не «успокаиваться» после плана, а продолжать закрывать.

- **Квоты И выплаты — недельные.** Выплата на карту сразу после закрытия недели (отработал вт→пн, в понедельник закрыл квоту — во вторник деньги на карте). Недельные квоты при месячных выплатах работают плохо.
- **Период вторник→понедельник.** Почему: понедельник = пик дозваниваемости (клиенты берут трубки) и пик активности сейлзов («новая жизнь с понедельника»). **Нельзя завершать период в воскресенье** — конец периода = пик «дожима» и конверсии, лучше отдать его на старт новой недели.
- **Фикс/бонус = 30/70.** Фикс покрывает только базу (жильё+еда), всё сверх (одежда, путешествия, гаджеты) — бонусом.
- **Квоты фиксированы** и не меняются от человека к человеку (иначе чувство несправедливости). Единственное исключение — **понижение в низкий сезон** (в РФ: майские, лето, новогодние; иначе сейлзы долго не выполняют квоту → демотивация → падение конверсии).

### РОП — миксованная мотивация

- Среднее между месячной и недельной. Недельный план; выполнил неделю — получил. Не выполнил — есть **право догнать** в месяце: отстал в нед. 1–2, перевыполнил 3–4, пришёл в месячный таргет → выплачиваются агрегированные бонусы за недели. У РОПа больше стратегических рычагов, поэтому горизонт шире, чем у сейлза (туннельное недельное мышление).

### «Вертолётные деньги»

- РОП в кризисный/критический момент: «Каждый, кто сегодня сделает 5 подач на рассрочку, кидаю $10 на карту / заказываю ужин».
- Хак краткосрочной мотивации (сейлзы живут «здесь и сейчас», долгосрочное планирование у них слабее).
- Бюджет **~$200–300/сейлз/мес** компания закладывает заранее под такие кейсы; РОП выдаёт «со своего счёта».

## 3. Планирование квот — 3 параметра

1. Количество **рабочих дней**.
2. Количество **лидов на сейлза** (от опыта: чем дольше выполняет планы — тем выше квота).
3. Соотношение **новичков vs опытных**. Опытный = прошёл онбординг + отработал ещё ≥1 месяц + выполнил план хотя бы в 50% случаев.

3 вида сейлзов в [SaaS-стартап]: **новички** (<2 мес) / **опытные** (прошли барьер) / **на испытательном** (нижние 20%).

## 4. Категоризация — правило «усиливать сильное»

Правило из го / «Искусства войны»: сильные лиды — сильным сейлзам.

**Сейлзы** делятся по конверсии и стабильности выполнения плана:

| Категория | Доля |
|---|---|
| **A** (топ-перформеры) | верхние **30%** |
| **B** | следующие **30%** |
| **C** (отстающие) | нижние **40%** (часть → испытательный) |
| **Новички** | работают <1 мес |

**Лиды** делятся по «горячести»/стоимости:

| Категория лидов | Источники | Кому |
|---|---|---|
| **A** | бренд, поиск, email, SMM, органика (дорогие, прогретые) | сейлзам **A** |
| **B** | вебинары, спецпредложения | сейлзам **B** (и частью C) |
| **C** | таргет, холодные базы, остальное | сейлзам **C** и новичкам |

- **Обновление каждые 2 недели** — принадлежность к категории не вечная, есть ротация вверх/вниз.
- Чем дороже лид (особенно B2B SaaS) — тем критичнее отдать его сильному (дорогой лид: купили + прогревали контентом + платили копирайтеру/дизайнеру/верстальщику).
- Авто-распределение настраивается в **самой CRM** (правила распределения есть у Битрикс24, amoCRM, HubSpot).

## 5. Дисциплина РОПа (рабочее расписание)

| Ритуал | Как |
|---|---|
| **Планёрка ≥1/день** (30–40 мин) | неформальный ритуал (рубрика «день в истории»), проверка смены (все ли в строю), контроль промежуточных метрик (звонки+минуты), план по выручке на день для каждого, **публичное порицание** не выполнивших норматив («что тебе помешало?») |
| **Прослушка ≥1/день/сейлз** | РОП слушает живые звонки самостоятельно — иначе теряет связь с реальностью |
| **Калибровка** | РОП + сейлз слушают звонок вместе, сейлз рефлексирует (что хорошо/плохо), вместе корректируют |
| **Ролёвка** | имитация продажи: РОП играет клиента, сейлз — себя; групповое обучение |
| **1-1 еженедельно** | состояние человека + **финансовая цель** (на что копит: велосипед, ужин в ресторане, поездка) + трекинг run-rate её достижения |
| **Ежедневные отчёты** | пирамидкой: сейлз → РОП → коммдир → фаундер. План на день / итоги (план/факт, что хорошо/плохо) / **скрин CRM** (минуты+звонки). РОП кидает скрин панели активности + объясняет по отстающим |

## 6. Нормативы и ключевые метрики ОП

### Выработка — 120/120

- **Норматив: 120 минут разговоров + 120 наборов в день.**
- Рассчитывается **от сейлзов с самой высокой конверсией**, раскатывается на слабых.
- Работает на любом рынке (B2B/B2C). Трекать ежедневно.
- **Выработка = ключевая опережающая метрика** (если сейлзы мало продают — смотри выработку).

### Дозваниваемость — вторая ключевая

- **Нижняя граница 40%.**
- Главная причина просадки — сейлз долго перезванивает.
- **SLA = разница между минутой оставления заявки и контактом сейлза.** Трекать по каждому сейлзу и в тотале, по сделкам.
- Жёсткий контроль универсален. Автодозвоны (в США нельзя) нельзя сочетать с распределением конкретных лидов на конкретных менеджеров. Первая линия / авто-квалификация через бот (GPT-4 API) лучше для B2B.

### NPS сейлзов — еженедельно

- Опрос **в Slack** каждую неделю.
- **<3.5/5 = идти к руководителю, искать причину.** «Тухлые» сейлзы с плохим настроением плохо продают.
- Частые причины: **РОП-тиран**, падение процента одобрения рассрочек. NPS — предтеча проблем команды.

### Цикл сделки

- Средний цикл с момента заявки — **очень важная метрика**. Зависел от страны.
- Рост цикла = либо сейлзы хуже отрабатывают, либо упало качество трафика.

### Перелидоз (связка маркетинг↔продажи)

- Миф «чем больше лидов — тем лучше» неверен. **Перелидоз** = лидов больше, чем сейлзы могут обработать качественно → растёт нагрузка, падает среднее время на клиента, падает качество консультации и конверсия. Сейлзы работают «как шредер» («нужен курс? нет, до свидания»).
- [SaaS-стартап] эмпирически: **>12 лидов/день на сейлза → конверсия падает**.
- Лекарство: **планировать закупку лидов от числа сейлзов на линии**. Сейлзы заполняют график на неделю (раз в неделю, в пятницу — кто в какие дни на линии, плавающие выходные). Маркетинг планирует закуп под это. Трекать на **дейликах маркетинг↔продажи**.
- Не давать слишком мало лидов тоже плохо (простаивают мощности).

## 7. Ротация и планирование найма

- Ежемесячно **нижние 20%** по результату → письмо-предупреждение → испытательный срок (пониженная квота, но обязательный таргет за месяц) → если не исправился, прощаемся. Хороший «пинок».
- **Общий отток ~15%** (вкл. тех, кто уходит сам). Данные передавать HR, чтобы нанимали заранее.
- **Средний срок жизни сейлза ~7 месяцев** (работа выгораемая: отказы, низкая значимость).
- Без ротации команда «закисает» и «заражает хворью» остальных.
- **Планируй найм заранее**: цикл найма+нестинг ~1 мес. Частая ошибка — планировать агрессивный рост по выручке, но не планировать рост числа сейлзов (или не закладывать время на их поиск/найм/обучение). Реальный кейс [SaaS-стартап]: открутили ×2 бюджета → ×2 лидов на сейлза → сейлзы утонули → конверсия упала → CAC вырос → окупаемость упала → бизнес потерял деньги.

## 8. Инструменты

### Флипбук (flippingbook, ~$50/мес)

- Журнал-презентация (как комикс), которую сейлз отправляет **после звонка**. Отстройка от скучных PDF конкурентов.
- Главная функция — **отработка заранее собранных возражений**, в т.ч. возражений тех, с кем клиент уходит советоваться (жена/муж/брат/сестра): стоимость, срок обучения, как быстро найду работу. Пример: жена спрашивает «как быстро вернёшь $1000?» → ответ зашит во флипбук.
- Внутри: спикеры, стажировка, количество вакансий, social proof, отзывы, инфо о фаундерах — готовый playbook ответов на фактические вопросы.
- Встроена **тепловая карта** (аналог Яндекс.Метрики): кто докуда долистал, где чаще кликают, что досматривают.
- Материалы шлифуются **фокус-группами** (10–12 человек из ЦА смотрят материалы → обратная связь → апдейт) — убирает субъективизм маркетолога.

### Simplesales (simsales.ru)

- Виджет **панели активности** в CRM: работает / не работает / в системе / на звонках. Контроль активности сейлзов в реальном времени.

### Приоритизация задач в CRM (Workspace)

Сейлз идёт по списку задач, закрывая по очереди — но очередь у него «в голове», легко расфокусироваться. Решение — жёсткий приоритет в Workspace CRM:

```
1. Просроченные задачи
2. Сделки БЕЗ задач      ← запрет работы, пока не закрыты
3. Лиды с вебинаров
4. Новые лиды (в рабочее время)
5. Остальные лиды
```

- **Запрет работы при наличии сделок без задач** (всплывающее окно: «Запрещено работать в системе, если есть сделки без задач»). Сделка без задачи = нарушение договорённости с клиентом = главный грех менеджера.
- CRM настраивается так, что критичные вещи нельзя не сделать: нельзя просрочить задачу, нельзя закрыть взаимодействие без постановки следующей задачи. Убирает человеческий фактор.
- [SaaS-стартап] использовал международную CRM того же класса. Под Битрикс24 то же самое собирается правилами распределения.
