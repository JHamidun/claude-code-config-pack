# Идеи экспериментов для онбординга (RU)

A/B-тесты онбординга и активации на примере подписочного edtech/SaaS-продукта (trial 7 дней, аха-момент = первая сессия ключевой функции). Запуск — `ab-testing-ru`. Метрики (активация, время до ценности, trial→paid, дроп по шагам) — своя веб-аналитика (Метрика/GA) + продуктовая БД; какой счётчик стоит, записано в `~/.claude/business-context.md` → «Учёт и аналитика».

## Упрощение потока

### Снизить трение
| Тест | Гипотеза |
|------|----------|
| Тайминг верификации email | Во время vs после онбординга |
| Пустые состояния vs демо-данные | Пред-заполненный пример результата ключевой функции |
| Готовые треки/пресеты | Ускорить старт (рекомендованный сценарий под цель) |
| Соцавторизация (Яндекс/VK/TG/Google) | Быстрее связать аккаунт |
| Число обязательных шагов | Меньше обязательных |
| Skip-опции | Пропуск некритичных шагов |

### Порядок шагов
| Тест | Гипотеза |
|------|----------|
| Порядок шагов | Разные последовательности |
| Value-first | Самое ценное первым (первая сессия ключевой функции сразу) |
| Тяжёлые шаги позже | Перенести трение (выбор тарифа — в конец trial) |
| Один путь vs ветвление | Единый vs персонализированный (по цели/сценарию) |
| Быстрый старт vs полная настройка | Минимальный путь к первому результату |

### Прогресс и мотивация
| Тест | Гипотеза |
|------|----------|
| Прогресс-бары | Показ % завершения пути |
| Длина чеклиста | 3-5 vs 5-7 пунктов |
| Геймификация | XP/бейджи/награды (если продукт их поддерживает) |
| Старт прогресса | С 20% vs с 0% |
| Моменты-празднования | Отмечать первый завершённый шаг / первую награду |

## Гайды и туры
| Тест | Гипотеза |
|------|----------|
| Интерактивный тур | Сделать (запустить ключевую функцию), а не смотреть |
| Тултип vs модалка | Деликатно vs привлекающе |
| Видео-туториал | Для сложных сценариев |
| Длина тура | Короче vs полный |
| Запуск тура | Авто vs по инициативе |
| CTA-текст/размещение | Action-oriented копия |

## Персонализация
| Тест | Гипотеза |
|------|----------|
| По роли | Разные пути (разработчик/маркетолог/предприниматель) |
| По цели/сценарию | Кастомизация по заявленной цели |
| Сегмент B2C vs B2B-когорта | Разные дефолтные сценарии |
| Персонализированное приветствие | Имя/цель/сценарий |
| Отраслевые примеры | Релевантные кейсы (для B2B-когорт) |
| Подсказка сценария | Рекомендовать сценарий под цель (квиз) |

## Быстрые победы и вовлечение
| Тест | Гипотеза |
|------|----------|
| Первая быстрая победа | «Пройди первый шаг» / «Получи первый результат» |
| Сообщения успеха | После ключевых действий |
| Превью результата | Как выглядит завершённый путь / итоговый артефакт |
| Контекстная помощь | Где нужна пользователю |
| Онбординг-звонок (B2B-когорта) | Куратор для сложных корп-внедрений |
| Доступ к сообществу | Канал/чат сообщества рано |

## Email и мультиканал (по trial 7 дней)
| Тест | Гипотеза |
|------|----------|
| Приветствие от основателя | Личное vs дженерик |
| Триггеры по поведению | По действию/бездействию (не запустил ключевую функцию) |
| Тайминг писем | Сразу vs с задержкой |
| «Осталось N дней trial» | Урезать срок как стимул |
| Тема письма | Оптимизация open rate |
| Видео в письме | Демо ключевой функции |

Вёрстка — `html-email`; логика/отправка — `n8n`. Согласие + отписка по 152-ФЗ.

## Реактивация застрявших
| Тест | Гипотеза |
|------|----------|
| Тайминг письма реактивации | Когда слать (24ч vs 48ч без сессии) |
| Личный контакт (B2B-когорта) | Куратор vs автомат |
| Упрощённый путь | Меньше шагов для вернувшихся |
| Оффер-стимул | Продление trial / founding-цена |
| «Что мешает?» | Выявить блокер |
| «С возвращением» | Признать возврат, продолжить с места |

## Технические и UX
| Тест | Гипотеза |
|------|----------|
| Скорость загрузки | Быстрее = выше completion |
| Прогрессивная загрузка | Воспринимаемая скорость |
| Тач-таргеты / мобайл | Размер и spacing |
| Меньше экранов | Короче на мобайле |
| Тайминг запроса прав | Когда просить разрешения |

## Метрики
- Activation rate (% trial → первая сессия ключевой функции), time to activation.
- Step completion rate, точки дропа по дням trial.
- Return rate, retention D1/D7 внутри trial.
- Trial→paid conversion по когортам/источникам (контент-канал vs прямой).
- Feature adoption (какие функции/сценарии используют).
- Объём обращений в поддержку во время онбординга.
