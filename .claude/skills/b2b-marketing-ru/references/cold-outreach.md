# Cold Outreach — детально

Источник: экспертная лекция «Cold Outreach».

Cold outreach — структурированное персонализированное обращение к человеку, который НЕ знает о
вас, НЕ оставлял заявку, НЕ выражал интерес. Задача — первое касание + перевод в тёплый диалог.
**70-80% людей предпочитают первый контакт сообщением, а не звонком.**

> Этот файл — про **методологию и инфраструктуру** аутрича. Написать конкретное письмо
> определённому ЛПР (research-first + копирайт) — это `draft-outreach`. Список лидов под аутрич
> строит `lead-research`.

## Email vs LinkedIn — синхронно лучше

| Канал | Преимущества | Недостатки |
|-------|--------------|------------|
| **Email** | быстрые ответы, низкая стоимость, высокая масштабируемость (тысячи контактов) | риск спама, перегруженные входящие |
| **LinkedIn** | высокий reply rate, профиль = trust layer, видны связи/опыт/активность | жёсткие лимиты, медленный отклик (многие заходят редко) |

**Лучший результат — при синхронном использовании Email + LinkedIn.**

## Технический стек email (50% провалов — технические)

Без правильной настройки письма уходят в спам, а конверсии падают в разы. Грамотная техническая
настройка — главный фактор доставки в инбокс.

1. **Покупка отдельных доменов** — нельзя использовать основной домен, чтобы не испортить его репутацию.
2. **2-3 почтовых ящика на каждый домен** (rotation под лимиты отправки, не сжечь домен).
3. **Прогрев доменов 2-4 недели** — сервисы имитируют живую активность: письма отправляются, отвечаются, архивируются.
4. **Обязательные DNS-записи:**
   - **SPF** — какие серверы вправе слать от имени домена
   - **DKIM** — криптоподпись письма
   - **DMARC** — политика для писем, не прошедших SPF/DKIM
   - **Custom Tracking Domain** — свой домен для трекинга открытий/кликов (не общий сервисный)

### Сервисы

| Сервис | Роль |
|--------|------|
| **Apollo** | универсал: база контактов + intent-данные + sequence sender |
| **Lemlist** | cold email кампании, прогрев, sequence builder с Liquid Blocks |
| **Instantly** | cold email + прогрев доменов |
| **Zapmail** | прогрев email-доменов (имитация живой активности) |

> Совет эксперта: у всех есть триал — зарегистрируйся в 2-3, протестируй, сравни. И смотри на
> **интеграцию с CRM** (вся дата в одно место, иначе теряется управляемость).

## Liquid Blocks (уникализация писем)

Автоматическая подстановка переменных, чтобы письма были уникальными (защита от спам-фильтров):

- автоматическая подстановка даты
- изменение приветствия в зависимости от времени
- рандомизация текста

Фича email-движков (Lemlist / Apollo / Instantly).

## База лидов от ICP → Tier-сегментация

Исходная точка — ICP (см. `funnel-tofu-mofu-bofu.md`). Что делаем:

1. Определяем параметры идеального клиента.
2. Подбираем лидов по фильтрам: география, роль, размер компании, индустрия.
3. **Делим на сегменты — Tier 1 / Tier 2 / Tier 3.**
4. Обогащаем: новости компании, активность в LinkedIn, новые наймы, технологический стек, intent-сигналы (рост штата / фондинг / смена роли / вакансии).

## 5 блоков холодного письма

### 1. Subject Line — определяет 70% успеха
- коротко и по делу
- без эмодзи
- без слов-триггеров («скидка», «бесплатно»)
- релевантность > длины

### 2. Персонализация — по КОМПАНИИ, а не по человеку
Задача — показать, что письмо не массовое. Лучший формат — **факт о компании, подтверждающий
ресёрч**: количество филиалов, запуск нового направления, партнёрство, данные с сайта/новостей.

> Гиперперсонализация по личным данным часто вызывает **отторжение**. Персонализация ради
> персонализации = ошибка.

### 3. Ценность — ответ на вопрос «что я получу?»
- конкретная
- привязана к реальной боли
- измеримая
- подтверждаемая кейсами

Пример: *«Мы сокращаем операционные затраты сетей из 300+ магазинов на 12-18% за счёт
автоматизации логистики».*

### 4. CTA — ВСЕГДА ОДИН
- конкретный
- чёткий
- без выбора из двух опций

Пример: *«Подходит ли вам короткий звонок на 10 минут в четверг?»*

### 5. P.S. — мощный инструмент увеличения ответов
Пример: *«Если этот вопрос решает ваш коллега, буду признателен, если подскажете, кому
написать».*

### Подпись
Минималистичная, текстовая, без тяжёлых элементов, возможно с 1 полезной ссылкой (кейс / статья).

## Цепочка 4-7 писем

Одного письма почти никогда недостаточно. Стандарт — **4-7 писем**, потому что **60% ответов
приходят после 2-3 письма**.

```
Email #1   — знакомство
+1 день    — напоминание / уточнение
+3 дня     — короткий follow-up с прямым CTA
+4-5 дней  — финальное break-up письмо
```

90% компаний пишут цепочки по 3 письма и останавливаются → удлинить цепочку = простой quick-win.

### Мультиканальная цепочка (выше конверсия)

```
просмотр профиля LinkedIn → коннект → сообщение в LinkedIn → email → звонок
```

Чем больше касаний — тем выше конверсия. Если работает SDR — пушить прозванивать, не закрывать
клиента после 2-3 звонков (если не было прямого отказа).

## Принципы письма

- В письме — про клиента, а не про вас.
- Первое письмо — не продаём, устанавливаем контакт.
- Персонализация → по компании, не по человеку.
- Хороший аутрич невозможно построить без грамотного ICP.
- Тестирование гипотез — обязательная часть работы.
- Длинная цепочка всегда лучше короткой.
- Любопытство и постоянные эксперименты создают рост.
- **Главное — релевантность, а не творчество.**

> Холодный аутрич работает тогда, когда письмо максимально релевантно, демонстрирует ценность,
> показывает понимание клиента и приводит его к одному конкретному действию.
