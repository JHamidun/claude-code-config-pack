# Пресет «эксперт / Магритт-Дали» — сюрреалистичные креативы для рекламы

Авторский метод генерации рекламных креативов **эксперта** (FAQ Traffic, 1+ млрд ₽ в VK/РСЯ). Цель — **пробить баннерную слепоту** через сюрреализм и несочетаемые образы, не нарушая авторских прав (каждая картинка — уникальная генерация).

Заточен под VK Ads, но применим к любым рекламным креативам (Telegram Ads, РСЯ, перформанс-баннеры).

---

## Метод несочетаемых пар (пошагово)

```
1. ChatGPT придумывает НЕСОЧЕТАЕМЫЕ пары/тройки слов
   Пример: «ниндзя + кофе + ракета»

2. Открыть генератор:
   — DALL-E 3 (бесплатный, через VPN из РФ) — КОРРЕКТНО держит русский,
     даёт нужный «характер» сюрреализма (метод заточен под него).
   — ИЛИ Gemini / Nano Banana Pro (без VPN, выше качество) — достойная замена.

3. Промпт по-русски в формате:
   [объект] + [несочетаемое слово/фраза] + «крупным планом»
   + «сюрреалистическое изображение в стиле Рене Магритта / Сальвадора Дали»

4. Сгенерировать несколько вариантов, отобрать лучшие.
```

### Почему работает (цитаты эксперта)

> «Я использую несочетаемые сочетания из двух слов — прошу ChatGPT придумать их. Дальше добавляю: крупным планом, сюрреалистическое изображение в стиле Рене Магритта или Сальвадора Дали. Это даёт нейросети больше фантазии, убирает границы буквального изображения».

> «Даже кривые картинки от нейросетей на некоторых проектах давали очень хорошие результаты за счёт того, что они пробивают баннерную слепоту и привлекают больше внимания. Не отсекайте эту идею сразу».

**Ключевые принципы:**
- Иррациональность привлекает внимание — мозг «спотыкается» на несочетаемом.
- Не нарушает авторские права (уникальная генерация под каждый запуск).
- «Кривизна» допустима, если бренд позволяет — **CTR важнее идеальной картинки**.
- Новизна = весь смысл метода. Не повторяй шаблоны буквально — каждый раз новая несочетаемая пара от ChatGPT.

## Шаблон промпта

```
[объект ниши] + [несочетаемый элемент от ChatGPT], крупным планом,
сюрреалистическое изображение в стиле Рене Магритта / Сальвадора Дали
```

Структура роли художника (опционально, усиливает стиль):

```
Ты сюрреалист в традиции Рене Магритта и Сальвадора Дали.
Изобрази: [объект ниши], [несочетаемый элемент], крупным планом.
Чистая композиция, мягкий свет, символизм, ощущение сна наяву.
```

## DALL-E 3 vs Gemini / Nano Banana (для РФ)

| Генератор | VPN из РФ | Русский в промпте | Заметки |
|-----------|-----------|-------------------|---------|
| **DALL-E 3** | Нужен | Держит корректно | Оригинальный генератор метода эксперта; бесплатный |
| **Gemini 3.1 Flash Image** (Nano Banana 2) | Не нужен | Держит | Выше качество, быстро, 4K — дефолт в этом скилле |
| **Gemini 3 Pro Image** (Nano Banana Pro) | Не нужен | Держит | Максимальное качество, медленнее |

Из РФ без VPN — используй Gemini / nano-banana (см. основной SKILL.md и `nano-banana-pro`). Метод промпта тот же, меняется только движок.
