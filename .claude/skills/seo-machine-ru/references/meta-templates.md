# Шаблонные мета-теги: формула сцепки на сотни страниц

Порог, после которого теги руками не пишут никогда: **20-50 страниц**. Дальше — только шаблоны.
На крупном проекте шаблонов не два-три, а **5-7-10** — по одному на тип страницы.

Роль `meta-creator` (`agents-checklists.md`) и пороги длин (`seo-guidelines-ru.md`) остаются в
силе — они про **штучную** страницу. Здесь механизм для массы.

---

## 1. Разбить страницы по типам

Под каждый тип — свой шаблон title и description:

| Тип страницы | Пример |
|--------------|--------|
| Категория каталога | «Семена томатов» |
| Карточка товара | «Семена томата Бычье сердце» |
| Бренд | «Семена Гавриш» |
| Услуга | «Ремонт камеры iPhone 13» |
| Теговая страница (срез) | «Японские семена томатов» |
| Статья блога | «Когда сажать томаты на рассаду» |

## 2. Сначала H1 — человеческим языком

H1 — динамическая часть, из которой собирается всё остальное. Пишется как говорит человек, а не
как выглядит запрос из Wordstat:

- ✗ «iPhone 13 задняя крышка ремонт»
- ✓ «Ремонт задней крышки iPhone 13»

Англоязычные бренды — латиницей и с большой буквы (`iPhone`, не `айфон`).

## 3. Шаблон = статика + динамика

Динамическая часть подставляется из H1, статическая живёт в отдельных ячейках.

**Title** — чисто техническая зона, **ни единого лишнего слова**:

```
{H1} + " в Москве — цена на " + {H1} + " услуги"
→ «Ремонт камеры iPhone 13 в Москве — цена на ремонт камеры iPhone 13 услуги»
```

**Description** — «2,5 предложения», допускает маркетинг:

1. SEO-предложение с вхождением ключа;
2. маркетинговое — преимущество/оффер;
3. неполное — CTA.

```
{H1} + " в Москве за 24 часа. " + {H1} + " — даём гарантию на качество ремонта и запчастей. Оставляйте заявку"
```

**Правило вхождений: по 2 вхождения ключа и в title, и в description.** Самое частотное — в
начало, дальше расширения по убыванию частотности.

## 4. Реализация формулой

Google Sheets / Excel, функция `СЦЕПИТЬ()` (`CONCATENATE`) или `&`. Статические куски — в
отдельных ячейках с фиксацией через `$`, чтобы не съезжали при протяжке:

```
=СЦЕПИТЬ(B2; $E$1; B2; $E$2)
```
где `B2` — H1 строки, `$E$1` = `" в Москве — цена на "`, `$E$2` = `" услуги"`.

Практично держать один лист на тип страницы: колонки `URL | H1 | Title | Description`, статика
шапкой сверху.

## 5. Обязательная проверка на аномалии

Шаблон механически ломается на локациях и склонениях. Живой пример: страница «Ремонт iPhone
Зеленоград» + шаблон «в Москве» дала **«Ремонт iPhone в Зеленограде в Москве»**.

Прогнать глазами весь столбец и вычистить:

- [ ] задвоенные локации («в Зеленограде в Москве»);
- [ ] неверные падежи после подстановки;
- [ ] дубли слов на стыке статики и динамики;
- [ ] длины: title и description не вылезли за пороги (`seo-guidelines-ru.md`);
- [ ] один и тот же title у разных URL (каннибализация).

Аномалии правятся руками — их обычно единицы процентов от объёма.

## 6. Если нет опыта в тематике

Перед написанием шаблонов посмотреть, **как пишут теги те, кто уже в топе** по этим запросам:
расширение **SEO META in 1 CLICK** показывает title/description/H1 любой страницы. Это же даёт
понимание типовых расширений ниши.

Отдельно: **meta keywords не заполнять** — тег не учитывается, его наличие сигнализирует о старом
или небрежном подходе.
