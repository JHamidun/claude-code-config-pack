# Семантика для рекламы vs SEO: в чём разница

> Источник методологии: эксперт, методология (7 поток), урок «Семантика + Wordstat».
> Wordstat-инструмент один и тот же, операторы идентичны (см. `wordstat-operators.md`), но **цель
> сбора разная** — это меняет, что берём, а что отсекаем.

Операторы Wordstat (`+`, `!`, `" "`, `[ ]`) и сама механика масок → подзапросов одинаковы для
платной рекламы и органики. Различается **что попадает в ядро**.

---

## 1. Главное различие — судьба холодных (информационных) запросов

| | Контекстная реклама (Директ) | SEO (органика) |
|--|------------------------------|----------------|
| **Холодные** («как сделать своими руками», «что такое X») | ❌ **отсекают** — низкая конверсия, бюджет в минус | ✅ **берут** — длинный хвост, TOFU-трафик, материал для AEO |
| **Тёплые** (сравнения, «лучший X») | ✅ берут | ✅ берут — comparison-страницы, MOFU |
| **Горячие** (транзакционные) | ✅ приоритет | ✅ берут — конверсионные/коммерческие страницы |
| **Ключевая метрика отбора** | коммерческость, точность, готовность купить | покрытие интента + охват хвоста |

Реклама работает там, где **спрос уже сформирован** (тёплые + горячие). Платить за информационный
клик, который не дойдёт до покупки, — слив бюджета.

SEO **формирует спрос и собирает хвост**: информационная статья на холодный запрос приводит
TOFU-аудиторию, перелинковывается на коммерческую страницу и становится **источником цитирования
для AI-ответов** (см. `aeo-geo.md`).

---

## 2. Прочие различия сбора

| Параметр | Реклама | SEO |
|----------|---------|-----|
| **Точность формы запроса** | критична — фразовое/точное соответствие, минус-слова, операторы `!`/`" "` экономят бюджет | важна для title/H1/URL, но ядро строится по корням (одна маска = все словоформы) |
| **Глубина хвоста** | ограничена коммерческой целесообразностью (НЧ с 0-3 показов часто не нужны) | максимальная — НЧ-хвост даёт дешёвый трафик и проще ранжируется |
| **Минус-слова** | обязательны (отсечь нецелевые показы) | роли минус-слов нет; вместо этого — разделение интентов по разным страницам |
| **Единица группировки** | группа объявлений = одна маска | пиллар-страница = маска, кластер спутников = подзапросы |
| **Что даёт «чистая» частота `" "`** | оценка ставки/бюджета на точную фразу | оценка, тянет ли пиллар сам, без хвоста |
| **Сезонность** | планирование флайтов и бюджета | планирование графика публикаций (готовить сезонный кластер заранее) |

---

## 3. Практическое правило

Один проход по Wordstat → **два ядра из одного сбора масок**:

1. **Рекламное ядро** — отсечь холодные, оставить тёплые/горячие, добавить минус-слова, проверить
   точную форму операторами. → для Директа.
2. **SEO-ядро** — оставить ВСЁ, включая холодные; разнести по интентам на пиллар + спутники
   (информационные/сравнительные/коммерческие); углубить хвост через правую колонку Wordstat. → сюда.

Маски (базисы) собираются **один раз** (см. `keyword-mapping.md`) — расходятся ядра уже на этапе
отбора и кластеризации.
