# Маски → подзапросы: методология семантического ядра (SEO)

> Семантика и Wordstat: как собрать ядро и разложить запросы по страницам.
> Адаптировано под **органику (SEO)**. Операторы Wordstat — в `wordstat-operators.md`. Различия
> сбора для рекламы и SEO — в `perf-vs-seo-semantics.md`. Эта методология питает фазу `research`
> (роль keyword-mapper в `agents-checklists.md`) и формирует `context/target-keywords.md`.

---

## 1. Базовые понятия

- **Поисковый запрос** — то, что человек вводит в строку поиска.
- **Семантическое ядро (семантика)** — совокупность всех ключевых слов, под которые делается контент.
- **Маска (базис, базовая маска)** — базовое словосочетание из **2-3 слов**, вызывающее показы по
  множеству вложенных запросов. Самая большая «матрёшка». Пример: `пластиковые окна`.
- **Подзапрос (вложенный запрос)** — маска + дополнительные слова. Каждый запрос делится на
  множество других (принцип фрактала/матрёшки). **Чем больше масок — тем шире охват.**

Для SEO: **маска ≈ пиллар-страница**, набор её вложенных подзапросов ≈ кластер спутников.
Связка с фазой `cluster`: маска → пиллар, лучшие подзапросы → 8-12 статей-спутников.

---

## 2. Алгоритм сбора масок

1. **Базовый запрос.** Источники: твой сайт (названия товаров/услуг/тем), сайты конкурентов
   (10-15 сайтов), знания о продукте/теме.
2. **Расширение через части речи** (главный приём). Для каждого слова маски подбери синонимы по
   3 частям речи, которые учитывает Яндекс:
   - **Существительное** → синонимы: машина / автомобиль / авто.
   - **Глагол** → синонимы: аренда / арендовать / прокат / напрокат / снять / нанять.
   - **Прилагательное** → синонимы: свадебный / свадебная / свадебное.
3. **Дополнительные вариации:**
   - **Простые синонимы** — однокоренные с приставками (прокат / напрокат), очевидные замены слова
     (машина / авто). Дают форму того же запроса.
   - **Сложные синонимы** — смысловые замены, не однокоренные: копия / реплика; бизнес-синонимы
     (перчатки ПВХ / строительные перчатки). Расширяют ядро на запросы, которые не вывести
     простым изменением формы.
   - **Транслит** — RU/EN названия брендов и терминов.
   - **Слитное/раздельное написание**, сокращения и аббревиатуры.
4. **Проверить в Wordstat** — что запросы реальные; посмотреть вложенные и правую колонку
   («что ещё искали»); оценить частотность и сезонность (см. `wordstat-operators.md`).
5. **Кластеризовать** по готовности и частотности (ниже).

**Пример (аренда свадебных авто):** из 1 базового запроса → ~10 масок: «аренда свадебных
машин/автомобилей/авто», «арендовать свадебную машину/авто», «прокат свадебных машин/авто»,
«автомобиль на прокат / машина напрокат», «снять свадебную машину / нанять авто на свадьбу».

### Где искать маски (источники расширения)

- Свой сайт.
- Сайты конкурентов (10-15).
- **Правая колонка Wordstat** («похожие запросы»).
- Тематические статьи, **Википедия**, онлайн-словари.
- Транслит, сокращения, аббревиатуры.

---

## 3. Кластеризация: два среза

### По готовности к покупке (тёплость)

| Тип | Суть | Интент | Для SEO |
|-----|------|--------|---------|
| **Холодные** (информационные) | «как сделать своими руками», «что такое X», «X своими руками» | информационный | **берём** — это длинный хвост, TOFU-трафик, материал для AEO и перелинковки на коммерцию |
| **Тёплые** (навигационные) | интерес есть, намерение не явное; сравнения, «лучший X», «X отзывы» | сравнение/выбор | берём — MOFU, comparison-страницы |
| **Горячие** (транзакционные) | явное намерение: «купить + товар», «X цена», «заказать X» | транзакционный | берём — коммерческие/конверсионные страницы |

> ⚠️ **Ключевое отличие от рекламы:** в контекстной рекламе холодные **отсекают** (низкая
> конверсия). В **SEO холодные — ценны**: на них строят информационный хвост, TOFU-воронку и
> цитируемость в AI-ответах. Подробнее — `perf-vs-seo-semantics.md`.

### По частотности

- **ВЧ** (высокочастотные) — много показов. Обычно = пиллар-маски, высокая конкуренция.
- **СЧ** (среднечастотные) — статьи-спутники, реалистично выйти в топ.
- **НЧ** (низкочастотные) — длинный хвост, точные подзапросы.
- Правило: **чем больше слов в запросе — тем он низкочастотнее** (и тем точнее интент).

Стратегия SEO: пиллар под ВЧ-маску, кластер спутников под СЧ/НЧ-подзапросы. НЧ-хвост часто
конвертит лучше и проще ранжируется — не игнорировать.

## 4. Связка с пайплайном

- Маски и подзапросы → `context/target-keywords.md` (по кластерам: пиллар / кластер / лонг-тейл +
  интент + текущие позиции).
- Реальные частоты по каждой фразе → `wordstat-real-recipe.md` (с операторами, см.
  `wordstat-operators.md`).
- Приоритизация собранного ядра → `scripts/opportunity_scorer.py` (поля `volume`, `intent`,
  `competition`, `cluster_size`).
- Карта пиллар + спутники + перелинковка → фаза `cluster` (роль cluster-strategist).
