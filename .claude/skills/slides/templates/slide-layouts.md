# Шпаргалка: композиция слайдов

Архетипы, которые покрывают 90% случаев. Используй комбинацию, не один шаблон на весь дек.

## Statement
Одна большая фраза по центру. Минимум всего остального. Подходит для манифестов, ключевых тезисов, разделителей.

```html
<section class="statement dark">
  <h1>Один тезис.<br/>Большой шрифт.</h1>
</section>
```

## Title + supporting
Заголовок сверху или снизу, 1–3 пункта или одна иллюстрация. Самый частый рабочий шаблон.

## Two-column
Слева тезис, справа доказательство (фото / график / скрин). Хорошо ложится на 16:9.

## Section divider
Контрастный фон (например, тёмный среди светлых), номер раздела крупно. Использовать каждые 4–6 слайдов для ритма.

## Full-bleed image
Изображение на весь канвас. Текст — в углу с полупрозрачной плашкой, чтобы не терялся.

## Data slide
Один график крупно. Один вывод текстом сверху или снизу. Не перегружай 5-ю графиками.

## Quote
Большая цитата, мелкая атрибуция (имя, роль). Кавычки — типографические («», " ").

## Comparison / before-after
Две колонки одинаковой ширины, одинаковой структуры, разный контент. Помогает читать.

## Timeline / steps
Горизонтальная или вертикальная последовательность. Номера крупные, описания короткие.

## Чего избегать

- Маркированных списков длиннее 5 пунктов.
- Заголовка + 4 одинаковых блока с иконками — это слайд-визитка из 2010-х.
- Всё центрировать. Длинный текст по центру нечитаем.
- Один и тот же layout 10 слайдов подряд.
