# Цели в Метрике — автоцели vs JavaScript-события, микро/макро, составная цель

> **Граница навыков:** методологию выбора целей под обучение автостратегии см. в `yandex-direct-pro-ru`.
> ЗДЕСЬ — техническая настройка целей и их создание через API Метрики (навык `yandex`).

## Базовое

- **Цель** — отслеживаемое действие пользователя (заявка, клик, просмотр страницы и т.п.).
- Лимит: **до 200 целей на один счётчик**.
- Типы целей: просмотр страницы, клики (автоцели), JavaScript-события, составные цели.

## Автоцели vs JavaScript-события

| | Автоцели | JavaScript-события |
|---|---|---|
| Точность | Несовершенны: ложные срабатывания (кнопка нажата, но форма не заполнена / показана ошибка → засчитывается) | Минимальная погрешность, надёжный способ |
| Настройка | Без программиста, «из коробки» | ~5 минут программисту (вставить код отслеживания) |
| Для обучения стратегий | Нежелательны (шум в данных) | **Рекомендуется** |

> «Автоцели в Метрике пока несовершенны… Для обучения стратегий лучше использовать
> JavaScript-события — настройка занимает у программиста 5 минут, а погрешность минимальная.» — мнение практиков Директа

**Настройка JS-цели в интерфейсе:** Настройки → Цели → Добавить цель → JavaScript-событие →
указать идентификатор события → проверить тестовой отправкой.

В коде сайта отправка события выглядит так:

```javascript
// COUNTER_ID — номер счётчика, 'form_submit' — идентификатор цели
ym(COUNTER_ID, 'reachGoal', 'form_submit');
```

## Макро- и микроконверсии

- **Макроконверсии** — основные действия бизнеса: продажи, заявки, лиды.
- **Микроконверсии** — сигналы заинтересованности (вовлечённость):
  - **≥ 60 секунд** на сайте,
  - **≥ 90 секунд** на сайте,
  - **скролл ≥ 70%** страницы,
  - просмотр карточек товара,
  - просмотр видео.

**Зачем микроконверсии:** когда макроконверсий мало (например, в B2B 2–3 продажи в месяц),
их недостаточно для обучения автостратегии (нужно ≥ 10 конверсий/неделю). Микроконверсии дают
объём данных для обучения. Но обучать лучше на максимально ценных действиях — поэтому микро
используются как дополнение, а не замена.

> «Микроконверсии нужны, когда у вас недостаточно макроконверсий… В B2B может быть 2–3 продажи
> в месяц, и это слишком мало для обучения.» — мнение практиков Директа

**Связь микро↔макро (корреляция Пирсона):** чтобы понять, какая микроцель реально предсказывает
продажи — выгрузить по неделям/кампаниям пары значений (микро, макро) в Excel и посчитать
корреляцию Пирсона (0–1). Чем ближе к 1, тем сильнее зависимость → эту микроцель можно
использовать для обучения. Корреляция может распадаться при смене настроек — тестировать связки.
(Детальная методика — `yandex-direct-pro-ru/references/strategies-learning.md`.)

## Составная цель (лайфхак)

Объединить несколько способов получения лида в **одну составную цель** (один шаг с условием ИЛИ):

```
Составная цель «Лид» = Отправка формы
                       ИЛИ Прохождение квиза
                       ИЛИ Посещение страницы «Спасибо»
                       ИЛИ Клик по номеру телефона
```

→ Все лиды из разных источников суммируются в одной цели → быстрее набирается объём для обучения
автостратегии (критично, когда отдельных конверсий по каждому каналу мало).

## Создание цели через API Метрики

```python
import requests, os
from dotenv import load_dotenv

load_dotenv(os.path.expanduser("~/.claude/.credentials.master.env"))  # заведи из templates/.credentials.master.env.example
TOKEN      = os.getenv("YANDEX_OAUTH_TOKEN")
COUNTER_ID = os.getenv("YANDEX_METRIKA_COUNTER_ID")
headers    = {"Authorization": f"OAuth {TOKEN}", "Content-Type": "application/json"}

base = f"https://api-metrika.yandex.net/management/v1/counter/{COUNTER_ID}/goals"

# Цель-просмотр страницы «Спасибо» (макроконверсия)
requests.post(base, headers=headers, json={
    "goal": {"name": "Спасибо за заявку", "type": "url",
             "conditions": [{"type": "contain", "url": "/thank-you"}]}
})

# Цель JavaScript-событие (надёжнее автоцелей)
requests.post(base, headers=headers, json={
    "goal": {"name": "Отправка формы", "type": "action",
             "conditions": [{"type": "exact", "url": "form_submit"}]}  # identifier из reachGoal
})

# Микроцель — время на сайте ≥ 90 секунд
requests.post(base, headers=headers, json={
    "goal": {"name": "90 секунд на сайте", "type": "step", "is_retargeting": 1}
})

# Список всех целей
print(requests.get(base, headers=headers).json())
```

**Типы целей в API:** `url` (просмотр URL), `action` (JS-событие / reachGoal),
`number` (число просмотров), `step` (составная — массив `steps` с условиями ИЛИ),
`email`/`phone` (клики по контактам). Поле `is_retargeting: 1` делает цель доступной для
ретаргетинга в Директе.
