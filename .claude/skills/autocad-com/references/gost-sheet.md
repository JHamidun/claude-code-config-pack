# Лист по ГОСТ 21.101 / 2.301 — размеры, снятые с эталонов и реализованные в `sheet.py`

Все числа — мм бумаги. Замер эталона: PNG 2400 px = 420 мм → 5,714 px/мм (A3); А3×3 → 2,694 px/мм.

## Форматы (`FORMATS`)

| Ключ | мм | Подпись под рамкой | Где применяется |
|---|---|---|---|
| A4 | 210×297 портрет | А4 | мелкие чертежи мебели 1:25 |
| A3 | 420×297 | А3 | общие данные, чертежи мебели, короткие развёртки |
| A3P | 297×420 портрет | А3 | спецификации (в эталоне — А3 вертикальный) |
| A2 | 594×420 | А2 | планы квартиры ~13×9 м при 1:60; ведомость монтажа при большом объёме |
| A3x3 | 891×420 | А3х3 | планы крупного объекта (эталон 35×17 м) |
| A4x3…A4x6 | 630/841/1051/1261 × 297 | А4х3… | развёртки по суммарной длине лент |

Формат листа — **свойство листа, выбираемое по содержимому** (`fmt: "auto"` + `choose_fmt(project)`), а не
константа «как в эталоне»: эталонный А3×3 для маленькой квартиры оставляет две трети листа пустыми.

## Рамка и поля

- Внешняя граница — тонкая по краю листа (0,1). Внутренняя рамка 0,6: слева **20**, сверху/справа/снизу **5**.
- Графы левого поля (ГОСТ 21.101, снизу вверх, ширина 7, подписи повёрнуты на −90°): `Инв. № подл.` 25 ·
  `Подп. и дата` 35 · `Взам. инв. №` 25 · блок `Согласовано` 4×15 (если высота позволяет).
- Под нижней линией рамки: `Копировал` левее середины штампа, `Формат А3` у правого края.

## Основная надпись — форма 3, 185×55, правый нижний угол вплотную к рамке

Левый блок 65 мм: колонки **10/10/10/10/15/10**, 11 строк по **5**: 5 строк изменений сверху, строка
заголовков `Изм. | Кол.уч. | Лист | № док. | Подп. | Дата`, ниже 5 строк ролей. Роли — **параметр**
(`meta.roles`): у дизайнеров `Дизайнер`, `Архитектор` без фамилий; у проектировщиков `Разраб.`, `Пров.`,
`Н.контр.` Правый блок 120 мм, строки **15 / 15 / 15 / 10**: обозначение документа (пусто у дизайнера),
объект (адрес, курсив 4,4, по центру), комплект (3,2) + справа `Стадия | Лист | Листов` 15/15/20 (шапка 1,8,
значения 3,2), наименование листа 1–2 строки (2,8 / 2,6+2,4) + ячейка организации 50.

**«Листов» заполняется всегда** из реестра — в эталоне на 59 листах пусто на всех. Адрес и название
комплекта — только из `meta` (`stamp_data()`), никогда аргументом функции листа: в эталоне два листа (p07, p34)
несут адреса чужих объектов — три разных адреса на один альбом.

Отклонение реализации от эталона: в левом блоке формы 3 сквозные только вертикали 20|20|15|10 (Изм+Кол.уч /
Лист+№ док / Подп / Дата), 10-мм делители через строки ролей не проходят (ячейка роли 20 мм);
`scaffold/sheet.py draw_stamp` рисует все шесть вертикалей насквозь — поправить при следующем касании.

Масштаб — только в штампе (`… М 1:60`), в заголовке листа не повторяется. Заголовок листа — сверху по
центру рабочего поля, курсив 5.

## Малый штамп — форма 6, 185×15

На листах «(продолжение)/(окончание)» спецификаций: левый блок те же 6 колонок × 3 строки, справа
обозначение документа и ячейка `Лист` 10 мм.

## Размеры

- Засечки 45° длиной ~2 (`tick`, вес 0,35); размерная линия 0,15 выступает за крайние засечки на 1,5 (все
  `dim_*`); выносные 0,1 доходят до размерной без выступа (исключение `dim_h` при линии ниже объекта —
  выносная удлинена на 1,5); текст **над** линией с зазором 0,7, кегль 2,2–2,4; узкий интервал — текст мельче
  со сдвигом вверх (`dim_chain_h`; `dim_chain_v` этого не делает — модули завели обёртку); вертикальные
  подписи повёрнуты на −90° (читаются снизу вверх).
- Наружные цепочки плана (`plans.draw_outer_dims`): по S и W — разбивка по проёмам на 9 мм от габарита плана
  (`plan_extent` = контур + наружная стена + лоджии) и общий габарит ещё через 7; по N и E — только габарит на
  8 мм от наружной грани стены.
- Габариты помещений: только для прямоугольных — bbox Г-образного режет соседей.
- Ярусы на чертежах мебели: первый 8 мм от контура, следующие через 7; расстояние план→фасад 25–30,
  фасад→разрез 20; в зазорах — размер ширины и стрелка «Вид А».

## Текст

Всё — чертёжный **курсив** (ГОСТ 2.304 тип Б наклонный); шапки таблиц прямые. Кегли (высота прописных, мм):
заголовок листа 5; заголовок изделия 3,5; заголовки таблиц 3–3,5; тело таблиц/примечания 2,3–2,5;
размеры 2,2–2,4; выноски 2,3; штамп: адрес 4,4, комплект 3,2, лист 2,8. Числа — десятичная **запятая**, один
форматтер на альбом (`util.fmt_num`); отметка `0.000` — с точкой (эталон и ГОСТ). Веса линий по замеру эталона
(furniture.md §24): контур стен 0,4–0,5; корпус/фасад 0,35; полки/членение 0,25; размерные, выносные,
штриховка, пунктир ≈ 0,18; метка разреза 0,7; красная ручка 1,0. В `sheet.py` реализовано тоньше:
размерная 0,15, выносная 0,1, штриховка 0,12, линия по умолчанию 0,18.

Каждый номер ГОСТ в примечаниях сверять с названием стандарта: в энергетическом альбоме «ГОСТ 21.605» оказался
тепловыми сетями, а не электрикой. Для листов ЭС набор такой: ГОСТ 2.702 / Р 21.101 / 21.613 (однолинейная
схема), УГО по ГОСТ 2.72x, спецификация по ГОСТ 21.110.

## Цветовой словарь альбома интерьера (`COLOR`)

серый + штриховка 45° — существующее; **синий** — всё новое (ГСП, размеры к ним, розетки, выключатели);
**оранжевый** — кирпич/пеноблок заделок; **красный** — стояки, демонтаж, шторы (волна), скрытый плинтус,
зоны тёплого пола, светотехника, выводы кабеля, потолочные указания; **зелёный** — остекление лоджий;
**cyan** — сантехника и стекло; magenta — не расшифровано в эталоне; бежевый/коричневый — типы потолка.
Штриховка фасадов мебели 45° шагом 2 (шпон `#C6BCB0`, стекло `#E4E4E4`, эмаль `#ECECEC`), заливка плана
`#E3E3E3`, красный ручек `#8A1C20`, метка разреза `#535353`.

## Таблицы (`draw_table`)

`draw_table(sh, x, y, widths, rows, header, row_h, max_y)` → при `max_y` возвращает `(y, rest)` для разбивки
на листы. Строки-группы `{"span": "1. Прихожая:", "align": "start"}`; ячейки-словари с `align/bold/underline/
color/size`; многострочные шапки списком.

Шесть примитивов, которых холсту не хватило и которые четыре воркера изобрели по отдельности (поднять в
`sheet.py` одним рефакторингом с попарной сверкой PNG): таблица с переменной высотой строк и переносом по
ширине колонки (три копии: `tables._paginate/_draw_rows`, `elevations.draw_finishes_table`,
`plans._legend_table`); горизонтальные метки разреза и стрелка «Вид А» (`furniture._cut_marks/_view_arrow`);
`dim_chain_v` с уменьшением кегля на узких интервалах (`furniture._chain_v`); выноски ярусами с полкой влево/вправо
(`elevations.Band._draw_leaders`); отметка уровня (`elevations._level_mark`); сетка плитки в мировых
координатах с клиппингом по полигону через `sheet._hatch_lines`.

Выбор формата и отрисовка обязаны идти через **одну** чистую функцию компоновки (`tables._montage_layout()`
зовут и `choose_fmt`, и `draw`): иначе выбор скажет «влезает», а рисунок вылезет. Вместимость первой
страницы (полный штамп + примечания) меньше, чем у продолжений (малый штамп) — считать обе.

## Экспликация / легенда / примечания — правая колонка плана

Ширина колонки = ширина штампа 185. Порядок сверху вниз: экспликация (Номер | Наименование | Площадь, м²,
строка «Общая площадь» жирным) → легенда «образец — тире — текст» или таблица `Усл.обознач | Наименование |
Кол-во` (количества считать — в эталоне пусто) → ведомость (полов/потолков) → примечания нумерованным
списком с переносом (`wrap_text`, ~80–90 знаков при 2,2–2,3). Не заезжать на штамп: `stamp_box(sh)`.
