# Talking-head + AI b-roll overlay reel (creator base, AI on top)

Жанр, которого нет в основном пайплайне video-generation (там — full-AI b-roll).
Здесь **блогер = ОСНОВА**: его снятое видео + его СИНХРОННЫЙ родной звук — фундамент,
а сгенерённые AI-клипы (Veo / Seedance) накладываются **ПОВЕРХ** окнами (иллюстрируют речь,
прячут джамп-каты дублей). Заработано на 2 рилсах для клиента-блогера (2026-06).

> **Главный принцип (ошибка стоила переделки):** «убрать паузы / смонтировать» из брифа на
> рилс = jump-cut видео+аудио ВМЕСТЕ, синхрон губ цел; **звук берётся ИЗ видео, не кроится
> отдельной дорожкой**. Блогер — база, AI иллюстрирует поверх, а не наоборот.

Скрипты: `scripts/talking-head/` (шаблоны; рабочая папка = `$REEL_DIR` или cwd, исходные MOV = `$REEL_SRC`).

## Пайплайн (8 шагов)

```
исходные MOV (много грязных дублей)
  1. gemini_select_takes.py  — Gemini ОТБИРАЕТ лучший чистый дубль под каждую строку скрипта
  2. build_from_selection.py — snap границ к тишине → нарезка чистой основы (видео+звук вместе)
  3. deepgram_transcribe.py  — ВЕРИФИКАЦИЯ + word-тайминги субтитров (Nova-3, НЕ Whisper!)
     verbatim_audit.py       — добор скрытых повторов (то, что ASR схлопывает)
     trim_glitches.py        — хирургический рез найденных дублей/фрагментов (+ afade на стыках)
  4. gemini_plan.py          — Gemini: пошаговый монтаж-план (face vs broll сегменты по смыслу)
  5. (video-generation)      — генерация b-roll клипов под план (Veo 3.1 Fast / Seedance)
  6. author_from_plan.py     — раскладка: какой клип в каком b-roll-окне, fx/переходы, SFX
  7. make_captions.py        — караоке word-pop ASS (динамический кегль — не вылезает за экран)
  8. assemble_overlay.py     — основа + b-roll ПОВЕРХ окнами + микс (музыка под голос) + грейд + концовка
```

## Шаг 1 — отбор лучших дублей (Gemini, не Whisper-глитч-детект)

Исходник = блогер переснимает каждую фразу по N раз с запинками/болтовнёй. Надо ОТОБРАТЬ
один чистый дубль на каждую строку скрипта. **Gemini силён в ОТБОРЕ** (семантика), но
**галлюцинирует в поиске глитчей** по тайм-кодам — не проси «найди ляпы», проси «выбери лучший дубль».

- `script_rX.json`: `{"raw":"IMG_5785","lines":["строка 1", "строка 2", ...]}`
- **Прокси для Gemini:** сырой MOV часто >2ГБ → `413 Media too large`. Сжать: `ffmpeg -i raw.MOV -vf scale=-2:360,fps=15 -crf 30 -c:a aac -b:a 96k proxy.mp4` (9-12МБ, тайминг 1:1). Селектор сам берёт `build/proxy_<num>.mp4`.
- Гоча: иногда даёт абсурдный диапазон (43с на фразу 3с) — клампить max-длину / чинить вручную.

## Шаг 2 — нарезка с подгонкой к тишине

`build_from_selection.py`: границы Gemini ±0.3-0.5с → `silencedetect=-30dB:0.18` подгоняет
start = конец тишины перед фразой, end = начало тишины после. Режет видео+аудио ВМЕСТЕ
(синхрон) + 18-20ms `afade` на краях (убивает щелчки на стыках).

## Шаг 3 — ВЕРИФИКАЦИЯ (без неё нельзя — главный урок)

**WhisperX СХЛОПЫВАЕТ повторы.** Если в звуке «Далее я бы предлож… Далее я бы предложил»
или «А те кто не придут, А те кто не придут» — Whisper пишет ОДИН раз. Транскрипт-проверка
говорит «чисто», а дубль ОСТАЁТСЯ в звуке. Я не слушаю медиа ушами → это слепое пятно,
заказчик ловил их на слух («далее далее 2 раза», «ты сам-то смотрел?»).

- **Deepgram Nova-3 НЕ схлопывает** — `deepgram_transcribe.py` (POST `api.deepgram.com/v1/listen?model=nova-3&language=ru&smart_format=true&punctuate=true`). Гоча: на полном длинном файле дропает первые ~15с (VAD) → транскрибировать ЧАНКАМИ по 30с + dedup на швах + ретрай на 408.
- **Gemini verbatim на коротких клипах** (`verbatim_audit.py` чанками 14с, промпт «дословно, повторы сохраняй, не схлопывай») — тоже ловит. Для точной локализации: `whisperx` НА КОРОТКОМ клипе разносит слова лучше (показывает гэп между двумя «Далее»).
- Найденные дубли → `trim_glitches.py` (диапазоны на таймлайне основы, режет + afade). После — повторить транскрипцию, пока текст не читается чисто end-to-end.

## Шаг 4 — монтаж-план (Gemini)

`gemini_plan.py` на ЧИСТОЙ основе → JSON сегментов встык от 0 до конца, каждый `face`
(показываем блогера) или `broll` (AI поверх) + topic. Принцип: лицо на хуке / эмоц-акцентах /
финальной шутке (вовлекает), b-roll на конкретных описаниях, новый клип каждые 2-2.5с.
Покрытие ~55-65% b-roll, остальное — лицо (блогер = база, AI бёрстами).

## Шаг 6-8 — раскладка, субтитры, композ

- `author_from_plan.py` — маппит b-roll сегменты плана на конкретные клипы (ручной список по смыслу), варьирует fx (in/out/left/right), переходы (cut/flash/zoom), SFX только на крупных входах.
- `assemble_overlay.py` — главный движок:
  - основа + gap (freeze последнего кадра) + концовка → full base (видео+голос блогера)
  - b-roll-оверлеи: `[i:v]setpts=PTS-STARTPTS+{t0}/TB` + `overlay=enable='between(t,t0,t1)':eof_action=pass` (b-roll играет ПОВЕРХ в своём окне, голос блогера снизу непрерывно)
  - **punch на b-roll — `zoompan d=1`, НЕ d=N** (d=N замораживает видео в фото! см. montage-toolkit гоча)
  - грейд (см. color-grading: спад светов для яркого уличного футажа) + субтитры
  - аудио: голос блогера (vol ~1.2) + музыка-бед под голос (gain ~0.26 + sidechaincompress ratio 5) + SFX тихо (×0.3) + loudnorm
- Концовка-CTA: реальный футаж блогера со СВОИМ звуком, замуксить аудио в видео (`-map 0:v -map 1:a`) ПЕРЕД конкатом — иначе concat дропнет звук немого ending.

## Микс (заработанные значения, заказчик подтвердил)

| Параметр | Значение | Заметка |
|---|---|---|
| Голос | `volume=1.25` | блогер всегда ВЫШЕ музыки |
| Музыка-бед | `volume=0.15` | заказчик ДВАЖДЫ: «музыка громче меня». 0.42→0.26 не хватило → **0.15** |
| Дакинг | `sidechaincompress=threshold=0.05:ratio=7:attack=25:release=320` | музыка глубоко проседает под речь |
| SFX | `×0.3` от 0.7-0.9 | «эффекты громкие» → тихо |
| Грейд | `curves=all='0/0 0.5/0.40 1/0.72',eq=brightness=-0.09:gamma=0.95` ДО LUT | заказчик ДВАЖДЫ: «картинка супер светлая». Мягкий 0.86/-0.04 не хватило → жёсткий 0.72/-0.09 |
| Финал | `loudnorm=I=-14:TP=-1.5:LRA=11` | соц-стандарт |

> **Урок калибровки:** клиент воспринимает правки СЛАБЕЕ, чем кажется в цифрах. Если жалоба
> «слишком X» — двигай параметр СРАЗУ заметно (музыку в ~2 раза, света на 25-30%), не на 10-15%.
> Иначе вернётся «как будто также осталось».

> **⚠️ loudnorm ПОСЛЕ микса поднимает музыку в паузах без голоса.** Финальный `loudnorm` нормализует
> громкость по всему файлу → тихие участки (gap-фриз перед CTA, интро без речи) ПОДТЯГИВАЮТСЯ вверх,
> и музыка там звучит громче, чем задумано (gap-музыка ≈ уровень речевого микса). Лечение: либо
> держать паузы без речи короткими (≤0.4с), либо **нормировать ГОЛОСОВУЮ шину ДО микса** (loudnorm
> только на VO → потом подмешать музыку фикс-гейном → финальный лимитер вместо loudnorm-на-микс).
> Проверка: `scripts/talking-head/audio_balance_check.py FINAL.mp4 --gap <music-only-ts>`.

## Cheat-sheet правок клиента (жалоба → какую крутилку повернуть)

Самые частые ревизии и точные параметры (всё в `assemble_overlay.py` / `cfg_*.json`). **Двигай заметно.**

| Жалоба клиента | Крутилка | Куда |
|---|---|---|
| «картинка светлая / я сияю / не такой белой» | `curves all` highlight 0.86→0.78→0.72, `brightness` −0.04→−0.09 | grade в assemble_overlay |
| «слишком тёмная / мрачная» | highlight обратно к 0.85+, `brightness` к 0; убрать `gamma` | grade |
| «музыка громче меня» | `music_gain` 0.26→0.15→0.10; дакинг `ratio` 5→7 | cfg + assemble audio |
| «музыки совсем не слышно» | `music_gain` к 0.22-0.28; `ratio` к 4 | cfg + assemble audio |
| «эффекты громкие» | `sfx_gain` ×0.3→×0.2 или убрать часть SFX | cfg.sfx_gain / author |
| «длинно / затянуто» | вырезать слабые take’и (короче скрипт) → re-cut основы | takes_sel / build_from_selection |
| «мало/много меня в кадре» | в `author_from_plan`/плане сдвинуть долю face↔broll | plan + author |
| «врезка не по смыслу» | поправить маппинг клип→сегмент в `author_from_plan` | author_from_plan |
| «субтитры мелкие/крупные/за краем» | `SIZE`/`MARGIN`/`GLYPH` в `make_captions.py` | make_captions |
| «дёргано / стыки видны» | мягче переходы (`flash`/`zoom`→`cut`), длиннее окна b-roll | plan/author |

После любой правки: `qa_contact_sheet.py` (визуал целиком) + `grade_preview.py` (экспозиция) +
`audio_balance_check.py` (баланс) — проверить ДО отправки, не на глаз.

## QA-хелперы (проверять каждую итерацию)

| Скрипт | Что |
|---|---|
| `grade_preview.py VIDEO --t <bright-ts>` | 4 варианта грейда (RAW/0.86/0.78/0.72) бок-о-бок на ярком кадре — выбрать силу за один взгляд |

## Транскрипция: Deepgram Nova-3 > WhisperX (прямое указание заказчика)

Для ДЕТЕКЦИИ повторов и финальных субтитров — Deepgram. WhisperX оставляем только для
ЛОКАЛИЗАЦИИ на коротких клипах (разносит близкие слова по времени) и как офлайн-фолбэк.
`DEEPGRAM_API_KEY` в `~/.claude/.credentials.master.env`.
