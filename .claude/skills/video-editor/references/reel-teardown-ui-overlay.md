# Разбор рилса — промо с соц-UI оверлеями (раскадровка + монтаж)

**Источник:** публичный промо-рилс из Instagram (ссылка не приводится).
**Тех. параметры:** 1080×1920 (9:16), 25 fps, 27.3 сек, VP9 video / AAC stereo 44.1 kHz, ~692 kbps, 2.0 МБ.
**Жанр монтажа:** промо продукта/приложения — **motion-graphics + композитные «соц-UI» оверлеи поверх реального b-roll** (НЕ rapid beat-cut). Это «UGC-фейк-скриншот» стиль: видео притворяется лентой Instagram/перепиской Telegram.

## Какие монтажные приёмы здесь работают (что стоит уметь)

1. **Композитный «соц-UI» оверлей** — хром Instagram (юзернейм-пилюля, лайк-сердце с pop-анимацией, ✕, прогресс-бары сторис, кнопки) и бабблы Telegram поверх реального футажа. Главный приём ролика, создаёт «нативность».
2. **Kinetic UI / app-mockup** — skeleton-loaders, slide-in карточек, card-stack (stagger), формы — анимированный интерфейс как графика.
3. **Scale-into-rounded-card переход** — футаж ужимается/наклоняется в floating-карточку. Мост между «реальным» и «интерфейсом». Подпись стиля.
4. **Whip / zoom-blur + white-flash** — быстрый motion-blur переход между планами.
5. **Overlay-persistent cut** — постоянный UI-слой, под ним меняется футаж (дешёвый, но связный приём).
6. **Pop-анимации элементов** — сердца, ценники, CTA, бабблы влетают scale+fade с лёгким overshoot (ease-out-back).
7. **Loose beat-sync** — крупные переходы на музыкальных свеллах.

> Ролик по исполнению средний — переходы простоваты, тайминг местами рваный, графика «шаблонная». Но набор приёмов — ровно то, чего обычно не хватает в автоматическом монтаже: **композит UI-оверлеев, kinetic-графика, card-переходы, pop-элементы**. Всё это кодируется (ffmpeg overlay + Remotion/Motion Canvas).

## Как собрать такие же артефакты у себя

Разбор ниже опирается на набор файлов, который делается из ролика в две команды.
Складывай их в рабочий каталог рядом с проектом (`./work/montage/reel/`):

```bash
mkdir -p ./work/montage/reel/frames
# 1. кадры раз в полсекунды — по ним видно, где режут и чем переходят
ffmpeg -i ./work/montage/reel/reel.mp4 -vf fps=2 ./work/montage/reel/frames/%03d.png

# 2. контактки с таймкодами: сетка 4x4 на лист.
#    drawtext и tile — ОДИН -vf через запятую: два флага -vf ffmpeg не складывает,
#    второй молча затирает первый, и таймкоды пропадают.
ffmpeg -i ./work/montage/reel/reel.mp4 \
  -vf "fps=2,drawtext=fontfile=/Windows/Fonts/arial.ttf:text='%{pts\\:hms}':\
x=6:y=6:fontsize=18:fontcolor=white:box=1:boxcolor=black@0.6,tile=4x4" \
  -vsync 0 ./work/montage/reel/sheet_%d.png
```

`fontfile` — путь к любому TTF на машине: на Windows подойдёт указанный,
на macOS `/System/Library/Fonts/Supplemental/Arial.ttf`,
на Linux `/usr/share/fonts/truetype/dejavu/DejaVuSans.ttf`.

Дальше — покадровые вырезки вокруг каждого стыка (`tr/`), по ним и читаются переходы.
