## SHORT #1 — `0hZpUn6ctbo` (2832v) ⭐ TOP

### ❌ Текущее
- **Title:** «Двадцатилетний студент создал ИИ-предсказатель за 10 дней и привлёк $4 млн»
  *(76 chars — слишком длинный для Shorts; описательный, не curiosity gap)*
- **Hook:** «Китайский студент за 10 дней разработал…» — slow build, expository
- **Длина:** 48 сек *(растянуто, нужно 25-35)*
- **Like rate:** 2.0% — best на канале, но всё ещё ниже 4% benchmark

### ✅ Re-script (target 30 сек)

**TITLE:** `20-летний студент → $4M за 10 дней (Китай)`  
*(38 chars — Number + Outcome + Context, declarative)*

**HOOK [0–3s]** — Mid-Action Open + visual pattern break  
> 🔊 «…и через 10 дней у него на счёте было четыре миллиона долларов»  
> 🎬 Visual: счёт банка с цифрой $4M zoom-in, no faces  
> 📝 On-screen: «20 ЛЕТ. 10 ДНЕЙ. $4 000 000»

**SETUP [3–8s]** — context tease  
> «Это китайский студент. ИИ-движок, который он написал, за неделю обогнал GitHub trending»

**REVEAL #1 [8–15s]** — pattern interrupt (смена темпа)  
> «Что он сделал — построил симулятор параллельных миров. Один промпт — сотня сценариев будущего»  
> 🎬 Smash cut: интерфейс → counter views → инвестор signing

**REVEAL #2 [15–22s]** — concrete payoff  
> «За первые 7 дней — 30 миллионов юаней инвестиций. Без MBA. Без demo day. Просто GitHub repo»

**SOFT CTA [22–25s]** — save-focused, ≤5 sec  
> «Сохрани — следующий $4M-проект, может быть, твой»

**LOOP SETUP [25–28s]**  
> «И именно поэтому через 10 дней у него на счёте было…»

**ABRUPT END [28–30s]** — hard cut на середине слова  
> «…четыре миллиона долла-» [HARD CUT]  
> Финальный фрейм = первый фрейм (счёт $4M zoom-in)

## 📊 Сводка изменений

| Параметр | Было | Стало |
|---|---|---|
| Длина | 23-51 сек | **25-30 сек** |
| Hook formula | Exposition | Mid-Action / Contradiction / Threat / Curiosity Gap |
| CTA | «подписывайтесь на ТГ» | Soft (save / tag / comment) ≤5 сек |
| Loop | Нет | Конец = начало (audio + visual match) |
| Abrupt end | Fade + outro | Hard cut на середине слова |
| Pattern interrupts | 0-1 | 2-3 (smash cut + смена темпа) |
| Title length | 50-76 chars | **28-38 chars** |
| Title formula | Description | Threat / Number+Outcome / Curiosity / Contradiction |

## 📝 Чек-лист для каждого нового shorts

- [ ] Hook 0-3s = visual interrupt + verbal promise (одна из 7 формул)
- [ ] Title <40 chars, declarative, без вопроса
- [ ] Длина 25-35 сек
- [ ] 2-3 pattern interrupts (смена темпа/локации/голоса)
- [ ] Smash cuts каждые 1-2 сек
- [ ] Loop: финал = начало (audio + visual match)
- [ ] Abrupt end на середине слова, hard cut, без fade
- [ ] CTA ≤5 сек, ОДИН ask (save/tag/share)
- [ ] On-screen text ≥60pt, контраст ≥7:1, верхняя 1/3
- [ ] Trending sound адаптирован под нишу
- [ ] Никаких «Привет, друзья» / «Сегодня поговорим»
- [ ] Никаких outro-карт / fade-out
