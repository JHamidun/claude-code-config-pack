# Lead Research (RU)

Построение **нового** списка лидов из ICP под российский рынок и его квалификация: от определения идеального клиента до отскоренного шортлиста, готового к передаче в касания. Оффер по умолчанию — **AI-воркшоп / AI-консалтинг / B2B-когорта ExampleProduct** компаниям, которые внедряют AI и имеют бюджет на обучение команды.

Скилл — **оркестратор**: сам он не переизобретает коннекторы, а зовёт готовые скиллы (фирмографика, ЛПР, сигналы, CRM). Тяжёлую логику держат три reference-файла — читай их по ходу.

## When to Use

- «найди клиентов / компании под оффер», «собери список лидов», «prospect research»
- Определить или уточнить ICP и отобрать под него компании
- Квалифицировать и отскорить кандидатов (Hot/Warm/Cold/Skip)
- Account research перед касанием

**НЕ используй здесь:**
- Обогатить **уже существующий** список/фрагмент (email/телефон/ИНН) → `lead-enrichment`
- Написать текст касания → `draft-outreach`
- Досье на уже известный handle → `social-intel`
- Учёт/операции в CRM → `revops-ru` (+ API твоей CRM)

## Границы честности (важно)

- Прямого API у Контур.Фокус / СПАРК / Rusprofile тут **нет** — это ручной web-research (WebFetch/WebSearch) или делегирование в `lead-enrichment` (там есть Checko/DaData/ЕГРЮЛ по ИНН).
- Никаких Clearbit/ZoomInfo/Apollo/Crunchbase — они западные и в стеке владельца недоступны. Их RU-замены — в `references/ru-data-sources.md`.
- Если данных по компании нет или они противоречивы — помечай уровнем уверенности (High/Medium/Low), **не выдавай догадку за факт**.

## Reference-файлы (читать по ходу)

| Файл | Когда |
|---|---|
| `references/ru-data-sources.md` | Карта RU-источников фирмографики/ЛПР/сигналов и какой скилл их исполняет |
| `references/qualification-ru.md` | 5-фазный фреймворк квалификации + RU-модель скоринга + 152-ФЗ |
| `references/pain-signal-prospecting.md` | **Signal-first режим** для запуска нового оффера / первых клиентов / design-партнёров, когда ICP ещё не доказан |

Перед стартом прочитай контекст оффера из своего навыка-контекста (ICP, персоны, что продаём, handoff/CRM) — в паке он не поставляется; заведи собственный и держи это там, а не в голове.

## Два режима

Выбери подход под задачу (детали в reference-файлах):

- **Top-down (фирмографический)** — есть проверенный ICP → фильтруешь компании по фирмографике → ищешь сигнал «почему сейчас». Массовый B2B-список зрелого оффера. → `references/qualification-ru.md`
- **Signal-first (bottom-up)** — есть оффер, ICP ещё гипотеза → ищешь людей/компании, публично выразивших боль → квалифицируешь по цитируемому сигналу. Запуск нового оффера, первые клиенты, design-партнёры. → `references/pain-signal-prospecting.md`

Можно комбинировать: signal-first ловит «горящих», top-down добирает look-alike.

## Процедура (top-down, по умолчанию)

1. **ICP** — из твоего навыка-контекста, если завёл; иначе собери шаблоном ниже. Вывод: ICP одним абзацем + чеклист pass/fail. Без ICP в discovery не идти.
2. **Discovery (кандидаты)** — собери 2–3× от нужного объёма (квалификация отсеет). Источники и исполняющие скиллы — `references/ru-data-sources.md`. Быстрый бесплатный стек: ЕГРЮЛ + Rusprofile (web) + сайт компании + вакансии на hh.ru (руками или через API — готового навыка в паке нет) + `linkedin`.
3. **Фирмографика по ИНН** — где нужны выручка/численность/статус, делегируй в `lead-enrichment` (Checko/DaData/ЕГРЮЛ). Оцени размер команды и L&D-бюджет.
4. **ЛПР (decision-maker mapping)** — HR-директор / рук. L&D / гендир / рук. функции / директор трансформации: `linkedin`, `social-intel`, вакансии на hh.ru, раздел «Команда/Карьера» на сайте.
5. **Сигнал «почему сейчас»** — вакансии «опыт работы с нейросетями» + L&D-роли (hh.ru), новости про AI/трансформацию/нового CDO (WebSearch, `last30days`, CNews/TAdviser), тендеры на AI-внедрение/обучение как сигнал бюджета (`tender-search-ru`).
6. **Квалификация и скоринг** — по `references/qualification-ru.md`: чеклист ICP + доказательство (URL) на каждый пункт, уровень уверенности, грейд Hot/Warm/Cold/Skip.
7. **Handoff** — шортлист → `draft-outreach` (касания) + учёт с lineage (источник+дата) в твоей CRM / academy-CRM `yourname-sales-postgres`.

## ICP Definition Template

```markdown
# Идеальный клиент (ICP)

## Компания
- Отрасль/сегмент: [ритейл / финансы / промышленность / услуги …]
- Размер: [численность 100+ / выручка]
- География: [РФ, регион]
- Форма: [юрлицо РФ, ИНН]
- Зрелость к AI: [есть цифровая трансформация / корп-университет / L&D-функция]

## ЛПР (buyer persona)
- Роль: [HR-директор / рук. L&D / гендир-владелец / рук. функции / директор трансформации]
- Что важно ЛПР: [скорость внедрения / измеримый ROI обучения / …]

## Боли
1. [команда не умеет в промпты / AI-инструменты]
2. [ручные процессы, которые закрывает автоматизация]
3. [давление внедрять AI сверху без экспертизы]

## Триггеры «почему сейчас»
- Вакансии с требованием AI-навыков (за 30–90 дней)
- Новый CDO / директор по цифровой трансформации
- Публичное заявление / тендер про AI / расширение L&D-бюджета

## Дисквалификаторы
- Микробизнес без бюджета на обучение
- Корп AI-обучение уже закуплено на год вперёд
- AI не релевантен бизнесу
```

## Модель скоринга

Каноничная RU-модель (вес 100, MQL-порог ≥60) — в `references/qualification-ru.md`. Ключевые измерения: отрасль/сегмент (15), размер компании (20), сигнал «почему сейчас» (25), роль ЛПР (20), L&D-зрелость/бюджет (5), контакт верифицирован (15). Грейд: A ≥80, B ≥60, C ≥40, D <40; в `draft-outreach` — от B и выше.

> Скорь вручную по чеклисту с доказательством (URL) на каждый пункт — это надёжнее, чем формула по неполным данным. Не проставляй балл, если под ним нет источника.

## Output

- **По умолчанию** — markdown-таблица: `Компания | ИНН | Размер | ЛПР (роль/имя) | Контакт | Сигнал (+дата/URL) | Уверенность | Грейд`.
- **CSV/XLSX** (через `csv-analysis` / `xlsx`) — при >25 строк или по запросу.
- **Топ-цели касания** — после таблицы 3–5 Hot с одним предложением, почему первыми.
- **Signal-first режим** — HTML-отчёт (вердикт → ICP → топ-прспект → карточки шортлиста → паттерны боли → 7-дневный план → ограничения); структура в `references/pain-signal-prospecting.md`.

## Пример (мини)

Запрос: «Найди 10 компаний под AI-воркшоп, ритейл РФ, 300+ сотрудников».

1. ICP из навыка-контекста: ритейл РФ, 300+ сотр., есть L&D/корп-университет, публичный AI-интент.
2. Discovery: список ~25 ритейл-юрлиц (Rusprofile + отраслевые рейтинги, web).
3. `lead-enrichment` по ИНН → выручка/численность отсеивает мелких.
4. ЛПР: hh.ru (кто открыл L&D/AI-вакансии) + `linkedin` (HR-директора).
5. Сигнал: у 4 компаний вакансии «опыт с нейросетями» за 14–30 дней; у 1 — тендер на корп-обучение (`tender-search-ru`).
6. Скоринг → 3 Hot, 4 Warm, остальное Cold/Skip.
7. Таблица + топ-3 касания → `draft-outreach`, lineage → в CRM.

## Комплаенс (152-ФЗ)

- Контакты — только публичные рабочие каналы (корп-email, профиль, info@). Личные email/телефоны — не использовать без основания.
- На каждый контакт — источник + дата (lineage). Фиксировать в CRM / `yourname-sales-postgres`.
- Не хранить ПДн дольше нужного, не перепродавать список.

## Чеклист перед сдачей

- [ ] Дубли убраны (по ИНН/домену).
- [ ] У каждого Hot — верифицированный контакт + ≥1 URL источника.
- [ ] Нет Hot без ясного сигнала «почему сейчас».
- [ ] Уверенность честная (High = 2 независимых источника); неполнота помечена.
- [ ] Источник + дата сохранены (152-ФЗ); личные адреса исключены/помечены.
- [ ] Итог совпадает с запросом или объяснено, почему меньше (планка качества выше объёма).
- [ ] Топ-цели касания добавлены; handoff в `draft-outreach` / CRM обозначен.
