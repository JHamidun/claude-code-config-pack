# RU-источники данных для prospecting (воркшоп/консалтинг)

Порт `prospecting`/data-sources под российский рынок. Западные базы (Apollo, ZoomInfo, Clearbit, Crunchbase, LinkedIn Sales Nav, Hunter) заменены на RU-эквиваленты. Цель — найти mid-large компании РФ, которые внедряют AI и имеют бюджет на обучение команды (под AI-воркшоп / консалтинг / B2B-когорту academy). Под каждым — какой **существующий скилл** исполняет (не реимплементировать клиенты, звать готовые).

## Маппинг западное → RU

| Западный инструмент | RU-эквивалент | Исполняющий скилл |
|---|---|---|
| Apollo / ZoomInfo / Clearbit (фирмографика) | **Контур.Фокус, Rusprofile, СПАРК, ЕГРЮЛ** | ручной research / web; CRM-запись — через API твоей CRM |
| Crunchbase (раунды/инвесторы) | **РБ.ру (Rusbase), Венчурная база, СПАРК** | web research |
| LinkedIn Sales Nav (ЛПР) | **LinkedIn** (через ScraperVendor) + **HeadHunter** + Telegram | `linkedin`, `headhunter`, `social-intel` |
| Hunter / Snov (поиск email) | Контур.Фокус контакты, сайт компании, Rusprofile | web research |
| Google Maps / Yelp (локальный) | **Яндекс Карты / Бизнес, 2GIS** | `maps-places` |
| BuiltWith / Wappalyzer (тех-стек) | вакансии HH (требование «опыт работы с AI/нейросетями»), L&D-вакансии | `headhunter` |
| Trigger monitoring (Google Alerts) | Яндекс Новости, CNews/TAdviser, пресс-релизы про AI/трансформацию, проф-ТГ | web research, `social-intel`, `last30days` |

## Источники по цели

### Фирмографика и реквизиты (B2B-ядро)

- **Контур.Фокус** (focus.kontur.ru) — карточка компании: ИНН/ОГРН, выручка, численность, руководитель, аффилированность, госконтракты, арбитраж. Лучший единый источник по РФ-юрлицу.
- **Rusprofile** (rusprofile.ru) — бесплатно: реквизиты, ОКВЭД, руководитель, финансы (из Росстата), связанные лица. Хорош для быстрой проверки.
- **СПАРК** (spark-interfax.ru) — глубокая аналитика, скоринг рисков, связи. Платный, enterprise-grade.
- **ЕГРЮЛ** (egrul.nalog.ru) — первоисточник: учредители, директор, ОКВЭД, статус. Бесплатно, официально.

> Целевые компании — mid-large РФ, которые внедряют AI и могут позволить себе обучение команды (под воркшоп/когорту). По таким бери численность и выручку из Контур.Фокус/СПАРК, чтобы оценить L&D-бюджет и размер команды под обучение.

### ЛПР (decision-maker mapping)

- **LinkedIn** (`linkedin` через ScraperVendor) — HR-директора, руководители L&D, директора по цифровой трансформации, руководители функций. Профиль + посты + смена работы.
- **HeadHunter** (`headhunter`) — кто кого нанимает (вакансии с требованием AI-навыков и L&D-вакансии = сигнал готовности обучать), контакты HR/найм-менеджеров.
- **Telegram / соцсети** (`social-intel`) — кросс-платформенное досье, проф-каналы ЛПР, активность.
- **Сайт компании** — раздел «Команда»/«Руководство»/«Карьера и обучение», корп-email паттерны.

### Сигналы «почему сейчас»

- **Яндекс Новости / CNews / TAdviser** — внедрение AI, цифровая трансформация, новые директора по трансформации/CDO, запуск корп-обучения.
- **Вакансии HH** (`headhunter`) — требование «опыт работы с нейросетями» и L&D-роли = намерение прокачивать команду в AI = прямой сигнал под воркшоп.
- **Проф-ТГ-каналы и конференции** (`last30days`, `social-intel`) — кто что обсуждает про AI и обучение команд, кто выступал про AI-внедрение.

### Локальный B2B (если применимо)

- **Яндекс Карты / Бизнес, 2GIS** (`maps-places`) — для региональных компаний: адрес, телефон, сайт, часы.

## Free / без платных подписок

Когда нет Контур/СПАРК — комбинируй: ЕГРЮЛ (бесплатно, официально) + Rusprofile (бесплатно) + сайт компании + HH + LinkedIn + Яндекс Новости. Медленнее, но даёт качественный небольшой список.

## Гигиена источников

- Кросс-проверка: минимум 2 независимых источника для статуса «High confidence».
- Для каждого контакта сохраняй **источник + дату** (нужно для 152-ФЗ lineage). Записывай в свою CRM или таблицу лидов.
- Контакты — только публичные рабочие каналы (корп-email, профиль, info@). Личные email/телефоны не использовать без основания.

## Последовательность (полный стек)

1. **ICP** из `~/.claude/business-context.md` (без инструментов).
2. **Список кандидатов** — Контур.Фокус/Rusprofile (фирмографика) → 2–3× от нужного объёма.
3. **ЛПР** — `linkedin` + `headhunter` + сайт (HR-дир / гендир / рук. отдела / директор трансформации).
4. **Сигналы** — Яндекс Новости + вакансии с AI-навыками + проф-ТГ.
5. **Квалификация и скоринг** — `references/qualification-ru.md`.
6. **Передача** — список в `draft-outreach` (касания) + твоя CRM или таблица (учёт).
