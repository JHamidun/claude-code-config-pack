# Готовые spec'и опросов (DSL для yandex_form_builder.js)

DSL: `['S',..]` секция, `['T',..]` короткий текст, `['P',..]` абзац,
`['R',q,[opts],req]` один вариант, `['C',q,[opts],req]` несколько вариантов, `['SC',q,'низ','верх',req]` шкала.

## Каркас «ИИ-амбассадоры» (постоянный, меняются только списки)
Переменные под клиента: `dirs` (направления), `tools` (инструменты), `tasks` (задачи), `metrics` (метрики).

```
['S','<интро под клиента>'],
['S','Блок 1. О себе'],
['T','ФИО',true], ['T','Рабочий email',true,'Нужен, чтобы связать ответы до и после обучения'],
['T','Должность / роль',true],
['R','Подразделение / направление', dirs, true],
['R','Вы скорее…', ['Руководитель среднего звена','Специалист','Смешанная роль'], true],
['C','Какими цифровыми инструментами пользуетесь ежедневно?', tools],
['S','Блок 2. Текущий уровень ИИ'],
['R','Как часто используете ИИ-инструменты сейчас?', ['Никогда','Пробовал пару раз','Иногда','Несколько раз в неделю','Каждый день'], true],
['C','Какими ИИ-инструментами пользовались?', ['ChatGPT','Claude','Gemini','(regional LLM A) / Алиса','(regional LLM B)','YourProduct','Генерация изображений / видео','Агенты / GPTs','Ничем','Другое']],
['SC','Оцените свой уровень владения ИИ','новичок','эксперт',true],
['P','Что уже пробовали делать с ИИ? (кратко)'],
['C','Что мешает использовать ИИ чаще?', ['Не знаю с чего начать','Нет времени','Не доверяю результатам','Безопасность данных','Не вижу пользы для своих задач','Нет доступа к инструментам','Был негативный опыт','Другое']],
['S','Блок 3. Рутина и задачи для ИИ'],
['P','Опишите 2–3 задачи, которые отнимают больше всего времени каждую неделю',true],
['R','Сколько часов в неделю уходит на шаблонную рутину руками?', ['Меньше 2 часов','2–5 часов','5–10 часов','Больше 10 часов'], true],
['C','Какие типы задач хотели бы ускорить или автоматизировать с ИИ?', tasks],
['P','«Агент мечты»: если бы ИИ делал одну вашу задачу — какую?'],
['C','На какой результат / метрику влияет ваша работа?', metrics],
['S','Блок 4. Данные и границы ИИ'],
['R','Работаете ли с чувствительными данными?', ['Да, регулярно','Иногда','Нет'], true],
['P','Какие задачи, по-вашему, НЕ стоит решать с ИИ?'],
['SC','Насколько критична проверка фактов (борьба с «галлюцинациями»)?','не критично','очень критично'],
['S','Блок 5. Ожидания от программы'],
['C','Что хотите получить от программы?', ['Научиться писать промпты','Освоить инструменты под свои задачи','Автоматизировать конкретную задачу','Собрать своего ИИ-ассистента','Понять возможности и границы ИИ','Стать амбассадором и обучать коллег','Другое']],
['P','Какой результат через месяц покажет, что всё прошло не зря?'],
['R','Готовы ли пойти в углублённый трек (мини-команда, сборка агента)?', ['Да','Скорее да','Не уверен','Нет']],
['R','Готовы ли помогать коллегам осваивать ИИ (быть амбассадором)?', ['Да','Скорее да','Не уверен','Нет']],
['SC','Насколько верите, что ИИ изменит вашу работу?','не верю','полностью верю'],
['S','Блок 6. Формат и время'],
['R','Сколько часов в неделю готовы выделять на обучение?', ['Меньше 1 часа','1–2 часа','2–4 часа','Больше 4 часов']],
['C','В какое время удобнее?', ['Будни, утро (9–12)','Будни, день (12–17)','Будни, вечер (17–21)','Выходные','Другое']],
['T','Ваш часовой пояс',false,'например: Мск / +3'],

```

## Пример адаптации: энергосетевая компания, 2 формы (топы + линейные)
Ситуация-пример: у клиента уже куплен корпоративный доступ к ИИ-инструменту. Аудитории:
~15 руководителей по направлениям (промо-обучение «показать возможности + дорожная карта»)
+ широкий круг сотрудников.

Списки:
```
dirs = ["Эксплуатация электросетей / производство","Технический блок (главный инженер)",
"Капитальное строительство и реконструкция","ТОиР — техобслуживание и ремонт",
"РЗА, АСУ, диспетчеризация","Технологическое присоединение и развитие",
"Транспорт электроэнергии / учёт / потери","Финансы и экономика","Закупки и МТО (223-ФЗ)",
"Управление персоналом (HR)","Охрана труда, промбезопасность, экология","Безопасность / режим",
"ИТ и цифровая трансформация","Правовое обеспечение","Документооборот / административный блок",
"Связи с общественностью / PR","Другое"]

tools = ["YourProduct","1С","Excel / Google Sheets","SAP / ERP","АСУ ТП / SCADA / диспетчерские системы",
"СЭД / электронный документооборот","BI / дашборды","ГИС / схемы сетей","ЕИС / ЭТП (закупки)",
"Электронная почта","Telegram / корпоративный мессенджер","Другое"]

tasks = ["Подготовка техдокументации, регламентов, инструкций","Производственная и отчётная документация",
"Анализ данных (аварийность, надёжность, потери)","Протоколы совещаний и оперативок",
"Договоры и закупочная документация (ТЗ, 223-ФЗ)","Письма и ответы контрагентам / в органы власти",
"Аналитические справки для руководства","Работа с таблицами (сводки, бюджеты, формулы)",
"Поиск и проверка нормативки (ГОСТ, ПУЭ, приказы)","Охрана труда: инструктажи, проверка знаний",
"HR: подбор, обучение, онбординг","Подготовка презентаций","Транскрибация совещаний → протоколы","Другое"]

metrics = ["Надёжность электроснабжения (SAIDI / SAIFI)","Снижение потерь электроэнергии",
"Сроки технологического присоединения","Аварийность и сроки восстановления",
"Исполнение ремонтной и инвестиционной программы","Затраты / бюджет","Сроки и качество отчётности",
"Безопасность труда (травматизм)","Скорость и качество работы команды","Другое"]
```
Форма ТОПОВ отличается: вопросы про численность подчинённых, активность ИИ у команды,
«пилот в направлении», дорожная карта, формат (очно в городе клиента / онлайн / гибрид,
1 день vs 2×4ч).

Результат билдера — ссылка вида `https://forms.yandex.ru/u/<surveyId>/` на каждую форму.
