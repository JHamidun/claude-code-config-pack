# Бенчмарки Meta Ads — все цифры

> ⚠️ Meta признана экстремистской в РФ. Раздел — для международных/СНГ-проектов.
> Все цифры — практические ориентиры, не гарантия результата.

---

## Аккаунты и бюджеты

| Метрика | Значение |
|---------|----------|
| Лимит нового аккаунта (старт) | **$50/сутки** |
| Лимит через 3-7 дней (тратя максимум) | **$200-500/сутки** |
| Лимит через полгода | **десятки тысяч/сутки** |
| Премиум-агентские кабинеты | комиссия **3-7%** от бюджета |
| Правило бюджета | дневной бюджет ≥ стоимости **3 целевых событий** |

## Обучение

| Метрика | Значение |
|---------|----------|
| Порог выхода из learning phase | **~50 событий за 7-10 дней** |
| Минимальная аудитория | **100-200K+** (меньше → плохое обучение) |
| Безопасный шаг масштабирования | **+10-15%/сутки** (×2-×3 = сброс обучения) |
| Резкое масштабирование (сбрасывает) | **×2-×3** бюджета |
| Пауза, сбрасывающая обучение | **> 7 дней** |
| Период накопления сигналов | первые **2-3 дня** (не выводы) |
| Не выключать кампанию | первые **5-7 дней** |

## Креативы

| Метрика | Значение |
|---------|----------|
| Оправданное число креативов | **6-8** (при десятках $/день) |
| Бессмысленно | **20-30 креативов на $10** |

## Аудитории (Lookalike)

| Сегмент | Точность |
|---------|----------|
| **1%** | максимально похожие (старт) |
| **1-3%** | расширение |
| **3-5%** | широкий охват |
| **>5%** | ⚠️ слишком широко, не использовать |

## Стратегии ставок

| Метрика | Значение |
|---------|----------|
| Maximize Conversions покрывает | **~90%** всех кейсов в продакшене |
| CBO риск перекоса | **80-90%** бюджета может уйти в один адсет |

## CPM / цена показа

| Метрика | Значение |
|---------|----------|
| CPM b2c EU столицы (Лондон/Париж/Берлин) | **$10-15** в среднем (разбежка по столицам) |
| Конец квартала | CPM **2-3×** выше нормы |
| Превышение дневного бюджета (признак сбоя) | FB тратит **2-3×** дневного → стоп |

## Метрики оценки результата

**Воронка метрик:** `CPM` → `CTR` → `CPC` → `CR` (в лид / в квал / в оплату) → `CPL` / `CPA`.

**По бизнес-модели:**
- **E-commerce:** ROMI, ROAS, LTV, CAC, AOV, CR в оплату → лучшая команда = низкий CAC + высокий ROMI/ROAS + объёмы;
- **Лидген (B2B/услуги):** + **CPQL** (cost per qualified lead) и **CR из лида в квал-лид** — без квалификации Meta ведёт много нецелевых лидов.

---

## ⚠️ Управление ожиданиями

- Все цифры — **практические ориентиры** (B2C международный контекст, многомиллионные бюджеты), а не гарантия.
- CPM/CPL/CPA **сильно** зависят от: гео, ниши, качества пикселя и CAPI, креативов, сезона (конец квартала ×2-3).
- **Достоверные выводы — только на собственной статистике.** Не используй чужие бенчмарки как KPI своего проекта.
- Атрибуция запаздывает — не делай выводы по 1-2 лидам и в первые 2-3 дня.
