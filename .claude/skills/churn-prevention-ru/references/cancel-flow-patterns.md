# Паттерны cancel-флоу (RU)

Детальные паттерны cancel-флоу ExampleProduct по типу подписчика, интервалу и сегментам.

## По типу подписчика

### B2C-профи / self-serve (индивидуальные подписки academy)
Высокий объём, низкое касание. Флоу работает без человека.
```
Кнопка отмены → Опрос (1 вопрос) → динамический оффер → Подтверждение → После отмены
```
- Полностью автоматизирован, 2-3 экрана макс, один оффер + запасной, мобайл-оптимизирован, видимое «Продолжить отмену».
- **Типовой save rate:** 20-30%.
- Пример для Plus 4 990 ₽/мес: «Главная причина?» → «Дорого» → «−25% на 3 месяца (экономия ~3 740 ₽)» → отказ → «Или Basic за 1 990 ₽/мес» → отказ → «Доступ сохраняется до [дата]».

### B2B-когорты / командные пакеты
Меньше объём, выше ставки. Личный контакт окупается.
- Аккаунты выше порога MRR → на куратора (через `crm`); показать влияние на команду («N сотрудников потеряют доступ к трекам»); звонок admin-to-admin; «запланировать звонок с куратором» как save-опция; отменять может только владелец/админ когорты.
- **Save rate:** 30-45%.

**Маршрутизация по MRR:**
| MRR | Флоу |
|-----|------|
| < ~10K ₽/мес | Автоматический с офферами |
| ~10-50K ₽/мес | Автоматический + флаг куратору |
| ~50-200K ₽/мес | На куратора до завершения отмены |
| ~200K+ ₽/мес | Блок self-serve, только звонок куратора/основателя |

### Даунгрейд тарифа (Plus/Pro → Basic)
Уходят со старшего тарифа на младший вместо полной отмены. Другая психология — не уходят, а оптимизируют расход.
- Вести Basic-тарифом как первой опцией (не save-оффером скидки); показать, что сохраняют на Basic vs теряют (premium-треки, флагманский трек, симуляторы); «save» = удержать на Basic; трекать для re-upgrade кампаний. Для academy актуально — лучше Basic, чем полный отток.

## По интервалу

### Месячные
Чувствительны к цене, короткий коммитмент. Скидки работают (20-30% на 2-3 мес), пауза эффективна (1-2 мес), предложить годовой со скидкой −20%.
Приоритет офферов: скидка/founding-оффер (если дорого) → пауза (если мало занимается) → переход на год.

### Годовые
Выше коммитмент, отменяют по более сильным причинам. Ожидания по возврату важны, длиннее окно save (уже оплатили), личный контакт оправданнее.
Приоритет: пауза остатка срока → корректировка тарифа + кредит на продление → личный контакт куратора → частичный возврат + даунгрейд.
**Возврат:** прорейт при значимом остатке; «пауза до продления» если <3 мес осталось; быть щедрым (плохой опыт возврата = громкие детракторы).

## Save-офферы

### Лестница скидок
Не вести с максимальной скидкой. Эскалировать:
```
Отмена → 15% → всё ещё отменяет → 25% → всё ещё → отпустить
```
Макс 2 скидочных оффера за сессию; не >30% (founding-оффер — отдельный кейс для первой сотни); time-limit (2-3 мес); трекать принявших (если отменяют снова на полной цене — не пере-оффер).

### Плейбук паузы
Пауза часто лучше скидки — не девальвирует продукт. Особенно для «нет времени заниматься».
| Настройка | Рекомендация |
|-----------|--------------|
| Длительность | 1, 2, 3 месяца |
| По умолчанию | 1 месяц |
| Максимум | 3 месяца |
| Во время паузы | Прогресс/XP/сертификаты сохранять, доступ снять |
| Реактивация | Авто + письмо за 7 дней |
| Повторные паузы | 1 пауза за 12 мес |

Серия реактивации: день -7 «Пауза закончится через 7 дней, вот новые треки»; день -1 «Завтра возвращаетесь к обучению»; день 0 «Вы вернулись, вот ваш прогресс».

### Путь даунгрейда
Для multi-plan продукта — сильнейший save. Показать чек-марками что сохраняют (базовые треки, прогресс, сертификаты) и крестиками что теряют (premium-треки, флагманский трек, продвинутые симуляторы); сохранить данные/XP; не показывать апгрейд-промпты 30 дней.

### Обработчик ухода к конкуренту
Спросить какой конкурент (опц.); показать сравнение (другой AI-курс / бесплатные туториалы — отстройка: практика на симуляторах + AI-тьютор + доступ к моделям включён + автор-практик; см. `competitive-analysis`); оффер migration credit; запросить фидбэк-звонок с основателем. Эти данные — золото для продукта.

## После отмены

### Страница подтверждения
```
Подписка отменена.
Что дальше:
• Доступ сохраняется до [дата окончания периода]
• Прогресс/XP/сертификаты хранятся 90 дней (учитывать 152-ФЗ по срокам и удалению)
• Реактивация в любой момент из настроек
[Возобновить подписку]
```

### Пост-cancel серия
| Тайминг | Действие |
|---------|----------|
| Сразу | Письмо-подтверждение с датой окончания доступа |
| День 1 | Ничего (не быть навязчивым) |
| День 7 | Опрос удовлетворённости |
| День 30 | «Что нового» с новыми треками/материалами |
| День 60 | Закрыть конкретную причину отмены, если решена (добавили трек) |
| День 90 | Финальный win-back со спец-оффером (founding/скидка) |

Win-back письма — вёрстка `html-email`, логика `n8n`. Также: вернуть ушедшего в TOP воронки (news/канал) и через nurture снова в academy.

## Сегментация

| Измерение | Зачем |
|-----------|-------|
| Тариф / MRR | Высокоценные / B2B-когорты → личный контакт куратора |
| Tenure | Долгосрочные → щедрее офферы |
| Уровень занятий | Active learner vs dormant — разный месседж |
| Интервал | Месяц vs год |
| Прошлые saves | Не пере-оффер той же скидки |
| Причина | Драйвит оффер (ядро маппинга) |

**Сегмент-специфичные флоу:** новичок после trial (<30 дней) — не активировался, save = онбординг/куратор, не скидки; вовлечённый на цене — скидка/год/даунгрейд Plus→Basic, высокий потенциал; dormant (нет входа 30+ дней) — пауза/«новые треки», низкий потенциал; achiever (прошёл нужный трек) — показать смежные треки/новый флагман, средний.

## Чеклист внедрения

**Фаза 1 (неделя 1):** cancel-флоу (опрос + 1 оффер + подтверждение); exit-опрос 5-7 причин; 1 оффер на причину; трекинг причин и save rate; pre-dunning алерты истечения карты (ЮKassa).
**Фаза 2 (недели 2-4):** запасные офферы; пауза; dunning-серия (4 письма/10 дней); умные ретраи; MRR-маршрутизация в Your CRM.
**Фаза 3 (месяц 2+):** health score; проактивные триггеры; A/B скидок/офферов; сегментация флоу; пост-cancel win-back; когортный анализ; отдельный трек предотвращения trial→churn (с `onboarding-cro-ru`).

## Комплаенс (RU)

- **Лёгкая отмена:** отмена должна быть так же проста, как оформление; нельзя требовать звонок если оформляли онлайн; нельзя добавлять лишние шаги. Save-офферы допустимы, но «Продолжить отмену» должно быть явным. (Закон о защите прав потребителей + офертная практика РФ.)
- **152-ФЗ / хранение данных:** информировать о сроке хранения прогресса/данных после отмены; предложить экспорт сертификатов; удалять по запросу; не использовать пост-cancel данные для маркетинга без согласия.
- Всегда явный путь к завершению отмены; никогда не прятать кнопку; обрабатывать отмену даже при ошибке save-флоу; подтверждать письмом.
