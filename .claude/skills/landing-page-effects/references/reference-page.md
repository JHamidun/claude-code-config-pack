# Эталонная страница — заполни своим

> **Зачем.** Каталог эффектов показывает каждый эффект по отдельности. Как они
> выглядят вместе — видно только на собранной странице. Эталон нужен, чтобы
> глитч на второй странице выглядел так же, как на первой, а не «примерно так же».

## Мой эталон

| Поле | Значение |
|---|---|
| Путь к файлу | `[./work/landing/index.html или URL опубликованной страницы]` |
| Какие эффекты стоят | `[перечисли номера из каталога: 1, 5, 8, 14…]` |
| Шрифты страницы | `[2-4 из списка в SKILL.md]` |
| Основной акцент | `[hex]` |
| Фон | `[hex]` |

## Как завести

1. Собери одну страницу с 5-8 эффектами из `effects-catalog.md` — теми, что реально нужны.
2. Прогони её через `verifier` (консоль без ошибок) и `perf-audit` (LCP, CLS): эффекты
   ломают именно эти две метрики.
3. Впиши сюда путь. Дальше при вопросе «как у нас делается глитч» открывай эталон,
   а не переписывай CSS заново.

## Правила, которые эталон должен держать

- не больше 3-4 шрифтов на странице;
- `prefers-reduced-motion` отключает всё, что движется само;
- Three.js / particles / GSAP — только lazy load, иначе LCP уезжает;
- один и тот же эффект на всех страницах берётся из каталога, а не переписывается.
