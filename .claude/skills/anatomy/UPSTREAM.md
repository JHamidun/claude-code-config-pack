# anatomy — откуда это

Источник: <https://github.com/wheresryan22/anatomy>, ревизия `689dcf966e63d92be10a5d593c6e19e10acd4422`
(ветка `main`, 12.10.2026).

Лицензия: **MIT**, `Copyright (c) 2026 Ryan`; полный текст — в файле `LICENSE` рядом.
MIT требует, чтобы этот текст сопровождал любую копию, включая копию внутри плагина
`plugins/web-publish/skills/anatomy/`. README и `SECURITY.md` — тоже из upstream: их
инструкции по установке (`npx skills add`) и контакты автора относятся к оригиналу, а не к паку.

Изменено относительно первоисточника:

1. `SKILL.md`: описание заменено коротким русским (оригинал около 1000 знаков и слишком
   агрессивные триггеры); после заголовка «# Anatomy» вставлен блок «ВСТАВКА ПАКЕТА»:
   рабочая папка вне навыка, размеры и бюджет (Figure сразу, Hero и Epic по слову
   пользователя, потолок 3 круга аудита или 90 минут), правило для чужого текста, порядок
   обновления.
2. `scripts/capture.mjs`, `scripts/drive.mjs`, `scripts/turn-check.mjs`: убран
   `--allow-file-access-from-files`, добавлен `--proxy-server=http://127.0.0.1:9` (мёртвый
   прокси на loopback): страница не читает чужие файлы и не выходит в сеть. Раздел про флаг
   в `SECURITY.md` описывает upstream, в паке этого флага нет.
3. `scripts/turn-check.mjs`: в список путей Chrome добавлен путь Windows (в двух других
   скриптах он уже был).
4. `README.md`: относительные ссылки на файлы, которых в паке нет (картинки `.github/assets/`,
   `evals/evals.json`, `CONTRIBUTING.md`, `CODE_OF_CONDUCT.md`), заменены на абсолютные
   ссылки на эту же ревизию upstream; остальной текст не тронут.

Не взято, потому что навыку не нужно: `.github/`, `tests/`, `scripts/*.test.mjs` (они ставят
пакеты из реестра и запускают Chrome), `CODE_OF_CONDUCT.md`, `CONTRIBUTING.md`,
`.gitattributes`, `.gitignore`, `agents/openai.yaml` (Codex), `evals/evals.json`.
Собранные страницы больших примеров (`examples/arcade-cabinet`, `raptor-engine`,
`ripple-tank`, `turning-dial`, до 1,6 МБ каждая) в пак не входят: они пересобираются
командой `node examples/<имя>/build.mjs`. Страницы `dial-indicator` и `desk-computer`
оставлены, чтобы пример открывался сразу.

Что проверено: сетевые обращения скриптов идут только на localhost (протокол отладки Chrome),
телеметрии нет, ключей и переменных окружения кроме `CHROME_PATH` скрипты не читают.
Платных ключей навык не требует.

Для сопровождающих. Код ядра (`kit/*.mjs`, шейдеры GLSL, `examples/*/build.mjs`) совпадает с
upstream. Если сканер или автозамена обезличивания находит в нём «личное» (английское слово
про вершины в шейдерах и геометрии, имя одной функции в примере `arcade-cabinet`), это ложное
срабатывание: имена взяты из upstream, а подстановка ломает вершинные шейдеры WebGL и сборку
примера (`SyntaxError`). Поэтому при синхронизации пака с живым конфигом каталог `anatomy/`
нужно исключать из замен. Новая ревизия: проверить код (сканеры и чтение), скопировать и
повторить правки 1–4.
