# Reference provenance

This skill's reference organization was informed by the public Apache-2.0 project [heygen-com/hyperframes](https://github.com/heygen-com/hyperframes), inspected at commit `8800214`.

Only general documentation patterns were retained, such as separating renderer contracts from examples and grouping related capabilities by deliverable.

All commands, APIs, schemas, timing semantics, effects, layout behavior, project mutation rules, and limitations documented here are for `higgsedit`. HyperFrames-specific `data-*` clips, GSAP timelines, adapters, lint commands, and render architecture are not supported `higgsedit` syntax.
