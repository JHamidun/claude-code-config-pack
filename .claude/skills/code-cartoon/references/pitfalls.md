# Грабли

Таблица «симптом / причина / починка»; пополняется при каждой новой ошибке (с. 20, 23). Искать по симптому — так,
как ошибку видно в кадре, в звуке или в консоли.

Откуда строка: «с. N» — методичка (`methodology.md`); «эталон» — поймано на мультике `<эталон>`
(октябрь 2026); «замер» — найдено замером при сборке навыка 05.10.2026. Как мерить — `frame-checks.md`.

Новая грабля — одна строка в таблицу своего раздела со следующим свободным номером. Код длиннее строки — под
таблицей, с номером строки.

```js
// zoom-through: the target slides linearly to the frame centre while the zoom grows exponentially
function zoomTo(c0, tg, k) {
  const z = Math.exp(lerp(Math.log(c0.zoom), Math.log(tg.zoom), k));
  const ox = (tg.x - c0.x) * c0.zoom * (1 - k), oy = (tg.y - c0.y) * c0.zoom * (1 - k);
  return { x: tg.x - ox / z, y: tg.y - oy / z, zoom: z, z: lerp(c0.z || 0, tg.z || 0, k), sway: (c0.sway == null ? 1 : c0.sway) * (1 - k) };
}
```
