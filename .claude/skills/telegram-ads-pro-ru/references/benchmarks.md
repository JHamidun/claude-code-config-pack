## 1. Пороги входа и аукцион

| Параметр | Еврокабинет | Тонкабинет |
|----------|-------------|------------|
| Минимальный депозит | **500 €** | **20 TON** (~30 $) |

| Минимальный CPM | ~0,5 € (реально 1–2 €) | от **0,1 TON** (~13–15 ¢) |

## 2. CPM по нишам (опыт эксперта)

| Ниша | CPM |
|------|-----|
| Финансы / инвестиции / крипто | **2–3 €** (дорогие ниши — до **6–20 €**) |
| Бизнес / маркетинг | **1,5–2,5 €** |
| Образование | **1–2 €** |
| Health / lifestyle / массовые | **1–4 €** |
| Развлечения / хобби | **0,5–1,5 €** |

> CPM зависит от конкуренции в тематике. Чем конкурентнее ниша — тем выше ставки в аукционе. Target Users помогает сбить CPM в дорогих нишах за счёт показа в дешёвых топиках (но ↓ релевантность).

## 3. CTR-бенчмарки

| Формат / сегмент | CTR |
|------------------|-----|
| **Текст, РФ** | **0,5–0,7 %** (хороший ориентир ~**0,6 %**) |
| **Текст, международный** | **2–4 %** |
| **Баннер, РФ** | до **~1,5 %** |
| **Баннер, международный** | **6–7 %** |
| Open rate рекламы (для калибровки CTR) | **~0,5–1 %** |

> Из экспертных бенчмарков (23.12): TG Ads текст — CTR **0,6%** хороший бенч; с баннером — **0,9–1%** (при наценке к CPM). Баннер оправдан, только если рост CTR перебивает рост CPM в процентах.

## 4. Наценки к CPM за форматы

| Формат | Наценка |
|--------|---------|
| Текст | 0 % |
| Кастомные эмодзи | **+20 %** (лучшее цена/результат) |
| Аватарка | +30 % (слабый эффект) |
| Баннер | **+50 %** (в части материалов +80%) |
| Видео | +70 % |

Суммируются: баннер + эмодзи = +70 %; видео + эмодзи = +90 %.

## 6. Кейсы (ROMI) — с оговоркой

| Кейс | Бюджет | Результат | ROMI |
|------|--------|-----------|------|
| Нутрициология (прямая + tripwire) | 220K ₽ | ~1,5 млн ₽ | **~500%** (сегодня ~200%) |
| Доставка из Китая (контентная) | 260K ₽ | 5,7 млн ₽ (44 продажи × 130K) | **~2300%** (повторные 1500→1000%) |
| Бот-воронки (самостоятельные) | — | — | **>80% негатив** |

> **⚠️ Управление ожиданиями.** Высокие ROMI — это **первые запуски**. На повторных ROMI закономерно снижается (выгорание ниши, рост конкуренции). **Не используй чужие ROMI как гарантию своего результата.** Достоверные выводы — только на собственной статистике, и особенно на топиках — только на больших бюджетах (нестабильность/«скальпинг»).

## 7. Признаки ботового подрядчика (антибот-чеклист)

Если подрядчик отчитывается такими цифрами — почти наверняка крутит **серые топики** (ASERS/Others, BS and Gambling, Offers and Promotions), и продаж не будет:

| Сигнал | Норма | Тревога |
|--------|-------|---------|
| **Цена подписчика** | 150–300 ₽ | **< 30–40 ₽** (или 20–40 центов в межд.) |
| **CTR на широких топиках** | текст РФ 0,5–0,7 % | **1,5–2 %+** на широких топиках |
| **Конверсии в продажу** | соразмерны объёму лидов | **единичные** при куче дешёвых подписчиков/событий |

**Как проверять:**
1. Запросить, **какие топики** используются в кампаниях (если серые — красный флаг).
2. Сверить **цену подписчика** с нормой 150–300 ₽.
3. Сверить **CTR** с текстовым бенчем (РФ 0,5–0,7 %).
4. Главное — **проследить путь до продажи**, а не до подписки/клика. Дешёвый трафик без продаж = бот-трафик.

> «Подписчики дешевле 30–40 рублей, CTR 1,5–2%+ на широких топиках, много подписчиков, но конверсии в продажу единичные — проверяйте, какие топики используются.»

## 8. Метрики оценки результата

| Тип бизнеса | Ключевые метрики |
|-------------|------------------|
| **E-commerce** | ROMI, ROAS, LTV, CAC, AOV, **CR в оплату** → лучшая команда = низкий CAC + высокий ROMI/ROAS + объёмы |
| **Лидогенерация** | то же + **CR из лида в квал-лид, CPQL** |

**Обязательная связка аналитики:** UTM-метки (`utm_source=telegram&utm_medium=cpm&utm_campaign=...&utm_content=...`) + GA4 / Яндекс.Метрика → трафик, поведение (глубина/время на сайте), конверсии. Внутри TG Ads — только показы, клики, CTR, расход, фактический CPM. CPL = расход / лиды; CPA = расход / целевые действия.

→ Сводная аналитика по каналам и бенчмарки CPL/CPA — скилл `performance-analytics`.
