# Telegram Ads Pro (RU)

Исполняемый playbook по **платной рекламе Telegram Ads**: закупка показов «спонсированных сообщений» через рекламный кабинет — аукцион, таргетинг, подбор каналов, воронки, медиаплан. Это **не** SMM и **не** контент канала.

> **Граница со скиллами.** Этот скилл — про **рекламный кабинет ads.telegram.org** (платная закупка показов). Он НЕ пересекается с:
> - `tg-post` — контент/посты твоего канала (прогрев, а не закупка);
> - `telegram-bot-toolkit` — разработка ботов (здесь бот — только как **цель** рекламы, см. воронки);
> - `crosspost` — кросспостинг контента по площадкам.

> **Главный диагноз платформы:** Telegram — охватный инструмент **без оптимизации**. Нет пикселя, нет обучения алгоритма, нет оптимизации на события. **Нет фазы обучения — результат виден сразу.** Успех строится не на «магии алгоритма», а на правильном выборе каналов, воронке и контентном прогреве. Поэтому к запуску подходим системно: медиаплан ДО пополнения кабинета.

## Когда использовать

- Запуск рекламной кампании в Telegram Ads с нуля (открытие кабинета, аукцион, первая кампания) — **основной сценарий, см. «Процедура»**.
- Выбор модели таргетинга под задачу (Target Channels / Target Users / топики / конкретные каналы).
- Решение «еврокабинет vs тонкабинет» (порог входа, CPM, фичи, агентские комиссии, гео).
- Подбор каналов для размещения (6 способов) + прогноз ёмкости (RPP × посты/неделю).
- Выбор формата объявления и расчёт наценки к CPM (текст / эмодзи / аватарка / баннер / видео).
- Построение воронки (прямая / контентная через канал / бот) + контент-стратегия канала.
- Омниканальность: совмещение TG Ads с органикой канала и посевами (закреп снизу, ретаргетинг подписчиков, посевы + Ads).
- Таргетинг на конкретную базу номеров → через ClientCorp8 Маркетолог Pro (когда нативные кастомные аудитории недоступны).
- Диагностика «почему дёшево, но нет продаж» → антибот-чеклист подрядчика.
- Составление/ревизия медиаплана TG Ads для YourProduct или клиента (ClientCo).

**НЕ использовать для:** контента/постов канала (`tg-post`, `crosspost`); разработки ботов (`telegram-bot-toolkit`); закупки прямых интеграций/посевов напрямую у каналов (`tg-channel-buyout-ru`); Meta Ads (`meta-ads-analyzer`), VK Ads (`vk-ads-pro-ru`), Google Ads, Яндекс.Директ.

## Процедура: запуск кампании (Шаг 1 → 10)

Результат процедуры — **медиаплан кампании** (шаблон в «Выход») + готовые к загрузке кампании. Иди по шагам, не пропуская; на каждом шаге указано, какой раздел/reference применять.

**Шаг 1. Собери входы (бриф).** Спроси у пользователя или возьми из контекста:
- продукт и оффер (что продаём, чек);
- ЦА и гео (РФ/СНГ/Европа/другое);
- бюджет в месяц (₽ или €) — критично для выбора модели таргетинга;
- цель: лиды сейчас / рост канала / сбор базы в бот;
- активы: есть ли канал (и контент в нём), лендинг/квиз, бот;
- горизонт: нужен результат за неделю или готовы греть 4–8 недель.
Чего-то нет → зафиксируй как допущение в медиаплане, не блокируйся.

**Шаг 2. Выбери кабинет.** По таблице «Аукцион и пороги входа» (ниже): бюджет ≥500 € и нужны Users/топики/гео → еврокабинет; старт без 500 € или гео Европа/Балканы → тонкабинет; нужен таргетинг по базе номеров → ClientCorp8 Маркетолог Pro (порог 50 000 ₽). Пошаговое открытие → `references/targeting-cabinets.md` §1.

**Шаг 3. Выбери воронку.** По таблице «Воронки» (ниже) и decision в `references/funnels-cases.md` §2: простой продукт + лиды сейчас → прямая (`Open link` на ленд/квиз); высокий чек + есть ресурс на контент → контентная (`View channel`, прогрев ~4 нед); сбор базы → бот как коллектор (не как самостоятельная воронка — 80% самостоятельных бот-воронок = негатив). Зафиксируй цель кампании: `Open link` / `View channel` / `View bot`.

**Шаг 4. Выбери модель таргетинга.** По таблице «Четыре модели»: **бюджет до 500K ₽/мес → только конкретные каналы + Target Channels** (база). Узкая ниша (B2B, консалтинг, юриспруденция) → каналы. Широкая массовая (психология, health, рецепты) + большой бюджет → можно топики. Users подключай позже, для масштабирования. Серые топики (`Others`, `BS and Gambling`, `Offers and Promotions`) — никогда (исключение: Offers для e-commerce с акциями).

**Шаг 5. Собери карту каналов.** Применяй 6 способов из `references/targeting-cabinets.md` §5 (TGStat/Telemetr, Telegram Search, Similar Channels ×2, спай-сервисы → скилл `ad-spy`, личный список). Собери **20–50 каналов**, разбей на **кластеры по под-темам** (3–6 кластеров), заполни таблицу карты каналов (шаблон в «Выход»). Для каждого канала: подписчики, RPP (охват/пост), постов/неделю.

**Шаг 6. Посчитай ёмкость и бюджет (RPP-формула).** Для каждого кластера:
```
Показы/нед (потолок) = Σ по каналам (RPP × постов/нед)
Бюджет/нед            = (Показы / 1000) × плановый CPM
```
Плановый CPM бери из «Бенчмарки» по нише. Реальные показы будут ниже потолка (конкуренция). Сумма по кластерам должна вписываться в бюджет из Шага 1 — не вписывается → режь кластеры, а не CPM ниже минимального.

**Шаг 7. Напиши креативы и UTM.** На каждый кластер — **3–5 текстовых объявлений** (заголовок + до 160 симв. + кнопка), промаркированных по гипотезе. Формат старта — **текст (0% наценки)**, вторым эшелоном кастомные эмодзи (+20%, лучшее соотношение цена/результат). Хуки и приёмы → `references/creatives-formats.md`. Каждому объявлению — UTM: `?utm_source=telegram&utm_medium=cpm&utm_campaign=<кластер>&utm_content=<креатив_v1>`. Учти модерацию: без капслока, без обилия эмодзи, без «ты».

**Шаг 8. Построй матрицу A/B.** Кампаний = объявления × аудитории (комбинаторный принцип, тесты только параллельные, меняется один параметр). Аудитории важнее креативов → баланс вида **5 объявлений × 4 аудитории** при ~20 кампаниях (не 20×1 и не 2×10). Занеси матрицу в медиаплан.

**Шаг 9. Собери артефакт-медиаплан и прогони чек-лист.** Заполни шаблон из «Выход» целиком, проверь по «Чек-лист» (ниже). Только после PASS — пополнение кабинета, загрузка кампаний, модерация (несколько часов), старт.

**Шаг 10. Контрольная точка через 3–7 дней.** Сними факт против бенчмарков (CTR текста РФ 0,5–0,7%, цена подписчика 150–300 ₽, CPL против плана). Решения: кластер/креатив хуже бенчей при потраченном ≥ CPM×10 показов → стоп; лучше плана → +бюджет. Подписчики дешевле 30–40 ₽ или CTR 1,5–2%+ на широких топиках → прогони антибот-чеклист (`references/benchmarks.md` §7). Для контентной воронки — проверь контент-микс канала (90/0/10 в наборе) → `tg-post`.

## Пример (сокращённый, «как выглядит done»)

**Вход:** ClientCo — онлайн-школа английского (B2C, чек 30 000 ₽), РФ, бюджет 150 000 ₽/мес, цель — лиды на бесплатный вебинар, есть квиз-лендинг, канала нет.

**Прохождение:** Шаг 2 → еврокабинет (РФ, бюджет ≥500 €). Шаг 3 → прямая воронка `Open link` на квиз (лиды сейчас, канала нет). Шаг 4 → бюджет <500K ₽ → конкретные каналы + Target Channels; ниша широкая, но топики не берём. Шаг 5–6 → 3 кластера. Фрагмент готового медиаплана:

| Кластер | Каналов | Показы/нед | CPM | Бюджет/нед | CTR план | Клики/нед |
|---|---|---|---|---|---|---|
| Изучение английского | 12 | 180 000 | 1,5 € | 270 € | 0,6% | ~1 080 |
| Переезд/релокация | 8 | 90 000 | 2,0 € | 180 € | 0,5% | ~450 |
| Карьера/саморазвитие | 10 | 120 000 | 1,8 € | 216 € | 0,5% | ~600 |
| **Итого** | 30 | 390 000 | — | **666 €/нед** | — | ~2 130 |

Шаг 7–8 → 5 текстовых креативов × 3 кластера = 15 кампаний; UTM `utm_campaign=english_channels`, `utm_content=creative_v1..v5`. Шаг 9 → чек-лист PASS → запуск. Шаг 10 → день 5: кластер «Карьера» CTR 0,2% при 40 000 показов → стоп; «Английский» CPL 380 ₽ при плане 500 ₽ → +30% бюджета.

**Выход:** заполненный медиаплан по шаблону + решение контрольной точки. Это «done».

## Чек-лист (quality gate перед запуском/сдачей медиаплана)

- [ ] Бриф заполнен: бюджет, гео, цель, чек, активы (допущения помечены явно).
- [ ] Кабинет обоснован таблицей порогов (не «по умолчанию еврокабинет»).
- [ ] Воронка соответствует чеку и активам; для контентной — заложен прогрев ~4 нед ДО продаж.
- [ ] Бюджет <500K ₽/мес → в плане НЕТ топиков; серых топиков нет нигде.
- [ ] Карта каналов ≥20 каналов, разбита на кластеры, у каждого канала есть RPP и частота постинга.
- [ ] Ёмкость посчитана по RPP-формуле; суммарный бюджет сходится с брифом; CPM не ниже минимального порога кабинета.
- [ ] На каждый кластер 3–5 креативов с гипотезами; формат старта — текст; модерация учтена (без капслока/«ты»/эмодзи-спама).
- [ ] У каждого объявления UTM (source/medium/campaign/content); аналитика (GA4/Метрика) готова принимать — пикселя в TG нет.
- [ ] Матрица A/B комбинаторная (объявления × аудитории), тесты параллельные.
- [ ] KPI и стоп/скейл-правила записаны ДО запуска; антибот-триггеры в плане.
- [ ] Ожидания откалиброваны: чужие ROMI-кейсы не обещаны клиенту как прогноз (см. «Управление ожиданиями»).

# Справочник методологии

## Что такое Telegram Ads (контекст платформы)

- **Только CPM-модель.** Оплата за 1000 показов «спонсированного сообщения». CPC недоступен; оптимизации на покупки/лиды нет.
- **Единственный формат — sponsored message.** Нативно в ленте канала, пометка «Спонсор» обязательна, кнопку действия Telegram добавляет сам.
- **Три цели кампании:** `Open link` (сайт/лендинг/квиз), `View bot` (в TG-бота), `View channel` (набор подписчиков).
- **Премиум-аудитория (~5%) рекламу не видит** — самые платёжеспособные пользователи вне охвата. Учитывай при планировании.
- **Нет пикселя, нет ретаргетинга по событиям, нет look-alike.** Конверсии — **только через UTM** + внешняя аналитика (GA4 / Яндекс.Метрика).
- **Нет фазы обучения.** Результат виден сразу, ждать «разгона» бесполезно.

## Аукцион и пороги входа

| Параметр | Еврокабинет (официальный) | Тонкабинет (через личный TG-аккаунт) |
|----------|---------------------------|--------------------------------------|
| **Порог депозита** | от **500 €** | от **20 TON** (~30 $) |
| **Минимальный CPM** | от ~0,5 € (реально 1–2 € в большинстве тематик) | от **0,1 TON** (~13–15 центов) |
| **Модели таргетинга** | Target Channels **+ Target Users** | **только** Target Channels |
| **Топики (41 категория)** | да | нет |
| **Геотаргетинг (город/область/девайс/OS)** | да (в русских еврокабинетах через IP) | нет |
| **Агентские комиссии** | да (технические) | **нет** |
| **Конкуренция в аукционе** | выше | ниже (выше CTR) |
| **Когда выбрать** | РФ/СНГ, нужны Users/топики/гео, большой бюджет | старт без 500 €, Балканы/Европа (еврокабинетов под Европу нет), низкая конкуренция |

- **Аукцион — закрытый по тематике.** При Target Channels конкуренция только внутри своей тематики (обособленные аукционы).
- **Контроль бюджета:** дневной лимит + общий бюджет; списание по факту показов; пополнение кратно 10 € (еврокабинет).
- **Открытие еврокабинета:** авторизация через Telegram → пополнение от 500 € международной картой (часть карт блокируется — пробуй другой банк) → кампания → модерация (несколько часов) → старт. Пошагово: `references/targeting-cabinets.md`.
- **Тонкабинет (Балканы/Европа):** проверка ёмкости — собрать 5–10 локальных каналов на нужном языке → прогнать через **Similar Channels** → увидеть реальный потенциал.

## Четыре модели таргетинга

Два измерения — **что таргетим** (топики ↔ конкретные каналы) × **как показываем** (Channels ↔ Users):

| Модель | Объём | Релевантность | CPM | Стабильность | Вердикт |
|--------|-------|---------------|-----|--------------|---------|
| **Каналы + Channels** | низкий | высокая | средний | стабильно | **база, лучший старт** |
| **Каналы + Users** | средний | падает | ниже | средне | расширение охвата + ретаргетинг |
| **Топики + Channels** | большой | средняя | низкий | нестабильно («скальпинг») | широкие массовые ниши при больших бюджетах |
| **Топики + Users** | сотни млн | минимальная | минимальный | минимальная | **не рекомендуется** |

### «Топики — это море, каналы — это его капли»

**41 топик** (тематика канала, не интерес пользователя) = сотни тысяч каналов → десятки миллионов показов в сутки. **Конкретный канал** — тысячи–десятки тысяч показов.

- Топики просты в управлении, но нестабильны → «скальпинг результатов»: каждый день показы в разных каналах. Стабильные выводы — только на больших бюджетах.
- **Бюджеты до 500K ₽/мес → только конкретные каналы.**
- **Узкие ниши** (консалтинг, B2B, юриспруденция) = каналы. **Широкие массовые** (психология, здоровье, рецепты) = можно топики.
- **Серые топики — НИКОГДА:** `ASERS / Others`, `BS and Gambling`, `Offers and Promotions` (спамеры, скамеры, лудоманы). Исключение: `Offers and Promotions` для e-commerce с акциями.

### Target Channels vs Target Users

- **Target Channels** — показ **всем**, кто заходит в выбранный канал. Высокая релевантность, ограниченная ёмкость. Доступна везде. **С этого начинаем.**
- **Target Users** — реклама «прилипает» к подписчику выбранных каналов и показывается в **любом** канале. Шире охват, ниже CPM, **но ниже релевантность и CTR**. Только еврокабинеты. Для масштабирования.

> **Палка о двух концах (Users):** если CTR и конверсия падают сильнее, чем CPM, итоговый CPA дороже. Users работает, **только если CPM снижается быстрее, чем падает конверсия**.

Полная матрица, кастомные аудитории, ClientCorp8 Маркетолог Pro, 6 способов подбора каналов — **`references/targeting-cabinets.md`**.

## Подбор каналов и прогноз ёмкости

**6 способов собрать подборку** (детали — `references/targeting-cabinets.md` §5):
1. **Личный список + нетворк** — быстрый старт.
2. **TGStat + Telemetr** — поиск по тематике/ключам (ERR24, лучшие посты).
3. **Telegram Search** — узкие/редкие ниши.
4. **Similar Channels в Premium** — пересечение аудиторий (нужен Telegram Premium).
5. **Similar Channels в Ads-кабинете** — **бесплатно**, даже без пополнения.
6. **Спай-сервисы TGMaps + TGSpice** — объявления конкурентов → см. скилл `ad-spy`.

**Формула RPP:**
```
Показы в неделю = RPP × Постов в неделю        (RPP = Reach Per Post, среднесуточный охват публикации)
Бюджет в неделю = (Показы / 1000) × CPM
```
Пример: RPP 7 000 × 3 поста/нед = 21 000 показов; при CPM 2,5 € → ~52,5 €/нед. Это **потолок** — реально меньше из-за конкуренции.

## Форматы объявлений и наценки CPM

| Формат | Наценка к CPM | Заметка |
|--------|---------------|---------|
| **Текст** (заголовок + до 160 симв. + кнопка) | **0 %** | база, с неё снимаем бенчмарки CTR |
| **Кастомные/анимированные эмодзи** | **+20 %** | ⭐ лучшее соотношение цена/результат |
| **Аватарка** (квадрат логотипа) | **+30 %** | слабый эффект, не оправдывает стоимость |
| **Баннер** | **+50 %** | только Target Channels |
| **Видео** | **+70 %** | только Target Channels |

- **Наценки суммируются:** баннер + эмодзи = +70 %; видео + эмодзи = +90 %.
- **Правило баннера:** рост CTR (~×2) должен **перебить наценку CPM в процентах**, иначе невыгодно.
- **Бесплатные приёмы ↑CTR:** короткое объявление (до 40 симв. — блок сужается, выбивается из ленты); кастомные эмодзи (код символов не считается в лимит 160); цветовая тема канала (слабый эффект).

Хуки, эмодзи-механика, комбинаторный A/B 5×4 — **`references/creatives-formats.md`**.

## Воронки в Telegram (3 типа)

| Тип | Куда трафик | Когда | Ориентир (см. оговорку в бенчмарках) |
|-----|-------------|-------|--------------------------------------|
| **Прямая (перформанс)** | лендинг / квиз / сайт | лиды сейчас, простой продукт | кейс: ROMI ~500% на первом запуске (позже ~200%) |
| **Контентная через канал** | канал → прогрев → продажа | высокий чек, есть ресурс на контент, горизонт 4–8 нед | кейс: ROMI ~2300% на первом запуске |
| **Через бот** | в TG-бота | дополнение к каналу: сбор базы, дожим в флайт | **80% самостоятельных бот-воронок = негатив** |

- **Прямая:** объявление → клик → сайт → заявка → квал-лид → продажа. Прогнозируема, лиды сегодня; минус — холодная аудитория. Разновидности: ленды/квизы, вебинарные воронки (доходимость 40–50%), tripwire.
- **Контентная (самая популярная в ТГ):** объявление → подписка → **контентный прогрев ~4 недели (90% пользы, почти без продаж)** → продающий прогрев 2 недели → лидген. **Главная ошибка — пропуск контентного прогрева.**
- **Бот:** модерация TG Ads режет эмоциональность (нельзя капслок, обилие эмодзи, «ты») → конверсия падает в 3+ раза. Идеален как **коллектор базы**: переливаем аудиторию из канала через оффер-плюшку → триггерные цепочки.

Полная экономика кейсов, Performance Analysis конкурентов — **`references/funnels-cases.md`**.

## Контент-стратегия канала (для контентной воронки)

| Период | Полезный | Продающий | Лайфстайл |
|--------|----------|-----------|-----------|
| **Набор подписчиков** (контентный прогрев) | **90 %** | 0 % | 10 % (о себе) |
| **Стандарт** (без запусков) | **75 %** | 20 % | 5 % |

Продающий превышает полезный → отписки и падение охватов. Текст в ТГ нативнее видео/аудио. Написание постов → `tg-post`; детали → `references/funnels-cases.md`.

## Омниканальность (TG Ads × органика × посевы)

TG Ads — лучше всего **усилитель** уже выстроенной системы:

- **«Закреп снизу»** (Target Channels → свой канал) — объявление постоянно в топе ленты **своего** канала: блокирует слот конкурентам, держит ссылку на оффер без продающих постов.
- **Ретаргетинг подписчиков своего канала** (Target Users → свой канал) — вытаскивает **70–80% «спящих»** подписчиков в период флайта без перегрева канала.
- **Посевы + TG Ads** — при покупке интеграции параллельно таргетируем TG Ads на тот же канал: выход интеграции = приток посетителей = показы рекламы. Допкост 10–30% к интеграции, эффект значительно выше.
- **Гибридная воронка** — трафик на **конкретный пост** в канале: в посте и оффер-ссылка, и подписка. Два сценария сразу.

Механики пошагово — `references/funnels-cases.md`.

## A/B-тестирование (комбинаторный принцип)

- **Только параллельные тесты** (один период), меняется **один параметр** — нет фазы обучения, последовательные тесты искажаются календарём.
- **Кампаний = объявления × аудитории.** Объявление плохо со **всеми** аудиториями → проблема в объявлении; аудитория плохо со **всеми** объявлениями → проблема в аудитории.
- **Аудитории важнее креативов** → при 20 кампаниях баланс **5 объявлений × 4 аудитории**.
