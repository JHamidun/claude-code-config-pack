# ManyChat Funnel (RU) — автоворонки «комментарий → директ»

Конкретная no-code механика превращения **органического контента в лиды**: пользователь пишет ключевое слово в комментариях под Reels/постом → ManyChat автоматически шлёт ему цепочку сообщений в личку → прогревает ценностью → ведёт к лиду и продаже.

Источник — блок Ninja Marketing: **Рома Кумар** (`@KumiKingKong`, L31 «Машинка контента» — ManyChat как последний слой контент-фабрики) + мастермайнды (L18 кейс Александра: «воронка через комментарии Reels + ManyChat», L42 AI-продажи). ManyChat — сквозная техника, упоминается в L18/L31/L42.

> **Граница скилла.** Здесь — КАК устроена и настраивается ManyChat-воронка «коммент → директ» для IG/FB/TG. Это **не** разработка собственных ботов на Telethon/Grammy (→ `telegram-bot-toolkit`, `autonomous-agent-creator`) и **не** universal-автоматизация на n8n. ManyChat — это no-code SaaS-конструктор диалоговых воронок поверх Instagram/Messenger/Telegram. Этот скилл — слой конверсии ПОВЕРХ контента: контент даёт просмотры, ManyChat превращает их в лиды.

## 🎯 ГЛАВНЫЙ ПРИНЦИП — контент без воронки теряет лиды (Кумар L31)

> Просмотры — это **прокси-метрика**. Главная метрика — **лиды из SMM**, не охваты.

Машинка контента генерирует виральные просмотры. Но без автоворонки внимание не конвертируется. ManyChat — это **мост от просмотра к лиду**:

- Контент = вход в воронку: комментарии → автоворонки (ManyChat) → ключевые слова → сообщения в директ → ценность → прогрев → продажа.
- **Результат (бенч Кумара L31):** даже с **10–15K подписчиков** десятки процентов лидов могут приходить из SMM — при работающей ManyChat-воронке.
- **Сигнал из мастермайнда (L18):** ManyChat + комментарии Reels = сотни лидов с фантастической окупаемостью.

ManyChat стоит **~$20/мес** — копейки против стоимости платного трафика на тот же объём лидов.

## ⚙️ МЕХАНИКА «КОММЕНТ → ДИРЕКТ» (5 шагов)

```
1. КОНТЕНТ      Reels / пост с CTA «напиши слово X в комментариях»
       ↓
2. ТРИГГЕР      Пользователь пишет ключевое слово в комментарии
       ↓
3. АВТО-DM      ManyChat ловит слово → шлёт первое сообщение в директ
       ↓
4. ПРОГРЕВ      Цепочка: ценность → ценность → квалификация → CTA
       ↓
5. ЛИД          Лид-магнит / регистрация / заявка → передача в CRM/продажу
```

**Почему это работает:**
- **Снимает трение.** Человеку не надо уходить из ленты на сайт — он просто пишет слово. Действие на 1 тап.
- **Прогревает алгоритм.** Комментарии = сигнал вовлечённости → платформа шире разносит пост → больше триггеров.
- **Квалифицирует.** Написал слово = проявил интерес. Дочитал карусель/досмотрел Reels = уже тёплый (см. ниже «карусели как фильтр»).
- **Масштабируется без людей.** Одна воронка обрабатывает тысячи диалогов параллельно.

## 🔑 РАЗНЫЕ КЛЮЧЕВЫЕ СЛОВА ПОД КАЖДЫЙ ОФФЕР (Александр, L18)

Ключевой приём из мастермайнда: **«воронка комментарий → ManyChat → директ с разными ключевыми словами под каждый оффер»**.

| Контент | Ключевое слово | Куда ведёт автоцепочка |
|---|---|---|
| Reels про метод A | `МЕТОД` | Гайд по методу → запись на разбор |
| Пост-кейс | `КЕЙС` | Разбор кейса → консультация |
| Карусель-чеклист | `ЧЕКЛИСТ` | PDF-чеклист → подписка на канал |
| Анонс вебинара | `ВЕБИНАР` | Регистрация на вебинар → напоминания |

**Правила выбора слов:**
- Одно слово = один оффер = одна цепочка. Не мешай офферы в одной воронке.
- Слово короткое, заглавными, на языке аудитории (RU: `ГАЙД`, `ХОЧУ`, `СТАРТ`, `ПЛАН`).
- Слово прямо в видео/посте + в подписи. Проговори вслух в Reels («напиши СТАРТ в комментах»).
- Избегай слов, которые люди пишут случайно (нейтральные «да», «круто» дают ложные срабатывания).

Каждый оффер → отдельный flow → отдельная атрибуция (видно, какой контент даёт лиды).

## 🎴 КАРУСЕЛИ КАК ФИЛЬТР (мастермайнд L18)

> **«Карусели как фильтр: кто дочитал — уже квалифицирован»** (L18).

Карусель — встроенный квалификатор перед воронкой:
- Свайп до последнего слайда = микро-инвестиция внимания. Дочитавший = тёплый лид.
- CTA с ключевым словом ставь **на последнем слайде** — его видят только дочитавшие.
- Так в ManyChat-директ попадают уже отобранные люди, а не вся холодная лента.
- Связка: карусель-агент машинки контента (1 формат = 1 агент) → ключевое слово на финальном слайде → ManyChat flow. Под карусели → `instagram-post`.

## 📐 АРХИТЕКТУРА ПРОГРЕВА В ДИРЕКТЕ

Цепочка сообщений = **каскад ценности**, а не сразу продажа:

```
Сообщение 1  →  Доставка обещанного (гайд/PDF/ссылка) + лёгкий вопрос
Сообщение 2  →  Ценность №2 (инсайт/пример) — БЕЗ продажи, строим доверие
Сообщение 3  →  Квалификация (1 вопрос: «что у тебя сейчас с X?»)
Сообщение 4  →  Оффер/CTA под ответ (регистрация / разбор / заявка)
Recovery     →  Если молчит — догоняющее через 24ч с новым углом
```

**Тон и темп:**
- Пиши как человек, не как робот. Короткие реплики, живой RU, эмодзи дозированно.
- Сначала отдай ценность (обещанное), потом проси. Не продавай в первом же сообщении.
- Пауза между авто-сообщениями (минуты/часы), чтобы не выглядеть спамом.
- Кнопки быстрых ответов (quick replies) → меньше трения, выше CR.
- Drop-off recovery: один догоняющий месседж тем, кто не дошёл до CTA.

## 🔁 WORKFLOW НАСТРОЙКИ (быстрый старт)

5. **Запиши контент с CTA** — в видео и подписи проговори ключевое слово.
6. **Поставь метки/теги** — на каждом шаге flow ставь tag (для сегментации и атрибуции).
7. **Подключи передачу лида** — webhook → CRM / Google Sheets / n8n, чтобы лид не терялся.
8. **Замеряй «лиды из SMM»** — главный KPI. Воронка метрик в `references/content-integration.md`.

| Метрика | Что показывает |
|---|---|
| Комментарии с ключевым словом | Сколько триггеров дал пост |

## ⚠️ ОГРАНИЧЕНИЯ И АНТИ-БЛОК

- **Meta может ограничивать** автоматизацию Instagram/Messenger (правила меняются). Не шли холодные сообщения без триггера; отвечай только на инициированный пользователем контакт (он написал слово первым — это разрешённый паттерн).
- **24-часовое окно Messenger/IG** — вне окна Meta ограничивает свободную отправку (нужны платные/utility-сообщения). Прогрев укладывай в первые 24ч.
- **Fallback на Telegram.** Если IG-аккаунт ограничен — дублируй воронку в Telegram через ManyChat TG-канал (или свой бот через `telegram-bot-toolkit`).
- **Не спам.** Ценность → ценность → CTA. Агрессивная продажа в первом сообщении = жалобы и бан.
- ManyChat — **no-code SaaS**, не путать со своими ботами. Для кастомной логики/CRM-связок backend делай через webhook → n8n.
