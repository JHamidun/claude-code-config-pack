# Content Integration — связь с контент-машиной, метрики, кейсы

Как ManyChat-воронка встраивается в машинку контента, почему карусели работают как фильтр, как считать «лиды из SMM» — плюс кейсы из практики.

---

## 1. Место ManyChat в машинке контента

ManyChat — **последний слой** контент-фабрики. Без него виральные просмотры не превращаются в деньги.

```
МАШИНКА КОНТЕНТА (6 шагов)
  100-500 аккаунтов → радар-аккаунт → трендвотчер →
  декомпозиция → AI-агенты (1 формат = 1 агент) → АВТОВОРОНКИ ManyChat ← здесь
                                                        ↓
                          комментарии → ключевые слова → директ → прогрев → ЛИД
```

Логика машинки контента:
> Контент = вход в воронку:
> комментарии → автоворонки (ManyChat)
> ключевые слова → сообщения в директ
> ценность → прогрев → продажа

**Каждый формат-агент кормит воронку:**
- Reels-агент → Reels с CTA «напиши слово» → flow A.
- Карусель-агент → карусель с CTA на последнем слайде → flow B.
- Пост-агент → пост-кейс с ключевым словом → flow C.

Один формат = один AI-агент = один оффер = одно ключевое слово = один flow. Чистая система, чистая атрибуция.

> Этот скилл (`manychat-funnel-ru`) детализирует конверсионный слой «машинки контента» (6-шаговый pipeline производства контента, unit-экономика, KPI).

## 2. Карусели как фильтр квалификации

> **«Карусели как фильтр: кто дочитал — уже квалифицирован».**

Карусель отбирает тёплых ДО входа в воронку:

| Слайд | Роль |
|---|---|
| 1 (хук) | Ловит внимание, останавливает свайп |
| 2–N (ценность) | Раскрывает тему — отсеивает нецелевых (им скучно, они уходят) |
| Последний | **CTA с ключевым словом** — видят только дочитавшие = квалифицированные |

Эффект: в ManyChat-директ попадают не вся холодная лента, а люди, которые **проинвестировали внимание** (досвайпали до конца). Это поднимает CR прогрева DM → лид, потому что вход уже отфильтрован.

Связка: `instagram-post` (производство карусели) → ключевое слово на финальном слайде → keyword-триггер ManyChat (см. `setup.md` §2).

## 3. Метрика «лиды из SMM» — главный KPI

> Просмотры — прокси-метрика. **Ключевая метрика — лиды из SMM.**

Не меряй охваты — меряй лиды. Считай воронку поэтапно:

```
Просмотры контента
   ↓  (прокси — НЕ главная цель)
Комментарии с ключевым словом        ← сколько триггеров дал пост
   ↓  CR коммент → старт DM
Старты диалога в директе             ← Meta иногда режет доставку
   ↓  CR DM → прохождение прогрева
Дошли до CTA                          ← качество цепочки
   ↓  CR CTA → заявка
ЛИДЫ ИЗ SMM (всего)                  ← ★ ГЛАВНАЯ МЕТРИКА
   ↓
CPL из SMM = (команда + инструменты) / лиды   ← со временем падает
```

**Почему CPL падает (стратегический плюс машинки):**
- Машинка не требует роста рекламного бюджета.
- Масштабируется без пропорционального роста команды (растёт число AI-агентов, не людей).
- Медийный актив накапливается → стоимость привлечения со временем стремится к стоимости команды + инструментов (~$20/мес ManyChat + AI-агенты).

**Бенч для сверки:** даже с **10–15K подписчиков** десятки процентов лидов могут приходить из SMM при работающей ManyChat-воронке.

**Бенч конверсии в бота:** «через бота в регистрацию» ~**15–20%** — близкий порядок для прогрева в мессенджере (исходно про платный TG-посев, но ориентир для DM-прогрева валиден).

## 4. Атрибуция по офферам

Раздельные ключевые слова + теги дают чистую картину «какой контент = какие лиды»:

| Оффер | Слово | Flow | Тег лида | Лидов/мес |
|---|---|---|---|---|
| Гайд по методу | `МЕТОД` | A | `lead_method` | ? |
| Разбор кейса | `КЕЙС` | B | `lead_case` | ? |
| Вебинар | `ВЕБИНАР` | C | `lead_webinar` | ? |

Из тегов ManyChat → сводка: какой формат-агент и какой оффер приносит больше лидов из SMM → усиливаешь рабочее, режешь слабое. Это и есть «инженерный SMM», а не «постим и надеемся».

## 5. Кейсы из практики

**Мастермайнд-кейс (Reels-воронка):**
- Воронка через комментарии Reels + ManyChat.
- Ключевое слово → автоцепочка в директ.
- **Разные ключевые слова под каждый оффер.**
- Сигнал: «ManyChat + Reels комментарии = сотни лидов с фантастической окупаемостью».
- Доп. инсайт: «нефотогеничность — преимущество в 2026» (живой, не глянцевый контент конвертит лучше).

**Машинка контента:**
- ManyChat — финальный слой фабрики: контент → комментарии → автоворонка → директ → прогрев → продажа.
- С 10–15K подписчиков — десятки % лидов из SMM.
- ManyChat ($20/мес) для Instagram/Telegram — копейки против платного трафика.

**Карусель-фильтр:**
- CTA с ключевым словом на последнем слайде → в директ попадают только дочитавшие = квалифицированные лиды.

**Сквозная техника:**
- ManyChat-механика «коммент → директ» проходит через всю методологию: мастермайнд-разборы, машинку контента и AI-продажи — это не разовый трюк, а опорная техника превращения органики в лиды.

## 6. Применение для разных платформ

| Платформа | Особенность ManyChat-воронки |
|---|---|
| **Instagram** | Главный канал. Reels + карусели → коммент → DM. Требует IG Business + FB Page. Окно 24ч, Meta-ограничения. |
| **Facebook** | Messenger flow от комментариев под постами Page. Те же 24ч-правила. |
| **Telegram** | Свой бот через ManyChat. Меньше ограничений по окну, чем у Meta. Хороший fallback при блоке IG. Для глубокой кастомизации → `telegram-bot-toolkit`. |

Выбор платформы — где живёт твоя аудитория.
