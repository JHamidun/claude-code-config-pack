# Setup — пошаговая настройка ManyChat-воронки «коммент → директ»

Конкретная настройка механики «ключевое слово в комментарии → автоцепочка в директ» для Instagram / Facebook / Telegram. Источник методологии — экспертная методология и мастермайнды. Детали платформы — общеизвестные возможности ManyChat (~$20/мес тариф Pro).

---

## 0. Что нужно до старта

- Аккаунт ManyChat (Pro-тариф, ~$20/мес — нужен для keyword-триггеров и комментариев).
- Для **Instagram**: бизнес/creator-аккаунт IG, привязанный к Facebook Business Page (требование Meta).
- Для **Facebook**: FB Page с правами админа.
- Для **Telegram**: токен своего бота от @BotFather, подключённый к ManyChat.
- Готовый **оффер** и **лид-магнит** (гайд/PDF/чеклист/регистрация) — то, что обещаем в обмен на коммент.
- Контент с CTA (Reels/пост/карусель), где проговорено ключевое слово.

> ⚠️ Один оффер = одно ключевое слово = один flow. Не смешивай. Это даёт чистую атрибуцию по контенту.

---

## 1. Подключение каналов

| Канал | Как подключить | Нюанс |
|---|---|---|
| Instagram | Settings → Channels → Instagram → Connect (через FB Business) | Нужен IG Business + FB Page |
| Facebook | Settings → Channels → Facebook → выбрать Page | Права админа Page |
| Telegram | Settings → Channels → Telegram → вставить токен бота | Бот создаётся в @BotFather |

После подключения проверь, что ManyChat видит аккаунт и имеет права на сообщения и комментарии.

---

## 2. Keyword Trigger (ключевое слово)

1. **Automation → New Automation** (или Keywords / Growth Tools в зависимости от версии UI).
2. Выбери триггер **Comment** (комментарий под постом/Reels) или **Keyword** (DM-слово).
3. Задай ключевое слово: короткое, заглавными, на языке аудитории — `СТАРТ`, `ГАЙД`, `ХОЧУ`, `ПЛАН`, `КЕЙС`.
4. **Match type:** «contains» (содержит) — ловит слово в любом месте комментария. Для строгих слов можно «is».
5. Привяжи к посту: **конкретный** Reels/пост (точная атрибуция) или **any post** (универсальная воронка под все посты с этим CTA).
6. Включи авто-ответ в комментариях (public reply) — ManyChat публично отвечает «отправил тебе в директ ✅», это дополнительный соц-сигнал алгоритму.

**Правила слов:**
- Не нейтральные («да», «круто») — будут ложные срабатывания.
- Разные слова под разные офферы → разные flow → раздельная аналитика.
- Проговори слово вслух в Reels + продублируй в подписи поста.

---

## 3. Сборка flow (цепочка прогрева)

Каждый flow = каскад ценности (не продажа в лоб). Структура:

```
[Старт DM]
  → Текст: «Привет! Держи [обещанное], как и говорил 👇» + ссылка/файл
  → Quick reply: «Спасибо!» / «Расскажи подробнее»

[Сообщение 2 — ценность]   (через паузу)
  → Инсайт/пример БЕЗ продажи. Строим доверие.

[Сообщение 3 — квалификация]
  → Один вопрос: «А что у тебя сейчас с [боль]?»
  → Кнопки-варианты ответа (сегментируют аудиторию)

[Сообщение 4 — CTA под ответ]
  → Регистрация / разбор / заявка. Ссылка или кнопка.

[Recovery — если молчит 24ч]
  → Догоняющий месседж с новым углом / напоминанием
```

**Технически в ManyChat:**
- Блоки **Send Message** + **Delay** (паузы минуты/часы между сообщениями).
- **Quick Replies / Buttons** на каждом шаге — снижают трение, повышают CR.
- **Condition / Split** по ответу пользователя → разные ветки под сегменты.
- **Actions → Set Tag** на каждом шаге (для сегментации и атрибуции, см. §5).

---

## 4. Прогрев — правила тона

- Пиши **живым RU**, как человек, не как робот. Короткие реплики.
- **Сначала отдай ценность** (доставь обещанное), потом проси. Не продавай в первом сообщении.
- **Паузы** между авто-сообщениями — выглядит как диалог, а не спам-залп.
- **Эмодзи дозированно** — 1–2 на сообщение, не гирлянда.
- **Один вопрос за раз** в квалификации — не анкета.
- **Drop-off recovery** — ровно один догоняющий месседж тем, кто не дошёл до CTA. Не долби.

---

## 5. Теги и сегментация

На каждом шаге flow ставь **tag** через Action → Set Tag:

| Шаг | Тег | Зачем |
|---|---|---|
| Вошёл в воронку | `smm_lead_<оффер>` | Атрибуция: какой контент дал лид |
| Дочитал прогрев | `warm_<оффер>` | Тёплый сегмент |
| Оставил заявку | `lead_<оффер>` | Главная метрика — лиды из SMM |
| Не дошёл до CTA | `dropoff_<оффер>` | Для recovery-рассылки |

Теги → потом сегментированные рассылки (broadcast) и чистая воронка метрик.

---

## 6. Передача лида (webhook → CRM)

Чтобы лид не остался в ManyChat, а ушёл в продажу:

1. В flow на шаге «оставил заявку» добавь блок **Action → External Request (webhook)**.
2. Отправь данные (имя, IG-ник, ответы квалификации, тег оффера) на:
   - **n8n** (`n8n` skill) → дальше в любую систему.
   - **Your CRM** (`crm` skill) → создать лид/сделку.
   - **Google Sheets** → простой реестр лидов.
3. Так финальный слой воронки «коммент → директ → лид → **продажа**» замыкается на CRM.

---

## 7. Проверка перед запуском (чек-лист)

- [ ] Канал подключён, права на сообщения и комментарии есть.
- [ ] Ключевое слово задано, match type корректный, привязан к посту.
- [ ] Flow собран: старт → ценность → квалификация → CTA → recovery.
- [ ] Паузы между сообщениями стоят (не залп).
- [ ] Теги ставятся на каждом ключевом шаге.
- [ ] Webhook в CRM работает (тестовая заявка дошла).
- [ ] Контент записан, слово проговорено в видео + в подписи.
- [ ] Прогрев укладывается в 24ч (окно Meta).
- [ ] Тест: сам написал слово в коммент → пришло DM → прошёл цепочку до конца.

---

## Анти-блок (Meta-ограничения)

- Отвечай **только на инициированный** пользователем контакт (он написал слово первым) — это разрешённый паттерн, не холодный спам.
- **24ч окно** IG/Messenger — весь прогрев в первые сутки; вне окна Meta режет свободную отправку.
- При ограничении IG-аккаунта — **дублируй воронку в Telegram** (тот же flow на TG-канал ManyChat, либо свой бот через `telegram-bot-toolkit`).
- Не шли холодные сообщения без триггера — это путь к бану.
