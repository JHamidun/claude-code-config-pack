# Машинка контента (OS) — фабрика органического контента

Операционная система для разворачивания **«машинки контента»** — системного процесса массового производства Reels / Shorts / постов / сторис, который работает **как бизнес внутри бизнеса**: стабильно даёт органический трафик, превращается в полноценный канал продаж и со временем снижает стоимость лида до стоимости команды и инструментов.

> **Это не хаотичный SMM. Это инженерный подход к контенту.**

## 🏭 ГЛАВНАЯ ИДЕЯ — фабрика, бизнес внутри бизнеса

Машинка контента — это **не контент-план и не «постить 5 раз в неделю»**. Это производственная система с собственной экономикой, метрикой и стратегической устойчивостью.

**Цель:** получать максимум органических просмотров → превращать внимание в комментарии, подписки, лиды и продажи.

**Метрика.** Просмотры — это **прокси-метрика**. Главная метрика фабрики — **лиды из SMM** (и далее — продажи), а не охваты. Любой дашборд фабрики строится вокруг неё.

### Почему это бизнес-модель, а не тактика

| Свойство | Что даёт |
|----------|----------|
| Не требует роста рекламного бюджета | Органика — себестоимость = команда + инструменты |
| Масштабируется без пропорционального роста команды | Растёт число **AI-агентов**, а не людей |
| Стоимость привлечения **падает со временем** | CPL → стоимость команды+инструментов на горизонте месяцев |
| Создаёт **медийный актив** | Монетизируется разными продуктами; переживает смену продукта |
| Стратегическая устойчивость | Горизонт **6-12 месяцев** вперёд, а не «трафик сегодня» |

> Контент не придумывается «из головы». Он **собирается из того, что уже работает** — и пересобирается под свой продукт. Это центральный принцип фабрики: вход = виральные форматы рынка, выход = адаптированные единицы под свою воронку.

### Формула машинки

```
машинка контента = трендвотчинг
                 + системное копирование лучших форматов
                 + эмоции и дофамин
                 + масштабирование через AI
                 + автоматизированные воронки
```

## ⚙️ 6 ШАГОВ ФАБРИКИ (operational pipeline)

Полный цикл — от пустого аккаунта до органического канала продаж. Каждый шаг детально расписан в `references/six-steps.md`.

```
1. ПУЛ МОНИТОРИНГА   100-500 аккаунтов (LiveDune + ручной ресёрч)
        │            конкуренты + блогеры + эксперты + инфлюенсеры
        ▼
2. АККАУНТ-РАДАР     отдельный analyzer-аккаунт, подписан на весь пул
        │            алгоритм сам «выкармливает» ленту виралом
        ▼
3. ТРЕНДВОТЧЕР       инструмент анализа virality/engagement
        │            лучшие ролики → отбор по просмотрам/комментам/ER
        ▼
4. ДЕКОМПОЗИЦИЯ      разбор виралки: хук + сценарий + структура
        │            копируем форму, адаптируем тезисы под свой продукт
        ▼
5. AI-АГЕНТЫ         1 формат = 1 агент (сценарии/картинки/видео/карусели)
        │            масштаб = больше агентов, НЕ больше людей
        ▼
6. АВТОВОРОНКИ       контент = вход; комментарии → ManyChat → директ
                     ключевые слова → прогрев → лид → продажа
```

| # | Шаг | Что делаем | Инструмент | Главный артефакт |
|---|-----|-----------|------------|------------------|
| 1 | **Пул мониторинга** | Собрать 100-500 аккаунтов ниши + смежных | LiveDune, ручной ресёрч, Apify | `monitoring_accounts.csv` |
| 2 | **Аккаунт-радар** | Отдельный аккаунт, подписка на весь пул → «идеальная лента» | Нативный клиент IG/TikTok | Радар-аккаунт (чистая гигиена) |
| 3 | **Трендвотчер** | Найти лучшие ролики по virality/engagement | [сервис]er, virlo.ai, meedro, viralscope, свой vibe-code | Список виралок-кандидатов |
| 4 | **Декомпозиция** | Разобрать хук/сценарий/структуру → форму копируем | → `ai-creative-factory-ru` | Таблица декомпозиции |
| 5 | **AI-агенты** | Под каждый рабочий формат — отдельный агент | → `ai-marketing-stack-ru`, agent-builder tooling | Реестр форматов-агентов |
| 6 | **Автоворонки** | Comment-keyword → DM → прогрев → продажа | → `manychat-funnel-ru` | Flow comment→DM |

> Важно: шаги **1-3** — это «радар» (что копировать), шаг **4** — мост (как именно устроена виралка), шаги **5-6** — «конвейер + монетизация». Эта операционка — каркас; «мясо» каждого шага (хук, декомпозиция, агент, воронка) делегируется соседним скиллам.

### Ключевой scaling-принцип: «1 формат = 1 агент»

> **Не увеличивать команду — увеличивать количество агентов.**

- Выявляются форматы, которые можно автоматизировать (Reels-нарезки, карусели-подборки, говорящая голова, сторис-дайджест и т.д.).
- Под **каждый формат** создаётся отдельный AI-агент: генерация сценариев / изображений / видео / каруселей.
- **Один агент = один формат.** Так снимается главное бутылочное горлышко — **объём контента**.
- Бутылочное горлышко смещается: было «сколько людей в команде» → стало «сколько форматов мы оцифровали в агентов». Подробнее об архитектуре — `references/operational-layer.md`.

## 📈 OPERATIONAL LAYER (экономика, KPI, roadmap)

Фабрика — это одновременно **продаваемый консалтинг-продукт** (упаковывается в дек/КП для клиента) И инструмент для собственного бизнеса. Здесь — то, что превращает «постить контент» в управляемую производственную систему. Полностью — в `references/operational-layer.md`.

### Unit-экономика (упрощённо)

```
CPL_органика  = (стоимость команды + стоимость инструментов + платный разгон) / лиды из SMM
```

- В начале CPL высокий (нет накопленного актива, мало форматов-агентов).
- По мере того как агенты тиражируют рабочие форматы и растёт база подписчиков — CPL **падает к себестоимости команды+инструментов**.
- **Break-even** — точка, где CPL органики ≤ CPL платных каналов. С этого момента фабрика — чистый рычаг.

### KPI-иерархия

| Уровень | Метрика | Зачем |
|---------|---------|-------|
| 🥇 Главная | **Лиды из SMM** (и продажи) | Единственная метрика, ради которой существует фабрика |
| 🥈 Воронка | CR `comment → DM`, CR `DM → регистрация` | Здоровье автоворонки |
| 🥉 Производство | Кол-во единиц / неделю на формат, стоимость единицы | Эффективность агентов |
| 📊 Прокси | Просмотры, ER, виральность | Ранний сигнал, НЕ цель |

> Ориентир: **с 10-15K подписчиков** десятки процентов лидов могут приходить из SMM — при работающей ManyChat-воронке.

### Roadmap 0-3-6-12 месяцев

| Веха | Что должно быть готово |
|------|------------------------|
| **0 мес** | Аудит ниши, собран пул 100-500 аккаунтов, поднят радар-аккаунт, выбран трендвотчер |
| **3 мес** | 2-3 рабочих формата стабильны, первые автоворонки, первые лиды из SMM |
| **6 мес** | Под каждый рабочий формат — свой AI-агент; объём контента не упирается в людей |
| **12 мес** | Самоокупаемый медийный актив; CPL ≤ платных каналов; фабрика — отдельный канал продаж |

Детальные чек-листы развёртывания, штатное расписание (которое почти не растёт), vendor-list и троублшутинг — в `references/operational-layer.md`.

## 🎬 РЕЖИССЁРСКИЙ MINDSET (как фабрика думает о единице)

Чтобы конвейер не выдавал слоп, единица производится **как режиссёр**, а не «одним промтом»:

```
❌ «сделать видео одним промтом»
✅ идея → сценарий → раскадровка → старт-фреймы → анимация → монтаж → ритм
```

И чтобы AI-контент **не «палился»** (anti-AI-slop): менять кодек, апскейлить, заменять аудио, правильно монтировать, избегать AI-слопа. Людям важна **ценность и эмоция**, а не способ производства.

> Конкретику хука, 5-блочного канона, дофаминовых триггеров и техник anti-AI-slop **бери в `ai-creative-factory-ru`** — здесь это только напоминание, что конвейер обязан их соблюдать.

## 🔧 WORKFLOW: развернуть машинку контента

Когда пользователь говорит «разверни машинку контента / контент-фабрику»:

1. **Определи объект и нишу.** Под кого фабрика — свой бизнес или клиент? Какая ниша + смежные? (для self-service — подтяни контекст своего продукта: ICP, оффер, позиционирование).
2. **Зафиксируй цель и метрику.** Лиды из SMM как №1. Сколько лидов/мес нужно, какой продукт монетизирует поток.
3. **Шаг 1-2 — радар.** Собери пул 100-500 аккаунтов (LiveDune + ручной ресёрч + Apify-рецепт из `apify-scraping`), заведи аккаунт-радар. Артефакт: `monitoring_accounts.csv`.
4. **Шаг 3-4 — что копировать.** Прогони трендвотчер, отбери виралки, **передай в `ai-creative-factory-ru`** для декомпозиции (хук/сценарий/структура).
5. **Шаг 5 — агенты.** Составь реестр рабочих форматов, под каждый — спека AI-агента (делегируй сборку в `ai-marketing-stack-ru` / agent-builder tooling). Правило: 1 формат = 1 агент.
6. **Шаг 6 — воронка.** Свяжи контент с автоворонкой comment→DM — делегируй построение flow в `manychat-funnel-ru` (keyword→директ→прогрев→продажа), бэкенд-интеграции в `n8n`.
7. **Operational layer.** Посчитай unit-экономику, собери KPI-дашборд (лиды из SMM в центре), разложи roadmap 0-3-6-12. См. `references/operational-layer.md`.
8. **Разгон.** Для платного буста органики — посевы в TG (`tg-channel-buyout-ru`): паблики разгоняют Reels-алгоритм через соавторство.

> При работе с фабрикой как **консалтинг-продуктом для клиента** — оформляй итог как дек/КП с roadmap и экономикой.
