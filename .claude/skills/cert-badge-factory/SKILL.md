# Сертификаты и бейджи

Выпускает именные сертификаты (PDF + PNG) и цифровые бейджи в двух готовых темах,
с машинной проверкой вёрстки. Выдача бейджей — через Accredible (по желанию).
Весь выпуск сертификатов и картинок бейджей работает локально и без ключей.

## Что нужно

- Python 3.10+ и пакеты `playwright`, `pillow` (для xlsx-списков ещё `openpyxl`);
  один раз `python -m playwright install chromium`.
- Шрифты уже лежат в `assets/fonts/` (Google Fonts, SIL OFL, вшиваются в HTML):
  интернет не нужен.
- Логотипы, подпись и бренд-строка в навыке — **заглушки** (`Your Company`,
  `Your School`, условный росчерк): перед выпуском подставьте свои, см. ниже.

## С чего начать

```bash
S=~/.claude/skills/cert-badge-factory

# 1. свой конфиг: скопировать пример из навыка к себе и поправить
cp $S/configs/vibe-example.json roster.json        # ещё: company-example.json, vibe-example-en.json

# 2. три образца, чтобы посмотреть глазами до полного тиража
python $S/scripts/make_certs.py --theme vibe --config roster.json --samples

# 3. сертификаты всем: HTML, затем PNG 2× и PDF (рядом с roster.json, папка certificates/)
python $S/scripts/make_certs.py --theme vibe --config roster.json --render

# бейдж под достижение (по умолчанию в ./badge_samples/)
python $S/scripts/make_badges.py --theme vibe --title "Вайбкодинг" --year 2026

# CSV для массовой выдачи в Accredible: список «ФИО;почта» по строке
# (формат — configs/roster_example.txt)
python $S/scripts/make_badges.py --roster roster.txt --csv
```

Конфиг копируют из папки навыка: результат пишется рядом с конфигом, а каталог навыка
может быть только для чтения и затирается при обновлении.

## Две темы

| Тема | Когда | Палитра | Типографика |
|---|---|---|---|
| `company` | корпоративные обучения, светлый деловой лист | сине-фиолетовый градиент `#3B3B95 → #5050C7 → #6464F8`, карточка на тёмной подложке | Segoe UI Semibold, без капса (на macOS и Linux браузер подставит Arial или Helvetica) |
| `vibe` | школа, курс, интенсив: тёмный техно-стиль | тёмный `#14151C`, терракота `#CC7357`, голубой `#4DABF7`, кремовый `#F6F4EF` | Oswald капсом + Manrope |

Палитра `vibe` снята с живого сайта-образца замером вычисленных стилей, не на глаз.

## Свои логотип, подпись и бренд

- **Логотип:** положить SVG в `assets/brand/` (или рядом с конфигом) и указать в конфиге
  `"logos": ["my_logo.svg"]`. Чёрная заливка (`fill="black"`) перекрашивается под фон
  темы, обводки (`stroke`) — нет: рисуйте заливками. Заглушки: `company_wordmark.svg`,
  `company_mark.svg` (круглый знак бейджа), `vibe_mark.svg`.
- **Подпись:** PNG с прозрачным фоном, `"signer": {"name": …, "role": …, "image": "signature.png"}`.
  Файл `assets/signature.png` — условный росчерк-заглушка.
- **Бренд-строка темы `vibe`** (знак + «Your School» + «by Your Name»):
  в конфиге `"brand": {"name": "Your", "tag": "School", "by": "by Your Name"}`,
  у бейджа — `--brand-name`, `--brand-tag`, `--brand-by`.
- **Значки инструментов в декоре** (`assets/ai_logos/`) — иллюстрация «чему учили», набор
  меняется в `AI_SPOTS` (`themes/vibe.py`) и `MEDALS` (`themes/company.py`).
- **Своя тема:** файл `themes/<имя>.py` по контракту `themes/base.py`, строка в `REGISTRY`
  (`themes/__init__.py`).

## Обязательный порядок сдачи

Три вещи, без которых работу сдавать нельзя. Каждая появилась после провала.

**1. Посмотреть глазами в реальном масштабе.** `--samples` даёт три образца:
самое длинное имя, среднее и «Фамилия И.». Открыть через Read и посмотреть.
Рендер в 2× прячет наложения — проверять только при `device_scale_factor=1`.

**2. Прогнать три чекера.** Они меряют геометрию в браузере, а не смотрят на картинку:

```bash
H="certificates/_html/*.html"       # весь тираж; образцы — certificates/_samples/*.html
python $S/scripts/check_layout.py "$H"   # наложения, обрывы, схлопнутые элементы
python $S/scripts/check_type.py   "$H"   # кегли ниже пола, интерлиньяж, трекинг, капс
python $S/scripts/check_medals.py "$H"   # каждый декоративный медальон против всех текстов
```

Чекеры читают HTML, а не картинки: образцы после `--samples` лежат в `certificates/_samples/`,
полный тираж — в `certificates/_html/` (папка `certificates/` рядом с вашим конфигом).
Запускать из папки, где лежит конфиг, или дать полный путь в кавычках.

**3. Не выхолащивать проверку.** Если чекер ругается — сначала понять, прав ли он.
Правило про пол кегля выведено для текста, который читают; на гравировку печати оно
не распространяется. Расширил исключения — проверь негативным тестом, что чекер всё
ещё ловит подложенный дефект. Зелёный отчёт должен означать «проверено», а не «ослеп».

## Что решает движок сам

- **Склонение** — «прошёл» / «прошла» по отчеству и имени; когда пол не восстановить
  («Коваленко О.»), ставится форма без рода: «участник программы».
- **Кегль имени** под длину, чтобы длинное ФИО не переносилось. Мерная линейка —
  «Ивановская Александра Владимировна», 33 знака.
- **Перекраска логотипа** под фон темы: чёрная заливка SVG пропадает на тёмном
  и желтит кремовым на светлом.
- **Неразрывный пробел** после однобуквенного предлога, чтобы «в» не висело в конце строки.

## Грабли, оплаченные временем

| Симптом | Причина |
|---|---|
| Полоска под именем невидима, в коде всё верно | в колоночном flex тонкий элемент схлопывается в НОЛЬ — нужен `flex:0 0 <высота>` |
| Логотип «пропал» на макете | чёрная заливка SVG на тёмном фоне; перекраска подбирается под фон |
| Фирменный знак в мелком круге — каша из линий | сложный знак рассчитан на крупный размер; для медальонов 12 мм нужны простые формы |
| Шрифт не тот, хотя в CSS указан верный | системные Inter и Manrope бывают битыми (на Windows автора — 303 КБ переводов строки), Chromium молча подставляет другой; поэтому шрифты вшиты |
| Чекер падает на SVG | у SVG-элементов `className` — объект `SVGAnimatedString`, не строка |
| Скрипт оборвался на середине списка | `\| head -N` убивает генератор по SIGPIPE — писать в лог, потом читать |

## Дизайн-канон

Наградной документ — это **плотность 3 по шкале design-taste**, не 8. Работа идёт
на удаление: метки-кикеры над блоками, дублирующие подписи к номеру и дате, ряды
одинаковых плашек — всё это утяжеляет лист и ничего не добавляет.

Пол читаемости: функциональный текст не мельче 11px, тело не мельче 14px, и пол
держится даже в подвале. Исключение — защитный микротекст и гравировка на печати:
их не читают построчно.

Капс с широким трекингом на кириллице читается хуже, чем на латинице: у неё меньше
выносных элементов, и капс стирает силуэт слова. Держать капс только на коротких метках.

Подробнее — `references/design-canon.md`.

## Бейджи и Accredible

Картинка бейджа — общая для всех получателей одного достижения; имя живёт в
метаданных credential, а не на картинке. Генератор рисует PNG 400×400 с прозрачным
фоном, как просит Accredible, и собирает CSV для загрузки списка в кабинете.

Нужен свой аккаунт Accredible (пробный план — до 20 получателей). Загрузка картинки и
CSV в кабинете обходится без API-ключа. Имена и почты получателей уходят в сам
Accredible — это сторонний сервис: перед выдачей убедитесь, что у людей есть на это
согласие.

> ⚠️ **NO-KEY GUARD (обязательно):** этот функционал требует ОПЦИОНАЛЬНОГО стороннего API-ключа. Перед вызовом проверь ключ в `.credentials.master.env`. Если ключ отсутствует, пустой или placeholder (`your_*_api_key`) — **НЕ проси пользователя оплатить счёт, включить биллинг или купить API**. Скажи одной строкой: «Эта функция опциональна и требует свой API-ключ (например, бесплатный ключ на aistudio.google.com); из коробки всё остальное работает по подписке Claude» — и предложи альтернативу или продолжай без неё.

Охраняется только выдача через API (`--api-json`, `ACCREDIBLE_API_KEY`): доступ к ключам
есть не на всех планах. Альтернатива готова — ручная загрузка CSV в кабинете.

Пошагово — `references/accredible.md`, про стандарт — `references/open-badges.md`.

## Чего этот скилл не делает
