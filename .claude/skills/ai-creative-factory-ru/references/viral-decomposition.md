# Viral Decomposition — декомпозиция виральных и трендвотчинг

Источник: Рома Кумар L31 (декомпозиция + аккаунт-радар) + Дмитрий Коробовцев L26 (AI-видео конвейер) + Олег Мазунин L29 (системный трендвотчинг, основатель Trendwatch AI / Viro studio).

> **Идея.** Контент не придумывается «из головы» — он **собирается из того, что уже работает.** Берёшь виральные образцы ниши, разбираешь их на паттерны, адаптируешь паттерны под свой продукт. Это не воровство ролика — это reverse-engineering структуры успеха.

---

## ЧТО копируем (и что НЕ копируем)

**НЕ копируем видео целиком.** Копируем **паттерн:**

- хук (визуальный + текстовый)
- хронометраж
- раскадровку
- структуру подачи
- дофаминовые триггеры

**Тезисы и примеры адаптируются под свой продукт.** Смысл — твой, упаковка — проверенная.

---

## Декомпозиция на 6 паттернов (L26)

Каждый отобранный виральный ролик разбирается на 6 слоёв → формируется **база успешных паттернов:**

| Слой | Что фиксируешь |
|------|----------------|
| **Хук** | Что именно в первые 0-3 сек остановило скролл (визуал + текст + звук) |
| **Сцены** | Какие сцены, в каком порядке, сколько их |
| **Монтаж** | Темп, тип переходов, ритм нарезки |
| **Текст** | Текст в кадре, субтитры, заголовки — формулировки |
| **Аудио** | Музыка/голос/SFX — тон, темп, тренд-звук |
| **Тайминги** | Длина каждого блока, где дофаминовые всплески |

**Разбор по сценам можно автоматизировать** через Gemini / GPT (video understanding) — модель смотрит ролик и расписывает сцены/тайминги. Затем база паттернов скармливается AI-агенту-сценаристу.

## Системный трендвотчинг (L29, Мазунин)

Виральные образцы надо где-то брать. Это отдельная дисциплина — поиск **долговечных, стабильно работающих** идей, а не случайных хайпов.

### Критерии годного аккаунта для слежки

- **Актуален для ниши** (твоя тема или смежная).
- **≥4 поста в неделю** (желательно ежедневно) — регулярность.
- **1 виральный пост из 9** — значительно выше среднего по самому аккаунту. Это ключевой критерий: аккаунт умеет попадать в вирусность стабильно, а не один раз случайно.

### Pipeline трендвотчинга

```
ключевые слова
  → Instagram Search (или YouTube/TikTok)
  → отбор аккаунтов по критериям выше
  → проверка регулярности (≥4 поста/нед)
  → измерение вовлечённости (просмотры/лайки/комменты)
  → отбор АНОМАЛЬНЫХ постов (выше среднего по аккаунту)
  → декомпозиция (6 паттернов)
```

**ДЗ урока 29:** собрать **20 аккаунтов** для трендвотчинга — стартовый набор сигнала.

## Аккаунт-радар вирусного контента (L31, Кумар)

Отдельный социальный аккаунт **только для слежки за нишей:**

1. Найди **100-500 аккаунтов** в нише и смежных нишах (конкуренты + блогеры + эксперты + инфлюенсеры). Важен не размер аккаунта, а просмотры / вовлечённость / повторяемость форматов.
2. Подпишись на все 100-500 с радар-аккаунта → формируется «идеальная» лента.
3. Алгоритмы соцсети сами начинают подбрасывать новые тренды.

> Это твой **радар вирусного контента** — лента превращается в автоматический поток свежих виральных образцов благодаря алгоритмическим рекомендациям.

Первичный поиск аккаунтов — через **LiveDune** + ручной ресёрч (подписки, рекомендации).

## AI-видео конвейер целиком (L26, Коробовцев)

Полный цикл фабрики, где трендвотчинг + декомпозиция встроены в начало:

```
AI собирает аккаунты конкурентов
  → парсит видео за период (Apify)
  → вытаскивает метрики (вовлечённость: likes/comments; виральность: распространение)
  → отбирает только видео с ВЫСОКОЙ вовлечённостью И виральностью
  → декомпозирует на 6 паттернов (хук/сцены/монтаж/текст/аудио/тайминги)
  → формирует базу успешных паттернов
  → AI-агент-сценарист: ТЗ + база паттернов → сценарий
  → AI-агент-производитель: генерирует видео
  → быстрые правки → экспорт под платформу → публикация
  → сбор новых данных (цикл замыкается)
```

> ИИ-видео — не «сделать красиво», а: ↓ стоимость единицы контента, ↑ скорость производства, ↑ объём тестируемых гипотез, ↑ шанс вирусности через анализ данных. **Но ИИ не гарантирует продажи** — плохой продукт + ИИ = быстрый провал.
