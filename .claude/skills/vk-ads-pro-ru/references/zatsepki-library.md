# Библиотека зацепок — шаблон

Накопительная система инсайтов Крестинина (L18). Превращает рекламу «из аморфного казино в систему, которой легко управлять».

> **Зацепка** = полезная информация об использовании параметра/сегмента/настройки, которая улучшает результат объявлений. Собираются в крупные инсайты → трафик ведётся всё эффективнее с каждым шагом.

---

## Правила ведения

1. **Фиксируй каждую находку** сразу после анализа запуска.
2. **Подтверждение на 2–3 категориях** перед тем как доверять (статус «правило»).
3. **Применяй ко всем новым тестам** — новую аудиторию запускай сразу с учётом накопленных зацепок, не с нуля.
4. **Достоверность ∝ объёму данных** — на малых цифрах это гипотеза, не правило.

**Статусы:** `гипотеза` (1 наблюдение) → `подтверждено` (2 категории) → `правило` (3+ категорий, применяется по умолчанию).

**Типы:** `пересечение (A∩B)` / `вычитание (A−B)` / `тип аудитории` / `возраст` / `гео` / `время суток` / `ставка (МЦ/ПЦ)` / `креатив` / `плейсмент`.

## Категории зацепок (что отслеживать)

| Категория | Примеры зацепок |
|-----------|-----------------|
| **Связки аудиторий** | какое `A∩B` / `A−B` / `B−A` даёт лучший CPL |
| **Обогатители** | Сэндлер, GetCourse и др. приложения-покупатели |
| **Тип аудитории** | Ф1 (ключи) дешевле категорий интересов |
| **X-коэффициент** | x2-x3 лучше в оплату, x6+ лучше в клик |
| **Возраст** | какие возрасты дёшевы / дороги в нише |
| **Гео** | топ-регионы по цене результата |
| **Время суток** | времязависимые (ночь/утро/обед под нишу) |
| **Ставка** | где выигрывает МЦ, где ПЦ |
| **Креатив** | какой из четвёрки / какое направление под температуру |

## Накопительный цикл

```
Запуск → анализ → зацепка (гипотеза)
   → проверка на 2-3 категориях → зацепка (правило)
   → применяю ко ВСЕМ новым тестам
   → новые запуски рождают новые зацепки
   → ... (система самоулучшается)
```

Цель — после N итераций иметь набор правил, при которых новый проект в знакомой нише стартует не «вслепую», а сразу с проверенными настройками.
