# Креативы для VK Ads — метод DALL-E 3 + Магритт/Дали

Практический метод генерации креативов. Цель — пробить **баннерную слепоту** через сюрреализм и несочетаемые образы, не нарушая авторских прав.

---

## Метод несочетаемых пар (пошагово)

```
1. ChatGPT придумывает НЕСОЧЕТАЕМЫЕ пары/тройки слов
   Пример: «ниндзя + кофе + ракета»

2. Открыть генератор:
   — DALL-E 3 (бесплатный, через VPN из РФ) — РАБОТАЕТ С РУССКИМ КОРРЕКТНО
   — ИЛИ Gemini / Nano Banana Pro (без VPN, лучше качество) — см. скиллы image-generation, nano-banana-pro

3. Промпт по-русски в формате:
   [объект] + [несочетаемое слово/фраза] + «крупным планом»
   + «сюрреалистическое изображение в стиле Рене Магритта / Сальвадора Дали»

4. Сгенерировать несколько вариантов, отобрать лучшие
```

### Почему работает

> Несочетаемые сочетания из двух слов придумывает ChatGPT. Дальше добавляем: крупным планом, сюрреалистическое изображение в стиле Рене Магритта или Сальвадора Дали. Это даёт нейросети больше фантазии, убирает границы буквального изображения.

> Даже кривые картинки от нейросетей на некоторых проектах давали очень хорошие результаты за счёт того, что они пробивают баннерную слепоту и привлекают больше внимания. Не отсекай эту идею сразу.

**Ключевые принципы:**
- Иррациональность привлекает внимание (мозг «спотыкается» на несочетаемом).
- Не нарушает авторские права (уникальная генерация).
- Метод заточен под **DALL-E 3** — она корректно держит русский и даёт нужный характер образов. Другие генераторы по этому методу дают хуже (но Gemini/Nano Banana — достойная замена без VPN).
- «Кривизна» допустима, если бренд позволяет — CTR важнее идеальной картинки.

## Готовые промпты под ниши

Шаблон: `[объект ниши] + [несочетаемый элемент] + крупным планом, сюрреалистическое изображение в стиле Рене Магритта / Сальвадора Дали`.

| Ниша | Пример промпта |
|------|----------------|
| **Кулинария / выпечка** | «Буханка хлеба, парящая в облаках над морем, крупным планом, сюрреалистическое изображение в стиле Рене Магритта» |
| **Авто** | «Автомобильное колесо, прорастающее цветами, на фоне пустыни с тающими часами, крупным планом, в стиле Сальвадора Дали» |
| **Инфобизнес / онлайн-курсы** | «Диплом, превращающийся в бумажный самолётик и взлетающий из открытого ноутбука, крупным планом, сюрреалистическое изображение в стиле Магритта» |
| **B2B-услуги** | «Рукопожатие двух рук, между которыми вырастает дерево с шестерёнками вместо листьев, крупным планом, в стиле Дали» |
| **E-commerce / товары** | «Картонная коробка с крыльями бабочки, парящая над городом вверх ногами, крупным планом, сюрреалистическое изображение в стиле Магритта» |
| **Финансы / инвестиции** | «Монета, плавящаяся как часы Дали и стекающая с края стола в звёздное небо, крупным планом» |
| **Здоровье / фитнес** | «Гантель, прорастающая зелёными побегами, на фоне неба с парящими яблоками, крупным планом, в стиле Магритта» |
| **Недвижимость** | «Дом с дверью, открывающейся в океан, ключ парит рядом в воздухе, крупным планом, сюрреалистическое изображение в стиле Дали» |

> Подставляй несочетаемый элемент от ChatGPT, не повторяй шаблоны буквально — новизна = весь смысл метода.

## 4 направления креативов под температуру аудитории

Тестируются **отдельными кампаниями** (не мешать в одной группе):

| Направление | Под кого | Суть |
|-------------|----------|------|
| **Интересный факт с цифрами** | холодные/тёплые | цепляет любопытством, конкретикой |
| **Прямая выгода / скидка** | тёплые | оффер «в лоб» с цифрой выгоды |
| **Сторителлинг** | холодные/тёплые | история, вовлечение через нарратив |
| **Прямой рекламный текст** | горячие `x4+` | прямая продажа — для тех, кто уже в теме |

**Роли элементов объявления:**
- **Картинка** — вырывает внимание пользователя из ленты, ведёт к заголовку.
- **Заголовок** — фильтр аудитории (отсекает нецелевых, цепляет целевых).
- **Старт теста:** разные **картинки** при **одинаковом тексте** → понять, какая визуалка работает на сегмент.

## Встроенные инструменты VK Ads

- **Медиатека с нейро-изображениями** — приемлемое качество, особенно режим **«реализм»**. Функция **«дорисовать»** расширяет картинку под нужный формат. Подходит для быстрого старта без нарушения прав.
- **Встроенная генерация текстов (заголовки/описания)** — **слабее ChatGPT**, использовать только для быстрых идей.

## Связь со скиллами

- **`image-generation`** — общий гид по промпт-инжинирингу DALL-E 3 / Imagen / SD; здесь живёт сюрреалистический пресет «Магритт/Дали».
- **`nano-banana-pro`** — замена DALL-E 3 на Gemini 3 Pro Image для тех же сюрреалистичных пар (без VPN, выше качество).
