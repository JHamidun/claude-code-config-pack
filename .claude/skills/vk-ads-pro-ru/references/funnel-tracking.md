# Оценка воронки после подписки — 4 способа

Подписка ≠ покупка. Дешёвый подписчик, который не доходит до денег, бесполезен — управлять кампанией нужно по нужному этапу воронки, а не по клику. Четыре независимых механизма; минимум один подходит любому проекту.

---

## 1. Встроенная мини-воронка кабинета

Метрика **«запуски»** (кто перешёл по ссылке мини-аппа) → **подписки**, с разбивкой по группам. Ориентир порядка величин из живого демо: 1500 переходов → 364 подписки.

## 2. Пиксель на подписной странице мини-аппа

Единственный способ получить в кабинете VK оптимизацию по реальному деньговому действию, а не по клику. Senler поддерживает точно; BotHunter — функционал дублирующий.

```
1. Поставить пиксель VK на подписную страницу мини-аппа
2. Раздел пикселя → визуальный конструктор событий (или вручную)
3. Создать цель нужной категории (напр. «Покупка»)
4. Правило срабатывания — попадание на URL страницы «спасибо» / thanks
5. Подключить цель в рекламный кабинет
6. В таблице статистики: Метрики → Конверсии → добавить цели
7. Колонки расставить в порядке ВОЗРАСТАНИЯ ценности действия:
   запуски → подписка → отписка → покупка
8. Читать как воронку на уровне групп и объявлений;
   останавливать/масштабировать по нужному этапу, а не по клику
```

## 3. Сторонние сервисы управления

**LeadHunter** (от Target Hunter) и аналогичный сервис управления рекламой VK — ведение кампаний + оценка воронки. Есть бесплатные тарифы при работе на их кабинетах и бонусы за пополнение.

## 4. «Дедовский» Excel-метод

Используется в **80% проектов** — у новых заказчиков ничего не настроено.

```
1. Excel-выгрузка из GetCourse / LMS / CRM заказчика
2. Сопоставить по UTM-меткам и ID объявлений/кампаний
3. Собрать дашборд: окупаемость на уровне кампаний, групп, объявлений
4. Ускорение: загрузить выгрузку + пример нужного результата + пару слов
   как считать → нейросеть сводит сама (раньше 1–1.5 часа руками на проект)
```

## Квал-лиды из CRM обратно в кабинет (фича с 29 июля 2026)

VK Реклама принимает из CRM статус «лид квалифицирован» по лидам из лид-форм — кабинет видит не заявку, а её качество.

```
Лид-форма VK → лид в CRM → менеджер квалифицирует → статус возвращается в VK

Настройка: раздел Пиксель → Воронки → Добавить воронку →
выбрать сервис импорта событий
Прямая интеграция: Битрикс24; остальные CRM — через API по запросу
```

⚠️ **Спикер сам её на момент урока не тестировал** — узнал за пару дней до эфира, инструмент вышел 29 июля: «поделиться результатами пока не могу, а поделиться новостью — пожалуйста». Один из участников добавил, что по сообщениям ВК фича «пока собирает данные, чтобы в дальнейшем это внедрить», — статус проверять в кабинете, а не считать рабочим по умолчанию.

**Дешёвый обходной пиксель, если сделки не онлайн:** для товаров до ~100 000 ₽ (которые люди не боятся покупать онлайн) пиксель ставится не только на «спасибо», но и на **страницу оплаты / заполнения платёжных данных** — «даже туда можно поставить пиксель, эти данные передавать в кампанию и по ним оптимизировать». Порог достоверности сегмента тот же: **10 конверсий по хорошей цене** (`bid-strategies.md`).

⚠️ **Галочка «Учитывать офлайн-конверсии» ставится ПРИ СОЗДАНИИ кампании** — на существующую потом не добавить. Ставить всегда, даже если офлайн-конверсии пока не планируются.
