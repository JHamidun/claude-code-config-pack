# MiniApp-воронка — рассыльщик вместо сайта

Основная рекомендация для продуктовых ниш и всего, где есть повторные продажи: вести трафик не на сайт, а в подписную воронку VK Mini Apps (рассыльщик). Подписчик остаётся в базе — дальнейшие касания практически бесплатны, пока человек не отписался.

---

## Выбор объекта рекламы

| Объект | Когда |
|--------|-------|
| **Лид-формы** | недвижимость, «замерные» ниши |
| **Сайт** | ⚠️ только при уже подтверждённой конверсии сайта. На голый сайт на старте проекта не вести |
| **Каналы Max / канал ВКонтакте** | новые объекты (появились в 2026) — трафик прямо на канал |
| **MiniApps (рассыльщик)** | 🔴 основная рекомендация для продуктовых ниш и повторных продаж |
| **Каталог товаров, подписчики в сообщество** | по ситуации |

**Три причины не вести на голый сайт:**
1. Технические: долго открывается, не прогружается, криво отображается на мобильном.
2. Лишний этап воронки — режет конверсию.
3. Люди не любят выходить из экосистемы приложения.

## Схема воронки

```
Объявление
  → переход по ссылке с хвостом ?force=1
  → окно «разрешить сообществу присылать сообщения»
    (автоподписка — человек в базе СРАЗУ)
  → редирект в сообщения сообщества
  → первое автосообщение (2–3 кнопки, не «пишите нам»)
  → дальше практически бесплатные касания до отписки
```

## Параметр `force`

- **`force=1` (автоподписка)** — сразу окно подтверждения подписки. Ставить по умолчанию.
- **`force=0`** — человек сначала попадает на подписную страницу, жмёт кнопку («узнать стоимость»), только потом окно подтверждения. На лишнем шаге теряется часть людей (передумал, кончился интернет).
- **Побочный эффект `force=1`, о котором обычно не думают:** конверсия в подписку выше → **алгоритм быстрее обучается**, кампания быстрее оптимизируется. Логика по нецелевым: «пусть какие-то лиды будут нецелевыми, зато всех остальных вы не теряете; вы всё равно за этого человека заплатили — пусть лучше сразу подпишется, потом прогреете».
- **Когда автоподписка вредна:** ниши, где люди не готовы «просто так» отдавать право на контакт — недвижимость (боятся звонков и спама). На продуктовых нишах (доставка еды, фермерские продукты) работает хорошо.
- Опция «с автоподпиской / без» есть **во всех рассыльщиках**; если сервис её не сделал — её обычно просят пользователи, «сильно хорошо влияет на конверсию в подписку».

## Первое автосообщение

- **2–3 кнопки с вариантами**, а не «пишите нам» — «мини-квиз на коленках» в 1–2 клика. Такая чат-бот-воронка конвертит дешевле, чем переход на сайт.
- **Цены в первом сообщении** — фильтр: меньше пустых диалогов у менеджера, но и меньше живых контактов. Обоюдоострый приём, решать по нагрузке отдела продаж.

## Связка для недвижимости

Вести на рассылку → после нажатия кнопки человек попадает **не в сообщения, а на сайт застройщика**. Итог: и в базе, и прогрелся на сайте, и может конвертнуться в лид — при этом без агрессивной автоподписки.

---

## Технические гочи

- **Все UTM зашивать прямо в ссылку мини-аппа**, а в настройках объявления выбирать **«не добавлять UTM-метки»**. В справке VK это не описано — выяснено опытным путём; метки из полей кабинета до рассыльщика не доезжают.
- Ссылка на MiniApp в кабинете **не копируется мышкой** — только Ctrl+A / Ctrl+C в поле (см. `vk-bugs-2026.md`).
- Целевое действие кампании — **Subscribe** (подписка).
