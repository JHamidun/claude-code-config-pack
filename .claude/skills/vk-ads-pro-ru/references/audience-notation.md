# Нотация аудиторий + поиск нетривиальных сегментов (CS)

Авторская система именования и сбора аудиторий Крестинина через Target Hunter (L17).

---

## Зачем нотация

Спарсенных аудиторий накапливаются десятки. Через месяц безликое `audience_4` ничего не скажет. Имя по нотации **несёт смысл состава** — понятно через любой промежуток времени, что внутри и насколько она вовлечённая.

---

## Префиксы (тип сбора)

| Префикс | Расшифровка | Что внутри |
|---------|-------------|-----------|
| **PS** | Поиск Сообществ | сообщества, найденные по ключу/нише напрямую |
| **CS** | анализ Целевых Сообществ | авторский Look-Alike (см. ниже) |
| **А** | Активности | те, кто лайкал/комментировал в сообществах |
| **ТУ** | Топ-Участники | ядро сообщества (самые активные) |
| **НВ** | Недавно Вступившие | свежие подписчики |
| **СУ** | Сбор Участников | все подписчики сообщества |

## X-коэффициент (индекс вовлечённости)

Двузначная нотация: в скольких профильных сообществах ниши состоит пользователь.

| Коэф. | в сообществах | размер | поведение |
|-------|---------------|--------|-----------|
| **x11** | 1 из 100 | 35 млн+ | холодная, случайная |
| **x22** | 2 | 650 000 | начинает интересоваться |
| **x33** | 3 | 190 000 | осознанный интерес |
| **x6+** | 6+ | 40 000 | макс. вовлечённость |

**Парадокс конверсии:**
- `x6+` → лучший **первый клик**, но **хуже оплата** (знают рынок, видели всех).
- `x2-x3` → дороже клик, но **лучше оплата** (не пресыщены, хороший оффер заходит).

## Шаблон имени

```
<Префикс>_<ниша>_<X-индекс>

Примеры:
PS_smm_x33     — поиск сообществ по "smm", вовлечённость x3
CS_smm_x7      — анализ целевых сообществ, ядро x7
А_smm          — активности в сообществах smm
НВ_competitor  — недавно вступившие в сообщество конкурента
ТУ_competitor  — топ-участники сообщества конкурента
```

> ⚠️ **Звёздочка `*` обязательна** на каждой задаче/аудитории при передаче в кабинет — иначе данные удаляются через **30 дней**.

## CS — анализ целевых сообществ (авторский Look-Alike)

«Инструмент даёт удочку, а не рыбу». Находит сообщества с высокой концентрацией ЦА, которые **сам бы не придумал по ключам**.

**Кейс:** паблик «Маркетинг и продажи» (33 000 подписчиков) — казалось бы, «далеко от SMM», но **85% подписчиков = наша ЦА**. Другой пример названия из урока: «Денис Каримов — трафик на конверсию».

### Алгоритм поиска нетривиальных аудиторий (6 шагов)

```
1. Собрать ЯДРО: подписчики по теме с x6+ или x7+ (самые вовлечённые)
2. Запустить «Анализ целевых сообществ» (CS) в Target Hunter — загрузить ядро
3. Получить список 24 000+ сообществ, отсортированных по концентрации ЦА
4. Выбрать топ-100 НЕТРИВИАЛЬНЫХ сообществ
   (не только очевидные по ключевым словам — именно неочевидные дают преимущество)
5. Собрать подписчиков этих сообществ с разбивкой по вовлечённости (X)
6. Пересечь с другими сегментами для обогащения (тройной тест A∩B / A−B / B−A)
```

---

## Разбивка одного сообщества на сегменты

Вместо таргета на всю массу подписчиков — собирать по типам (каждый даёт лучший результат, чем «всё подряд»):
- **А** — активности (лайки/комменты).
- **ТУ** — топ-участники (ядро).
- **НВ** — недавно вступившие.
- **СУ** + контакты сообщества.
- Каждый сегмент дополнительно режется по X-коэффициенту.

---

## Источники аудиторий (откуда брать)

1. **Кабинет VK Ads** — быстро, но размыто (подписчики + все активные). Сообщества от 500 подписчиков, лимит 300/группа.
2. **Парсинг (Target Hunter)** — точно, с разбивкой по вовлечённости. Видит сообщества <500 (где часто сидит лучшая ЦА).
3. **Категории интересов** — «вечные» (обновляются в кабинете), но огромные → **обязательно пересекать/вычитать**, в одиночку не использовать.
4. **Ключевые фразы** — «вечные», источник Wordstat, обновление по понедельникам.
5. **Look-Alike** — myTarget (старый кабинет) ИЛИ расширение VK Ads → тестировать параллельно.
