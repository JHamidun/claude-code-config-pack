# VK Ads — бенчмарки, цифры, пиксель

Ориентиры из практики таргетологов на русском рынке. Цифры — для понимания порядка величин, не как жёсткие KPI.

> ⚠️ **NDA-оговорка (читать первой).** Крупные кейсы обычно **закрыты NDA** — раскрытие цифр может быть воспринято заказчиком как разглашение коммерческой тайны. Цифры в примерах **иллюстративные**, для демонстрации методологии. **Не используй конкретные CPL из кейсов как бенчмарк своего проекта.** Достоверные выводы — только на собственной большой статистике.

## Автоматические события пикселя VK Ads (14 шт)

Срабатывают по условиям в URL/действиях. **Хранятся 7 дней — не полагаться, дублировать вручную.**

| Событие | Триггер |
|---------|---------|
| Поиск на сайте | страница с `q=`, `text=`, `query`, `search` |
| Просмотр списка товаров | `catalog`, `shop` |
| Просмотр карточки товара | `product` |
| Поиск офлайн точек | `contact`, `map` |
| Начало оформления заказа | `cart`, `basket` |
| Добавление платёжной информации | `checkout` |
| Завершение оформления заказа | `order` |
| Клик по телефону | ссылка с `href=tel` |
| Клик по e-mail | ссылка с `href=mailto` |
| Переход в соцсеть | клик на ссылку соцсети |
| Переход в мессенджер | клик на веб-интерфейс/диплинк мессенджера |
| Отправка формы | форма с полями `phone`, `email`, `телефон` |
| Успешное действие | страница с `success` |
| Заявка | страница с `booking` |

> Код пикселя ставится перед закрывающим `</head>`. Если пиксель уже стоит — система предложит запросить доступ через email прежнего установщика (без него — ставить заново).
