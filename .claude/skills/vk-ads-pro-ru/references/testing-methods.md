# Методики тестирования VK Ads — глубокая детализация

Пошаговые алгоритмы рабочих методик VK Ads из практики таргетологов с крупными бюджетами. Это то, чего нет в публичных гайдах. Все цифры и кейсы — иллюстративные, из реальной практики.

---

## 1. Метод А (алфавит-в-ключи) — условно бесплатное тестирование

**Суть:** протестировать любое количество ключевых фраз, **не тратя на них отдельный бюджет**. VK Ads в отчёте сам разбивает результат по словам — мы этим пользуемся как «бесплатным» источником данных.

**Почему называется «условно бесплатным»:** бюджет всё равно тратится — но тот, что ты и так потратил на основную кампанию. Сверху бесплатно получаешь «зацепки» по тестируемым фразам.

### Алгоритм (4 шага)

```
1. Создать аудиторию из ключевых фраз:
   — Добавить ВЕСЬ алфавит (а, б, в, г, д ... я) — каждая буква как отдельное слово
   — Добавить целевые фразы, которые хочешь протестировать (5–10 шт)
   — Размер аудитории становится 10–13 млн человек (почти весь активный ВК)

2. Пересечь эту «алфавитную» аудиторию с твоей основной ЦА (например, 100 000 человек):
   — После пересечения остаётся ~95 000 (потеря ~5%, размер ПРАКТИЧЕСКИ НЕ МЕНЯЕТСЯ)
   — Это статистический трюк: алфавит покрывает почти всех, поэтому пересечение
     не «режет» твою ЦА, но активирует разбивку отчёта по фразам

3. Запустить кампанию как обычно на этот сегмент (~95 000)

4. Открыть статистику по ключевым фразам:
   — VK Ads показывает результат по КАЖДОМУ слову/фразе (по буквам и по тестам)
   — Фразы с лучшими показателями → новые гипотезы → масштабировать
```

### Математика (зачем нужен алфавит)

- Алфавит-аудитория = **10–13 млн** (буквы встречаются почти у всех).
- Твоя ЦА = 100 000.
- `Алфавит ∩ ЦА` ≈ **95 000** (≈ −5%).
- Без алфавита пересечение твоей ЦА с узким набором тестовых фраз вырезало бы её в ноль. Алфавит — «несущая» аудитория, которая держит размер, чтобы статистика по фразам набралась.

### Cross-channel: применимость к Telegram Ads

Метод А — **универсальная техника**, упоминается и в контексте TG Ads. Логика пересечений в TG другая (другой кабинет, другие операторы), но принцип «активировать разбивку отчёта через широкую несущую аудиторию» переносится. При работе с Telegram Ads адаптируй под их таргетинг — не копируй один-в-один.

## 2. Метод ИИ (неочевидные ключевые фразы)

**Отдельная методика, работает в связке с Методом А.** ChatGPT генерирует нестандартную семантику, которую ты сам не придумаешь, → кладёшь в общий пул ключей через Метод А → получаешь по ним бесплатную статистику.

**Кейс (ниша «выпечка/хлеб»):**
> Сам не догадаешься написать «хлебушек». Но людям, которые пишут «хлебушек», интересна выпечка хлеба. Или «пирог с капустой» — тоже не очевидно. Все эти фразы метод ИИ позволяет тестировать условно бесплатно, не сливая бюджет вслепую.

Примеры неочевидной семантики: «хлебушек», «пирог с капустой», «ржаная закваска».

### Алгоритм

```
1. Попросить ChatGPT: «Дай 30–50 НЕОЧЕВИДНЫХ поисковых фраз, которые пишут люди,
   интересующиеся <ниша>. Не прямые ("купить курс"), а косвенные,
   разговорные, по смежным интересам».
2. Отобрать живые варианты (отсеять мусор).
3. Закинуть в пул ключей основной кампании через Метод А.
4. Через цикл (неделя) — снять статистику по фразам.
5. Дешёвые фразы → масштабировать; дорогие → отключить.
```

## 3. Зацепки — накопительная система инсайтов

**Главная философия методологии.** Превращает работу с рекламой «из непонятного аморфного казино, где неизвестно как аудитория отреагирует, в систему, которой легко управлять, неизбежно приближаясь к нужному результату».

**Определение:**
> «Зацепка — это полезная информация об использовании какого-либо параметра или сегмента, который улучшает и даёт положительный результат нашим объявлениям. Эти зацепки мы собираем в более крупные инсайты и потом на основе них дальше ведём трафик всё эффективнее».

### Принципы

1. **Накопительный эффект** — каждый шаг использует прошлые зацепки и **рождает новые** для следующих шагов. Результат улучшается на каждой итерации.
2. **Применяй к новым аудиториям** — любую новую аудиторию тестируй **сразу с учётом накопленных зацепок**, а не с нуля.
3. **Подтверждение на 2–3 категориях** — зацепке можно доверять только если она сработала на нескольких разных категориях/нишах. Тогда она становится «базовым правилом» для всех новых тестов.
4. **Достоверность ∝ объёму данных** — выводы тем точнее, чем больше статистики. На малых цифрах — гипотеза, не правило.

### Как вести (шаблон → `zatsepki-library.md`)

Каждая зацепка фиксируется: `параметр / сегмент → эффект (CPL) → на скольких категориях подтверждена → статус (гипотеза / подтверждена / правило)`.

## 4. Пересечение vs вычитание (тройной тест связок)

Для **каждой** связки двух аудиторий тестируй **три** варианта, а не один:

| Вариант | Что значит |
|---------|------------|
| `A ∩ B` (пересечение) | оба признака одновременно — самая концентрированная аудитория |
| `A − B` (вычитание) | A без тех, кто в B |
| `B − A` (обратное вычитание) | B без тех, кто в A |

> ⚠️ **Ограничение кабинета:** **категории интересов нельзя пересекать между собой** — только вычитать. Полное пересечение (`∩`) доступно только для **парсер-аудиторий** и **ключевых фраз**.

### Кейс «Кулинария» (флагманский пример)

| Связка | Результат (CPL) |
|--------|-----------------|
| «Кулинария» ∩ приложение «Сэндлер» | **~200 ₽** |
| «Кулинария» − «Сэндлер» | 300–400 ₽ |

Пересечение стабильно выигрывало. **Подтверждение на второй категории** («Образование»): 170 ₽ в пересечении vs ~500 ₽ без → зацепка достоверна.

Нюанс из практики: «Кулинария × Сэндлер → дешёвые результаты есть, но не каждый день → значит наша ЦА там есть, но надо что-то ещё обрезать» (т.е. пересечение нашло ЦА, но нужно доочистить вычитанием).

### «Обогатители» (Сэндлер, GetCourse)

**«Сэндлер», «GetCourse» — универсальные обогащатели.** Это приложения/категории, аудитория которых = **покупатели**. Пересечение любой ЦА с обогатителем повышает платёжеспособность сегмента.
- **GetCourse** — аудитория онлайн-курсов → логичный мэтч для инфобиза.
- Аудиторию обогатителя можно дальше пересекать с разными приложениями и их сегментами + комбинировать со временем суток (см. времязависимые зацепки в `scaling-playbook.md`).

## 5. Нотация аудиторий + X-коэффициент (детально)

См. также `audience-notation.md`. Здесь — суть для методологии.

**Зачем нотация:** понимать состав спарсенной аудитории через любой промежуток времени (через месяц ты не вспомнишь, что в `audience_4` лежит). Имя несёт смысл.

| Префикс | Расшифровка |
|---------|-------------|
| **PS** | Поиск Сообществ (по ключу/нише) |
| **CS** | анализ Целевых Сообществ (Look-Alike) |
| **А** | Активности (лайки/комменты) |
| **ТУ** | Топ-Участники (ядро) |
| **НВ** | Недавно Вступившие |
| **СУ** | Сбор Участников (все подписчики) |

`+ индекс вовлечённости (X-коэффициент)`.

**X-коэффициент — двузначная нотация** (`x11`, `x22`, `x33`, `x6+`):

| Коэф. | в скольких сообществах | размер | поведение |
|-------|------------------------|--------|-----------|
| **x11** | 1 из 100 | 35 млн+ | холодная, случайная |
| **x22** | 2 | 650 000 | начинает интересоваться |
| **x33** | 3 | 190 000 | осознанный интерес |
| **x6+** | 6+ | 40 000 | максимальная вовлечённость |

**Поведенческий парадокс (важнейший инсайт):**
- **x6+** = лучший **первый клик** (знают рынок, реагируют), но **хуже конверсия в оплату** — уже видели все офферы конкурентов, выбрали или пресыщены.
- **x2-x3** = дороже первый контакт, но **лучше конверсия в покупку** — ещё не пресыщены, хороший оффер заходит.

> Логика: x6+ — самая вовлечённая, но эти люди часто уже нашли решение и знают все предложения. x2-x3 — дороже первый контакт, но выбор у них меньше, и хороший оффер купят с большей вероятностью. Заранее не знаем — но разбивая на сегменты, получаем выбор.

**Вывод:** не таргеть в общую массу подписчиков. Разбивка по X даёт **выбор** между «дешёвый трафик» и «дорогой, но платящий».

## 6. Метод четвёрок (структура группы)

**Правило:** в группе всегда **4 объявления** (можно 3/5/7, никогда 1-2).

- Объявления различаются **ровно одним элементом** (картинка ИЛИ заголовок) → понятно, что сработало.
- **Кейс:** в группе ПЦ победили объявления **2 и 3**, в группе МЦ — **1 и 4**. С двумя объявлениями половина победителей упущена, группа могла быть ошибочно отключена как «дорогая».
- Смысл: метод четвёрок даёт возможность на уровне группы оставить крутиться объявления, которые больше всего подходят аудитории, попавшей в данный сегмент.

## Связка методик в реальном цикле

1. Спарсил аудитории (Target Hunter) → именовал по нотации (PS/CS/А/ТУ/НВ + X).
2. Запустил группами по 4 объявления (метод четвёрок), МЦ ↔ ПЦ параллельно.
3. Прогнал Метод А + Метод ИИ → бесплатно собрал зацепки по фразам.
4. Каждую связку проверил тройным тестом `A∩B / A−B / B−A`.
5. Подтверждённые зацепки → в библиотеку → применяю ко всем новым тестам.
6. Масштабирую лучший креатив × лучшие сегменты + времязависимые зацепки (см. `scaling-playbook.md`).
