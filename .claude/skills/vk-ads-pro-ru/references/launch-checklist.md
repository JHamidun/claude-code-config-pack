# Чек-лист запуска первой кампании VK Ads

Пошаговый чек-лист по методологии Крестинина (L17). Две задачи запуска — именно в этом порядке.

---

## Задачи первого запуска

1. **Пройти модерацию** текстов и картинок — выяснить, можно ли вообще рекламировать продукт, ДО того как пообещал заказчику, завёз бюджет, настроил процессы.
2. **Получить 1-ю конверсию.**

---

## Чек-лист

### Структура
- [ ] **Оптимизация бюджета кампании — ОТКЛЮЧЕНА** (иначе ~95% в одну группу).
- [ ] 1 группа, **4 объявления** (метод четвёрок — никогда не 1-2).
- [ ] Объявления отличаются **одним элементом** (разные картинки при одном тексте — для старта).

### Таргетинг
- [ ] **Гео-исключения:** 7 республик Северного Кавказа (всегда); Крым (осторожно — отдельно); Дальний Восток (если бизнес по МСК и не успевает обрабатывать заявки из другого пояса).
- [ ] **Устройства: только мобильные** (десктоп отключить — 90% трафика, выше CTR, дешевле).
- [ ] **Город/регион** — выбирать в **старом кабинете ВК** (там точнее).
- [ ] Аудитория для старта: ключевые фразы (самые целевые, из Wordstat) + подписчики сообществ конкурентов (через **парсинг**, не кабинет).
- [ ] **Исключить:** закредитованных (микрозаймы/рефинансирование), уже купивших, ищущих бесплатное («скачать бесплатно», «своими руками»), конкурентов-таргетологов (защита креативов).

### Плейсмент и формат
- [ ] Только **лента ВКонтакте** (клипы — после рабочих связок; Mail.ru/рекламная сеть — НЕ на старте).
- [ ] Формат **картинка 1:1**.
- [ ] **Автогенерированное видео — отключить** (статика 1:1 в ленте стабильнее).
- [ ] Видео — **отдельной кампанией**, параллельно (для чистоты сравнения).

### Ставки
- [ ] Стратегия: **Предельная цена (ПЦ)** для контроля бюджета ИЛИ **Минимальная (МЦ)** для объёма.
- [ ] (на масштабировании) дубль группы: одна МЦ, другая ПЦ → сравнить по сегментам.

### UTM и пиксель
- [ ] **UTM:** если цель — рассылка/чат-бот, метки **прямо в ссылке**, не в полях кабинета.
- [ ] Пиксель установлен перед `</head>`, **все события созданы вручную** (автособытия живут 7 дней).

### Расписание
- [ ] Расписание показов задано **вручную** + чек-бокс **«учёт местного времени»** (показ в нужный час у пользователя независимо от его TZ).
- [ ] Время старта — когда таргетолог онлайн и может следить.

### Модерация
- [ ] Отправить на модерацию → **остановить кампанию** (чтобы все объявления стартовали одновременно; если что-то не пройдёт — без перекоса; и чтобы не было слива до проверки).
- [ ] Поставить расписание на 10:00 следующего дня (после одобрения).

### Проверка пути пользователя (ОБЯЗАТЕЛЬНО перед стартом)
- [ ] Пройти по ссылке **с мобильного**.
- [ ] Лендинг открывается корректно.
- [ ] Отправить **тестовую** заявку/регистрацию.
- [ ] **UTM-метки видны в аналитике**, трафик идёт через виджет.
- [ ] Только после этого настройка считается «твёрдой» → плохие результаты искать в параметрах, а не в технической поломке.

### После модерации
- [ ] Масштабирование по типу ставок (МЦ ↔ ПЦ).
- [ ] Масштабирование по аудиториям.
- [ ] ⚠️ При **дублировании** проверить статусы: выключенные объявления исходной группы наследуются в дубль выключенными.
- [ ] Настроить таблицу отчёта со столбцами и сохранить.

---

## Подбор ключевых фраз для старта

1. Основной источник — **Яндекс Wordstat**.
2. Встроенный инструмент VK Ads (10 похожих слов) — для быстрых идей.
3. Выбирать фразы, максимально точно описывающие проблему/задачу ЦА.
4. **Минусовать только очевидно нецелевое** (не как в поисковой рекламе).
5. Тестировать разные периоды поиска (7 / 14 / 30 дней).
6. Помнить: аудитория обновляется **по понедельникам** → рассчитывать объём на неделю.
