# Dependencies Map — карта зависимостей 23 скиллов

Главный принцип маркетинг-машины: **стратегия ДО исполнения**. Нельзя осмысленно настроить канал, не зная JTBD клиента, типа воронки и того, какой канал вообще нужен. Эта карта показывает правильный порядок и что от чего зависит.

---

## Матрица зависимостей «что нужно ДО»

| Скилл | Что должно быть пройдено ДО него | Что он даёт следующему |
|---|---|---|
| `market-selection-ru` | — (старт) | Выбранный рынок/модель/страна |
| `jtbd` | желателен market-selection | Работы клиента, сегменты → база для воронки и креативов |
| `funnel-design-ru` | ajtbd (что цепляет) | Тип воронки + дерево метрик с целевыми значениями |
| `media-planning-ru` | funnel-design (тип воронки, цель) | Channel mix → какой playbook открывать |
| `ad-benchmarks-ru` | — (справочник, в любой момент) | Норматив для сверки / детект ботовода |
| `yandex-direct-pro-ru` | media-planning (канал выбран) | Рабочая кампания → данные в analytics |
| `google-ads-pro-ru` | media-planning | то же + вызывает capi-no-code |
| `telegram-ads-pro-ru` | media-planning | Рабочая кампания TG Ads |
| `vk-ads-pro-ru` | media-planning | Рабочая кампания VK |
| `meta-ads-launch-ru` | media-planning + capi-no-code (трекинг) | Рабочая кампания Meta |
| `capi-no-code-setup` | до масштабирования любого канала | Серверный трекинг → корректные данные в analytics |
| `tg-channel-buyout-ru` | media-planning (если посевы в миксе) | Размещения у каналов/блогеров |
| `b2b-marketing-ru` | market-selection + ajtbd | Заменяет «воронка+канал» для B2B; передаёт лид в sales-team |
| `ai-creative-factory-ru` | ajtbd (что цепляет) | Креативы для playbook'ов и органики |
| `content-machine-instructor2-ru` | ajtbd | Поток контента → manychat-funnel |
| `manychat-funnel-ru` | content-machine (есть контент) | Лиды из SMM → analytics/sales |
| `ai-seo-agent-pipeline` | — (параллельно) | Масса страниц → органический трафик |
| `geo-aeo-ru` | — (параллельно) | Видимость в LLM-ответах |
| `sales-team-ru` | funnel-design (категоризация лидов) | Конверсия лида в деньги → данные для LTV |
| `full-funnel-analytics-ru` | capi-no-code (трекинг) + любой канал | Управленческие решения по когортам/LTV |
| `marketing-team-builder-ru` | когда есть процесс, нужны руки | Команда |
| `marketing-masterminds-ru` | — (в любой момент) | Нестандартный ход |

## Кросс-блочные техники (повторяются в разных скиллах)

Эти темы «прошивают» несколько скиллов — если задача про них, скилл выбирается по КАНАЛУ/КОНТЕКСТУ:

| Техника | В каких скиллах | Куда роутить |
|---|---|---|
| **Lookalike / Look-alike** | yandex, google, meta, vk | По каналу → соответствующий playbook |
| **Custom Audiences / загрузка списков** | yandex, google, meta, vk | По каналу → playbook |
| **Атрибуция (Last Click / MTA)** | yandex, google, meta, capi, full-funnel | Стратегия выбора модели → `full-funnel-analytics-ru`; техническая передача → `capi-no-code-setup` |
| **Обучение алгоритма (50 событий / сброс)** | yandex, google, meta | По каналу → playbook |
| **A/B-тесты** | все performance + meta (5×4) | По каналу → playbook; универсальная статистика → `ab-testing-ru` (стек) |
| **ManyChat коммент→директ** | manychat-funnel, content-machine, masterminds | → `manychat-funnel-ru` |
| **CAC / LTV / ROMI / ROAS** | все performance + full-funnel | Решения по ним → `full-funnel-analytics-ru` |
| **Трендвотчинг / декомпозиция виральных** | ai-creative-factory, content-machine | Структура → `ai-creative-factory-ru`; операционка → `content-machine-instructor2-ru` |
| **Cursor / vibe-coding** | ai-marketing-stack, full-funnel, masterminds | → `ai-marketing-stack-ru` |

## Анти-паттерны порядка (частые ошибки)

| Ошибка | Почему плохо | Как правильно |
|---|---|---|
| Открыть ad-playbook сразу на «настрой рекламу» | Канал выбран наугад, бюджет в неэффективный канал | Сначала `media-planning-ru` |
| Запускать кампании без `capi-no-code-setup` | Нет серверного трекинга → события теряются (iOS 14.5, блокировщики) → нечем оптимизировать | Трекинг ДО масштабирования |
| Оптимизировать по CPL | Дешёвый лид может не конвертиться; решение по половине воронки | Когортная выручка/LTV → `full-funnel-analytics-ru` |
| Делать креативы без JTBD | Хук «в пустоту», не цепляет работу клиента | `jtbd` → `ai-creative-factory-ru` |
| Проектировать воронку без JTBD | Тип воронки не под реальную работу/срочность клиента | `jtbd` → `funnel-design-ru` |
| Нанимать команду до процесса | Люди без системы = хаос | Сначала процесс (слои 1-4), потом `marketing-team-builder-ru` |
| Считать B2B как B2C-воронку | Линейная AIDA не работает для длинного цикла | `b2b-marketing-ru` (TOFU/MOFU/BOFU) |
| Лить трафик на сырой продукт/рынок | Слив бюджета на невалидированное | `market-selection-ru` + `jtbd` сначала |

## Минимальные «срезы» (когда не нужен весь поток)

Не каждая задача требует всех 5 слоёв. Типовые короткие маршруты:

- **«Просто запустить один канал, продукт уже валиден»** → `media-planning-ru` (подтвердить канал) → playbook → `capi-no-code-setup` → `full-funnel-analytics-ru`.
- **«Только органика/контент»** → `jtbd` → `content-machine-instructor2-ru` → `manychat-funnel-ru`.
- **«Только видимость в поиске/AI»** → `ai-seo-agent-pipeline` и/или `geo-aeo-ru`.
- **«Только B2B-аутрич»** → `b2b-marketing-ru` (+ `lead-research`/`draft-outreach` из стека).
- **«Диагностика проседающей воронки»** → `funnel-design-ru` (найти узел) → `full-funnel-analytics-ru` (подтвердить данными) → точечный playbook/CRO.
