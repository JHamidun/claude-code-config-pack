## Пограничные случаи (как разруливать конфликты)

| Двусмысленный запрос | Решение |
|---|---|
| «настрой рекламу» (канал не назван) | НЕ прыгать в playbook → сначала `media-planning-ru` (выбрать канал), он сам направит. |
| «реклама в телеграме» | Кабинет Telegram Ads → `telegram-ads-pro-ru`. Прямая закупка у каналов/блогеров/посевы → `tg-channel-buyout-ru`. Написать пост → `tg-post`. Уточни, если неясно. |
| «CAPI» / «server-side» | Всегда `capi-no-code-setup` (он общий для Meta и Google), даже если упомянут конкретный канал. |
| «воронка» | Спроектировать тип/дерево метрик → `funnel-design-ru`. CRO конкретной страницы → `*-cro-ru`. Lifecycle MQL/SQL → `revops-ru`. |
| «контент» | Написать пост → `content-engine`/`tg-post`. Структура хука/креатива → `ai-creative-factory-ru`. Масштабировать как фабрику → `content-machine-instructor2-ru`. |
| «SEO» | Одна статья под Яндекс → `seo-machine-ru`. Масса страниц → `ai-seo-agent-pipeline`. Видимость в LLM → `geo-aeo-ru`. |
| «аутрич» / «холодное письмо» | Вся B2B-система/инфраструктура → `b2b-marketing-ru`. Одно письмо под лида → `draft-outreach`. Список лидов → `lead-research`. |
| «аналитика» | Когортная full-funnel на масштабе → `full-funnel-analytics-ru`. Метрики канала/ROAS-отчёт → `performance-analytics`. Метрика API/счётчик → `yandex`. |
| «AI для маркетинга» | Cursor как сотрудник/vibe-coding → `ai-marketing-stack-ru`. Прод-бот клиенту → agent-builder tooling. AI-видео → `video-generation`. |
| «выучиться маркетингу» / «учебный план» | НЕ один скилл → `references/learning-paths.md` (4 траектории). |
| «маркетинг с нуля / под ключ» | Чеклист нового проекта (SKILL.md) + `references/project-playbooks.md`. |

**Эвристика по умолчанию:** если запрос про СТРАТЕГИЮ/МЕТОДОЛОГИЮ/«как делают топы» — курсовой скилл. Если про КОНКРЕТНЫЙ АРТЕФАКТ/«дёрни API»/«напиши X» — существующий скилл стека. Часто = цепочка из обоих.
