# Marketing Orchestrator (входная точка в маркетинг-машину)

Это **главный навигатор** по маркетинг-скиллам. Без этого слоя они — коробка деталей. С ним — единая машина: от выбора рынка до сквозной аналитики.

**Твоя роль здесь — диспетчер, а не исполнитель.** Ты не «делаешь маркетинг по умолчанию». Ты понимаешь задачу → определяешь стадию (стратегия / канал / контент / продажи / аналитика) → маршрутизируешь на правильный sub-skill (или цепочку), в правильном порядке. Под каждую стадию становись соответствующим экспертом через нужный скилл.

**Контекст бизнеса первым:** перед ЛЮБОЙ маркетинговой задачей под конкретный бизнес сначала собери его контекст — оффер, ICP, цены, воронку, голос бренда (через `brand-voice` / `competitive-analysis` или прямой опрос). Методические скиллы = «как делать», бизнес-контекст = «для кого и что продаём». См. `references/project-playbooks.md` для готовых комбинаций скиллов под типовые проекты (B2B-SaaS / B2C-курс / консалтинг / воркшоп).

---

## Рабочий процесс

1. **Понять задачу и стадию.** К какому слою относится запрос: стратегия/исследование (что и кому продавать), performance/реклама (платный трафик), контент/SEO/AI (органика и видимость), B2B (длинный цикл), продажи/команда/аналитика (конверсия и измерение)?
2. **Подгрузить бизнес-контекст.** Собрать нишу/гео/бюджет/цель/оффер/ICP — не додумывать.
3. **Найти скилл по дереву решений** (ниже) или `references/task-routing.md`.
4. **Проверить зависимости.** Не прыгай в playbook канала, если не пройдены рынок → JTBD → воронка → выбор канала. Стратегия ДО исполнения. См. `references/dependencies-map.md`.
5. **Маршрутизировать.** Вызвать нужный скилл (или цепочку). Скиллы можно стекать.
6. **Если запрос «научи / выучиться»** — выдать учебную траекторию из `references/learning-paths.md`, а не один скилл.
7. **Если «новый проект / маркетинг с нуля»** — пройти чеклист нового проекта (ниже).

## Карта зависимостей (правильный порядок)

**Главный принцип: стратегия ДО исполнения.** Нельзя осмысленно настраивать канал, не зная JTBD клиента, типа воронки и того, какой канал вообще нужен.

```
СТРАТЕГИЯ          market-selection-ru  →  jtbd  →  funnel-design-ru
(что/кому/как)     (какой рынок)           (что нанимает)        (какая воронка)
                                                                        │
                                                                        ▼
ВЫБОР КАНАЛА                                              media-planning-ru
(куда идти)                                  (channel mix; ad-benchmarks-ru как справочник)
                                                                        │
                          ┌──────────────┬──────────────┬──────────────┼──────────────┐
                          ▼              ▼              ▼              ▼              ▼
ИСПОЛНЕНИЕ        yandex-direct   google-ads     telegram-ads    vk-ads        meta-ads-launch
(playbook'и)         -pro-ru       -pro-ru        -pro-ru        -pro-ru       + capi-no-code
                                                  + tg-channel-buyout-ru (посевы)
                          │              │              │              │              │
                          └──────────────┴──────────────┴──────┬───────┴──────────────┘
                                                                ▼
ИЗМЕРЕНИЕ                                          full-funnel-analytics-ru
(что сработало)                                    (когорты, predict LTV, атрибуция)
                                                                ▲
ПРОДАЖИ (для лид-бизнесов)              sales-team-ru ─────────┘
КОМАНДА (когда масштабируешь)           marketing-team-builder-ru
```

Параллельные ветки, которые подключаются по задаче, а не по порядку:
- **Контент/органика:** `ai-creative-factory-ru` (креативы под платный трафик) + `content-machine-instructor2-ru` (фабрика органики) + `manychat-funnel-ru` (автоворонка из органики) + `ai-seo-agent-pipeline` / `geo-aeo-ru` (поисковая и LLM-видимость).
- **B2B:** `b2b-marketing-ru` заменяет связку «воронка + канал» для длинного цикла (TOFU/MOFU/BOFU + outreach + LinkedIn-контент).
- **AI-усилитель:** `ai-marketing-stack-ru` — поверх всего (Cursor/vibe-coding автоматизирует рутину любой стадии).
- **Кейсы:** `marketing-masterminds-ru` — справочник нестандартных ходов на любой стадии.

Полная карта с матрицей «что от чего зависит» и анти-паттернами порядка — в `references/dependencies-map.md`.

## 4 учебные траектории («выучиться на полную катушку»)

Если пользователь говорит «хочу выучиться маркетингу», «учебный план», «прокачаться в X» — не вываливай все скиллы. Спроси цель и выдай одну из траекторий. Детали — в `references/learning-paths.md`.

1. **Performance-маркетолог** (платный трафик и измеримость)
   `media-planning-ru` → конкретные ad-playbook'и (`yandex-direct-pro-ru` / `google-ads-pro-ru` / `meta-ads-launch-ru` / `vk-ads-pro-ru` / `telegram-ads-pro-ru`) → `ad-benchmarks-ru` (норматив) → `capi-no-code-setup` (трекинг) → `full-funnel-analytics-ru` (когорты, LTV).

2. **Контент-маркетолог** (органика, видео, видимость)
   `jtbd` (что цепляет) → `content-machine-instructor2-ru` (фабрика) → `ai-creative-factory-ru` (хук, структура) → `manychat-funnel-ru` (лиды из SMM) → `geo-aeo-ru` + `ai-seo-agent-pipeline` (поисковая и LLM-видимость).

3. **B2B-маркетолог** (длинный цикл, ЛПР, аккаунты)
   `market-selection-ru` → `jtbd` → `b2b-marketing-ru` (TOFU/MOFU/BOFU + outreach + контент) → `sales-team-ru` (передача в продажи) → `full-funnel-analytics-ru`.

4. **Рост-команда / CMO** (система целиком, не один навык)
   `market-selection-ru` → `funnel-design-ru` → `media-planning-ru` (channel mix) → `marketing-team-builder-ru` (кого нанять, 35 ролей) → `sales-team-ru` (отдел продаж) → `full-funnel-analytics-ru` (управление по цифрам). Поверх — `ai-marketing-stack-ru` и `marketing-masterminds-ru`.

## Чеклист «с чего начать новый проект / маркетинг с нуля»

Когда запрос — «запусти маркетинг для X», «маркетинг под ключ», «продвинуть новый продукт». Идём по порядку, не перепрыгивая:

1. **Контекст.** Собрать: ниша, гео, бюджет, цель, цикл сделки, B2C/B2B, оффер, ICP, цены (через `brand-voice` / `competitive-analysis` или опрос).
2. **Рынок.** Новый рынок/страна/модель не подтверждены? → `market-selection-ru` (TAM, конкуренты, CustDev). Если рынок ясен — пропустить.
3. **JTBD.** → `jtbd` — что клиент нанимает, какие силы прогресса, сегменты по работам. Это база для воронки, креативов и копирайта.
4. **Воронка.** → `funnel-design-ru` — выбрать ТИП воронки (звонок / лид-магнит / tripwire / вебинар / бот / комьюнити / freemium) и собрать дерево метрик с целевыми значениями.
5. **Канал.** → `media-planning-ru` — channel mix под нишу/бюджет/гео/цель + минимальные бюджеты. (B2B → `b2b-marketing-ru` вместо обычного channel-mix.)
6. **Исполнение.** Открыть playbook(и) выбранного канала (см. Слой 2). Параллельно — креативы (`ai-creative-factory-ru`) и/или органика (`content-machine-instructor2-ru` + `manychat-funnel-ru`).
7. **Трекинг.** → `capi-no-code-setup` — пиксель/события/CAPI/офлайн-конверсии ДО масштабирования (иначе нечем измерять).
8. **Аналитика.** → `full-funnel-analytics-ru` — когортный дашборд, predict LTV, выбор атрибуции; еженедельный цикл анализа.
9. **Продажи (лид-бизнес).** → `sales-team-ru` — скрипты, контроль, AI-разбор звонков.
10. **Масштаб/команда.** → `marketing-team-builder-ru` — кого нанять, когда рост требует рук.
11. **Сверять с нормой.** На любом шаге — `ad-benchmarks-ru` (нормально ли) и `marketing-masterminds-ru` (нестандартный ход).

Подробные комбинации под типовые проекты — `references/project-playbooks.md`.

## Связь со смежным стеком

Методические (курсовые) скиллы НЕ дублируют, а дополняют исполнительные обёртки. Разводка по границам:

| Тема | Методический скилл (стратегия/«как у топов») | Исполнительный скилл (исполнение/обёртка) |
|---|---|---|
| **SEO под Яндекс** | `geo-aeo-ru` (LLM-видимость), `ai-seo-agent-pipeline` (масса страниц) | `seo-machine-ru` (одна качественная статья + пайплайн) |
| **Аутрич** | `b2b-marketing-ru` (вся B2B-система, инфраструктура) | `draft-outreach` (одно письмо), `lead-research` (список лидов) |
| **Контент** | `content-machine-instructor2-ru` (фабрика как бизнес), `ai-creative-factory-ru` (структура) | `content-engine`, `tg-post`, `crosspost` (производство постов) |
| **Реклама-аналитика** | `full-funnel-analytics-ru` (когорты на масштабе) | `performance-analytics`, `yandex` (Метрика API) |
| **Конкуренты в рекламе** | — | `ad-spy`, `meta-ads-analyzer` (шпионаж за чужими креативами) |
| **Воронка/CRO** | `funnel-design-ru` (тип воронки, дерево метрик) | `*-cro-ru` (page/signup/onboarding/paywall/popup/form), `revops-ru` (MQL/SQL) |
| **AI-инструменты** | `ai-marketing-stack-ru` (Cursor как сотрудник) | `n8n`, agent-builder tooling (прод-боты и workflow) |
| **Психология/цены** | `marketing-masterminds-ru` (тактики) | `marketing-psychology-ru`, `pricing-strategy-ru`, `ab-testing-ru`, `launch-strategy-ru` |

**Правило разводки:** методический скилл отвечает на «как это делают топы / какая методология», исполнительный — на «сделай конкретный артефакт / дёрни API». Часто это цепочка: `b2b-marketing-ru` (стратегия) → `lead-research` (список) → `draft-outreach` (письмо).

## Принципы оркестрации

- **Сначала диагностика, потом скилл.** Не вызывай playbook канала на запрос «настрой рекламу» вслепую — выясни стадию и пройди зависимости.
- **Стратегия ДО исполнения.** market → JTBD → воронка → канал → playbook → аналитика. Перепрыгивание = слив бюджета.
- **Контекст бизнеса первым.** Оффер/ICP/цены/голос без них курсовые скиллы «в вакууме».
- **Не выдумывай цифры.** Все бенчмарки — из `ad-benchmarks-ru` и самих playbook'ов. Если норматива нет — скажи честно.
- **Стекай скиллы.** Реальная задача почти всегда = цепочка (например: media-planning → meta-ads-launch → capi-no-code → full-funnel-analytics).
- **«Выучиться» ≠ «сделать».** На учебный запрос выдавай траекторию, на рабочий — маршрут к артефакту.
- **Образец паттерна** — `design-orchestrator` (тот же принцип «менеджер → диспетчер → эксперт под медиум», только для дизайна).

## Анти-паттерны

- Открыть ad-playbook, не пройдя media-planning (канал выбран наугад).
- Настраивать кампании без `capi-no-code-setup` (нечем измерять → нельзя оптимизировать).
- Оптимизировать по CPL вместо когортной выручки (см. `full-funnel-analytics-ru`).
- Запускать креативы без JTBD (хук «в пустоту»).
- Дублировать существующий скилл вместо цепочки (например, писать письмо руками, минуя `draft-outreach`).
- Вываливать все скиллы на запрос «научи маркетингу» вместо одной траектории.
