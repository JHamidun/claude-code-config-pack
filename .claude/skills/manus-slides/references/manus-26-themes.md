# Каталог 26 тем слайдов в стиле Manus 1.6

Описания тем — наблюдения за продуктом (июль 2026): что за визуальный язык, каким
способом рендерится, где уместна. Это ориентир для СВОИХ шаблонов, а не выгрузка
чужого каталога.
Описания тем ниже сняты с превью-рендеров глазами (по одному на связку «тема × режим × модель»). Самих .webp пак не несёт — описания самодостаточны.
Полные 8-слайдовые сэмплы для 7 image-тем: `references/manus-theme-samples/<Theme>__<model>/`.

## Как устроен такой пайплайн

1. Агент пишет **markdown-outline** (`# Title`, `## Слайд N: …`) → тул `slides` с `generate_mode: html | image`.
2. Режим рендера и модель привязаны к теме:
   - `image` + **nano-banana** → Whiteboard, Sketch (в UI шаг «Generating with Nano Banana Pro»);
   - `image` + **gpt-image** → Etching, Editorial, Pixel, Vellum, Dossier (GPT Image 2);
   - пустой режим = **html/react** → остальные 19 тем (LLM пишет React/HTML, рендер headless-Chromium).
3. Экспорт: `manus-export-slides manus-slides://<version_id>` → серверный конвертер → PPTX/PDF.

## Визуальные описания (по превью, глазами)

### Image-темы (7) — полнокадровая генерация «картинка = слайд»

**Sketch** (nano-banana) — `slide_templates_previews\Sketch__image__nano-banana.webp`
Тёплая кремовая «бумага» (#F7F4EC) с еле заметной серой клеткой (миллиметровка/тетрадь). ВСЁ нарисовано тонкой чёрной тушью/линером: округлый дружелюбный hand-lettering заголовок, милые линейные человечки (точечные лица, лёгкая штриховка), простые дудл-иконки (кофе, колонны-пьедесталы для пунктов), волнистые подчёркивания, спиральные дудлы по углам. Чистый монохром, много воздуха. НАШ старый `sketch` (белый мел на тёмной бумаге) — это ДРУГОЙ стиль; реплика Manus = `sketch-notebook`.

**Whiteboard** (nano-banana) — фотореалистичная белая маркерная доска в алюминиевой раме, офисное освещение, лоток с маркерами. Заголовок синим маркером с живым рукописным наклоном, подзаголовок чёрным, жёлтая лампочка-дудл, красные подчёркивания и стрелки, полустёртые заметки по краям. = наш `whiteboard`.

**Etching** (gpt-image) — кремовая бумага, тонкая перьевая гравюра с серой акварельной отмывкой (Нью-Йоркер/старая энциклопедия): силуэт города, одинокая фигура. Заголовок — разреженный letterpress-serif КАПИТЕЛЬЮ, курсивный подзаголовок между тире, римская нумерация страницы, бегущая строка-колонтитул внизу. = наш `etching`.

**Editorial** (gpt-image) — сплит: слева тёплое editorial-фото (стопка журналов, кофе, сухоцветы, оконный свет), справа тёмно-угольная панель с огромным Didone-serif в слоновой кости, медная линейка под заголовком, letterspaced-футер капителью. Kinfolk/Monocle. = наш `editorial` (на контентных слайдах у Manus — светлая «бумажная» вёрстка, в нашем промпте это учтено).

**Pixel** (gpt-image) — слайд = окно классической Mac OS (титул-бар с пинстрайпом и тремя «светофорами») на Bondi-синем пиксельно-дизеренном десктопе. Жирный слегка пиксельный гротеск, оранжевое подчёркивание, моно-подзаголовок, внизу utility-бар с тегами через буллеты, голубой line-art iMac. = наш `pixel`.

**Vellum** (gpt-image) — рисовая бумага, суми-э: туманные горы слоями, кривая сосна, мягкие растёки туши. Заголовок глубоким чернильно-зелёным serif, серый подзаголовок, единственный яркий акцент — красная печать-чоп. = наш `vellum`.

**Dossier** (gpt-image) — фотореалистичный flat-lay сверху: состаренный лист, приколотый латунной кнопкой к пробковой доске; по краям антиквариат (гостиничный звонок, марки, сургучная печать, ключ с биркой, белая перчатка, перо, конверт). Заголовок тёмно-синим serif КАПИТЕЛЬЮ, золотые виньетки-разделители, красная курсивная строка «Est. 1892». = наш `dossier`.

## Использование рецептов

```bash
# image-тема «как Manus» (пример: Sketch):
python ~/.claude/skills/manus-slides/scripts/whiteboard_generator.py generate slides.json ./out sketch-notebook
# премиум-качество ближе к Manus (у них nano-banana-pro / gpt-image):
MANUS_SLIDES_MODEL=nano-banana-pro-preview python .../whiteboard_generator.py generate slides.json ./out etching
```

Соответствие моделей: Manus nano-banana ≈ наш `gemini-3.1-flash-image-preview` (деф.) / `nano-banana-pro-preview` (премиум); Manus gpt-image (GPT Image 2) — прямого аналога нет, эмулируем теми же Gemini-моделями по стилевому промпту.

## Честные ограничения (не забывать)

1. **Серверные промпты Manus НЕ извлечены.** В 34-МБ бинаре песочницы нет ни одного слайд-промпта и ни одного литерала image-модели — выбор модели и промпт-инжект живут на сервере Manus. Наши STYLES-промпты — реконструкция «по глазам» с превью и 8-слайдовых сэмплов. Это **эмуляция стиля, не пиксельная копия**.
2. **E2E наблюдён только Sketch/nano-banana** (10 слайдов, ~2 мин). Для остальных тем флоу подтверждён каталогом + сэмплами, но не прогоном.
3. **HTML-темы Manus — это React-компоненты с фото-сорсингом.** Наш HTML-путь (slide_templates.py) — 32 категория-шаблона без автоматического подбора фото; 4 темы (Emerald, Mist, Linen, Mahogany) без нового шаблона честно не воспроизводятся, ещё 6 закрыты только image-эмуляцией.
4. Точная генерация «как Manus» возможна только через сам Manus (тул `slides`, экспорт `manus-export-slides manus-slides://<version_id>`).
