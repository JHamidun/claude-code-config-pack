# Идеи экспериментов для пейволлов (RU)

A/B-тесты пейволлов вашего продукта (онлайн-курс/SaaS/premium-подписка). Запуск — `ab-testing-ru`. Метрики (показы/клики пейволла, trial→paid, апгрейды тарифов, revenue per user, churn после апгрейда) — ваш аналитический стек / `yandex`.

## Триггер и тайминг

### Когда показывать
- После аха-момента (первая ключевая сессия / первый результат) vs при попытке открыть premium-раздел.
- Раннее напоминание об окончании trial (день 3-4) vs позднее (за 1 день).
- После X действий (уроков/задач) vs после X дней trial.
- По паттернам использования (упёрся в лимит раздела/функции) vs только по времени.

### Тип триггера
- Hard gate (нельзя дальше) vs soft gate (превью + промпт).
- Гейт флагманского раздела (premium-модуль) vs гейт продвинутой функции как основной триггер.
- In-context модалка vs отдельная страница апгрейда.
- Баннер-напоминание «осталось N дней trial» vs модалка.

## Дизайн

### Раскладка
- Полноэкранный vs модалка-оверлей.
- Минимальный (CTA-фокус) vs насыщенный фичами.
- Один план vs сравнение тарифов (Basic/Plus/Pro).
- С превью раздела/функции vs только текст.

### Подача ценности
- Список фич vs формулировки выгод.
- Что потеряете после trial (loss aversion) vs что получите.
- Персонализированное резюме по использованию («Вы прошли N шагов, M сессий, K баллов прогресса»).
- До/после, ROI-обоснование («Pro дешевле, чем набор отдельных инструментов/подписок»).

### Визуал
- Скриншоты/превью ключевых premium-функций.
- Короткое демо/GIF флагманского раздела.
- Иллюстрация vs продуктовые изображения.
- Визуализация прогресса (баллы, % пройденного, путь к цели/результату).

## Подача цены

### Отображение
- Месяц vs год vs тумблер (−20% годовая).
- Подсветка экономии за год (₽ vs %).
- Цена «за день» («меньше чашки кофе»).
- Цена заметна vs приглушена до клика.

### Опции планов
- Один рекомендованный (Plus) vs все три тарифа.
- Бейдж «Популярный» на рекомендованном плане.
- Число видимых планов (2 vs 3).
- Флагманский разовый оффер рядом vs скрыт.

### Скидки и офферы (RU)
- **Founding-оффер: специальная цена пожизненно для первых N покупателей** vs обычный тариф.
- Скидка на первый месяц для trial-конверсии.
- Ограниченный по времени оффер с таймером (на финише trial).
- Скидка за годовую оплату.
- Реферальная скидка (если есть реферальная программа).

## Копия и месседжинг

### Заголовки
- Про выгоду («Откройте весь каталог/все функции») vs про фичи («Получите Pro»).
- Вопрос («Готовы освоить это системно?») vs утверждение.
- Срочность («Не теряйте прогресс») vs ценность.
- Соцпруф (ваши маркеры авторитета: роль, ключевой результат, узнаваемые клиенты).

### CTA
- «Попробовать Plus» vs «Перейти на Plus» vs «Продолжить с Plus».
- 1-е лицо («Хочу Pro») vs 2-е.
- Конкретно («Открыть весь доступ») vs дженерик («Апгрейд»).
- С ценой в CTA vs отдельно.

### Возражения
- Гарантия возврата.
- «Отмена в любой момент».
- FAQ на пейволле.
- Подтверждающие артефакты (сертификаты/отчёты, валидирующие результат) — для B2C-профи.
- Чат/AI-агент поддержки на пейволле.

## Trial и конверсия

### Структура trial
- 7 vs 14 дней (текущее — [укажите ваше]).
- Карта обязательна vs нет (текущее — [укажите ваше]).
- Полный доступ vs ограниченные разделы в trial.
- Продление trial для вовлечённых.
- Второй trial для истёкших/ушедших.

### Окончание trial
- Видимость таймера (всегда vs у конца).
- Частота/тайминг email-напоминаний (день 5/6/7).
- Grace-период vs мгновенный даунгрейд.
- «Последний шанс» с founding-оффером по спеццене.
- Пауза подписки vs отмена.

### Путь апгрейда (RU-платежи)
- 1 клик с пейволла vs отдельный чекаут.
- Предзаполненные платёжные данные.
- Несколько способов оплаты (карты МИР, СБП, платёжный провайдер).
- Годовой план рядом с месячным.
- Флоу для B2B-когорты (solo → корп-пакет от 5 человек).

## Персонализация

### По использованию
- Копия пейволла по пройденным разделам.
- Подсветка самых релевантных premium-функций.
- Статистика использования (баллы, шаги, сессии).
- Рекомендация тарифа по поведению (Basic vs Plus vs Pro).

### По сегменту
- Power user vs casual.
- B2C-профи vs B2B-когорта (карьера/результат vs командное обучение/ROI).
- Цель использования (разные сценарии/юзкейсы).
- По источнику трафика (контент vs прямой vs реклама).

## Частота и UX
- Число промптов на сессию.
- Cool-down после dismiss (часы vs дни).
- Эскалация срочности к концу trial vs постоянный месседж.
- Варианты dismiss: «Может позже» vs «Допройти trial» vs «Напомнить завтра».
- Спросить причину отказа / альтернативный оффер (Basic вместо Plus, founding-спеццена, годовая скидка).
