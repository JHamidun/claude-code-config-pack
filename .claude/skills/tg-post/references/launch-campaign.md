# Launch-кампания в @your_channel — пост + карусель + сторис + видео (one-shot)

> Схема собрана на разборе запуска крупной модели: один пост + карусель + сторис + видео-догон.
> Готовых артефактов-образцов в паке нет намеренно (они были привязаны к конкретному каналу
> и его картинкам) — анатомия ниже полная, собирается с нуля за один прогон.
> Движок постинга → `tg-post/scripts/tg_rich_post.py`. Движок карточек → `cards-creator/`.

Это сценарий «новость под ключ»: один прогон даёт оформленный пост с rich-форматированием,
карусель карточек, сторис 9:16 и видео-догон, всё по расписанию МСК.

---

## Анатомия поста (структура, проверенная на engagement)

Порядок блоков:

1. **Хук от первого лица** — почему тема личная, 2–3 предложения. Не «компания представила».
2. **Цитата-тезис** — `<blockquote>` (НЕ раскрывающаяся) — главная мысль одной фразой.
3. **Мост к деталям** — «Коротко, что поменялось. Детали спрятал в раскрывающиеся блоки — разверни, если зацепило 👇»
4. **3–5 раскрывающихся блоков** — каждый `<blockquote>` c `<b>ЗАГОЛОВОК</b>` на первой строке.
   Это сворачиваемые списки (`collapsed=True`) — пост выглядит коротким, детали по тапу.
   Цифры — только проверенные (см. правило фактчека ниже).
5. **Цена + ссылка на первоисточник** — инлайн `<a href>` на оригинал анонса (не голый URL).
6. **Личная рефлексия с ОДНИМ спойлером** — честная тревожная нотка; punchline спрятан под блюр.
7. **Афоризм-закрытие** — `<blockquote>` (НЕ раскрывающийся) — ёмкий вывод «инструмент vs напарник».
8. **Голосование реакциями + CTA в комменты** (см. ниже).
9. **FOOTER (3 гиперссылки)** — `FOOTER_HTML` из `tg_rich_post.py`.
10. **Хештеги** — 2–3, ПОСЛЕ футера.

### Концовка: голосование реакциями (текстом) + призыв в комменты

Высокий engagement. Один вопрос + 3 варианта-эмодзи + явный CTA:

```
Важно ли, чтобы ИИ признавал свои ошибки?

🔥 — это главное, что нужно от нейронки
🤖 — мне важнее скорость
🤔 — не замечал разницы

Поделитесь в комментариях
```

Правила: вопрос ↔ теме поста; 3 варианта (не 2, не 5); первый = «правильный»/сильный;
эмодзи разные и осмысленные. Не стакать с другими CTA — одно голосование на пост.

### Спойлер-логика (КРИТИЧНО — частая ошибка)

Блюрить можно **только punchline / признание / разворот**, который интереснее прочитать после
паузы. **НИКОГДА не блюрить тезис или факт** — читатель не поймёт мысль.
- ✅ «…тем меньше я делаю руками. ||Кажется, мне это нравится больше, чем стоило бы.|| И это затягивает.» (блюр на самоиронии-признании)
- ❌ блюр на «модель честнее в 4 раза» (это тезис — его нельзя прятать)

### 3 гиперссылки

= `FOOTER_HTML` (свои три ссылки, константа в `tg_rich_post.py`) + при наличии 4-я инлайн —
ссылка на первоисточник в теле. Всегда инлайн `<a href>`, не голый URL.

### Голос
Строго по `tg-post/SKILL.md` (ДНК голоса + анти-ИИ правила). Если текст звучит «не по-человечески» —
переписать простым разговорным («чем больше агент делает сам, тем меньше я делаю руками», а не
«саму работу делает уже не я»). Фактчек: каждое число сверять с первоисточником/скриншотом.

## Rich-форматирование (что умеет только `tg_rich_post.py`)

`tg_client.py` НЕ умеет альбомы/спойлеры/раскрывашки. Используем `scripts/tg_rich_post.py`:
- **раскрывающийся список** = `MessageEntityBlockquote.collapsed=True` (Telethon html не ставит флаг сам)
- **спойлер (блюр)** = `MessageEntitySpoiler(offset,len)`, офсеты в **UTF-16** (`build_caption(spoilers=[...])`)
- `formatting_entities=` несовместимо с `parse_mode=`; подпись только на ПЕРВОМ медиа; Premium ≤4096
- альбом ≤10 (фото + видео можно вместе); `schedule=` tz-aware МСК; чужие отложки НЕ удалять

`build_caption(html, expandable='all_but_first', spoilers=[...])` делает всё это за тебя.

## End-to-end команды (рабочая папка ~/cards-X, НЕ внутри скилла)

```bash
mkdir ~/cards-X && cd ~/cards-X
# styles.css первой серии пишется руками — скелет и токены в cards-creator/SKILL.md,
# дальше копируешь styles.css предыдущей серии и правишь.

# 1. КАРТИНКИ — единый стиль через wrapper (gpt-image-2), потом rembg-вырезка
python ~/.claude/skills/cards-creator/scripts/card_image_generator.py generate cards.json ./img

# 2. КАРТОЧКИ — собери series.html по типам из cards-creator/references/card-types.md
#    (≤10 карточек, лого в углу, 1-2 акцентных цвета на серию)
python ~/.claude/skills/cards-creator/scripts/render_cards.py series.html      # -> png/series-NN.png

# 3. СТОРИС 9:16 — вписать карточки в кадр без обрезки боков
python ~/.claude/skills/cards-creator/scripts/build_story_frames.py            # -> story_png/story-NN.png

# 4. ПОСТ+КАРУСЕЛЬ+ВИДЕО по расписанию — свой скрипт на хелперах tg_rich_post
#    (build_caption -> schedule_album(spoilers=,expandable=) -> schedule_media(video))
python my_campaign.py

# 5. СТОРИС в канал (учитывай дневной лимит = boost level!)
python ~/.claude/skills/cards-creator/scripts/post_stories.py list  your_channel
python ~/.claude/skills/cards-creator/scripts/post_stories.py post  your_channel
#    починить уже висящие кривые без расхода квоты:
python ~/.claude/skills/cards-creator/scripts/post_stories.py edit  your_channel 3,4,5,6,7,8,9,10
```

## Грабли всей кампании (hard-won 2026-05-29)
- **Сторис: дневной лимит = boost level** (канал level 8 → ~8/сутки), 9-я → `BOOSTS_REQUIRED`. Планируй число карточек-сторис под уровень; чинить живые — только `EditStory` (медиа-only сохраняет подпись).
- **Карточка 4:5 как сторис → режет бока.** Всегда прогоняй `build_story_frames.py`.
- **gpt-image-2 НЕ умеет прозрачный фон** → генерим обычно + `cut_bg.py` (rembg isnet).
- **.session лочится sqlite** → работай с копией файла; консоль в utf-8 (cp1251 падает на эмодзи).
- **Фактчек таблиц** — сверять каждое число со скриншотом/блогом до планирования.
