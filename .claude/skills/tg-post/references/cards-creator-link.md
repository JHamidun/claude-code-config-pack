# Связка с cards-creator: карусели для канала

Когда пост превращается в карусель карточек, что передавать в `cards-creator`, как согласуются обложка и серия. Читай, когда к посту нужна карусель.

## СВЯЗЬ С `cards-creator` (карусели для канала)

Если пост написан и контент содержит **визуально благоприятную структуру**, предложи пользователю запустить `cards-creator` для создания carousel-карточек к посту.

### Когда предлагать cards-creator (≥ 2 признаков из 5):

1. **list ≥ 4 пунктов** — пост содержит 4+ нумерованных или маркированных пункта (как в режимах `long`, `roundup`, `personal manifesto`)
2. **before/after / vs** — упоминается «было/стало», «до AI / после AI», «раньше vs сейчас»
3. **3+ конкретных цифр** — пост насыщен числами (метрики, проценты, суммы, длительности)
4. **режим `long` / `review` / `roundup` / `announce`** — длинные/обзорные/анонс форматы выигрывают от визуальной поддержки
5. **тематика «инструмент / стек / сетап»** — обзор Claude Code, AI-стека, скиллов, инструментов

### Что говорить пользователю

После того как пост написан, если 2+ признака выше — добавь в конце вывода:

```
═══════════════════════════════════════════════
💡 Бонус: карусель для этого поста?
═══════════════════════════════════════════════

В посте 5 тезисов + 3 цифры — это просится в carousel из 7 карточек productodud-style.
Запустить `cards-creator` для рендера серии?

Структура будет:
01 cover-hero — заголовок поста
02-06 inner/list — по тезису
07 closer — CTA на @your_channel
```

Если пользователь соглашается — передай свой готовый пост в `cards-creator` skill как seed для карточек.

### Маппинг режим tg-post → типы карточек

| Режим tg-post | Рекомендуемые типы cards-creator |
|---|---|
| `short` | Часто без карточек, но возможна 1-2 cover-card |
| `long` | 6-9 карточек: cover + inner×4-5 + (stat/compare) + closer |
| `review` | 5-7 карточек: cover + features-list + score + closer |
| `thread` | Обычно без карточек (текст важнее) |
| `announce` | 3-5 карточек: cover-photo + event + speakers + closer |
| `roundup` | 7-9 карточек: cover + по 1 на инструмент + closer |
| `personal` | 1-3 карточки опционально: cover + quote + closer |

### Передача контента в cards-creator

Когда передаёшь — структурируй так:

```yaml
post_title: "Полный заголовок поста"
post_lead: "1-2 строки тизера"
sections:
  - type: list
    items:
      - title: "Тезис 1"
        body: "Описание тезиса 1"
      - title: "Тезис 2"
        body: "Описание"
  - type: stats
    numbers:
      - {value: "172", label: "скиллов"}
      - {value: "49", label: "субагентов"}
      - {value: "35", label: "плагинов"}
  - type: closer
    cta: "Подписывайся → t.me/your_channel"
photos:
  - author-portrait — для cover-photo
  - workspace — для tool-roundup
hashtags: [ИИ, инструменты, ClaudeCode]
```

### Workflow

```
user: «сделай длинный пост про мой опыт с Claude Code за год»
→ tg-post активируется, режим long
→ tg-post пишет 1800-символьный пост с 5 тезисами
→ tg-post сканирует: 5 пунктов + 3 цифры + режим long = 3 признака
→ tg-post в конце вывода: «💡 Бонус: запустить cards-creator?»
→ user: «да»
→ tg-post передаёт структуру в cards-creator
→ cards-creator рендерит 7 PNG в /tmp/png/
→ возвращает: «Готово, серия в /tmp/png/. Отправить через tg_client send-album?»
```

См. `~/.claude/skills/cards-creator/SKILL.md` для полной документации cards-creator.
