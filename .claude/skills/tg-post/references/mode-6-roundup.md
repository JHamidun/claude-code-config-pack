# Режим 6: подборка (1000–2500 знаков)

Структура, ритм и примеры для режима «подборка инструментов или ресурсов». Читай ТОЛЬКО тот файл, чей режим выбран — остальные режимы в контекст не тащи.

## РЕЖИМ 6: ПОДБОРКА (1000-2500 символов)

Курированный список инструментов, советов, ресурсов или выводов из события/разговора.

### Структура
1. Жирный заголовок — о чём подборка
2. Контекст: откуда это (стрим, чат, статья)
3. 🟥 пункты с описаниями и `↳` ссылками
4. Опциональная финальная мысль
5. Футер

### Особенности
- `🟥` цветные квадраты как маркеры (НЕ ▫️)
- `↳` для вложенных ссылок под каждым пунктом
- Краткое описание каждого пункта — что делает + почему важно
- Можно указать источник: "Позвал @username показать его сетап. Что узнал:"
- Ссылки на GitHub, инструменты, сайты

### Пример

```
**Промпты, которые улучшили мой опыт с AI агентами**

Мои личные лайфхаки после плотной работы с Claude Code.

🟥 **Давай обсудим.**
Явно просишь задать наводящие вопросы по твоей идее. Помогает приблизиться к ожидаемому результату.

🟥 **Не останавливайся, пока не сделаешь.**
Иногда агент заканчивается на полпути: "задачу сделал, но PR давай сам". Не-а, газ до конца.

🟥 **Покажи, не рассказывай.**
Вместо описания - работающий код. Вместо плана - результат.

Что работает у вас? Кидайте в комменты.

➡️ <Название канала> ⬅️

#промпты #ClaudeCode
```
