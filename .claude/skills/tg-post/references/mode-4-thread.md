# Режим 4: тред (400–800 знаков)

Структура, ритм и примеры для режима «затравка для обсуждения в комментариях». Читай ТОЛЬКО тот файл, чей режим выбран — остальные режимы в контекст не тащи.

## РЕЖИМ 4: ТРЕД (400-800 символов)

Пост, заточенный на обсуждение в комментариях. Сначала делишься сам, потом тянешь аудиторию.

### Структура
1. Зацепка по теме (жирная или с эмодзи)
2. Твой вклад первым (1-3 пункта)
3. Прямой CTA поделиться в комментариях
4. Футер

### Особенности
- Всегда показывай пример — делись СВОИМИ находками/опытом первым
- Прямой CTA без церемоний: "А у вас?", "Кидайте в комменты"
- Можно спросить "Кого позвать?", "Что запрогать дальше?"

### Пример

```
Тред реально полезных скиллов и MCP

Я начну:

• agent-browser - CLI для управления браузером, от Vercel. Работает стабильнее родного chrome mcp
  ↳ agent-browser.dev

• coolify mcp - деплою на свой сервер через coolify, через mcp легко чекать прод
  ↳ github.com/StuMason/coolify-mcp

А у вас? Кидайте в комменты

➡️ <Название канала> ⬅️

#инструменты #MCP
```
