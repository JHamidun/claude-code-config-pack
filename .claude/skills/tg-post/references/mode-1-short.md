# Режим 1: короткий пост (600–1000 знаков)

Структура, ритм и примеры для режима «быстрая реакция на новость или событие». Читай ТОЛЬКО тот файл, чей режим выбран — остальные режимы в контекст не тащи.

## РЕЖИМ 1: КОРОТКИЙ ПОСТ (600-1000 символов)

### Структура
1. Жирный заголовок (3-5 слов, CAPS по желанию)
2. Ключевые факты + цифры (2-3 предложения)
3. Позиция автора (1-2 абзаца)
4. P.S. с поворотом (опционально, только если есть настоящая мысль)
5. Футер (варианты):
   - `➡️ <Название канала> ⬅️`
   - `⚡️ <Название канала> ⚡️`
   - `➡️ [<Название канала>](https://t.me/your_channel) ⬅️`
6. Хештеги (1-3) — ПОСЛЕ футера
7. К посту обычно прикрепляется фото, видео или скриншот

### Варианты начала (выбирать естественно)
- Удар фактом: `РОБОТ ОСВОИЛ МОРДОБОЙ.`
- Начать с факта: `Google приоткрыл Gemma 3.`
- Личный зачин: `Нашёл ещё один способ...`
- Цитата: `Мустафа Сулейман написал: "..."`
