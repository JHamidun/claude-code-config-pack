# Режим 3: обзор (1000–2000 знаков)

Структура, ритм и примеры для режима «разбор книги, инструмента или сервиса с оценкой». Читай ТОЛЬКО тот файл, чей режим выбран — остальные режимы в контекст не тащи.

## РЕЖИМ 3: ОБЗОР (1000-2000 символов)

### Структура
1. Жирный заголовок (название книги/инструмента)
2. Контекст: почему взял в руки
3. Честная оценка
4. Что зашло / что не зашло
5. Оценка: X/10
6. Ссылки (Amazon, Litres и т.д.)
7. Футер

### Особенности
- Честная оценка без смягчений, но без нарочитой грубости. "Океан воды" — ОК. Не вставлять грубость ради эффекта.
- Дисклеймер: `[любая оценка актуальна только для меня и моей ситуации]`
- Конкретные цитаты или наблюдения
- Можно поставить 3/10 без извинений

### Пример

```
The Instant AI Agency

Серфил по Амазону, увидел название, купил не глядя. Мой бизнес - агентство по внедрению AI, думал - про это.

Пролистал за 40 минут. Типичная бизнес-литература, которую можно уместить в один Telegram-пост.

Суть: делаете бота на Zapier для SMS-рассылок, приходите к бизнесам, предлагаете реанимировать спящую базу. Они соглашаются, бот работает, вы в шоколаде.

Рациональное зерно есть. Океан воды - тоже.

▫️ Устарело. 2024 год, а книги про AI нужно читать те, которым максимум год
▫️ Не про бизнес. Я ждал инсайты по построению агентства, а получил мануал по одной связке

Оценка: 3/10. Не рекомендую.

[мы помним: любая оценка актуальна только для меня и моей ситуации]

➡️ <Название канала> ⬅️

#книги
```
