# CTA Templates для Habr-статей

Готовые блоки call-to-action, обкатанные на живой серии статей. Использовать как стартовую точку, кастомизировать под статью.

---

## Тип 1. «Забери каркас» (для технических флагманов)

Используется когда статья описывает реальную систему/проект и читатели хотят попробовать у себя.

```markdown
## Если хотите забрать каркас {{PROJECT_NAME}}

Если хотите забрать каркас {{PROJECT_NAME}} как стартовый шаблон — оставьте комментарий под статьёй, я пришлю архив в личку. Это анонимизированный набор: {{ARTIFACTS_LIST}}.

Без моих API-ключей, без personal data, без внутренних деталей. {{LIST_WHAT_TO_REPLACE}} — нужно подставить свои.

Это не курс и не платный продукт — просто отдаю то, на чём сам работаю каждый день.
```

Параметры:
- `{{PROJECT_NAME}}` — имя твоего проекта, как оно звучит в статье
- `{{ARTIFACTS_LIST}}` — `docker-compose.yml`, шаблон `soul/`, `routing-rules.json`, etc.
- `{{LIST_WHAT_TO_REPLACE}}` — TG bot token, OWNER_TELEGRAM_ID, API ключи

---

## Тип 2. «Если хотите попробовать инструмент» (для обзоров)

Когда статья — про сторонний продукт (диктофон, IDE, CLI — что разбираешь).

```markdown
P.S. {{TOOL}} — рабочий инструмент, факт. Если хочется попробовать: я не получаю реферал, не делаю кросспостов, не имею affiliate-ссылок. {{ALTERNATIVES_NOTE}}
```

---

## Тип 3. P.S. + P.P.S. с каналом

Стандартный финальный блок для всех статей.

```markdown
---

P.S. {{ОДНА СТРОКА — личный комментарий, инструмент или мысль}}

P.P.S. Свежие находки и апдейты выкладываю в Telegram-канале «{{CHANNEL_NAME}}» — заходите, если хочется быть в курсе.

---

**Хабы:** {{HUB_LIST}}
**Теги:** {{TAG_LIST}}
```

---

## Тип 4. Series footer (для статей в серии)

Используется в long/flagship статьях, где есть смежные публикации.

```markdown
Это была {{N}}-я статья серии. Если интересна остальная картина — три предыдущих подходят с разных сторон:

- **{{TITLE_1}}** — {{ONE_LINE_DESCRIPTOR_1}}. ([ссылка](series:{{SLUG_1}}))
- **{{TITLE_2}}** — {{ONE_LINE_DESCRIPTOR_2}}. ([ссылка](series:{{SLUG_2}}))
- **{{TITLE_3}}** — {{ONE_LINE_DESCRIPTOR_3}}. ([ссылка](series:{{SLUG_3}}))
```

`series:slug` резолвится publisher'ом из `templates/series.json`.

---

## Тип 5. «Если у вас N — позвоните» (для коммерческих)

Используется аккуратно, не более одного раза на серию. Лучше для VC.ru и LinkedIn чем для Habr.

```markdown
Если у вас в команде есть похожая боль — {{SPECIFIC_SITUATION}} — приходите в личку @{{TG_HANDLE}}. Не продаю, просто делюсь опытом.
```

---

## Анти-паттерны CTA на Habr

- Длинные «спасибо за прочтение» — Habr минусует
- Прямые продажи курса/продукта — банится модерацией
- Множественные CTA в одной статье (один P.S. + один P.P.S. — максимум)
- Призыв «подписывайтесь на меня здесь и в других соцсетях» — выглядит тщеславно
- Анкета / форма / опрос — отвлекает от технической сути
