# Типы кампаний, RSA и настройка Search (Google Ads)

> Источник: экспертная методология (уроки «Типы рекламы», «Настройка поисковых кампаний», «PMax/Smart/YouTube/GDN»). Дополняет разделы SKILL.md «8 типов кампаний» и «Рабочий процесс №2». Разбор каждого типа + RSA пошагово + полный чек-лист настройки Search.

---

## 1. Восемь типов кампаний — разбор и критерии

### 1. Search (Поисковая сеть) — приоритет №1
- Реклама по ключам в поисковой выдаче. **Самый горячий, целевой трафик** (пользователь готов купить).
- Запускать **первым**, если есть поисковый спрос (100+ запросов/мес). Если спроса нет/мало → таргетированные форматы.

### 2. Display Network / КМС
- Баннеры, видео, тексты на сайтах-партнёрах через **Google AdSense**. Аналог РСЯ Яндекса.
- ⚠️ **«Самый мусорный инструмент Google»:** CTR обычно **<0.4%**, слабый контроль площадок, много некачественного инвентаря. **Яндекс РСЯ качественнее** (жёстче модерация, CTR >0.4%).
- Применение: ремаркетинг, охват — но не как основной перформанс-канал.

### 3. Shopping (Товарная)
- Карточки товаров в выдаче. Для **e-commerce**.
- Данные берутся из **Google Merchant Center** (название, фото, цена).

### 4. YouTube
| Формат | Что это |
|--------|---------|
| **In-Stream skippable** | видео с пропуском после 5 сек (самый популярный) |
| **In-Stream non-skippable (Bumper)** | до 6 сек, без пропуска (охват) |
| **Out-Stream** | реклама вне видео — в ленте рекомендаций YouTube, под видео, в поиске YouTube |
- Брендовый и перформанс-формат. Видео 6–15 сек / Shorts / TrueView. Эффективен с особыми сегментами + ремаркетингом.

### 5. Demand Gen
- AI-кампания. Показывается в **YouTube (видео + Shorts), Gmail, Discover Feed** (новостная лента в Chrome/на мобильных).
- **С 2025:** можно выбирать **каждый плейсмент отдельно** (раньше только пакетом).
- Внутри доступен **look-alike** (Customer Match → похожие).

### 6. Performance Max (PMax)
- **Самая автоматизированная** кампания: все плейсменты разом (поиск, YouTube, Gmail, карты, Display). Максимум ИИ — Google сам решает, где и кому показывать.
- ⚠️ **Минусы:** нельзя отключить отдельные плейсменты; **нет детальной статистики по каналам**.
- Запускать при **30+ конверсиях**. Можно «обучить как Search»: перезапускать, пока первые конверсии не пойдут именно с поиска. Эффективен с особыми сегментами + ремаркетингом.

### 7. Smart Campaigns
- Поиск + GDN + ремаркетинг, алгоритм сам распределяет показы. Можно обучить работать только на поиске.
- **Устаревший AI-формат, редко полезен → не рекомендуется.**

### 8. App
- Продвижение мобильного приложения (установки). Отдельная кампания типа «App Install».

### Логика выбора инструмента
- Поисковый спрос есть → **Search в приоритете**.
- Спроса нет/мало → YouTube / Demand Gen / Display.
- **Точка баланса:** когда выкуп 60–70% поиска становится в 2× дороже — дополнять другими инструментами.

## 2. Адаптивные поисковые объявления (RSA)

Google **сам комбинирует** заголовки и описания, выбирая лучшие сочетания под запрос.

### Структура
| Элемент | Количество | Правило |
|---------|-----------|---------|
| **Заголовки** | **12–15** | **~8 с ключами** (макс. совпадение с запросами) + **~4–6 уникальных** с УТП |
| **Описания** | **4** | развёрнутые выгоды |
| URL финальной страницы | 1 | отдельный лендинг под поисковую кампанию |
| Путь отображения | опц. | для читаемости |

### Что повышает рейтинг качества объявления
- Релевантность ключей.
- Уникальные заголовки (не дубли).
- **Все расширения** в наличии.
- Высокий CTR.
- **Дополняемость:** первый заголовок усиливается вторым в связанную мысль.
- Цель эффективности объявления — **«Отлично»** (не «Хорошо»/«Среднее»).

### Обязательные расширения (assets) — добавлять сразу
- **Уточнения (Callouts):** «Бесплатная доставка», «Гарантия 2 года».
- **Быстрые ссылки (Sitelinks):** ссылки на разделы сайта.
- **Структурированные описания (Structured Snippets):** категории товаров/услуг.
- **Изображения / логотип.**
- **Телефон / адрес** (если актуально).

> «Обязательно максимальное количество объектов добавляем сразу» — расширения повышают CTR и Quality Score.

### Лайфхаки RSA
- **Закрепление (pin) заголовков** на позициях **1–3** (контроль порядка ключевых сообщений).
- **Динамическая вставка ключевого слова** `{KeyWord:текст по умолчанию}` — подставляет запрос пользователя в заголовок.
- **Таймер обратного отсчёта** (FOMO) — для акций с дедлайном.

## 3. Типы соответствия ключевых слов

| Тип | Запись | Описание | Пример ключа → запрос |
|-----|--------|----------|------------------------|
| **Точное** | `[furniture store]` | запрос максимально близок к ключу | → "furniture store", "home furniture shop" |
| **Фразовое** | `"furniture store"` | запрос содержит фразу, может быть длиннее | → "buy furniture store online" |
| **Широкое** | `furniture store` | семантически связан, широкий охват | → "modern furniture", "home decor shop" |

- **Старт — точное + фразовое.** Широкое — осторожно (требует жёсткой минусации).
- Массово менять формат — через **Match Type Tool**.
- Один кластер ключей = одна группа объявлений.

## 4. Полный чек-лист настройки Search-кампании

### Этап 0. Подготовка (до кампании)
- [ ] Создать **Google Analytics 4**, поставить счётчик (через GTM или напрямую). **Server-side GTM** — стандарт 2026.
- [ ] Настроить цели/события (лид, заявка, звонок, покупка); выбрать **основное массовое событие** для оптимизации.
- [ ] Связать **GA4 ↔ Google Ads**, импортировать конверсии.
- [ ] Для e-commerce — передавать **выручку** (`value` в `purchase`).

### Этап 1. Создание кампании
- [ ] Кампании → **+** → **«Не указывать цель»** (открывает все 8 типов).
- [ ] Тип: **«Поисковая сеть»**.
- [ ] Проверить, что цели **не по умолчанию** (использовать конкретные).
- [ ] **⚠️ Снять галочку «Контекстно-медийная сеть»** (вырубить КМС — иначе комбинированная кампания низкого качества).
- [ ] Гео: **только «Присутствие в местоположении»** (убрать «Интерес»).
- [ ] Языки: нужные (RU/EN/др.).
- [ ] **Ротация объявлений на старте — выключена.**
- [ ] **UTM-метки на уровне кампании.**

### Этап 2. Семантика и группы
- [ ] Структура: тематика → кампания, базис → группа, ключи → в группу (см. `semantics-budget.md`).
- [ ] Типы соответствия: старт `[exact]` + `"phrase"`.
- [ ] Список минус-слов (базовый: free, download, конкуренты).

### Этап 3. Объявления
- [ ] RSA: 12–15 заголовков (8 с ключами + 4–6 уникальных), 4 описания.
- [ ] Все расширения (callouts, sitelinks, structured snippets, изображения, телефон/адрес).
- [ ] Лайфхаки: pin 1–3, `{KeyWord:...}`, таймер.
- [ ] Проверить эффективность объявления — цель «Отлично».

### Этап 4. Ставки и бюджет
- [ ] Стратегия: **«Максимум кликов»** (старт, нет истории).
- [ ] Ставка: минимальная для показа в верхнем блоке (по планировщику, на 30–40% объёма).
- [ ] Дневной бюджет — чтобы каждое объявление набрало 30–50 кликов.

### Этап 5. Запуск и мониторинг
- [ ] Запустить → первые 3–7 дней мониторинг.
- [ ] **Чистка минус-слов ежедневно** (или раз в 3 дня) по отчёту поисковых запросов.
- [ ] После 30–50 кликов на объявление → включить ротацию (оптимизацию показов).
- [ ] Следить за CTR, CPC, CR.

## 5. Типичные ошибки (НЕ делать)

| Ошибка | Почему плохо |
|--------|--------------|
| Оптимизация на уровне **аккаунта** вместо кампании | теряешь контроль над структурой |
| **Отсутствие минус-слов** | сливаешь бюджет на нецелевые клики |
| Использование **только Broad Match** | поток мусорных запросов |
| Слабое объявление **без расширений** | низкий Quality Score, дорогой клик |
| **Завышенные ставки на старте** | переплата до накопления данных |
| **Включённая КМС** в поисковой кампании | падение качества трафика |
| **Гео «Интерес»** вместо «Присутствие» | показы не той географии |
| Указание **цели** при создании | Google скрывает часть типов и навязывает настройки |

## 6. Лучшие практики (резюме блока)

- ✅ Подбирай максимально релевантные заголовки → Quality Score 8–10.
- ✅ Делай **отдельные лендинги** под поисковые кампании.
- ✅ Для e-commerce подключай **Google Merchant Center**.
- ✅ Для анализа конкурентов — **Google Transparency Center** (adstransparency.google.com, аналог Ads Library).
- ✅ Для мобильных приложений — отдельные кампании «App Install».
- ✅ Оптимизируй **по фактическим данным, не «по ощущениям»**.
- ✅ Помни: **50% успеха — правильные ключи, 50% — качество объявлений и посадочной страницы.**
