# Конструктор аудиторий (Google Ads) — самое ценное в блоке

> Источник: экспертная методология (урок «Performance Max, Smart, YouTube, GDN и Ремаркетинг. Менеджер аудитории»). Дополняет раздел SKILL.md «Конструктор аудиторий». Это **главная идея блока Google Ads**: в Google аудитории — фактор №1 (8–9 случаев из 10), а не алгоритм ИИ.

---

## 1. Фундаментальный принцип

> **«Google ≠ Meta. В Meta алгоритм сам всё решает, а в Google нужно руками управлять аудиторией и событиями. Google Ads — это конструктор: каждую аудиторию можно запускать в каждом инструменте. В 8–9 случаях из 10 аудитории — это фактор номер один. Креатив важен, но он вторичен — третий по значимости после аудиторий и инструментов.»**

```
[Аудитории] × [Инструменты] = Успех
```

| **6 категорий аудиторий** | **6 инструментов** |
|---------------------------|--------------------|
| Соцдем (пол, возраст, **семейный доход**, дети) | Search |
| Интересы (финансы, еда, технологии, красота) | YouTube |
| Заинтересованные (Intents) | Display (КМС) |
| Life Events (события жизни) | Demand Gen |
| Ремаркетинг | Gmail |
| **Custom Segments** (особые сегменты) | Performance Max |
| + Комбинированные (пересечения) | |

**Любая аудитория × любой инструмент** — отсюда «конструктор».

---

## 2. Разбор шести категорий аудиторий

| Категория | Что внутри | Вердикт эксперта |
|-----------|-----------|------------------|
| **Соцдем** | пол, возраст (вилки, не точечно), **семейный доход**, наличие детей | слишком широкая → **только для тестов** |
| **Интересы** | темы: финансы, еда, технологии, красота | лучше когда другие сегменты **исчерпаны** |
| **Заинтересованные (Intents)** | поведение: что ищут, что покупают, какие сайты посещают | **хорошая отправная точка для узкого таргета** |
| **Life Events** | ремонт, покупка дома, свадьба, смена работы | очень точные, но **ограничены по количеству** |
| **Ремаркетинг** | посетители сайта, корзины, база лидов | при наличии данных в GA4 |
| **Custom Segments (особые)** | вручную: по поисковым запросам / интересам / сайтам конкурентов / приложениям | **самые эффективные аудитории** |
| **Комбинированные** | пересечение разных аудиторий | узкий и точный портрет ЦА, «золотые связки» |

### Приоритет применения

> **Начинай с самых узких — особые (Custom Segments) и комбинированные. Постепенно расширяйся, если не хватает трафика. Проверяй, какие дают лучший результат, и переноси победителей в разные инструменты.**

**Custom Segments по ключам в URL / сайтам конкурентов — самые эффективные.** Это ручная настройка: задаёшь поисковые запросы, сайты конкурентов, приложения — Google собирает людей с таким поведением.

## 3. Семейный доход (Household Income)

- **Недооценённая** настройка внутри соцдема.
- Доступна **не во всех странах**: **США, Индия, Индонезия, Мексика, Колумбия, ваш регион** и др.
- Позволяет таргетироваться на **верхние 10–50%** по доходу.
- **Кейс:** в **Индии** топ **20–30%** по доходу помогали вытаскивать качественный трафик.
- **Применение для проектов пользователя:** рынки US/IN/ID/MX/CO/BR, где есть платёжеспособный сегмент под продукт.

## 4. Наблюдение vs Таргетинг — ключевой приём

Аудитории добавляются в кампанию в **двух режимах**:

| Режим | Что делает | Когда |
|-------|-----------|-------|
| **Таргетинг** | **ограничивает** показы только выбранной аудиторией | когда уверен в сегменте |
| **Наблюдение** | **не ограничивает** показы, собирает **статистику** | для анализа / сбора инсайтов |

### Фреймворк роста (от поиска к медийке)

```
Этап 1: SEARCH
  → запустить поисковую кампанию
  → добавить аудитории в НАБЛЮДЕНИЕ
  → горячий поисковый трафик автоматически разбивается по аудиториям
  → собрать статистику

Этап 2: АНАЛИЗ
  → проанализировать успешные аудитории (CPA, CR, клики)
  → выявить топовые сегменты

Этап 3: МАСШТАБИРОВАНИЕ
  → запустить топ-сегменты как ТАРГЕТИНГ в YouTube / Display / Performance Max
  → экспериментировать с разными каналами
```

**Лайфхак с поиском:** на Search можно добавлять аудитории в раздел «Аудитории» — режим **наблюдения** даёт бесплатную кластеризацию горячего трафика; режим **таргетинга** дополнительно ограничивает показы.

### Как добавить аудитории (UI)
Google Ads → Кампании → выбрать кампанию → вкладка «Аудитории» → «+ Аудитории» → выбрать режим (Таргетинг / Наблюдение) → выбрать сегменты → Сохранить.

### Как анализировать
Кампания → «Аудитории» → метрики по каждой → сравнить CPA / CR / клики → выявить топ → использовать в медийных кампаниях.

## 5. Ремаркетинг по интервалам

Разбивай аудиторию ремаркетинга по давности визита, делай **отдельные офферы/визуалы** на каждый интервал:

| Интервал | Применение |
|----------|-----------|
| **3 дня** | свежие, агрессивный «догоняющий» оффер |
| **7–14 дней** | прогрев, один из лучших |
| **30–60 дней** | напоминание |
| **60–180 дней** | реактивация |

> **Лучше всего работают интервалы 14–30 и 60–90 дней.**

Ремаркетинг доступен при наличии данных в GA4 (посетители, корзины, база лидов). Эффективен особенно в связке с YouTube и Performance Max.

## 6. Customer Match (загрузка клиентов → look-alike)

- Загрузка списка клиентов: **имя, e-mail, страна**.
- Google строит **похожую аудиторию** (look-alike) на основе твоих клиентов.
- **Качество зависит от объёма и точности** данных.
- ⚠️ Look-alike в Google доступен **только в Demand Gen** (в Search — нет; в этом отличие от Meta, где lookalike везде).

## 7. Масштабирование (связь с инструментами)

После того как через **наблюдение** на Search нашли топовые аудитории — масштабируй их в инструменты:

| Инструмент | С какими аудиториями лучше всего |
|------------|----------------------------------|
| **YouTube** | особые сегменты + ремаркетинг (видео 6–15 сек, Shorts, TrueView) |
| **Performance Max** | особые сегменты + ремаркетинг (запускать при 30+ конверсиях) |
| **Display (GDN)** | ремаркетинг, интересы (помни CTR <0.4%) |
| **Demand Gen** | look-alike (Customer Match) + интересы + Intents |
| **Search** | наблюдение для сбора + таргетинг для ограничения |

**Принцип переноса:** нашёл «золотую связку» аудитория + инструмент с хорошим CPA → перенеси в другой инструмент → проверь, держится ли результат → масштабируй бюджет.

---

## 8. Чек-лист архитектуры аудиторий

- [ ] Custom Segments собраны (ключи в URL, сайты конкурентов, приложения) — это база.
- [ ] Комбинированные сегменты для узких связок.
- [ ] Ремаркетинг разбит по интервалам (3 / 7–14 / 30–60 / 60–180), офферы отдельные.
- [ ] Семейный доход проверен (если рынок US/IN/ID/MX/CO/BR).
- [ ] На Search аудитории добавлены в **наблюдение** для сбора статистики.
- [ ] Топовые сегменты выявлены по CPA/CR → перенесены в медийку как таргетинг.
- [ ] Customer Match загружен (если есть база) → look-alike в Demand Gen.
- [ ] Помни: креатив — третий фактор, аудитория + инструмент решают.
