# Семантика и прогноз бюджета (Google Ads)

> Источник: экспертная методология (урок «Типы рекламы Google Ads и семантика»). Дополняет раздел SKILL.md «Рабочий процесс №1». Глубокая детализация карты базисов, инструментов семантики и трёх формул прогноза.

---

## 1. Инструменты сбора семантики

### Keyword Planner (Планировщик ключевых слов) — бесплатно

- Встроен в Google Ads. Аналог Яндекс.Wordstat.
- Показывает: **среднее число запросов/месяц**, конкуренцию, **диапазон ставок** (минимальная/максимальная для показа вверху страницы).
- **Минус:** нужен Google Ads аккаунт. Из РФ создаётся, но рекламу на РФ запустить нельзя (только СНГ/мир).
- **Доп. задание эксперта:** открыть кабинет и найти в нём планировщик ключевых слов (это уже первый шаг к запуску).

### Keyword Tool ($90/мес) — опционально

- Парсит данные сразу из **Google, YouTube, Bing, Amazon, App Store, TikTok** и др.
- **Три ключевые фичи:**
  - **Questions** — автоматически выделяет информационные запросы (что/как/почему).
  - **Prepositions** — разбивает запросы на базисы (кластеры по предлогам).
  - **Related Keywords** — похожие запросы (находит смежные темы: Big Data, Data Science).
- **Рекомендация:** взять на **1 месяц** для глубокого анализа рынка/продукта → собрать всё → отписаться.
- В операционных заметках курса упоминается связка **Keyword Planner + keywordtoolcollector.io** (для анализа стоимостей кликов, позиций, ставок).

### ChatGPT для расширения

Промпт-шаблон:
> «Ты профессиональный маркетолог. Запускаем курсы Data Analytics в [регионе]. Придумай смысловые базисы тем на английском для сбора семантики.»

Помогает найти неочевидные кластеры (например, «SQL for Data Analytics», «Data Analytics for beginners»). Используется и для **кластеризации**: разделить собранные запросы на прямые / смежные / информационные.

## 2. Структура семантического ядра (Mindmap)

**3-уровневая приоритизация запросов** (порядок запуска):

| Приоритет | Тип | Примеры | Когда запускать |
|-----------|-----|---------|-----------------|
| **№1** | Прямые коммерческие | купить, курсы, цена, онлайн, заказать | в первую очередь |
| **№2** | Смежные | Data Science (вместо Data Analytics), Big Data, IT-курсы | после насыщения прямых |
| **№3** | Информационные | что такое, кто такой, как стать | последняя очередь, низкий приоритет |

> **Сигнал потолка:** «Прямые коммерческие — номер один. Смежные — номер два. Информационные — номер три. **Когда дошли до информационных запросов, значит, почти достигли потолка в поиске**.»

**Два подхода (используются вместе):**
- **Логический** — продумать 5–10 направлений руками (курсы X, программы, онлайн-курсы, с сертификатом, в городе Y). Составить Mindmap (Miro/XMind/бумага).
- **Количественный** — прогнать основные запросы через Keyword Tool / Keyword Planner → скачать с частотностью **100+** → кластеризовать через ChatGPT.

## 3. Карта базисов — главный фреймворк

**Что такое базис:** общая семантическая структура группы запросов.

Пример базиса 3-го уровня — **«Data Analytics Courses Online»**:
- «Data Analytics Courses Online in Jakarta»
- «Data Analytics Courses Online Price»
- «Data Analytics Courses Online Free»

### Архитектура кампаний (жёсткое правило)

```
1 тематика  = 1 рекламная кампания
1 базис     = 1 группа объявлений
Ключи внутри группы = «хвосты» базиса
```

### Порог создания группы объявлений

- **Минимальная частотность базиса:** **250+ запросов/месяц суммарно**.
- **Минимум один ключ:** **100+ запросов/месяц**.
- Если ниже → **не создавать отдельную группу**, объединить с другой (иначе статус **«мало показов»** и группа не работает).

> Из Notion-задания: «собрать любой объём семантики и кластеризовать, но **минимум на 1 тему и 5 групп**» (пример в шаблоне ДЗ).

## 4. Минус-слова (Negative Keywords)

- Собирать **параллельно** со сбором семантики — отмечать нерелевантные приставки сразу.
- Базовый список: `free`, `download`, `pirate`, `torrent`, названия конкурентов, «бесплатно», «своими руками».
- **Добавлять в кампанию сразу**, чтобы не платить за нецелевые клики.
- **Различие, которое надо держать в голове:**
  - **Ключевое слово** — *условие*, по которому показывается объявление.
  - **Поисковый запрос** — *то, что реально ввёл* пользователь.
  - Минусуем именно по отчёту **поисковых запросов** (Кампания → Ключевые слова → Поисковые запросы).
- **Регулярность чистки:** ежедневно или раз в 3 дня (зависит от объёма трафика).

## 5. Шаблон карты базисов (ДЗ эксперта)

Google Sheets / Excel со столбцами:

| Тематика | Базис | Ключи | Частотность (сумма по базису) | Минус-слова |
|----------|-------|-------|-------------------------------|-------------|
| Data Analytics Courses | Data Analytics Courses Online | …Jakarta / …Price / …Free | 1 200 | free, download |
| Data Analytics Courses | Data Analytics Bootcamp | …Online / …Reviews | 800 | free |

**Фильтр перед запуском:** оставить только базисы с частотностью **250+** и хотя бы одним ключом **100+**.

Шаблон карты базисов удобно вести в Google Sheets: колонки «базис / варианты / left-right расширения / частотность / конкуренция».

## 6. Прогноз бюджета — 3 формулы

> Цель — получить **вилку** бюджета (минимум / средний / максимум), а не одну цифру. Погрешность **±20–30%** (зависит от конкуренции и качества объявлений).

### Исходные данные
- Семантическое ядро со всеми ключами + частотность каждого.
- MIN/MAX ставка для показа вверху страницы (из Keyword Planner).
- Average CPC (из Keyword Tool, если есть).

### Три способа взять CPC

| # | Способ | Формула |
|---|--------|---------|
| 1 | **Средневзвешенная ставка** (Keyword Tool) | `Σ(Частотность_i × Ставка_i) / Σ Частотность_i` |
| 2 | **Средняя ставка Google Ads** | `(MIN ставка + MAX ставка) / 2` |
| 3 | **Average CPC** | колонка «Avg. CPC» из экспорта Keyword Tool |

### Расчёт бюджета

```
Бюджет = (Частотность × Доля трафика × CPC) / CTR
```

Где:
- **Доля трафика** — сколько спроса выкупаем. Для старта **20–50%**.
- **CTR (целевой)** — зависит от рынка: **СНГ 10–15% / Европа-США 5–7%**.

### Пример расчёта (одна тематика)

| Параметр | Значение |
|----------|----------|
| Частотность (показы при 100% выкупе) | 50 000/мес |
| Доля трафика | 30% → 15 000 показов |
| CTR | 6% → 900 кликов |
| CPC | $1.50 |
| **Бюджет** | **900 × $1.50 ≈ $1 350/мес** |

> ⚠️ В саммари урока фигурировал «грязный» вариант формулы без деления показов на CTR — он давал нереалистичную цифру. **Каноничный расчёт:** сначала показы → клики (показы × CTR) → бюджет (клики × CPC). Считать по всем 3 способам CPC → получить мин (оптимистичный) / средний (реалистичный ±20–30%) / макс (пессимистичный).

Пример прогнозирования удобно вести в отдельной таблице (Google Sheets) — карта базисов, три способа расчёта CPC и итоговая вилка бюджета в одном месте.

## 7. Чек-лист семантического этапа

- [ ] Mindmap из 5–10 направлений (3 уровня приоритета).
- [ ] Расширение через ChatGPT (неочевидные базисы).
- [ ] Частотность собрана (Keyword Planner; опц. Keyword Tool).
- [ ] Карта базисов заполнена (Тематика / Базис / Ключи / Частотность / Минус-слова).
- [ ] Базисы отфильтрованы (250+ сумма, 100+ хотя бы один ключ).
- [ ] Минус-слова собраны параллельно.
- [ ] Прогноз бюджета по 3 формулам → вилка мин/средний/макс.
- [ ] Структура: тематика → кампания, базис → группа, ключи → в группу.
