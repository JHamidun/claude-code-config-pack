# Viral Shorts Script Template (30 секунд)

## Метаданные
- **Тема:**
- **Hook formula:** [Curiosity Gap / Mistake Callout / Fast Result / Direct Question / Mid-Action / Contradiction / Visual Break]
- **Target retention:** >100% (loop activated)

## Скрипт по секундам

### [0–3 сек] HOOK
**Visual:** [pattern break — необычный кадр / инвертированный цвет / нестандартный crop]
**On-screen text:** [строка хука, ≥60pt, верхняя 1/3]
**Audio:** [verbal promise — declarative]

> Пример: «Я отключил RAG — точность выросла на 40%»

### [3–8 сек] CONTEXT TEASE
**Не раскрывать payoff.** Setup ситуации:

> «За неделю до этого я тестировал production-инстанс с большой базой документов…»

### [8–13 сек] PATTERN INTERRUPT #1
Смена темпа / локации / голоса:

> «И вот что я попробовал: [reveal #1]»

### [13–20 сек] CORE VALUE
Конкретный приём / цифра / факт:
- Smash cut каждые 1–2 сек
- Motion на статике (Ken Burns 1.0→1.05)
- Цифры > прилагательных

### [20–25 сек] PATTERN INTERRUPT #2 + SOFT CTA
Один ask, ≤5 сек:

> «Сохрани — через неделю забудешь это имя»

### [25–28 сек] LOOP SETUP
Готовим возврат к началу:

> «И именно поэтому…»

### [28–30 сек] ABRUPT END
Hard cut на середине слова. Финальный фрейм = первый фрейм:

> «…я отключил RAG и точность выросла на сорок про-» [CUT]

---

## CHECKLIST перед публикацией

- [ ] Hook первых 3 сек содержит visual interrupt + verbal promise
- [ ] Никаких «Привет, друзья» / slow build
- [ ] CTA ≤5 секунд, ОДИН ask
- [ ] Конец = начало (loop, audio + visual match)
- [ ] Нет fade-out, hard cut на середине слова
- [ ] Длина 25–35 сек (НЕ 60 сек растянутых)
- [ ] Pattern interrupt каждые 5 сек
- [ ] Title: declarative <40 символов, без вопроса
- [ ] Trending sound адаптирован под нишу
- [ ] First frame — самый сильный визуал
- [ ] On-screen text ≥60pt, контраст ≥7:1, верхняя 1/3
- [ ] Save-focused CTA, не «подпишись»

## Title formula

Стек: **Number + Outcome + (контекст)**

> «5 фич Claude 4.5, которые никто не заметил (гайд 2026)»

Если выбираешь Wish I Knew (+78% CTR):

> «7 ошибок RAG, которые я жалею, что сделал»
