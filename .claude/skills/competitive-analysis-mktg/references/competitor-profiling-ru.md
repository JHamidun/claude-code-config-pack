# Профилирование конкурентов (RU)

Порт `competitor-profiling` из marketingskills: на вход — список URL конкурентов, на выход — структурированные профили. Переложено под RU-рынок (AI-образование и AI-консалтинг) и стек пользователя: Firecrawl → DataForSEO/Ahrefs заменены на **Яндекс Wordstat/Вебмастер + similarweb-analytics**, отзывы G2/Capterra → **otzovik/startpack/soware/CNews/Яндекс Бизнес**.

**Перед началом:** `~/.claude/business-context.md` → раздел «Продукт» (кто вы, отстройка). Профили потом идут в `comparison-pages-ru.md` (страницы) и `sales-enablement-ru` (battlecard).

## Принципы

1. **Факты, не мнения.** Каждый тезис — со ссылкой на источник (скрейп страницы, отзывы, метрики трафика). Выводы помечай как выводы.
2. **Структурно и сравнимо.** Все профили по одному шаблону.
3. **Свежесть.** Профиль — снимок, ставь дату. Флаг устаревшего («цены не менялись с 2024»).
4. **Честная оценка.** Не преувеличивай слабости и не приуменьшай силу конкурента.

## Кто конкуренты пользователя (RU AI-образование / консалтинг)

Категории для профилирования (примеры; точный список собрать под задачу):
- **Онлайн-курсы по нейросетям / промптингу** (edtech-платформы, авторские курсы, школы).
- **AI-консалтинг / интеграторы** (студии внедрения ИИ, консультанты, агентства).
- **Корпоративное обучение AI** (провайдеры корп-тренингов, T&D-вендоры).
- **AI-агрегаторы с обучением** (платформы доступа к моделям + контент).

Найти и квалифицировать конкурентов: `lead-research`, `headhunter` (по вакансиям видно фокус), `social-intel`, `last30days` (RU-обсуждения), Wordstat по «обучение нейросетям»/«курс по AI».

## Инструменты (RU-замены)

| Запад (оригинал) | RU-замена | Скилл |
|------------------|-----------|-------|
| Firecrawl scrape/map | Firecrawl (через `firecrawl:*`) или `dev-browser` | `firecrawl-*`, `dev-browser` |
| DataForSEO ranked keywords / traffic | **Яндекс Wordstat + Вебмастер** | `yandex` |
| DataForSEO domain rank / backlinks | **similarweb-analytics** (трафик, источники) | `similarweb-analytics` |
| G2 / Capterra / TrustRadius отзывы | **otzovik, startpack.ru, soware.ru, CNews/TAdviser, Яндекс Бизнес** | `firecrawl-search`, `social-intel` |
| Reddit / форумы | **VK, Pikabu, Habr-комменты, vc.ru-комменты, TG-чаты** | `social-intel`, `last30days` |
| Технологии сайта | similarweb/ручной осмотр | `similarweb-analytics` |

## Что собирать по странице

| Страница | Что извлечь |
|----------|-------------|
| Главная | заголовок, value, CTA, соцпруф, на кого нацелено |
| Цены / тарифы | тиры, цены (₽), что в каждом, trial, корп-условия |
| Программа / продукт | модули, формат (онлайн/офлайн), длительность, особенности |
| О компании / авторе | кто за продуктом (эксперт vs безымянная школа), регалии |
| Кейсы / клиенты | названные клиенты, отрасли, заявленные результаты |
| Блог / соцсети | частота, темы, площадки (TG/VK/Habr/YouTube) |

## Шаблон профиля

```markdown
# [Конкурент] — Профиль конкурента

**URL:** [сайт]   **Сгенерирован:** [дата]   **Глубина:** [быстрый скан / глубокий]

## Сводка
| Метрика | Значение |
|---------|----------|
| Тэглайн | [с главной] |
| Кто за продуктом | [эксперт / школа / агентство] |
| Цена от | [нижний платный тир, ₽] |
| Trial / бесплатно | [да/нет + детали] |
| Оценка трафика (similarweb) | [визиты/мес] |
| Основные источники трафика | [органика/директ/соцсети] |
| Главные площадки контента | [TG/VK/Habr/YouTube] |

## Позиционирование
Заголовок · подзаголовок · угол позиционирования · 3 ключевые темы (с источником).

## Продукт / программа
Состав, формат, длительность, чем выделяются, направление развития.

## Цены (₽)
| Тир | Цена | Что входит |
Trial, корп-условия, скрытые расходы.

## Клиенты и соцпруф
Названные клиенты, отрасли, темы кейсов, отзывы (otzovik/startpack/Яндекс Бизнес — оценка + объём + темы похвалы/жалоб + 3-5 цитат).

## SEO / контент
Оценка трафика (similarweb), ключевые запросы (Wordstat-пересечение), топ-страницы, площадки и частота контента.

## Сильные / слабые стороны
Силы (с источником) · слабости (с источником).

## Выводы для пользователя
Где они сильнее нас · где мы сильнее · возможности (их дыры) · угрозы.

## Источники данных
Что и когда скрейпили/тянули.
```

Глубина: **быстрый скан** (главная + цены + similarweb-трафик + позиционирование) по умолчанию; **глубокий** (все страницы + отзывы + Wordstat-пересечения + контент-стратегия) — для топ-3–5 конкурентов или по запросу.

## Сводный документ (после всех профилей)

`_summary.md`: обзор поля одним абзацем · сравнительная таблица (вы + конкуренты по ключевым метрикам) · карта позиционирования (оси под рынок: «теория ↔ практика», «дёшево ↔ премиум», «соло-курс ↔ платформа+эксперт») · 3-5 стратегических выводов · дыры рынка и возможности.

## Несколько конкурентов

Параллель: главные страницы всех → цены всех → similarweb всех → отзывы всех. Профили синтезируй последовательно (нужна фокусировка), сводку — в конце. При 10+ конкурентах — сначала топ-5 по близости рынка/трафику.

## Обновление

Снимок с датой. Цены — ежеквартально, программа/продукт — при изменении, similarweb-трафик — раз в месяц, полный рефреш — раз в год. Внизу профиля — `## Change Log`.

Связки: `comparison-pages-ru.md` (страницы из профилей) · `competitive-intelligence` (sales-battlecard) · `similarweb-analytics` (трафик) · `yandex` (Wordstat/Вебмастер) · `social-intel`/`last30days` (отзывы/обсуждения RU) · `lead-research`/`headhunter` (поиск конкурентов).
