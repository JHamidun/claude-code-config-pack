# AI Корректура: $ARGUMENTS

## Пайплайн

Три прохода подряд, всё делает один субагент `proofreader`
(сведён 2026-08-22 из трёх отдельных корректоров — этапы и правила сохранены целиком):

```
Исходный текст → [1. Орфография] → [2. Пунктуация] → [3. Типографика] → Результат
```

## Инструкция по выполнению

### Подготовка

1. Прочитай входной файл: `$ARGUMENTS`
2. Определи имя файла без расширения и расширение для формирования промежуточных файлов
3. Создай директорию для промежуточных результатов рядом с исходным файлом (если её нет)

### Прогон

Запусти субагент @proofreader с задачей:

- **Вход:** исходный файл `$ARGUMENTS`
- **Задача:** прогнать текст через три прохода строго по порядку, каждый — по своему
  разделу `agents/references/proofreader-rules.md`:
  1. **Орфография** — только правописание слов + разметка речевых ошибок тегами `<err>`.
     Результат записать в файл с суффиксом `_1_ortho` рядом с исходным
     (например, `text_1_ortho.txt`).
  2. **Пунктуация** — только знаки препинания, орфографию не трогать (уже проверена),
     все теги `<err>` сохранить. Результат — в файл с суффиксом `_2_punct`.
  3. **Типографика** — только тире, кавычки, пробелы, валюты, сноски; орфографию и
     пунктуацию не трогать, теги `<err>` сохранить. Результат — в файл с суффиксом `_final`.
- **Выход:** `*_1_ortho.*`, `*_2_punct.*`, `*_final.*`

### Завершение

После выполнения всех 3 проходов:

1. Покажи пользователю путь к финальному файлу
2. Покажи краткую сводку: сколько изменений на каждом проходе (если можно определить)
3. Если были найдены речевые ошибки (теги `<err>`), перечисли их списком

## Важно

- Проходы идут ПОСЛЕДОВАТЕЛЬНО — результат предыдущего является входом следующего;
  слитный «умный» проход даёт правки не в своей зоне и портит текст
- Агент не выходит за рамки зоны текущего прохода
- Теги `<err comment="...">...</err>` сохраняются на протяжении всего пайплайна
- Промежуточные файлы сохраняются для возможности ревью каждого прохода
