# Meeting Notes: $ARGUMENTS

Structure the meeting notes with clear sections:

## 1. Meeting Info
- Date and attendees
- Duration and agenda

## 2. Key Decisions
- Decisions made
- Action items with owners
- Deadlines

## 3. Discussion Points
- Main topics discussed
- Open questions
- Blockers identified

## 4. Next Steps
- Immediate actions
- Follow-up meetings
- Documentation needed

Format as clear Markdown artifact.
