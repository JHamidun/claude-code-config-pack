# Models — движки и спавн

> ⚠️ **ЕДИНЫЙ КАНОН моделей** (все ID, алиасы, image-модели, внешние) → `config/models.md`.
> Здесь только то, что нужно в КАЖДОМ запросе: кого спавнить и каким движком.
> Конкретные идентификаторы тут намеренно не дублируются — расхождение уже было
> (правило несло Opus 4.8 против Opus 5 в каноне) и молча отдавало вчерашнюю модель.
>
> Таблицы выбора уровня, внешние модели и стоимость → `config/rules-ref/models-decisions.md`.

- **Аутентификация:** подписка Claude Code Max — все модели доступны, не по API.

## Роли моделей (канон)

| Алиас | Модель | Роль |
|-------|--------|------|
| `fable` | Fable 5.1 | Движок text-воркеров (дефолт спавна); числом не ограничивать |
| `opus` | Opus 5 | Оркестратор сессии; максимум reasoning; 1M контекст; подхват после лимита Fable (resume + смена model) |
| `haiku` | Haiku 4.5 | Массовые дешёвые прогоны (10+ параллельных), классификация |
| `sonnet` | Sonnet 5 | Доступен, но для воркеров НЕ дефолт |

**Уровни ниже (opus-level/standard/light) выбирают СЛОЖНОСТЬ задачи — глубину промпта и контекст, — а НЕ движок воркера.** Сложность регулируй промптом и контекстом, не сменой движка.


## Spawn Patterns

```python
Task(subagent_type="general-purpose", model="fable", prompt="...")  # text-воркер (дефолт)
Task(subagent_type="general-purpose", model="haiku", prompt="...")  # простое/быстрое
Task(subagent_type="general-purpose", model="opus",  prompt="...")  # оркестратор/сложное
```

- В frontmatter агентов: `model: fable` (канон, проставлен во всех agents/; исключение — orchestrator.md = opus).
- Смена модели сессии: `/model opus|fable|sonnet|haiku`.


## Уровни сложности задачи

| Уровень | Что означает для промпта воркера |
|---------|----------------------------------|
| **opus-level** | Богатый контекст, явные ВНЕШНИЕ гейты (сборка, тесты, сканер — то, чей результат не знаешь, пока не запустишь); оркестрирует сессия (Opus) |
| **standard-level** | Обычный промпт с целью и file paths; Fable справляется сам |
| **light-level** | Короткий промпт, низкий effort; для 10+ параллельных простых прогонов допустим `model: "haiku"` |
