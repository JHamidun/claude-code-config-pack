# AUTO-LEARNING

## Auto Memory (built-in)

**При КАЖДОЙ сессии** перед завершением обнови `~/.claude/projects/<project>/memory/`:

1. **MEMORY.md** — краткий индекс (до 200 строк), ссылки на topic-файлы
2. **Topic-файлы** — детальные заметки по темам (debugging.md, patterns.md, etc.)

### Что ВСЕГДА сохранять в auto memory:
- Решения багов и их root cause
- Новые паттерны, конвенции, архитектурные решения
- Ключевые команды и конфигурации которые работают
- Решения пользователя ("выбрал X потому что Y")
- Неочевидное поведение инструментов/библиотек
- Рабочие конфигурации (docker, deploy, CI/CD)

### When to update (immediately):
- Сразу после исправления бага
- Сразу после настройки нового инструмента
- Когда пользователь принимает решение
- Когда найдено неочевидное поведение
- В конце сессии — проверь, есть ли что сохранить
- **Record from SUCCESS too** — если подход сработал и был неочевиден, сохрани. Иначе будешь помнить только ошибки и станешь слишком осторожным

### Лимит индекса — проверять при каждой записи

MEMORY.md грузится в начало сессии, и всё за пределом **200 строк ИЛИ 25 КБ**
отбрасывается молча: ни ошибки, ни предупреждения. Однажды так выпали целые
разделы вместе с указателем на архив.

После добавления строки в индекс:

```bash
python ~/.claude/scripts/memory_fit.py          # проверит и ужмёт
python ~/.claude/scripts/memory_fit.py --check  # только проверить
```

Ужимает по возрастанию потерь: сначала режет длинные пояснения у старых
записей, потом выносит операции прошлых месяцев в отдельный файл. Свежие
пометки не трогает.

### Dream Consolidation (периодическая)
Раз в несколько сессий проводи "dream" — рефлексивный проход по памяти:
1. **Orient** — ls memory dir, прочитай MEMORY.md, просмотри topic-файлы
2. **Gather** — найди новую информацию: drifted memories, противоречия с кодом
3. **Consolidate** — обнови/создай файлы, конвертируй даты в абсолютные, удали противоречия
4. **Prune** — держи MEMORY.md под 200 строк и ~25KB, убери stale записи

### Формат:
- В MEMORY.md: краткая строка + ссылка на topic-файл если нужны детали
- Topic-файлы: структурированные заметки с примерами кода
- Не дублируй — сначала проверь существующие файлы

## Дисциплина ПРИМЕНЕНИЯ памяти (не только запись)

- **Применяй знания из памяти НЕВИДИМО** — как собственный опыт, а не как «извлечённый факт». НЕ говори «судя по памяти», «как я помню», «в MEMORY.md записано», «I notice/I can see». Атрибуцию источника давай только если спросили откуда.
- **Чувствительное** (семья/финансы/здоровье/конфликты) из памяти НЕ поднимай первым — пока YourFirstName сам не затронул тему.
- Память НЕ делает из ассистента поддакивателя: feedback-заметки не отменяют честный фидбек.
- **Signal-extraction**: сохраняй при СИГНАЛАХ (решение / root cause / фикс / «выбрал X» / неожиданно сработало) + 2-3 хода контекста — не «вспомни всё в конце».

## Иммутабельность (bi-temporal) — факт не удаляем, а закрываем

- Противоречие с прошлой заметкой → НЕ переписывай и НЕ удаляй её. Создай новую с `supersedes: [[старый-id]]`, старой добавь `status: superseded` / `superseded_by:` / `invalid_at:`. История «что считали верным и когда» = данные.
- **anti-churn**: если в dream нечего менять — НЕ трогай файл (лишний дифф ломает prompt-cache).
- Полный регламент frontmatter v2 (id/trigger/action/confidence/evidence/valid_at/invalid_at/discovery_tokens) + dream v2 (rethink/decay −0.02/нед/prune pending>30д/promote project→global/top-K TOP-INSTINCTS) — **в skill `dream`** (читается по требованию, не грузит промпт).

## Поиск по истории (3-слойный, token-aware)

- `search_chats.py search "запрос"` — компактный индекс (id/дата/проект/сниппет + оценка токенов), окно `--days` (деф 90; ai-news-bot шум скрыт).
- `search_chats.py timeline <id>` — контекст вокруг якоря. `search_chats.py get <id,id>` — полные тексты по id.
- **Recall-дисциплина**: вопрос о ПРОШЛОМ (решения / грабли / статусы проектов / «что мы делали с X») → СНАЧАЛА `brain_search`/`search_chats`, ПОТОМ веб/grep; найденное применяй невидимо.
- Перед промптом Fable-воркеру по знакомой теме: `python ~/.claude/scripts/memory_brief.py "<тема>"` → блок KNOWN GOTCHAS (≤600 ток) в промпт воркера.

## Memory commands

- `/memory-search query` - search memory
- `/memory-learn content` - save knowledge
- `/memory-stats` - memory statistics
- `/memory-ingest` - index chat history
- `/search-chats query` - full-text search across all chats
