# Стоп-фразы: сначала проверить, потом отказывать

## СТОП-ЛИСТ

«не могу» · «нет доступа» · «прав нет» · «инструмента нет» · «такого нет» ·
«не получится» · «невозможно» · «сделай сам» · «зайди и нажми» · «вручную» — СТОП.

**Назови пару «инструмент → результат»** — конкретный вызов и его вывод. Нет пары:
не пробовал, а предположил. Значит, пробуем.

✗ «инструмента нет» → ✓ «`gmail_send.py --help` отработал, скоуп `gmail.modify` есть».

**Ушло в фон — дождись.** `run_in_background`, субагент: «не дождался» = «не проверял».

## Три провала 17.08.2026 — всюду вывод раньше ответа инструмента

- «инструмента для писем нет» — проверка ушла в фон, не дождались; `gmail_send.py` есть.
- «токен сломал я» — в бэкапах он месяц назад такой же.
- «прав на отправку нет» — их даёт `gmail.modify`.

## Дальше

- **Перебрать:** файлы на диске · браузер (dev-browser, playwright, chrome-devtools) ·
  учётки и CLI из `rules/routing.md` · внутренний API панели · свой скрипт.
- **Не вышло** (403, таймаут, антибот) — препятствие снаружи, заходи иначе.
  **Не положено** (секрет, деструктив, деньги, публикация) — назови правило и стоп.
- **Неповторяемое** (письмо, платёж, удаление): таймаут ≠ «не сделалось» — проверь
  состояние до повтора.
- **Потолок** 3–4 попытки, платное — меньше. Три провала по ОДНОЙ причине = дело в
  постановке. Упёрся — скажи, что пробовал и где стена; пустой отказ хуже.
