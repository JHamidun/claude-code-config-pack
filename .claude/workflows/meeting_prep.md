# Workflow: Meeting Preparation

> Подготовка к встречам: 1:1, презентации, переговоры, интервью

## Keywords
`подготовка`, `prep`, `agenda`, `встреча`, `meeting`, `call`, `presentation`

## Inputs
- **task**: описание задачи из Todoist
- **meeting_type**: 1on1 | presentation | negotiation | interview | sales_call | team_meeting
- **participants**: кто участвует
- **topic**: основная тема
- **date_time**: когда
- **duration**: длительность

## Steps

### 1. Research Participants
```
Tool: Memory MCP + LinkedIn + past interactions
Output for each participant:
- Role, background
- Recent activity/news
- Past interactions (from Memory)
- Communication style
- What they care about
- Potential concerns/questions
```

### 2. Define Meeting Goals
```
Questions:
- What's the BEST outcome?
- What's the MINIMUM acceptable outcome?
- What do THEY want from this meeting?
- What decisions need to be made?
```

### 3. Create Agenda
```
Template:

# Meeting: [Topic]
Date: [date]
Duration: [X min]
Participants: [names]

## Goals
- [Goal 1]
- [Goal 2]

## Agenda
1. [Topic 1] - [X min] - [owner]
2. [Topic 2] - [X min] - [owner]
3. Q&A / Discussion - [X min]
4. Next steps - [5 min]

## Pre-Work (if any)
- [What participants should review]

## Materials Needed
- [Slides, docs, demos]
```

### 4. Prepare by Meeting Type

#### 1:1 Meeting
```
- Updates to share
- Questions to ask
- Feedback to give/receive
- Blockers to discuss
- Career/development topics (if applicable)
```

#### Presentation
```
- Slides prepared and tested
- Key messages (3 max)
- Anticipated questions + answers
- Demo tested (if applicable)
- Backup plan if tech fails
```

#### Negotiation
```
- BATNA (best alternative)
- Walk-away point
- Opening position
- Concessions prepared (what can give)
- Their likely position
- Win-win options
```

#### Interview (as interviewer)
```
- Questions prepared (10-15)
- Evaluation criteria
- Red flags to watch
- Company info to share
- Next steps process
```

#### Interview (as candidate)
```
- Company research done
- Role requirements understood
- Stories prepared (STAR format)
- Questions to ask (5-7)
- Salary expectations ready
```

#### Sales Call
```
- Prospect research done
- Pain points identified
- Solution mapped to pains
- Objection responses ready
- Next step proposals
- Pricing ready (if needed)
```

### 5. Technical Setup
```
Checklist:
- [ ] Calendar invite sent with agenda
- [ ] Video call link works
- [ ] Screen share tested
- [ ] Relevant docs open
- [ ] Backup dial-in number
- [ ] Quiet environment secured
- [ ] Camera/audio tested
```

### 6. Pre-Meeting Review
```
15 min before:
- Review agenda and goals
- Check participant profiles (from step 1)
- Prepare opening statement
- Clear mind from other tasks
```

## Post-Meeting

### 7. Capture Notes & Actions
```
Template:

# Meeting Notes: [Topic]
Date: [date]
Participants: [names]

## Key Decisions
- [Decision 1]
- [Decision 2]

## Action Items
- [ ] [Action] - @owner - due [date]
- [ ] [Action] - @owner - due [date]

## Key Discussion Points
- [Point 1]
- [Point 2]

## Next Meeting
- [Date/topic if scheduled]
```

### 8. Follow Up
```
Within 24 hours:
- Send meeting notes
- Create action items in Todoist
- Schedule follow-ups
- Save insights to Memory MCP
```

## Quality Checks
- [ ] Participants researched
- [ ] Agenda clear и shared
- [ ] Goals defined (best/minimum)
- [ ] Materials ready
- [ ] Tech tested
- [ ] Post-meeting follow-up planned

## Completion Criteria
- Prep document created
- Agenda sent to participants
- Materials ready
- Post-meeting tasks scheduled

## Time Estimate
- **Quick 1:1**: 5-10 minutes
- **Standard meeting**: 15-20 minutes
- **Presentation**: 30-60 minutes
- **Negotiation**: 30-45 minutes
- **Important interview**: 45-60 minutes

## Meeting Type Templates

### 1:1 Template
```
## Updates from me
- [Update 1]
- [Update 2]

## Questions for them
- [Question 1]
- [Question 2]

## Discussion topics
- [Topic 1]

## Asks/Blockers
- [Ask 1]
```

### Sales Call Template
```
## Prospect Profile
- Company: [name]
- Role: [title]
- Pain points: [list]
- Budget: [if known]
- Timeline: [if known]

## Call Goals
- Primary: [goal]
- Secondary: [goal]

## Questions to Ask
1. [Discovery question]
2. [Pain question]
3. [Impact question]
4. [Timeline question]

## Objection Responses
- "Too expensive" → [response]
- "Not now" → [response]
- "Need to think" → [response]

## Next Steps Options
- [Option A]
- [Option B]
```

## Notes
- Over-preparation можно, under-preparation нельзя
- Always have clear next steps
- Save all meeting insights to Memory
- Track follow-up completion
