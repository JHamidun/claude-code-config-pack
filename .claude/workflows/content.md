# Workflow: Content Creation

> Создание контента: посты, статьи, threads, видео scripts

## Keywords
`контент`, `пост`, `статья`, `thread`, `video`, `content`, `write`, `draft`

## Inputs
- **task**: описание задачи из Todoist
- **type**: post | thread | article | video_script | newsletter
- **platform**: Twitter/X | LinkedIn | Telegram | Blog | YouTube
- **topic**: о чём контент
- **goal**: engagement | leads | education | brand

## Steps

### 1. Analyze Platform & Audience
```
Tool: AI Analysis + Platform data
Output:
- Platform best practices
- Optimal length/format
- Posting time
- Audience expectations
- What performs well there
```

### 2. Research & Gather Material
```
Tool: Perplexity + Memory MCP + Notes
Sources:
- Personal experience/stories
- Industry data/stats
- Expert quotes
- Counter-arguments
- Real examples
```

### 3. Create Content Structure
```
Format by type:

## Twitter Thread
- Hook (tweet 1): [curiosity/controversy/value promise]
- Body (tweets 2-N): [one idea per tweet, story arc]
- Closer: [CTA, summary, question]

## LinkedIn Post
- Hook: [first 2 lines = 90% of success]
- Story/Value: [relatable, specific]
- Insight: [what reader learns]
- CTA: [engagement ask]

## Article/Blog
- Headline: [curiosity + benefit]
- Intro: [problem + promise]
- Body: [structured sections, H2s]
- Conclusion: [summary + next step]

## Video Script
- Hook (0-3s): [pattern interrupt]
- Intro (3-15s): [what you'll learn]
- Content (15s-end): [deliver value]
- CTA: [specific ask]
```

### 4. Write First Draft
```
Tool: AI Generation с personal voice
Requirements:
- Your authentic voice (not generic AI)
- Specific examples (not abstract)
- One core idea (not 5 topics)
- Actionable (not just informative)
```

### 5. Edit & Polish
```
Checklist:
- [ ] Hook grabs attention in 2 seconds?
- [ ] Every sentence earns its place?
- [ ] Specific > generic everywhere?
- [ ] Reading grade level appropriate?
- [ ] Call to action clear?
- [ ] Formatted for skimming?
```

### 6. Add Media (if needed)
```
Tool: Image generation / Canva / Screenshots
Types:
- Hero image
- Data visualization
- Infographic
- Meme/reaction
- Screenshot
```

### 7. Schedule or Publish
```
Tool: Platform scheduler or direct post
Considerations:
- Best time for audience
- Avoiding conflict with other content
- Cross-posting strategy
```

### 8. Track & Learn
```
Tool: Todoist + Memory MCP
After 24-48 hours:
- Performance metrics
- What worked/didn't
- Learnings for future
```

## Quality Checks
- [ ] Hook проверен (читается за 2 сек)
- [ ] Один core message (не несколько)
- [ ] Примеры конкретные
- [ ] Voice authentic (не generic AI)
- [ ] CTA понятный
- [ ] Формат правильный для платформы

## Completion Criteria
- Контент опубликован или запланирован
- Tracking task создан
- Draft сохранён (для repurposing)

## Time Estimate
- **Tweet/Post**: 10-15 minutes
- **Thread**: 20-30 minutes
- **Article**: 45-90 minutes
- **Video script**: 30-60 minutes

## Content Repurposing Map
```
Article → Thread → Posts → Newsletter section
Video → Blog post → Social clips → Quote cards
Thread → Newsletter → LinkedIn article
```

## Platform-Specific Tips

### Twitter/X
- First line = everything
- Use line breaks aggressively
- Numbers perform well (7 lessons, 10 tools)
- "Here's what I learned" format works

### LinkedIn
- Personal stories outperform advice
- Formatting matters (short paragraphs)
- Engagement in first hour critical
- Controversial takes get reach

### Telegram
- Longer form OK
- More personal tone
- Multimedia works well
- Community engagement важен

## Templates

### Thread Template
```
Tweet 1: [Hook - promise/controversy/curiosity]

Tweet 2: [Context/Background]

Tweet 3: [Point 1 + example]

Tweet 4: [Point 2 + example]

Tweet 5: [Point 3 + example]

Tweet 6: [Counter-argument or nuance]

Tweet 7: [Summary + CTA]

If you found this valuable, [specific CTA]
```

### LinkedIn Template
```
[Hook - 1 strong line]

[Line break]

[Story opening - specific moment]

[What happened]

[What I learned]

[Why it matters to reader]

[Line break]

[CTA question]
```

## Notes
- Consistency > perfection
- Repurpose successful content
- Save top performers to Memory for templates
- Test different formats, track what works
