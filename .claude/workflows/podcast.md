# Workflow: Podcast Preparation

> Подготовка к подкасту как гость или хост

## Keywords
`podcast`, `подкаст`, `interview`, `гость`, `host`, `episode`

## Inputs
- **task**: описание задачи из Todoist
- **role**: guest или host
- **podcast_name**: название подкаста
- **topic**: тема эпизода
- **date**: дата записи
- **person**: хост/гость (в зависимости от роли)

## Steps (As Guest)

### 1. Research the Podcast
```
Tool: Perplexity + YouTube/Spotify
Output:
- Format (length, style, audience)
- Recent episodes (3-5)
- Host's interview style
- Common questions they ask
- What guests do well there
- Audience demographics
```

### 2. Research the Host
```
Tool: LinkedIn + Twitter + Previous episodes
Output:
- Background
- Hot takes / opinions
- What they care about
- Pet peeves
- Communication style
```

### 3. Prepare Talking Points
```
Tool: AI + Personal notes
Output (doc):

# Episode Prep: [Podcast Name]
Date: [date]
Host: [name]
Topic: [topic]

## My Key Messages (3 max)
1. [Message 1 + supporting story]
2. [Message 2 + data point]
3. [Message 3 + actionable takeaway]

## Likely Questions
1. Q: [predicted question]
   A: [prepared answer + story]

2. Q: [predicted question]
   A: [prepared answer]

## Stories to Tell
- [Story 1]: context, setup, punchline, lesson
- [Story 2]: context, setup, punchline, lesson

## Quotable Moments (soundbites)
- "[Short memorable quote]"
- "[Another soundbite]"

## CTA for Listeners
- Where to find me: [links]
- What I'm working on: [project]
- How to connect: [method]

## Questions FOR the Host
- [Thoughtful question 1]
- [Thoughtful question 2]
```

### 4. Technical Setup Check
```
Checklist:
- [ ] Microphone tested
- [ ] Camera/lighting (if video)
- [ ] Quiet environment
- [ ] Backup internet
- [ ] Water nearby
- [ ] Notes accessible but not reading
```

### 5. Pre-Episode Warm-Up
```
30 min before:
- Review key messages
- Do vocal warm-up
- Clear head (no stress tasks)
- Energy check (coffee if needed)
```

## Steps (As Host)

### 1. Research the Guest
```
Tool: Deep research
Output:
- Full background
- Recent work/projects
- Controversial takes
- Unique insights
- Previous podcast appearances
- What they DON'T usually talk about
```

### 2. Prepare Questions
```
Format:

# Episode: [Guest Name] - [Topic]

## Opening
- [Warm-up question]
- [Origin story question]

## Core Questions (7-10)
1. [Question]
   - Why: [what insight we want]
   - Follow-up: [if they go shallow]

2. [Question]
   - Why: [insight]
   - Follow-up: [deeper]

## Signature Questions
- [Your standard closer]

## Rapid Fire (optional)
- [Quick question 1]
- [Quick question 2]

## If Time Allows
- [Bonus question]
```

### 3. Create Show Notes Template
```
# Episode [#]: [Title]
Guest: [Name]
Date: [date]

## Summary
[2-3 sentences]

## Key Takeaways
1. [Takeaway 1]
2. [Takeaway 2]
3. [Takeaway 3]

## Timestamps
00:00 - Intro
XX:XX - [Topic 1]
XX:XX - [Topic 2]

## Resources Mentioned
- [Resource 1]
- [Resource 2]

## Connect with Guest
- [Links]
```

## Quality Checks
- [ ] Podcast и хост researched
- [ ] 3 key messages prepared
- [ ] Stories rehearsed (but not scripted)
- [ ] Technical setup tested
- [ ] Questions для хоста готовы
- [ ] CTA ясный

## Completion Criteria
- Prep document создан
- Tech check done
- Calendar event с reminders
- Post-episode follow-up scheduled

## Time Estimate
- **Typical**: 30-45 minutes
- **Max**: 1.5 hours (для важного подкаста)

## Post-Episode
```
After recording:
1. Send thank you note to host
2. Share episode when published
3. Engage with comments
4. Track performance metrics
5. Save learnings to Memory
```

## Notes
- Over-preparation kills spontaneity
- Stories > facts (люди запоминают истории)
- Energy match the format
- Always have 1 surprising/counterintuitive take
