# Workflow: Cold Outreach

> Написать незнакомому человеку с предложением/запросом

## Keywords
`cold`, `outreach`, `написать незнакомому`, `reach out`, `pitch`

## Inputs
- **task**: описание задачи из Todoist
- **target**: кому пишем
- **goal**: что хотим получить
- **context**: почему именно этот человек

## Steps

### 1. Deep Research on Target (CRITICAL)
```
Tool: Perplexity AI + LinkedIn + Twitter/X
Output:
- Full background (career, company, achievements)
- Recent activity (posts, talks, interviews)
- Pain points / interests
- Mutual connections
- Preferred communication channel
- Best time to reach (timezone, activity patterns)
```

### 2. Find Unique Hook
```
Tool: AI Analysis
Output:
- What makes YOU relevant to THEM
- Recent trigger event (funding, launch, hiring, post)
- Personalization angle (shared interest, comment on their work)
- Why NOW is the right time
```

### 3. Craft Message (Multi-Version)
```
Tool: AI Text Generation

Version A - Short (LinkedIn/DM):
"Hi [Name], [Specific observation about their work].
[One-sentence value prop]. Worth a quick call?"

Version B - Medium (Email):
Subject: [Personalized + Curiosity hook]

Hi [Name],

[Opening: specific reference to their recent work]

[1 sentence: who you are + credibility]

[1-2 sentences: what you want + why it benefits them]

[Soft CTA: question or low-commitment ask]

Best,
[Name]

Version C - Long (если нужно):
[Detailed pitch with more context]
```

### 4. Validate & Optimize
```
Tool: AI Review
Checks:
- Is it about THEM more than you?
- Is the CTA clear and low-friction?
- Is personalization genuine (not creepy)?
- Would YOU respond to this?
- Length appropriate for channel?
```

### 5. Send via Right Channel
```
Priority:
1. Warm intro (if mutual connection exists)
2. Twitter/X DM (if active there)
3. LinkedIn (if B2B professional)
4. Email (if found)

Tool: Appropriate platform
```

### 6. Track & Follow-Up
```
Tool: Todoist
- Create follow-up task in 5-7 days
- Save message copy and context
- Track response status
```

## Quality Checks
- [ ] Research глубокий (не поверхностный)
- [ ] Hook уникальный (не generic)
- [ ] Сообщение о НИХ, не о вас
- [ ] CTA низкий барьер (не "buy now")
- [ ] Правильный канал выбран
- [ ] Follow-up запланирован
- [ ] НЕТ спама (1 человек = 1 попытка, потом follow-up)

## Completion Criteria
- Сообщение отправлено
- Context сохранён в Memory
- Follow-up task создан
- Response tracked (responded/no response)

## Time Estimate
- **Typical**: 15-20 minutes
- **Max**: 45 minutes (для VIP targets)

## Anti-Patterns (НЕ ДЕЛАТЬ)
- Generic templates без персонализации
- "I/We" в первых 3 предложениях
- Длинные pitch decks в первом сообщении
- Несколько messages подряд без ответа
- Агрессивный follow-up

## Follow-Up Sequence
```
Day 0: Initial outreach
Day 5-7: Follow-up #1 (add value, not just "checking in")
Day 14: Follow-up #2 (different angle)
Day 30: Final follow-up (break-up email)
```

## Examples

### Good Hook
"Saw your thread on X about AI in sales - particularly the point about personalization vs automation. Wrestling with exactly this..."

### Bad Hook (generic)
"I noticed you work in tech and thought we could connect..."

## Notes
- Качество > количество (5 хороших > 50 спам)
- Всегда check LinkedIn connection status first
- Save all research to Memory for future reference
- Track success rate по типу outreach для learning
