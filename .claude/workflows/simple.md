# Workflow: Simple Tasks

> Простые задачи, которые не требуют специального workflow

## Keywords
Всё остальное, что не попало в другие категории

## Inputs
- **task**: описание задачи из Todoist
- **context**: любой дополнительный контекст

## Steps

### 1. Quick Analysis
```
Questions (2 seconds):
- Can I do this right now?
- Is it actually simple? (if no → route to proper workflow)
- Any blockers?
```

### 2. Execute Directly
```
Just do it:
- No fancy process
- No extensive planning
- Direct action
```

### 3. Mark Done
```
Tool: Todoist
- Complete the task
- Add comment if useful for future
```

## Completion Criteria
- Task done
- Todoist updated

## Time Estimate
- **Typical**: 2-5 minutes
- **Max**: 10 minutes (если больше → выбери другой workflow)

## Examples

### Simple Tasks
- "Ответить на сообщение"
- "Прочитать статью"
- "Скачать файл"
- "Позвонить маме"
- "Купить молоко"

### NOT Simple (redirect)
- "Написать статью" → content workflow
- "Разобраться с X" → research workflow
- "Исправить баг" → coding workflow

## Rule
```
If task takes > 10 minutes or requires:
- Research
- Multiple steps
- Other people
- Special skills

→ It's NOT simple. Route to appropriate workflow.
```

## Notes
- 2-minute rule: if < 2 min, do it now
- Batch similar simple tasks
- Don't over-engineer simple things
